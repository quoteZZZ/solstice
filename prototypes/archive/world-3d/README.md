# Solstice · 3D 世界版

> 入口：`index.html`（双击，离线可开）。Three.js 0.160.0 在 `vendor/`，不走 CDN。
> **已并入 [`../solstice/`](../solstice/README.md)**：本目录保留为历史实现，不再修改。

## 验证什么

"施卡造世界 + 世界自己转"在 3D 微缩视角下看不看得下去：开局一片黑，打出土地才浮出地面，打出太阳才有光，然后放手看生态自己演化。

## 已实现

- **卡**：21 张（`CARDS`），七元素（金木水火土光暗）× 三类（物 / 术 / 律）
- **物种**：11 个（`SPECIES`），含草食、肉食、鸟类
- **地形**：5 种格（land / water / rock / grass / forest），每格是独立 mesh + 立牌
- **生态**：`entityTick` 逐实体 tick（找食 / 捕食 / 饿死），`computeEnv` 算光照 / 温度 / 湿度
- **交互**：拖卡落点、悬停高亮、回收（`recycle`）
- **界面**：手牌、开包、HUD、日志
- **相机**：绕世界旋转 + 缩放（连续 yaw / pitch / dist），打完土地后自动回重心

## 未实现

- 存档（无 localStorage）
- 音频
- 确定性回归（同种子跑两次不可比）
- 540 张卡池（只有 21 张有数据）
- 图鉴 / 年表 / 设置界面

## 已知坑

1. **1283 行单文件**：卡表、生态、Three.js 渲染、卡面 CSS 全在一起，没有模块接缝，转正必须重切。
2. **卡面尺寸写死**：302×440、手牌 260×380，与 `specs/ui/CARD-LAYOUTS.html` 的三档实测未对账。
3. **卡面美术是内联 SVG**（每张卡的 `art` 字段手写），新增一张卡就要手画一段路径，没有生成管线。
4. **相机没有格点吸附**，是连续角度。
