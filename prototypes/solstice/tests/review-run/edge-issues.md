# Solstice 边界工况评审 · 键盘路径 / 1080 / 1366 / 断点

取证：`tests/review-run.js`，三份独立跑批
- `mine-edge-kb`（1680×1000，scenario=keyboard，41 张）
- `mine-edge-1080`（1080×700，scenario=narrow，29 张）
- `mine-edge-1366`（1366×860，scenario=narrow，29 张）

**横向溢出结论**：三份 log.json 共 99 张 shot，`state.docW` 与 `viewport[0]` 全部相等，
页面级横向滚动为 0。本文里的「溢出」都是**容器内部**溢出（`scrollWidth > clientWidth`）或
子元素越过容器边界，已在每条里写清是哪一层。

**统计**：40 条 · P0 1 · P1 8 · P2 19 · P3 12
其中窄屏 19 条（1080 占 15、1366 占 4），键盘路径 14 条，细节类（1px 级 / 对齐 / 断点抖动）9 条。

## 一、键盘路径

### E01 · P1 · 手牌拖拽 · 连续两次 pointerdown 后残留卡片钉在视口 (0,0)
- **触发场景**：drag-over → drag-recycle（脚本在未松手时再次按下，真实用户「拖着拖着又按一下」同样会触发）
- **现象**：一张 136×216 的手牌副本永久留在 `#ghostwrap` 的静态位置 (0,0)，只露出右下角约 76×118，
  文字被左/上边缘切断（「不再损失 / 不再致… / 停下。/ ↩ —」），盖住顶栏 `SOLSTICE`（只剩「CE」）
  和左栏第一个按钮「年表」。此后 15 张截图全部带着它，切摆件模式也不消失。
- **证据**：`mine-edge-kb/12-dropped.png`、`mine-edge-kb/31-key-w.png`、`mine-edge-1080/26-narrow-world.png`、`mine-edge-kb/39-key-p.png`
- **建议**：`beginDrag` 开头先清掉所有 `#ghost` 并取消上一个 drag；`endDrag` 按元素引用删，不要按 id 取。

### E02 · P1 · 摆件模式（P）· 「UI 全隐」并没有全隐
- **触发场景**：1680 按 P
- **现象**：左栏 / 右栏 / actbar 都隐藏了，但**顶栏整条仍在**（暂停、0.5×–4×、抽包 38 全部可读），
  `#handwrap` 只 `translateY(222px)`（高 262），底部仍露出约 40px 的卡顶；
  E01 那张残卡也还在。所谓「摆件」画面里仍有 3 层 UI。
- **证据**：`mine-edge-kb/39-key-p.png`、`mine-edge-1080/25-ambient.png`
- **建议**：`#stage.ambient #top` 一起隐藏；手牌改为 `translateY(100%)` 或 `visibility:hidden`。

### E03 · P1 · 手牌 · Tab 聚焦后按 Enter 完全没反应
- **触发场景**：Tab×13 聚焦到 `.handslot[1]`，按 Enter
- **现象**：手牌 8 张不变、`W.sel` 仍是 0、无 toast、无任何视觉变化。`onKey` 里 Enter 只认
  `cursor`（必须先用 WASD），`bindHand` 只绑了 `pointerdown`，所以「Tab 到牌 → Enter」这条路是死的。
- **证据**：实测（`focus1080.png` 同流程；log `mine-edge-kb/34-key-Enter.png` 同机制）
- **建议**：`.handslot` 上补 `keydown` → `UI.select(i)`；Enter 无 cursor 时先选中而不是静默返回。

### E04 · P1 · 焦点环 · 环画在未旋转的槽位上，四角露出、右侧被邻卡盖 22px
- **触发场景**：1080 下 Tab 聚焦第 2 张手牌
- **现象**：`outline: 2px solid rgba(224,163,62,.95)` 画在 `.handslot`（111.5×177）这个**轴对齐矩形**上，
  而里面卡面 `rotate(±N deg)` 后外接框是 122×184——**四角各有 5–6px 卡面在环外**，看起来像环画歪/缺角。
  右侧邻卡 `z-index:98 > 95` 且左移 22.3px，直接把环的右段盖住。
  `.handslot:focus-visible .card` 的 box-shadow 也没生效（实测只有 `--sh-3`）。
- **证据**：`focus1080.png`（1080×700，聚焦第二张）
- **建议**：环画在 `.cardwrap` 内随卡旋转的伪元素上；聚焦时把该槽 `z-index` 提到 200。

### E05 · P1 · 键盘游标 · 按 WASD 后画面上找不到游标在哪
- **触发场景**：1680，w → w → d
- **现象**：读数框已变成「裸地 -3,-4」，但截取画面中央 900×560 区域放大后**没有任何格子被框出**；
  只在画布最右缘（约 x=1030 / 1680）露出一小段白线。镜头只轻微平移，没把游标带回安全区中心。
- **证据**：`mine-edge-kb/33-key-d.png`、`mine-edge-kb/34-key-Enter.png`（二者几乎同图）
- **建议**：`follow()` 改为「游标不在安全区中心 30% 内就 glideTo」，并对游标做屏幕内夹取。

### E06 · P2 · 键盘游标 · 1px 白线压在同色沙地上，对比度不足
- **触发场景**：1680，F1 低俯仰 + WASD
- **现象**：游标高亮只有 1px 白色描边，落在 `#8b8478` 左右的沙地上，放大 1.2× 后仍难以分辨；
  与鼠标悬停的读数和落点范围（暖色）不是同一套视觉语言。
- **证据**：`mine-edge-kb/33-key-d.png`（裁切 `cur33`）
- **建议**：游标改为「2px 白 + 1px 内描边加暗」双层，或直接复用橙色落点预览。

### E07 · P2 · 键盘读数框 · 固定左上角，和「痕迹」日志叠在一起
- **触发场景**：任何一次 WASD 之后
- **现象**：`syncCursor` 把 `#hoverinfo` 固定在 (128,96)；`#log` 在 (76,68)、236×182。
  两个框重叠约 180×80，读数（裸地/水/光/温）直接压在世界痕迹的「土地铺开 25 格」上。
- **证据**：`mine-edge-kb/31-key-w.png`、`mine-edge-kb/33-key-d.png`
- **建议**：键盘模式下把读数框挪到左栏右侧、痕迹下方，或给 `#log` 让位（`top` 下移 110px）。

### E08 · P2 · F1 俯仰档 · 世界被压到下半屏，上半 45% 空天
- **触发场景**：1680 按 F1
- **现象**：地平线抬到 y≈300，世界只占 300–760，手牌从 y≈740 起遮住世界底部；
  真正可操作的地块是一条 460px 高的横带，上方约 240px（24%）纯空。
- **证据**：`mine-edge-kb/26-key-F1.png`
- **建议**：低俯仰档同时抬高 `target.y` 或加大 `distance`，让世界仍落在安全区内。

### E09 · P2 · z 缩放 · 单步跨度太大、没有档位反馈
- **触发场景**：1680 按 z（F4 俯视之后）
- **现象**：一次按键从「能看见整片陆地」直接跳到「一格占屏幕 1/3」，再按一次就只剩 2–3 格；
  顶栏、右栏都没有缩放档位或百分比。反向只有 Shift+Z 一档档退。
- **证据**：`mine-edge-kb/29-key-F4.png` → `mine-edge-kb/30-key-z.png`
- **建议**：缩放步长减半（或按当前距离比例插值），并在 actbar 加一个档位读数。

### E10 · P2 · Enter 施卡 · 没有落点反馈
- **触发场景**：1680，游标在 (-3,-4) 按 Enter
- **现象**：只有手牌从「水」换成「土丘」、顶部「时素」少了一点；没有 toast、没有 `gainfly` 飘字、
  没有落点标记。键盘用户无法确认「打的是不是我指的那一格」。
- **证据**：`mine-edge-kb/33-key-d.png` vs `mine-edge-kb/34-key-Enter.png`
- **建议**：键盘施卡后强制 `flyTo(cursor)` + 在落点画 400ms 的脉冲框。

### E11 · P3 · Esc 分层 · 在世界层什么都不做，游标/选中不会退出
- **触发场景**：1680，施卡后按 Esc
- **现象**：`35-key-Escape` 与 `34-key-Enter` 像素级一致：面板没关（本来也没有）、选中态还在、
  键盘游标模式没退出。玩家会以为 Esc 失灵。
- **证据**：`mine-edge-kb/35-key-Escape.png`
- **建议**：世界层 Esc 增加一档「清除游标 + 取消选中」，再按才无动作。

### E12 · P0 · 键位面板 · 标签列塌成 1 字宽，整页读不出功能名
- **触发场景**：1680 按 K；1080 打开「键位」
- **现象**：`.keyRow` 是 flex 但没有给标签 `min-width`，输入条 `flex:1` 把标签挤到 20px：
  「随 机 释 放」竖排 5 行、「回 收 选 中」4 行、「重 抽 一 手」4 行、「选 卡 1-8」4 行、
  「时 间 换 档」4 行。每行被撑到 98px 高，一屏只放得下 6 条绑定。
  1680（`keyRow` 786px 宽）与 1080（786px）**一模一样**，与宽度无关，是布局写法问题。
- **证据**：`mine-edge-kb/37-key-k.png`、`mine-edge-1080/29-narrow-keys.png`
- **建议**：`.keyRow` 首列给 `flex:0 0 96px; white-space:nowrap`，键名条 `flex:1`，别让文字参与收缩。

### E13 · P3 · 痕迹日志 · UI 操作被写进「世界痕迹」，且同一句刷 8 条
- **触发场景**：任意面板开关之后
- **现象**：日志里出现「打开：卡库 / 打开：设置 / 图鉴点亮：长脊」这类 UI 动作，与世界事件混排；
  一次性铺 81 格土地会连写 8 条完全相同的「土地铺开 25 格」，占满 236×182 的整块。
- **证据**：`mine-edge-kb/31-key-w.png`、`full-1680/26-long-run.png`
- **建议**：UI 动作走单独的 dev 通道；同名痕迹按 `×N` 折叠（`.itc` 已经支持）。

### E14 · P2 · 键位表与实际绑定对不上（K 开的是「设置›键位」，不是年表）
- **触发场景**：1680 按 K
- **现象**：K 打开的是「设置 · 键位」页，而页面里这张表本身读不出（E12），所以没人能核对
  「P=摆件、Esc=关闭、L=卡库、X=回收」到底对不对；面板标题也被残卡裁成「置」。
- **证据**：`mine-edge-kb/37-key-k.png`
- **建议**：先修 E12；面板标题区加 `padding-left` 避开左上角浮层。

## 二、1080×700

### E15 · P1 · 右栏 · 下半滚动区只有 147px 高，内容 528px
- **触发场景**：1080×700 进界后
- **现象**：`.rp.grow` 高度 147、内容 `scrollHeight` 528（3.6 倍）。「痕迹 / 年表」一次只能看到
  3 行，剩下的必须在这个 147px 的小窗里滚；而它上面的「这一界 / 环境 / 生态」占掉 287px。
- **证据**：`mine-edge-1080/26-narrow-world.png`、`mine-edge-1080/19-panel-chron.png`
- **建议**：≤1080 时把「生态」收成一行芯片或折叠，把高度让给痕迹。

### E16 · P1 · 手牌 · 视觉字号只剩 9.8px，每张只露 89px
- **触发场景**：1080×700，8 张手牌
- **现象**：`--hand-scale:.82`，`.hsum` 的 CSS 字号仍是 12px，实际视觉 **9.84px**（1280 时 10.8px）。
  槽宽 122→视觉 112，槽间距 −23px，每张卡只露出 89/112px，效果句按句子中间被邻卡切断
  （「本格水量+0.2，蒸」「本格成为水源。每」）。
- **证据**：`mine-edge-1080/26-narrow-world.png`
- **建议**：窄屏改两行牌组或允许横向滚动，别用缩放换空间（设计约定是「字号就是设计字号」）。

### E17 · P2 · 手牌行 · scrollWidth 785 > clientWidth 760，末张卡越界 1px
- **触发场景**：1080×700
- **现象**：`#handwrap` 760 宽、`scrollWidth` 785（+25）；末张槽右缘 813，而手牌区右界 812，
  正好压到右栏左边界 1px。卡面旋转外扩让这一行比容器宽 25px。
- **证据**：`mine-edge-1080/26-narrow-world.png`（DOM 读数）
- **建议**：`#handwrap` 给 `overflow:hidden`，并把最外圈卡的旋转角度在 ≤1080 收到 ±5°。

### E18 · P2 · 卡面 · 效果句底部被切 2px（8 张里 4 张）
- **触发场景**：1080×700
- **现象**：`.hsum` 的 `scrollHeight` 80 / `clientHeight` 78，`overflow` 由 `.card.h` 裁掉 2px；
  第 1/3/6/8 张（旋转角最大的外侧卡）最后一行字底部被削平。
- **证据**：`mine-edge-1080/26-narrow-world.png`（DOM 读数）、`mine-edge-1366/26-narrow-world.png`（同为 80/78）
- **建议**：`.hsum` 加 2px 下内边距，或把 `line-height` 收到 1.5。

### E19 · P1 · 面板标题 · 被左上角残卡盖住，「卡库」只剩「库」
- **触发场景**：1080 打开卡库 / 设置 / 年表 / 键位
- **现象**：`#panel` 的 `#phead` 从 x=44 开始，残卡覆盖 0–76，标题第一个字被吃掉：
  「卡库 · 已见 16/55」→「库 · 已见 16/55」；「设置」→「置」；「年表 · 55 条」→「表 · 55 条」。
- **证据**：`mine-edge-1080/27-narrow-codex.png`、`mine-edge-1080/28-narrow-settings.png`、`mine-edge-1080/29-narrow-keys.png`
- **建议**：根因同 E01；另给 `#panel` 的 `z-index` 提到 80 以上，浮层不再压面板。

### E20 · P2 · 卡库详情 · 正文最后一行与页脚只剩 2px
- **触发场景**：1080 卡库，右侧 257px 宽的详情卡
- **现象**：「供水 +1.0/月 蒸发 1/0.62/0.26 上限 3.0」这行紧贴卡面下边框，与页脚
  「0019 / 0055　ATK 5 · DEF 15」之间只有 2–3px；视觉上两行粘在一起，像是压字。
- **证据**：`mine-edge-1080/27-narrow-codex.png`（裁切 `codexdetail`）
- **建议**：`.num` 行与 `.foot` 之间补 8px 间距，或详情卡给 `min-height`。

### E21 · P2 · 卡库网格 · 第三行卡被面板底边切一半，无滚动提示
- **触发场景**：1080 卡库
- **现象**：`#pbody` 536px 高、`overflow:hidden`；网格 3 列 → 8 张卡排到第三行，
  第三行只露出上半截（y=565–636），没有滚动条也没有底部渐隐，像是被硬切。
- **证据**：`mine-edge-1080/27-narrow-codex.png`
- **建议**：`#pbody` 内部网格区改 `overflow:auto`，或加 `mask-image` 底部渐隐。

### E22 · P2 · 面板 · 几乎贴到屏幕底（只剩 7px）
- **触发场景**：1080×700 任意面板
- **现象**：`#panel` 994×630，位于 y=63…693，顶部距顶栏 7px、底部距视口 7px；
  700 高的屏上几乎没有呼吸位，关闭按钮 `#pfoot` 下半截像要掉出屏幕。
- **证据**：`mine-edge-1080/27-narrow-codex.png`（DOM 读数）
- **建议**：`#panel` 的最大高度改 `calc(100vh - 96px)`，并给 4px 底部安全边。

### E23 · P2 · 创世页右栏 · 特征标签只有 130px，文字顶满
- **触发场景**：1080 创世页
- **现象**：`.tchip` 宽 130，「物种隔离 ×0.8 繁殖」文字宽 128 / 内容宽 128，只剩 2px；
  标签右边框与 `#cRight` 右边界（1072）共线，距窗口右缘只有 8px，读起来像被切掉半个字。
- **证据**：`mine-edge-1080/01-creator.png`（裁切 `cr_r3`）
- **建议**：≤1080 时特征区改单列（`grid-template-columns:1fr`），不要再并两列。

### E24 · P3 · 创世页 · 7 个判据方格与「7/7」不同基线
- **触发场景**：1080 创世页
- **现象**：7 个 20px 方格从 812 排到 985（左对齐），「7 / 7」右对齐在 1043；
  中间 58px 空档，数字与方格既不同基线也不同节奏，读数像掉队。
- **证据**：`mine-edge-1080/01-creator.png`
- **建议**：方格 `justify-content:space-between` 铺满整行，读数贴最后一格。

### E25 · P3 · 创世页 · 世界读数「标签与数值零间距」
- **触发场景**：1080 与 1366 创世页
- **现象**：显示为「水覆盖51 %」「山系数1」「起伏0.93」「物种池8 种」——标签和值之间没有空格，
  也没有 `space-between` 的对齐列；两个宽度下都一样。
- **证据**：`mine-edge-1080/01-creator.png`、`mine-edge-1366/01-creator.png`
- **建议**：读数行改 `display:flex; justify-content:space-between`，值右对齐。

### E26 · P3 · 创世页 · 1080 与 1366 的版心留白差一倍
- **触发场景**：1080 vs 1366
- **现象**：1080 外边距 8px、列间 8px（`#cMain` 用 `--s-4`）；1366 外边距 16px、列间 12px。
  同一条 `max-width:1080` 断点两侧，三列版心跳 8px，切换窗口时会「涨一圈」。
- **证据**：`mine-edge-1080/01-creator.png`、`mine-edge-1366/01-creator.png`（DOM 读数 236/548/264 vs 301/682/328）
- **建议**：`#cMain` 的 padding 用 `clamp(8px,1.2vw,16px)`，不要跳档。

### E27 · P2 · 世界痕迹 · ≤1080 时整块 `display:none`
- **触发场景**：1080 进界
- **现象**：`@media (max-width:1080){#log{display:none}}`，左上角世界痕迹在 1080 完全消失；
  同一次游玩在 1366 下是 236×182 的可读列表。玩家在 1080 上失去「刚才发生了什么」的即时反馈，
  只能去右栏那个 147px 的小窗里翻。
- **证据**：`mine-edge-1080/26-narrow-world.png` vs `mine-edge-1366/26-narrow-world.png`
- **建议**：1080 不隐藏，改为收成 1 行「最近 1 条 + 展开」。

### E28 · P2 · 创世页 · 剖面图在 447px 框里只画 278px，上下各 85px 空
- **触发场景**：1080 创世页（1366 更明显：599px 框、347px 图、上下各 126px）
- **现象**：`#cutaway` 447 高，`svg` 534×278 垂直居中，上下各留 85px 纯黑；
  世界剖面是这一页的主角，却只占 62% 高度。
- **证据**：`mine-edge-1080/01-creator.png`、`mine-edge-1366/01-creator.png`（DOM 读数）
- **建议**：`svg{max-height:100%}` 改成 `height:100%` + `object-fit:cover` 的等价写法，让图吃满。

### E29 · P2 · 事件弹窗 · 658px 宽只用 400px，右侧 256px 空
- **触发场景**：1080 事件弹窗
- **现象**：图标 120 + 文字 253，正文到 x=613 就结束，弹窗右边界 869；
  下方按钮组挤在左下（210–392），右下只剩一行「时素 988 · Esc 关闭」。
- **证据**：`mine-edge-1080/24-event.png`
- **建议**：弹窗宽度收到 520，或让正文 `flex:1` 吃掉右侧空白。

## 三、1366×860 与断点

### E30 · P2 · 右栏宽度锁死 292px，特征标签 160px 顶满
- **触发场景**：1366×860
- **现象**：`--right: clamp(292px, 21vw, 368px)`，1366 时 21vw=287 → 取下限 292；
  而 1680 时是 353。1366 上「本界特征」两列各 162px，
  「贫瘠土壤 ×0.7 生长」文字宽 160 / 内容宽 160，最后一字贴住边框（0 余量）。
- **证据**：`mine-edge-1366/01-creator.png`（DOM 读数）
- **建议**：下限从 292 提到 316，或窄右栏改单列标签。

### E31 · P2 · 断点 1280→1281 · 1px 内三处同时跳变
- **触发场景**：窗口从 1280 拖到 1281
- **现象**：`--right` 320→292（−28px）；`--hand-scale` .9→1（每张手牌 122→136px，+14）；
  `--rail` 52→56（+4）；手牌行总宽 908→933。也就是**屏幕变宽 1px，右栏反而窄 28px、
  牌变大 11%**，画面整体重排。
- **证据**：实测 1280/1281 两档 DOM 读数；对照 `mine-edge-1366/26-narrow-world.png`
- **建议**：把 `.9 / 320px / 52px` 这一档的区间拉到 1366，或把手牌缩放改成连续 `clamp`。

### E32 · P3 · 手牌右端 · 1080 越界 1px、1366 留空 12px
- **触发场景**：1080 / 1366 对比
- **现象**：1080 末张卡右缘 813 > 手牌区 812（−1px）；1366 末张卡右缘 1062 < 手牌区 1074（+12px）。
  临界两侧一边顶死一边空 12px，同一套扇形排布在两种宽度下不对称。
- **证据**：`mine-edge-1080/26-narrow-world.png`、`mine-edge-1366/26-narrow-world.png`（DOM 读数）
- **建议**：`renderHand` 的 `avail` 预留 12px 安全边，统一居中。

### E33 · P3 · 1366 手牌 · 8 张时每张重叠 13px，外圈卡文字仍被切
- **触发场景**：1366×860
- **现象**：槽间距 −13/−14px，最外侧两张卡的文字句首/句尾被邻卡压住（例如「本格成为水源。每」
  只剩「本格成为水」），而 `--hand-scale:1` 说明并没有缩小，纯靠重叠省空间。
- **证据**：`mine-edge-1366/26-narrow-world.png`
- **建议**：1366 起把 8 张拆成 4+4 两排，或允许横向滚动。

## 四、共通细节（1680 也中）

### E34 · P2 · 抽卡面板 · 卡背在深色底上几乎看不见
- **触发场景**：1680 按 B 打开「基础包」
- **现象**：6 张卡背与面板底色的对比不足 5%，只剩很淡的矩形边和斜线；扇形排布看不出张数，
  也看不出「可以划开」。
- **证据**：`mine-edge-kb/40-key-b.png`
- **建议**：卡背加 1px 亮边 + 内发光，或给整扇一个底板。

### E35 · P3 · 年表 · 分类计数之和 54 ≠ 总数 55
- **触发场景**：1080 年表
- **现象**：左列 干涉 51 + 气候 1 + 生态 0 + 灾害 0 + 文明 0 + 图鉴 2 = 54，
  但顶部写「全部 55」「7 组 · 55 条」。有 1 条不属于任何分类，或计数取错。
- **证据**：`mine-edge-1080/19-panel-chron.png`
- **建议**：默认「未分类」兜底，或按实际分组重算总数。

### E36 · P3 · 卡库 · 筛选条只有中间一项有边框，选中态不可辨
- **触发场景**：1680 卡库
- **现象**：「已见 16 / 55」「只看已见」「池 50 / 53」三项里只有「只看已见」有 1px 边框，
  另两项是纯文字；同时 55 与 53 两个不同总数并列，容易被当成同一个数的两个写法。
- **证据**：`mine-edge-kb/36-key-l.png`
- **建议**：三项统一成 chip，选中态用底色区分；两个总数改标签（「已见 16/55」「卡池 50/53」）。

### E37 · P2 · 悬浮详情 · 贴着左栏，压住 52px 图标列
- **触发场景**：1080/1366 悬停第一张手牌
- **现象**：`showTip` 的 `left` 下限写死 `Math.max(8, …)`，1080 时详情卡落在 (8,273)、292 宽，
  直接盖住 0–52 的左栏（卡库/换界/设置），只露出右侧 44px 的图标。
- **证据**：`mine-edge-1080/05-cardtip.png`（DOM 读数 x=8,w=292）
- **建议**：下限改成 `leftrail.right + 8`（56+8），与 `follow()` 的安全区用同一套量法。

### E38 · P3 · 顶栏右边距 · 12px / 8px / 8px 三套
- **触发场景**：1680、1080、面板内
- **现象**：顶栏最后一个按钮右缘：1680=1668（距边 12）、1080=1072（距边 8）；
  而 1080 的面板内边距也是 8。同一屏上两套右边距，窗口一缩就换一套。
- **证据**：`mine-edge-kb/26-key-F1.png`、`mine-edge-1080/26-narrow-world.png`（DOM 读数）
- **建议**：顶栏统一 `padding-right: max(12px, env(safe-area-inset-right))`，不要在断点里改。

### E39 · P3 · 长局年表 · 年份写两遍
- **触发场景**：full 场景，36 个月后
- **现象**：组标题「第 4 年」下面第一条又是「第 4 年 146 格 · 植物 2 种 · 兽 0 种」，
  同一年份上下紧邻重复；4 个年份组全都如此。
- **证据**：`full-1680/26-long-run.png`
- **建议**：组内条目去掉年份前缀，只留「146 格 · 植物 2 种」。

### E40 · P3 · 创世页 · 右栏「悬停：亮图上 / 出说明」贴到栏右边界
- **触发场景**：1080 / 1366 创世页
- **现象**：提示文字右端 1072 / 1350，与 `#cRight` 右边界完全相同（0 padding），
  与左端「本界特征 · 3 条」的 8px 内缩不对称，读起来像被裁了半句。
- **证据**：`mine-edge-1080/01-creator.png`、`mine-edge-1366/01-creator.png`
- **建议**：`#cRight > *` 统一 8px 内边距，提示单独右对齐并留 8px。
