## 判定：最严重的 5 条（均为当前工作区仍在的）

1. **F14（P0）** 在已有地块上点一下土地：手牌被消耗、世界毫无变化、没有任何提示——资源凭空消失且无反馈。
2. **F09 + F10（P1）** 首屏引导只说「先打一张土地」不说怎么做；6 张灰卡没有一句话解释「为什么不能打」。
3. **F26（P1）** 抽卡翻牌步骤：6 张纯空白卡背、按钮文案与步骤条错位，连取证脚本自己都卡死在这一步。
4. **F39（P1）** 拖拽中按 Esc 取消后，`#ghost` 残留在左上角（129×205，z-index 64），把「SOLSTICE」啃掉一半、左栏「年表」入口整块盖住，且此后每一帧都在（并入 a-hud 的 U38）。
5. **F13（P1）** 连续失败时同一条 toast 堆到 4 条、最新的一条沉到最下面，玩家最需要的那句话离视线最远。

（F30 世界事件弹窗整块飞出屏幕，取证时是 P0，已被 `panels.css` 的 `panelIn → fadeIn` 修掉，复跑确认居中，故不进此榜。）

> F20 / F25 两条标了「疑似」，判断依据写在各条「现象」里（分别是 CSS 层级 + 夹取常数、面板矩形存在但画面为空且复跑未复现）。F39 原先也标了疑似并被我误判为「层级问题」，已由像素比对与 a-hud 的 `#ghost` 矩形坐实为拖拽残留，改按事实描述并入 U38。
