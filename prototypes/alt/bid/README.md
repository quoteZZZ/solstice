# 破产（bid）

> 入口：`index.html`。无依赖，纯 DOM。

## 验证什么

拍卖场上"跟价还是弃掉"的紧张感：同一件藏品，对手 AI 一轮轮加价，玩家判断要不要跟。

## 已实现

- 藏品刷出、玩家跟价、对手回合、结算、下一件、终局
- 每轮的跟价记录与飘字反馈

## 未实现

- 存档、音效、难度档

## 已知坑

- 对手行为写死在同一个函数里，没有难度档位；数值只经过一轮手工试调

## 状态：冻结

不进主线。结算到"破产"就是失败判定，与 [CHARTER](../../../specs/CHARTER.md) §3.1「无失败与胜负」冲突。留作竞价类机制的对照实现。
