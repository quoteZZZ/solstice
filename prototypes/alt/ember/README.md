# 焚尽（ember）

> 入口：`index.html`。无依赖。

## 验证什么

"烧牌换资源"的取舍：预燃一张手牌换 3 点余烬、当回合不造成伤害；BOSS 下回合意图提前公示，玩家决定打出去还是攒着。

## 已实现

- 玩家 45 HP / BOSS HP / 意图预告
- 出牌、预燃（烧牌 → 余烬 +3）、结束回合（余烬熄灭 1）
- 牌库 / 手牌 / 弃牌与"本回合烧掉几张"的计数
- 胜负结算
