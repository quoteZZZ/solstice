# 撕（tear）

> 入口：`index.html`。无依赖。9 KB，是五个试吃里最小的一份。

## 验证什么

单键操作的节奏：点牌、连击、分数走高、发热过载后归零，纯粹测"点下去的反馈够不够爽"。

## 已实现

- 计分、热度（`hot`）、死亡（`dead`）三态与对应视觉
- 牌桌点击交互、结束界面

## 未实现

- 难度曲线、音效、关卡

## 已知坑

- 只有一套阈值，玩一两分钟就见底；没有可延展的结构

## 状态：冻结

不进主线。有明确失败状态与分数，与 [CHARTER](../../../specs/CHARTER.md) §3.1 冲突。留作"单次点击反馈"的手感参照。
