# 潮痕（strand）

> 入口：`index.html`。无依赖，canvas 绘制。

## 验证什么

荒岛生存的完整资源循环：探索捡遗物 → 制作工具 → 造船离开，中途有沉船与鲨鱼两类威胁。也是五个试吃原型里工程最完整的一份（45 KB）。

## 已实现

- 程序化岛形生成、遗物、制作、状态机、输入、交互、面板
- 两类威胁：沉船、鲨鱼
- 存档（localStorage）
- canvas 主循环 + HUD + 提示 + 结束界面

## 未实现

- 多岛、天气、结局分支

## 已知坑

- 生存压力（饥饿 / 威胁）是主循环的骨架，去掉之后循环就没有驱动，无法直接改造成主线形态
- 全部逻辑在一个文件里，绘制与状态没有分开

## 状态：冻结

不进主线。生存压力即失败条件，与 [CHARTER](../../../specs/CHARTER.md) §3.1 冲突。

但它是现成的**参照实现**：主循环、绘制分层、存档、威胁调度都可以直接借来评估将来 `game/` 的结构。
