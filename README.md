## 跑起来

主原型零依赖、零构建，浏览器直接打开：

```text
demo/index.html
```

自测（Playwright，可选，需要 Node 18+）：

```powershell
cd demo
npm install
npm test               # 施卡链路 + 控制台报错
npm run check:layout   # 版式比例实测
```

`demo/shot-*.png` 是这两个脚本产出的截图证据。
