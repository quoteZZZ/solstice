# 时间控制

> **卡片不涉及时间。**时间只由玩家通过界面控制：暂停、加速。

---

## §1 基本刻度

| 项 | 值 |
|---|---|
| 1 tick | **1 世界月** |
| 1 年 | 12 tick |
| **1 昼夜** | **12 月 = 1 年**；1 月 = 2 小时（见 [SETTING.md](SETTING.md) §1.3.1「昼夜：一年一昼夜」） |
| 默认速度 | 1 秒 = 1 月（1×） |

---

## §2 只有五个档位

| 档 | 每秒 tick | 说明 |
|---|---|---|
| **暂停** | 0 | 世界完全不动，零结算 |
| 0.5× | 0.5 | 仔细观察 |
| **1×** | 1 | 默认 |
| 2× | 2 | 常规推进 |
| 4× | 4 | 快速看长周期 |

**这就是全部。**没有倍率叠加、没有时间桶、没有冻结规则。

---

## §3 为什么时间不能做成卡

| 如果时间能被打牌改 | 后果 |
|---|---|
| 「停滞」卡让某格 ×0 | 那格所有倒计时停住——**炸弹永远不炸** |
| 「暂停」卡让全图 ×0 | 玩家手里没卡就**永久锁死**，存档废了 |
| 「倒流」卡 | 需要全量快照 + 反向计算，而捕食吃掉的东西**不可逆** |
| 「加速」卡叠加 | ×2 ×2 ×2 = ×8，一帧跑不完，直接卡死 |
| 存档/读档 | 快照里的倍率恢复不出来，世界会错乱 |

**时间是最底层的参数。它一动，上面所有东西都跟着动。**

---

## §4 删掉了哪些卡

| 层 | 删掉 | 数量 |
|---|---|---|
| L3 状态 | 停滞、加速 | 2 |
| L5 抽象 | 加速、减速、暂停、倒流、循环、时间砂 | 6 |

**共删 8 张。**

### 4.1 保留的"看起来像时间"的卡

这些改的不是**流速**，是**寿命**——两件事：

| 卡 | 层 | 它改什么 |
|---|---|---|
| 速死 | L5 | 寿命 ×0.25（个体死得快，世界不加速） |
| 不死 | L5 | 生物不老化 |
| 复生 | L5 | 死者复活 |
| 轮回 | L5 | 灭绝物种 50 年后回归 |
| 时间感 | L6 | **认知能力**：能预测季节（不是改时间） |

**判据：改"东西活多久"可以，改"时间走多快"不可以。**

---

## §5 暂停时会发生什么

**零结算。**不是"跑 0 倍速"，是**一次 tick 都不跑**。

| 项 | 暂停时 |
|---|---|
| 组件 tick | 不跑 |
| 倒计时（`Modifier.duration`） | 不走 |
| 动画 | 停 |
| 施卡 | **可以**（暂停状态下可以打牌、可以拖拽预览） |

**这是设计**：暂停是"想清楚再动手"的工具，不是"世界停止"的卡。

---

## §6 快照：只用于存档

时间卡删掉之后，快照只剩一个用途：**存档**。

| 项 | 值 |
|---|---|
| 保存时机 | 手动保存 + 每 **10 年**自动存 |
| 内容 | 全量世界状态（每格量 + 实体 + Trait + 卡库） |
| 大小 | 约 20 KB / 份 |
| 不存 | 时素（真实时间产物）、图鉴（账号级） |

> **没有"倒流到 10 年前"这个功能了。**重开就是重开。

---

## §7 世界怎么表现"时间在走"

时间不被打牌改，所以**必须靠表现让它可感**：

| 手段 | 治什么 |
|---|---|
| **季节环**：年份盘外圈一圈四色 | 一年过去了 |
| **年轮**：树一年一圈 | 这棵树多大了 |
| **光**：昼与夜各占半年，至日切换 | 现在是一年的哪一半 |
| **十年幽灵层**：长按叠加 10 年前地形 | 长期变化看不见 |

**这四条是"时间存在"的全部证据。**没有它们，玩家只会觉得世界没动。

### 7.1 昼夜是投影，不是第二口钟

| 项 | 规则 |
|---|---|
| 来源 | `S.sunHour(month) = (month % 12) × 2`，**只由整数月决定** |
| 表现 | `W.hour = S.sunHour() + 月内进度 × 2`（仅渲染用，不参与结算） |
| 暂停 | `hour` 随之冻结——它是投影，不是累积器 |
| 结算 | 夜行 / 昼行物种只读 `S.night(month)` |

**判据只有一条：同一个世界，换一台机器、换一个帧率，跑出来的森林必须一样。**
任何"跟着真实时间累积"的量都不许进结算（裁决记录见 [`REVIEW-2026-11-03`](REVIEW-2026-11-03.md) §3「冲突矩阵与裁决」）。

### 7.2 至日

**月 0 与月 6 是至日**：昼与夜在这里换手，世界表现上不做任何仪式，只换光。

> 名字与机制在这里对上：一年一次昼夜，两半各有一个至日。
