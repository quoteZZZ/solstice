# 立项、非目标与已否决

## §1 一句话

> **从一片虚无开始，用抽到的卡创造世界，然后看它自己运转。**

| 项 | 值 |
|---|---|
| 类型 | 卡牌驱动的创世沙盒 |
| 时长 | 无终局，想玩多久玩多久 |
| 目标 | 纯自由 + 世界成就图鉴 |
| 玩家 | 造物主：无身体、不被看见、只能施卡与观察 |

（以上四项是 [SETTING.md](SETTING.md) §0「一句话」的复述，冲突以 SETTING 为准。）

---

## §2 三条支柱

1. **虚无开局**——不是给你一座岛，是给你一片黑。差异必须在前 30 秒出现（[SETTING.md](SETTING.md) §0.1「第一眼必须和 WorldBox 不一样」）。
2. **卡是唯一交互**——玩家没有身体、不能被看见，能做的只有把卡按进世界。
3. **世界自己运转**——卡造出的是因果，不是贴图：顺序由依赖图推导，灾害是涌现的，不是随机事件表（[SETTING.md](SETTING.md) §1.4.2「顺序由依赖图推导」/ §1.5「灾害是涌现的」）。

三条缺一不可：去掉 1 就是 WorldBox 换皮，去掉 2 就是模拟器，去掉 3 就是静态卡面册。

---

## §3 非目标

1. **不做失败与胜负**：无血量、无倒计时、无失败结算、无数值成长。唯一软目标是图鉴点亮。
2. **时间不进卡池**：暂停 / 加速只由 UI 控制（[TIME.md](TIME.md) §3「为什么时间不能做成卡」）。
3. **不做引擎工程、不做服务端、不做账号**：仓库只装前端原型与文档（这条是仓库现状，不是设定）。

---

## §4 已否决

### 4.1 形态（全部已清除，不要再提）

动态壁纸 → 场景引擎（WebGL）→ 卡牌收集《牌语四季》→ 自走棋 → 纸雕微缩 → UE5 模拟沙盒。

### 4.2 五个机制试吃原型（保留在 `prototypes/alt/`，只作对照）

| 原型 | 机制 | 为什么没进主线 |
|---|---|---|
| `bid`《破产》 | 拍卖跟价、对手回合 | 有输赢（结算到"破产"），与 §3.1 冲突 |
| `ember`《焚尽》 | BOSS 战、玩家 45 HP、意图预告、预燃换余烬 | 有敌对目标与死亡结算，与 §3.1 冲突 |
| `strand`《潮痕》 | 荒岛生存：岛形生成、遗物、制作、沉船、鲨鱼 | 生存压力（饥饿 / 威胁）即失败条件，与 §3.1 冲突 |
| `tide`《潮痕·核心循环》 | 回合日程：采集 / 移动 / 制作工具 / 造船 | 同上，是 strand 的轻量验证版 |
| `tear`《撕》 | 单键反应、连击计分 | 分数与"dead"状态即失败判定，与 §3.1 冲突 |

**共同点**：它们都在验证"如何制造紧张"，而主线要的是"没有紧张也能看得下去"。这不是执行问题，是品类选择问题——所以不修，只留档。

### 4.3 机制

- **时间做成卡**（静止 / 加速 / 倒带 / 循环 / 时砂）：已删，理由见 [TIME.md](TIME.md) §4「删掉了哪些卡」。
- **关系 / 抽象 / 概念三层卡**：要求玩家在脑内建图，打出 5 秒内看不到任何可见结果，已删。
