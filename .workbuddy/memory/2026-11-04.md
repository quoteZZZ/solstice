## 画面与节奏整备 · 7505440 / abd7753

- **立牌接地阴影一直是假画的**：`render/grid.js` 贴图上画了 `rgba(0,0,0,.42)` 的椭圆，材质却写 `alphaTest: 0.5` → 0.42 < 0.5，阴影像素整片被丢弃。降到 0.34（常量 `STANDEE_AT`）。**这是「以为画了其实没画」的典型，改画面先量像素别信代码意图**。
- **立牌从 `MeshBasicMaterial` 换 `MeshLambertMaterial`** 才吃光照；环境光只有 `0x334b66×1.85`，白面会掉到一半，底色补 1.35 倍（常量 `TINT`）。
- **主体色原来 `shade(元素色, -0.35)`**：木 `#5e8f47` 被压成 `(5,54,0)`，整片林子是黑剪影。改 `-0.06`。颜色改取 `card.art.palette[1]`（卡面画的真源），同元素的树才不再长一个样。
- **`cell.h` 一律 0.30**（只有抬地卡会动），所以草地/林地/岩地全一样高。现在高度由 `S.TERRAIN[kind].h` 给（水 .08 / 土 .30 / 草 .36 / 林 .44 / 岩 .62），`cell.h − 0.30` 作为抬地增量叠加。**`S.TERRAIN` 现在真源只有一份，render 不许再抄**。
- **俯视档立牌塌成竖线**：`rotation.order='YXZ'` + 几何原点先 `translate(0, h/2, 0)` 挪到脚底 + **`rotation.x = -tilt`（负号是必须的）**。绕中心转或正号都会让背面朝上（Lambert 反面法线朝下 = 一片黑）。
- **基础降水 0.12 → 0.24**（`sim/eco.js` 的 `RAIN`）：蒸发在温带 = `0.19×W`，0.12 的平衡点 0.63 低于植物生长线 1 → 离水源两格以外永远干，整界只有 13 格能活，**世界第 12 个月就完全静止（120 月实测：植物 2 种、兽 0 种，之后 100 月无变化）**。
- **气候接进结算**：`data/world.js` 新增 `climateFx`（温度/生长/繁殖/降水/蒸发/光照六通道），`startWorld` 写进 `W.effects`。温带海洋是全 1/全 0 的基准，所以改之前的世界结果不变。
- **时钟改了**：`S.MONTH_MS = 12000`（1× 12 秒 1 月）。原来 1 秒 1 月 vs 时素 10 秒 1 点 → 一包基础卡 = 120 个世界月。`TIME.md §1–§2` 已同步。
- **`mods` 每月向 0 回落 ×0.84**：不回落的后果是一次「长夜」事件把世界永久压暗且无法扳回。
- **8 处卡面失真**：太阳温度 / 不锈防饿死 / 引流 `neighbors` 错加在光照通道（新增 `nbW`）/ 瀑布 spill·rise·needW / 芦苇 `species.minW` 补实现；花楸与猴改文案；夜沼鸟不进卡池未动。**`sim` 里 `neighbors` 是邻格光照专用键，别再拿它加水量**。

## 地面连续化 + 水面波纹 · 650b351

- **高差在方块世界里是「地形差异」的语言，不是「质感」的语言**。第一版给每格加 `hash3(x,y)` 随机高程（±0.045），截图是**一堆厚薄不一、浮在虚空上的饼干板**——相邻格差 0.09，侧壁整条露出，草地中间一级级台阶。改用连续正弦（波长约 2 格，`0.030×sin(0.52x)+0.030×cos(0.61y)`，相邻格最多差 0.03）才对。
- **让同种地表不呆板的是颜色，不是几何**：低频大斑（波长约 2 格）+ 每格 ±3 % 微差。颜色不产生几何，永远不会立起台阶。
- **乐高底板的三个成因**：方块 0.995 留 5 mm 缝 + 顶面亮度 ×1.5（每格一个亮砖）+ 界缘线之外没有分隔。现在 0.998 / ×1.28。
- **`js` 里注入 shader 用 `array.join('\n')`，不要用 `'...\n' + ...`**：经 bash heredoc → python 写入时反斜杠会被吃掉，`\n` 变成真换行 → 语法错误。文件里出现裸换行就是这个问题。
- **水面波纹零 CPU**：`WATER_U` 共享 uniform + `mat.onBeforeCompile` 注入 `#include <begin_vertex>` 后位移 `transformed.z`。顶面必须 `PlaneGeometry(w,h,3,3)` 分段，1 段只有 4 个角 = 整体倾斜。水面顶要抬到 `h/2+0.022`（振幅 + 1 mm），否则波谷沉进方块、水面出现暗块。
- `R.jitOf` / `R.hOf` 现在是表现高度的唯一出口，立牌 / 痕迹环 / 落点覆盖层全走它。
- 回归四套全绿（smoke / cards 10 / codex 21 / det 6）。

## 整体表现诊断 · DIAG-2026-11-04（实测，未实装）

诊断结论写进 `specs/DIAG-2026-11-04.md`（14 条 P0/P1/P2）。四条「不看代码猜不到」的：

- **卡手不是「没牌可打」，是「手上亮、落下被拒」**。`S.playable(card, life)` 的签名里**没有 cell**，只能判世界（有没有植物/兽），判不了格；落点合法性与 op 内二次校验是另外两处独立实现 → 必然漂移。实测 4 张卡高亮说能打、落地被拒（擦痕/萌发/疯长/引燃）。修法：`playable(card, life, cell)` 单点真源 + 手牌重绘时机改成 hover 换格。
- **`playable` 从不拦人**：`refill.dead = 0/400`、`blockedNow = {}`。所以「卡手」这件事压根不是它判出来的，别去调它的阈值。
- **55 张卡里只有 8 张能在空世界打**（4 land + 1 sun + 3 law），`field` 17 + `spawn` 18 = 35 张（64%）全都要「已有地块」。8 张手牌里 land 的期望 `4/55×8 ≈ 0.58` 张 → **平均两次开局就有一次摸不到土地卡，真卡死**。靠概率解决不了，必须在发牌规则里保底。
- **画面成本由对象数驱动，不是面数**：1307 格 → **917 draw calls / 1674 geometries / 5548 三角（视锥内）**，`R.sync` 1.05ms/帧是 CPU 主开销。三角数低到可以忽略，合批（InstancedMesh）才是唯一解，且必须在地形几何稳定之后做。
- **画面 0.5 以上零像素**：亮度直方图 `[67810,156855,555193,37306,208,0,0,0,0,0]`，0.2–0.4 占 72.5%，0.4–0.5 只有 208 px。`R.jitOf` 的连续起伏**没有阴影就等于白做**——起伏要靠明暗才读得出来。修法是在顶点色里烘四档 cel shading（静态、零运行成本），不是加实时光影。
- **首屏提示与选中态不一致**：文字说「先打一张土地」，`W.sel` 初值是 index 0（土山）。6 张灰牌的原因只在 `title` 里、要悬停才看得到。
