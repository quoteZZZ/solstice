### 3. R-43（本轮新发现，P0）· bench 一直在比两个随机世界
`bench.ps1 -Days 2` 跑出 NON-DETERMINISTIC。查下来**跟渲染无关，是 Sim 读真实时钟**：
- `world.json` 的 `seed: 0` =「每次开局摇新世界」，内核见 0 就拿 `FDateTime::Now().GetTicks()`；
- 开局 `WorldMinute` 由 `Now()` 的时分推出。

于是同进程两次 run 是两个不同世界，换进程又是第三个数。红线 2 实际已失效（可能失效很久）。
改：`FWorldConfig` 增 `StartingMinuteOfDay`（-1 = 真实时钟，玩家侧不变），**bench 钉死**
`seed=20261016 / dayOfYear=80 / 06:30`。两次独立进程 `digest == CE8B0D7BE6489900`。
> 教训：**Sim 里只要还有一处 `FDateTime::Now()`，"digest 不变"就永远无法成立。**

## 坑
- `Remove-Item` 在本机被平台安全删除钩子接管，对 `tmp/` 下文件会 fail-closed 抛异常；
  脚本里删文件用 `[System.IO.File]::Delete()`。
- PowerShell 里 probe 子进程（`& python -c "import PIL"`）的 stderr **压不住**，
  会打印成红色 traceback；别 probe，按顺序取第一个存在的解释器。
- `shot.ps1` 会先删旧 PNG：抓图失败时脚本必须报"没有产出"，不能让量具读到上一轮的图。
- 改 `BuildCel()` 一定要 bump `CelRecipeVersion`，否则已有 checkout 永远不重建。
