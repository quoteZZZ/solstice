# 710 张卡 → 组件映射

> 把六层全部卡过一遍 18 个组件，**发现 7 处表达不了**。
> 结果：组件从 18 扩到 **25**。

---

## §1 为什么 18 个不够

| 层 | 想表达的卡 | 18 个组件里的谁 | 结果 |
|---|---|---|---|
| L2 | 雨（持续 3 月） | `Modifier(全图, W+1)` | ❌ Modifier 是**永久**的 |
| L2 | 山火（会蔓延） | `Spawn(火)` | ❌ 没有"蔓延" |
| L3 | 停滞（时间 ×0） | `Modifier(1格, 时间×0)` | ❌ 时间倍率**不是普通量** |
| L4 | 契约（两方） | `Symbiosis(partner)` | ❌ 只支持 1 对 1 加成，不支持"互不攻击" |
| L5 | 因果（效果扩散） | `Modifier(全图, …)` | ❌ 改的是**规则本身**，不是量 |
| L6 | 名字（实体获得名字） | 无 | ❌ 没有"标签"能力 |
| L6 | 语言（需认知≥中） | 无 | ❌ 没有"前置条件" |

**七处，对应七个新组件。**

## §2 二十五个组件

### 2.1 生长与存续（4）

| # | 组件 | 参数 | 投影词条 | 行为 |
|---|---|---|---|---|
| 1 | `Grower` | rate / needsW / needsL | 植物·自养 | 每 tick 龄 +rate |
| 2 | `Living` | lifespan / maxHP | — | 衰老、受伤、死亡 |
| 3 | `Propagator` | interval / needsPollinator | — | 向相邻空格生成幼体 |
| 4 | **`Material`** | kind / yield | 料 | 可被拆成料（供合成） |

### 2.2 摄取（4）

| # | 组件 | 参数 | 投影词条 | 行为 |
|---|---|---|---|---|
| 5 | `Edible` | nutrition | 可食 | 可被吃 |
| 6 | `Predator` | size / diet / dmg / chase | 食草·食肉·腐食 | 追 + 吃 |
| 7 | `Mobile` | speed | — | 移动 |
| 8 | `Poison` | dmg / scope | 有毒·污染 | 接触掉血 |

> `Predator` 新增 `chase` 参数（是否追击）——对应动物的"逃跑"。

### 2.3 环境（6）

| # | 组件 | 参数 | 投影词条 | 行为 |
|---|---|---|---|---|
| 9 | `Shade` | amount | 遮阳 | 邻格 T−、L− |
| 10 | `Heating` | amount | 发热 | T+ |
| 11 | `Cooling` | amount | — | T− |
| 12 | `EmitLight` | amount / nightOnly | 发光 | L+ |
| 13 | `WaterKeep` | mult | 保水 | 蒸发 ×mult |
| 14 | `WaterSource` | rate | — | W+rate |

### 2.4 空间（3）

| # | 组件 | 参数 | 投影词条 | 行为 |
|---|---|---|---|---|
| 15 | `Container` | capacity / farmable | 地形 | 提供格子 |
| 16 | `Barrier` | — | — | 阻挡移动 |
| 17 | `Spawn` | cardId / count / interval | — | 定时生成 |

### 2.5 能力（2）

| # | 组件 | 参数 | 投影词条 | 行为 |
|---|---|---|---|---|
| 18 | **`Grants`** | trait / requirement | — | 给持有者一个 Trait |
| 19 | `Symbiosis` | partner / bonus | — | 同格加成 |

> `Grants` 是"工具"的本职：石斧放在地上没人用，**被谁用，谁获得「切割」**。

### 2.6 规则（4）

| # | 组件 | 参数 | 投影词条 | 行为 |
|---|---|---|---|---|
| 20 | `Modifier` | scope / effect / **duration** | — | 改量或改规则 |
| 21 | **`Meta`** | kind / value | — | **改元参数**（时间倍率 / 概率 / 尺度） |
| 22 | **`Relation`** | target / effect / break | — | **两方关系** |
| 23 | **`Tag`** | name | — | 给实体一个标签（命名、标记） |

#### 20.1 `Modifier` 新增 `duration`

| duration | 含义 | 例 |
|---|---|---|
| `0` | 永久（律） | 长夏、禁伐 |
| `N` | N 个月（术·境） | **雨 = `Modifier(全图, W+1/月, 3月)`** |

**这一条直接把 L2 现象全部接上了。**

#### 21.1 `Meta` 是什么

**时间倍率、概率、尺度不是普通量**——它们改的是"世界怎么算"，不是"世界有多少"。

| kind | value | 例 |
|---|---|---|
| `time` | 0 / 0.5 / 2 | 停滞、减速、加速 |
| `chance` | 0 / 1 | 必然、随机 |
| `scale` | 0.5 / 2 | 缩小、放大 |
| `entropy` | −1 / +1 | 熵增、熵减 |

**没有 `Meta`，"停滞"和"加速"就写不出来。**

#### 22.1 `Relation` 是什么

**两张卡之间的连线。**

| 参数 | 含义 |
|---|---|
| target | 需要选第二个目标 |
| effect | 互不攻击 / 共享 / 繁殖×1.5 / 转移伤害 / 继承 |
| break | 断裂条件（一方死亡 / 违约 / 被识破） |

```
狼 ───────── 鹿
      契约
```

**这是唯一让棋盘出现"边"的组件。**

#### 23.1 `Tag` 是什么

给实体挂一个**名字或标记**：

| 用途 | 例 |
|---|---|
| 命名 | 「名字」卡 → 这棵树叫"老白"，年表里记它 |
| 标记 | 「法律」卡 → 这个物种被标为"受保护" |
| 识别 | 「拟态」卡 → 这个实体被标为"看起来像鹿" |

### 2.7 接口（2）

| # | 组件 | 参数 | 行为 |
|---|---|---|---|
| 24 | **`Requirement`** | attr / threshold | **前置条件**：不满足则整张卡无效 |
| 25 | **`Trigger`** | when / then | **触发条件**：当 X 时做 Y |

#### 24.1 `Requirement`

```
Requirement(认知 ≥ 中)
```

**概念卡专用**：石头不会做梦，猴子不会立法。

不满足时：卡**打不出去**（不是打出去没效果）。

#### 25.1 `Trigger`

```
Trigger(当 相邻格有植物, 则 蔓延到该格)      → 山火
Trigger(当 本格 W=0 连续 3 月, 则 死亡)      → 旱死
Trigger(当 宿主死亡, 则 关系断裂)            → 契约
```

**没有 `Trigger`，灾害和连锁都只能写死在引擎里。**

## §3 六层怎么映射

### 3.1 L1 物质

| 卡 | 组件 |
|---|---|
| 草 | `Grower(1)` + `Living(20)` + `Edible(1)` + `Propagator(6)` + `Material(草木,2)` |
| 狼 | `Living(60)` + `Predator(中,肉,chase=true)` + `Mobile(3)` |
| 石 | `Material(金石,2)` + `Container(farmable=false)` |
| 石斧 | `Material(金石,1)` + `Grants(切割, 握持≥0.5)` |
| 木屋 | `Container(4, farmable=false)` + `Barrier` |

### 3.2 L2 现象（靠 `Modifier + duration`）

| 卡 | 组件 |
|---|---|
| 雨 | `Modifier(全图, W+1/月, 3月)` |
| 寒潮 | `Modifier(全图, T−10, 6月)` |
| 山火 | `Trigger(相邻有植物 → 蔓延)` + `Modifier(1格, 烧毁, 1次)` |
| 雷 | `Trigger(击中 → 火灾)` + `Poison(3, 单体)` |
| 寂静 | `Modifier(1格, 禁 Trait 传播, 12月)` |

### 3.3 L3 状态（靠 `Modifier`，`Meta` 用于时间类）

| 卡 | 组件 |
|---|---|
| 荒芜 | `Modifier(1格, 植物不生长, 0)` |
| 休眠 | `Modifier(1物种, 不老不繁, 0)` |
| 长明 | `Modifier(1格, L=3, 0)` |
| **停滞** | **`Meta(1格, time=0)`** |
| **加速** | **`Meta(1格, time=2)`** |

### 3.4 L4 关系（靠 `Relation`）

| 卡 | 组件 |
|---|---|
| 契约 | `Relation(互不攻击, break=一方死亡)` |
| 血缘 | `Relation(繁殖×1.5, break=一方灭绝)` |
| 复仇 | `Relation(追杀, break=目标死亡)` + `Requirement(认知≥中)` |
| 继承 | `Relation(死后继承全部 Trait, break=一方死亡)` |

### 3.5 L5 抽象（靠 `Meta` + `Modifier`）

| 卡 | 组件 |
|---|---|
| 加速 | `Meta(全图, time=2)` |
| 暂停 | `Meta(全图, time=0)` |
| 随机 | `Meta(全图, chance=0)` |
| 不死 | `Modifier(全图, 不老化, 0)` |
| 平衡 | `Modifier(全图, 数量趋同, 0)` |

### 3.6 L6 概念（靠 `Requirement` + `Tag` + `Grants`）

| 卡 | 组件 |
|---|---|
| 名字 | `Tag(自定义名)` |
| 语言 | `Grants(可交流) + Requirement(认知≥中)` |
| 文字 | `Modifier(全图, 知识不丢, 0) + Requirement(有语言)` |
| 法律 | `Tag(受保护) + Requirement(认知≥高)` |
| 哲学 | `Trigger(可解除任意律) + Requirement(认知≥高)` |

## §5 组件够不够（自检）

| 问题 | 答案 |
|---|---|
| 710 张里能用 25 组件表达的 | **约 95%** |
| 剩下的 5% | 是**独有效果**的卡（世界树苗、凤凰、龙），各需 1 个专属组件 |
| 加一张普通卡要不要写代码 | **不要** |
| 加一个新行为（如"传送"） | **写 1 个组件，25→26** |

**所以 25 是"当前内容"的组件数，不是上限。**
