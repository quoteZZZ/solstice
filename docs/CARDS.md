# 卡（CARDS）

> 玩家只有两种行为：**使用**与**回收**。没有合成、没有退环境、没有赛季——所有卡永久在池。
> 乐趣来自三处：**抽到什么**、**卡面好不好看**、**这张卡能把这个世界的哪条规则改掉**。
> 卡怎么改世界见 [WORLD.md](WORLD.md)；卡面规格见 [ART.md](ART.md) §8。

## 1 坐标：7 × 11 × 3

| 维 | 取值 | 数量 | 回答 |
|---|---|---|---|
| 元素 | 金木水火土光暗 | 7 | 用哪种材料改 |
| 环级 | 0–9 + 超环 | **11** | 改多大尺度（**环级即稀有度**） |
| 卡类 | 物 / 术 / 律 | 3 | 创造 / 瞬时 / 立规 |

| 段 | 算式 | 卡种 |
|---|---|---|
| 常规（0–9） | 7 × 10 × 3 | 210 |
| 超环 | 7 × 1 × 3 | 21 |
| **小计** | 7 × 11 × 3 | **231** |
| 禁物 | 7 × 1 × 3（矩阵格位，不带元素标签） | 21 |
| **合计** | | **252** |

- **环级即稀有度**：0 环碎卡最常见，9 环闪卡与超环最稀有，禁物只能由世界事件漏进来。
- **卡种 ≠ 实体**：卡种是设计，实体是持有。

**卡类**

| 类 | 是什么 | 落地 |
|---|---|---|
| 物 Matter | 世界里的东西（生物 / 死物 / 地形 / 器物） | 留驻实体 |
| 术 Rite | 主动施展的效果 | 只改状态，留一块印记 |
| 律 Law | 写进世界的规则 | 刻成永久规则，改 `FRuleSet` |

## 4 效果：原语 + 曲线（实现口径）

**一张卡 = 一个原语 + 曲线引用**，不写独立代码分支。

### 4.1 参数曲线（唯一真源）

```json
"radius_m": [1.5, 3, 5, 8, 12, 18, 26, 40, 80, 160, 320]
"peak_m":   [0.3, 0.8, 1.5, 2.5, 4, 6, 9, 14, 22, 36, 64]
"minutes":  [1, 2, 5, 10, 20, 40, 80, 160, 480, 1440, -1]
```

索引 0–9 对应环级，索引 10 对应超环；`-1` = 永久。**代码里不写任何半径/高度字面量。**

### 4.2 原语表

| 原语 | 参数 | 域 | 用途 |
|---|---|---|---|
| `raise` / `lower` / `flatten` / `ridge` | radius、peak、falloff | 地形 | 改高度场 |
| `paint` | radius、material | 地表 | 改地表类型 |
| `ignite` / `heat` / `chill` | radius、intensity、minutes | 温度 | 燃烧与冷热 |
| `water` | level、radius | 水体 | 水位与淹灌 |
| `ore` | radius、depth | 地下 | 矿脉 |
| `seed-life` | species、count | 生态 | 投放生命 |
| `erode` | radius、strength | 地质 | 侵蚀 |
| `weather` | target、minutes、radius | 气候 | 推天气 |
| `record` | text | 年表 | 石碑 |
| **`rule_set`** | key、value、scope | **规则** | **改物理法则** |
| **`spawn-entity`** | template、count | **实体** | 造聚落 / 城邦 / 文明 |

`rule_set` 与 `spawn-entity` 是新增的两条主脉：前者让“法则卡”成立，后者让“文明卡”成立。

> 新卡不加 C++：加一行 JSON。若确实需要新原语，先在本表加一行、写清参数与边界，再实现。

## 5 三套生克（自然涌现）

**五行相生**：金→水（凝露）· 水→木（疯长）· 木→火（助燃）· 火→土（焦土沃化）· 土→金（结矿）
**五行相克**：金→木（伐）· 木→土（固）· 土→水（掩）· 水→火（灭）· 火→金（熔）
**光暗**：光生暗（昼→影）· 暗生光（夜→昼）· 光克暗（显形）· 暗克光（隐蔽）
**级生克**：高环盖过低环（尺度覆盖）· 低环长期叠加可诱发高环结果（累积诱发）

> 级生克是**尺度覆盖**，不是数值碾压：低环卡永远有效，只是痕迹会被更大的尺度盖住。

## 6 禁物（21 件，无环）

**规则**：只启不养、不带元素标签、不可回收、同时只能启用一件、件件有代价。**不随机出**，世界条件达成才漏进来。

| 物 | 术 | 律 |
|---|---|---|
| 常温水杯（水无处可排） | 无雨的铁云（生物失水） | 不坠之律（漂浮物遮天） |
| 不落的叶（根周寸草不生） | 托举的风（尘土不落） | 越剪越旺之律（必须喂养） |
| 第二颗太阳（昼夜紊乱） | 寂声的雾（种群衰退） | 抹平之律（山脉逐日削低） |
| 逆流的沙漏（永久斑点） | 丰穰的息（蔓生失控） | 不死之律（食物链崩断） |
| 自鸣的钟（实体永不安置） | 温存的焰（火无法扑灭） | 影离之律（失影者停滞） |
| 无底的篮（它会饿） | 疾长的风季（根系拱裂） | 互渗之律（水封全失效） |
| 永燃的炭（热量外溢） | 显影的光（隐蔽者暴露） | 冷燃之律（孵化/消化停摆） |

**触发条件**（6 条）：火山喷发 / 大洪水 / 物种灭绝 / 首个文明诞生 / 施放超环 / 连续 30 日无雨。

## 8 玩家侧

### 8.1 三个池

| 池 | 是什么 | 规则 |
|---|---|---|
| 实体池 | 实际持有的卡（按张） | 0 环无限补；1–9 环靠开包；每种最多 3 张（满了折算 20% 余响） |
| 手牌 | 从实体池随机抽 10 张 | 用掉一张立即补；`R` 整手重抽（退回池、不返余响、免费无限） |
| 开局 | 0 环卡种各 1 张 | 首手保底地形 + 天气各 ≥1；**开局余响 = 0** |

### 8.2 两个动作

| 动作 | 结果 | 键 |
|---|---|---|
| 使用 | 卡被消耗，效果落到世界；有落地形态时选「生效即散 / 落地成实体」 | 上拖 / 数字键 + 左键 |
| 回收 | 卡被销毁，返还折扣余响 | 下拖 / `X` |

**不可撤销**。唯一反悔窗：落地成实体后 3 秒内可点回。

### 8.3 余响

| 源 | 触发 | 量级 |
|---|---|---|
| 事件回响（主） | 干涉使世界跨过阈值并写入年表 | 按偏移幅度 |
| 沉淀回响（次） | 按 生物量 × 多样性 × 稳定度 持续微产 | 小、持续 |
| 初见回响 | 首次出现某类现象（初雪 / 首捕 / 灭绝） | 一次性 |

**防刷**：反复刷同一张小卡几乎不产出；每分钟上限 20，超出按 25% 计。

### 8.4 扰动

0–100 全局单值；0–30 稳定 / 30–60 波动 / 60–100 剧烈。**不是惩罚**，只提高奇观与极端事件概率。自然消退每世界小时 −2，平息花费 1 余响 / 2 点。
