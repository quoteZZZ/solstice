## §0 一句话

> **从一片虚无开始，用抽到的卡创造世界，然后看它自己运转。**

| 项 | 值 |
|---|---|
| 类型 | 卡牌驱动的创世沙盒 |
| 时长 | 无终局，想玩多久玩多久 |
| 目标 | 纯自由 + 世界成就图鉴 |
| 玩家 | 造物主：无身体、不被看见、只能施卡与观察 |

## §0.1 第一眼必须和 WorldBox 不一样

**风险**：俯视小岛 + 造物主视角 = 玩家会把它当成"又一个 WorldBox"。

**差别必须在前 30 秒出现，不能等 5 分钟后**：

| 第几秒 | 屏幕上是 | WorldBox 有没有 |
|---|---|---|
| 0 | **一片纯黑**，只有 6 张卡 | ❌ WorldBox 一开局就有一座岛 |
| 3 | 打一张土地 → 黑暗里浮出一块地 | ❌ 地图是生成的，不是画的 |
| 8 | 打一张太阳 → 光落下来 | ❌ 太阳是常驻的 |
| 15 | 时素开始累积，**数字在涨** | ❌ 没有货币 |
| 30 | 打一张「语言」给猴子 → **猴子开始砍树** | ❌ 没有 Trait |

**"虚无开局"就是这一作的差异点**：WorldBox 给你一座岛，这里给你一片黑。

# 第一部 世界

## §1.1 虚无

开局**什么都没有**：没有地、没有光、没有水、没有时间。

玩家手上只有一包卡。第一件事是**把卡按到虚空里**。

| 缺什么 | 世界会怎样 |
|---|---|
| 土地 | 所有卡无处可放 |
| 太阳 | 全屏漆黑，只能看见手牌 |
| 水 | 放不了任何生命 |
| 时间 | 世界不流动 |

> 前四张卡的功能不是"变强"，是**让世界存在**。

## §1.1.1 世界的大小由卡决定

**世界没有预设尺寸。**开局是 **0 格**，每打一张土地卡，世界长大一次。

| 项 | 规则 |
|---|---|
| 初始 | **0 格** |
| 一张「土地」 | 生成 **9 格（3×3）** 陆域，形状可编辑（涂抹 / 拉山） |
| 十张「土地」 | 世界可以有 **90 格** |
| 上限 | **无**。受时素与卡量限制，不受系统限制 |

**后果**：

| 世界变大后 | 变化 |
|---|---|
| 视口 | 从 Z1 拉到 Z0，格子变小，一屏装不下 |
| 距离 | 物种移动、灾害蔓延、Trait 传播都要走更久 |
| 管理 | 边缘的格子会"看不见"——**你的世界会大到管不过来** |
| 探索 | **世界变大本身就是探索**，不需要单独一套"地图系统" |

> 世界大小不是难度调节器，是**玩家自己的决定**。你想要一个 24 格的花园，还是 200 格的次大陆，都由你打几张土地卡决定。

## §1.2 量是卡创造的，不是预设的

**没有"每格四个数"这回事。**

世界初始连"温度"这个概念都没有。**量由卡注册**：

| 你打了 | 世界才出现这个量 | 谁写它 | 谁读它 |
|---|---|---|---|
| 太阳 | **光照 L** | `EmitLight` / `Shade` | `Grower` |
| 水 | **水量 W** | `WaterSource` | `Grower` / `Living` |
| 火 | **温度 T** | `Heating` / `Cooling` | 蒸发规则 |
| 土 | **养分 N** | 腐尸分解 | `Grower` |
| 以后的卡 | **任意新量** | 新组件 | 新组件 |

**所以"温度"不是游戏的基础设定，是太阳卡打出来的。**

- 没打太阳 → 没有光照 → 植物不能长
- 没打火 → 没有温度 → 不会蒸发，也不会烧
- 没打水 → 没有水量 → 没有东西会渴

### 1.2.1 一个"量"由三部分组成

注册一个量时，要一起声明：

```
Name     名字（L / W / T / N / …）
Init     初值（0 或某格自带）
Decay    每 tick 的自然衰减（可为空）
Clamp    上下限（可为空）
```

| 量 | Decay | 说明 |
|---|---|---|
| 光照 L | 无 | 每 tick 由光源重算 |
| 水量 W | 蒸发（读 T） | **它依赖温度，所以温度必须先算** |
| 温度 T | 向 20 回归 0.1 | 没有热源就慢慢变回常温 |
| 养分 N | 无 | 只增不减 |

**加一个新量 = 注册一次，引擎不用改。**

### 1.2.2 遮阳的正确物理

`Shade` 只作用于**相邻格 + 本格的其他实体**，**不减自己的光照**。

> 树冠遮的是树下的草，不是树自己。这条一改，稳态才成立。

## §1.3 时间

| 项 | 值 |
|---|---|
| 刻度 | 1 秒 = 1 个月（1×） |
| 速度 | 0.5× / 1× / 2× / 4× |
| 一局 | 无终局 |
| 施卡 | **不停表**，即时干预 |

**时间不是货币，是环境。**时素（§3.1）才是货币。

## §1.4 没有"阶段"这回事

**旧版设计了五层演变（生命史 / 演替 / 林冠闭合 / 气候周期 / 纪元），全部删除。**

原因只有一句：**它们都是组件跑起来之后自动出现的结果，写成"层"等于给涌现命名，然后再把它当成规则。**

| 旧"层" | 其实是什么 | 现在由什么产生 |
|---|---|---|
| 生命史 | `Living.lifespan` + `Grower` | 组件自带，年龄本来就在涨 |
| 演替 | 草 `Propagator` 生出灌木，灌木生出树 | 组件自动 |
| 林冠闭合 | 树有 `Shade`，累积降低 L | 组件自动 |
| 干湿 | W 低了就是干旱 | 量本身 |
| 纪元 / 世界规模 | —— | **删除** |

**所以你不需要"让它演变"——你只需要让组件跑起来。**

### 1.4.1 实际会发生什么（不是设计，是后果）

只要放上这几个组件，下面这些会自己出现，一行代码都不用写：

| 你放了什么 | 会自己发生什么 |
|---|---|
| `Grower` + `Living` | 长到一定年龄就死，死后留腐尸 |
| `Propagator` + 相邻空格 | 自己铺开，铺到没有空格为止 |
| `Shade` 累积 | 下层 L 掉到 1 以下，草停止生长 |
| `Shade` 树死掉 | 光回来，草重新长 |
| `WaterSource` 干了 | 周围植物旱死，动物离开 |
| `Predator` + `Edible` | 捕食者跟着食物走，食物没了就饿死 |

**这些不是"层"，是"如果你放了这些组件，就会这样"。**

### 1.4.2 顺序由依赖图推导，不是五相位

**没有"五相位"。**组件不声明"我在第几相"，只声明两件事：

```
Reads   [L, W]
Writes  [age]
```

引擎每 tick：

1. 收集所有组件的 `Reads` / `Writes`
2. 按依赖关系**拓扑排序**
3. 依次执行

**举例**（世界里已有太阳、草、树）：

```
EmitLight  写 L
Shade      写 L
───────────────────  L 先算完
Grower     读 L,W → 写 age
───────────────────  再算生长
Living     读 age → 写 alive
```

**冲突处理三条**：

| 情况 | 处理 |
|---|---|
| 两个组件写同一个量 | 加法可交换，无所谓顺序 |
| 有乘法 | 统一在加法之后 |
| **循环依赖**（A 读 B 写的量，B 读 A 写的量） | 用**上一 tick 的值**，标为"延迟一 tick" |

**加新组件不用改引擎**——它自己声明了读写什么，排序是自动的。

## §1.5 灾害（涌现，不是随机事件）

灾害**没有随机数**，全部由参数触发：

| 灾 | 触发条件 | 效果 |
|---|---|---|
| **山火** | T>35 且 W<0.5 且 有植物 | 该格烧毁，向相邻格蔓延（概率随 T 上升） |
| **干旱** | 气候干旱相 + W=0 连续 6 月 | 该格植物停滞、动物离开 |
| **洪水** | W>2.8 且 地形低 | 冲走该格动物，养分 −0.5 |
| **疫病** | 同格动物 >5 | 该格动物生命 −1/月 |

**玩家能预判灾害**——看 T 和 W 就知道会不会烧。这是"可读的因果"，不是"随机惩罚"。

# 第二部 卡

## §2.1 身份四字段

| 字段 | 取值 | 作用 |
|---|---|---|
| **元素** | 金 / 木 / 水 / 火 / 土 / 光 / 暗 | **决定材料归属**（§2.7） |
| **环级** | 0–9 / 超环 / 禁物 | 强度预算 + 稀有度 + 出场条件 |
| **类** | 物 / 术 / 律 | 作用方式（§2.2） |
| **源** | 创世 / 自然 / 神奇 / 禁物 | 来历，决定进哪个卡包 |

### 2.1.1 元素 = 材料归属

元素不再只是视觉，它决定这张卡拆出来的**料**：

| 元素 | 料 | 去向 |
|---|---|---|
| 金 | 金石 | 工具、机械 |
| 木 | 木质 | 建材、燃料 |
| 水 | 水液 | 灌溉、溶解 |
| 火 | 热源 | 冶炼、烧制 |
| 土 | 土石 | 砖瓦、陶器 |
| 光 | 光能 | 照明、驱暗 |
| 暗 | 暗质 | 禁物、诅咒 |

**这就是"7 元素 × 3 类 × 12 环"矩阵里元素那一维的真实用途。**

## §2.2 三类：物 / 术 / 律

**判据只有一句：这张卡要不要找地方放？**

| 类 | 定义 | **目标** | 例 |
|---|---|---|---|
| **物** | 造出一个持续存在的东西 | **空格** | 太阳、土地、树、狼 |
| **术** | 改变**已有**的东西 | **已有格子 / 已有实体** | 暴雨、焚烧、语言、用火 |
| **律** | 改变规则 | **不用找，直接生效** | 长夏、禁伐、永夜 |

### 2.2.1 术的两个子型

| 子型 | 改什么 | 例 |
|---|---|---|
| **术·境** | 改格子与环境 | 暴雨、焚烧、引水、翻土、霜 |
| **术·体** | 改一个实体（挂 Trait） | 语言、用火、工具、耕作 |

### 2.2.2 三类契约（硬约束，填错报错）

| 类 | 必须含 | **绝不能含** | 生效方式 |
|---|---|---|---|
| 物 | `Living` / `Container` / `WaterSource` 至少一个 | `Modifier` | 持续（实体存在期间） |
| 术 | 效果组件 或 `Trait` | `Living` / `Container` | 立即 + 衰减（境）／持续（体） |
| 律 | `Modifier` | `Living` / `Container` | 持续（全局） |

### 2.2.3 三类的可见性

| 类 | 玩家怎么知道生效了 | 保障 |
|---|---|---|
| **物** | 看见它出现 | 剪影 + 颜色 |
| **术·境** | 看见格子变了 | 湿润 / 焦黑 / 结霜 |
| **术·体** | 看见它做了新动作 | 猴子开始砍树 |
| **律** | **看不见，只能看见后果** | **全屏微光一次 + 角落常驻标记** |

> 律类最危险：改了全局，玩家可能十分钟没察觉。没有这两条保障，就会出现"我什么都没做，怎么全死了"。

## §2.4 Trait（术·体）

术·体不创造新实体，它给实体挂一个 `Trait`——**一张组件覆盖表，不是新组件**。

```
猴子
├─ 基础：Living(60) + Predator(小,草) + Mobile(1)
└─ Trait: 语言
     ├─ Mobile.speed 1 → 2        活动范围 ×2
     ├─ Predator.group = true      可围猎，目标体型 +1 级
     ├─ Social.teach = true        可教给同格同类
     ├─ Social.inherit = true      后代继承
     └─ sideEffect: 破坏 +1        会砍树开地
```

**规则**：一个实体最多 **3 个 Trait**；同参数**取最高档，不叠乘**。

### 2.4.2 传播与失传

| 规则 | 值 |

## §2.6 环级 12 档 = 效果水平 + 稀有度 + 预算

**环级仍然是 12 档**（0–9 + 超环 + 禁物），它同时是三件事：

| 环级 | 效果水平 | 稀有度 | 点数预算 |
|---|---|---|---|
| 0 | 引子（石、木、水、火） | 极常见 | 4 |
| 1 | 简单工具（石斧、绳、燧石） | 常见 | 6 |
| 2 | 组合（弓、陶罐、骨刀） | 常见 | 8 |
| 3 | 复合（熔炉、犁、渔网） | 少见 | 11 |
| 4 | 大型营造（木屋、筏、梯） | 少见 | 13 |
| 5 | 文明基石（文字、轮） | 稀有 | 16 |
| 6 | 城市级 | 稀有 | 19 |
| 7 | 王国级 | 很稀有 | 23 |
| 8 | 世界级 | 极稀有 | 27 |
| 9 | 改写规则 | 传说 | 32 |
| **超环** | 造物主的手 | 一局最多 3 张 | 40 |
| **禁物** | 有代价 | 买不到，只能成就解锁 | ∞（付债务） |

**环级 = 合成深度 = 效果水平 = 稀有度，四个说法是一件事。**

- 0 环是原材料
- 每往上合成一层，环级 +1，效果更强，也更难抽到
- 所以要"石斧的环 > 石头和木头"，天然成立

**规则：组件档位点数之和 ≤ 该环级的点数。**

> 三义绑定的好处：不可能出现"低环却很强"的卡，也不可能出现"高环却很弱"的卡。

### 2.6.1 环级的"上限"是内容决定的，不是规则决定的

12 档是**当前内容的边界**，不是系统的上限。

如果以后要加第 13、14 档，只需要**在合成图上再往上长一层**——因为环级本来就是从图里算出来的。

### 2.6.1 组合溢价

| 协同对 | 溢价 |
|---|---|
| `Shade` + `WaterKeep` | +3 |
| `WaterSource` + `Poison(水体)` | +3 |
| `Grower` + `Edible` | +2 |
| `Shade` + `EmitLight` | +2 |

**溢价从预算里扣，不是白给。**

### 2.6.2 禁物靠债务

禁物预算 ∞，但强制挂 `Debt`：点数 = 本卡强度 × 0.8，**不可移除**。

```
强度点 − 债务点 ≤ 0
```

> 禁物是"预算为负的卡"。

## §2.7 合成 = 蕴含（不是配方表）

### 2.7.1 一条关系，三个推论

```
石斧 = 石 + 木
```

| 推论 | 内容 |
|---|---|
| **向下蕴含** | 有石斧 → **自动拥有石与木** |
| **向上蕴含** | 有石 + 木 → **自动获得石斧的知识**（不需要额外卡） |
| **环级** | 石斧的环级 > max(石, 木) |

**第二条是最关键的**：即使世界**从没打过石斧卡**，只要打了石头和木头，这个世界就"知道"石斧。

> 用户口径：世界只用了石头+木头，也等于世界存在一个石斧知识卡。

### 2.7.2 "知识"是世界的属性，不是卡库的

这一条必须分清：

| | 卡库 | 世界知识 |
|---|---|---|
| 是什么 | 你手里有什么卡 | **这个世界知道什么** |
| 怎么来 | 抽包、成就 | **用过的卡 + 它们的合成闭包** |
| 用途 | 决定你能施什么卡 | **决定世界里能造出什么** |

```
世界用过：石、木
世界知识：石、木、石斧、石锤、燧石、弓（如果木+纤维也满足）
```

**抽不到石斧卡不影响你造石斧**——你只需要有石头和木头。

### 2.7.3 反向：用高环卡等于用了低环卡

```
世界只用了「石斧」一张卡
→ 世界知识自动包含：石、木
```

**所以一张高环卡 = 一套低环卡的集合**。它省的是"抽卡次数"，不是"材料"。

### 2.7.4 三条合成法则（仍然是法则，不是表）

| 法则 | 规则 | 例 |
|---|---|---|
| **同类 ×2** | 两个同类 → 更高一级 | 木 + 木 = 木材 |
| **异类 ×2** | 两个不同类 → 工具 | **石 + 木 = 石斧** |
| **相克** | 相克两类 → 变体或禁物 | 水 + 火 = 蒸汽 |

**再加一类"具名合成"**：少数必须有名字的组合（石斧、弓、骨刀、陶罐、犁、熔炉），其余全走法则。

### 2.7.5 一张示例图

```
0 环    石    木    纤维    骨    土    水    火
         │     │      │      │     │     │     │
1 环     ├─ 石斧（石+木）        │     │     │
         ├─ 石锤（石+木）        │     │     │
         ├─ 燧石（石+石）        │     │     │
         ├─ 骨刀（骨+石）        │     │     │
         ├─ 绳  （纤维+纤维）     │     │     │
         ├─ 弓  （木+纤维）       │     │     │
         └─ 陶罐（土+火）────────┘     │     │
                                          │     │
2 环          ├─ 熔炉（石+火+土）────────┘     │
              ├─ 犁  （木+石）                  │
              ├─ 渔网（绳+纤维）                │
              ├─ 木屋（木+木+石）               │
              └─ 筏  （木+绳）                  │
                                                 │
3 环          ├─ 冶炼（熔炉+火）────────────────┘
              ├─ 文字（陶罐+骨）
              ├─ 轮  （木+石）
              └─ 城  （木屋+石+石）
```

**这张图就是"卡片树"。**往下的边是"由什么合成"，往上的边是"能合成什么"。

### 2.7.6 卡数不再是固定的

**没有 252 这个数了。**卡的数量 = 这张图有多少个节点，而图可以有无限层。

| 决定卡数的 | 是什么 |
|---|---|
| 底层原材料 | 你想让世界有多少种基础物质（7 种？20 种？） |
| 中间层 | 每层组合出多少新东西 |
| 顶层 | 你想要多复杂的文明 |

**加一张卡 = 在图上加一个节点**，只要它有两个输入，就自动获得"合成关系"。

## §2.8 卡数的分配原则（不固定总数）

**没有固定的卡数。**但三类的比例和律的层级有原则。

### 2.8.1 三类的大致比例

| 类 | 比例 | 理由 |
|---|---|---|
| **物** | 最多（约 50%） | 世界里的东西本来就最多 |
| **术** | 次之（约 35%） | 干预手段，比实体少 |
| **律** | **最少**（约 15%） | 全局规则一多就失控 |

### 2.8.2 律必须分两级

| 级别 | 作用域 | 例 |
|---|---|---|
| **全域律** | 整个世界 | 长夏、禁伐、永夜 |
| **局部律** | 一个格 / 一个物种 / 一段时间 | 「这片林 50 年不落叶」 |

**全域律永远只占少数**，否则世界的规则集会先崩。

### 2.8.3 生物卡的数量 = 物种上限

世界上能有几个物种，**等于卡图里有多少张生物卡**。

这不是限制，是选择：你想要一个物种丰富的世界，就在图里多放几种。

### 2.8.4 卡图是"活的"

| 加什么 | 自动发生什么 |
|---|---|
| 加一张原材料卡 | 它成为某个合成节点的输入 |
| 加一张组合卡（有两个输入） | **自动获得深度，自动进图** |
| 加一张生物卡 | 世界里可能出现的物种 +1 |
| 加一张全域律 | 规则集多一条（慎用） |

**所以卡数会随着内容增长，不需要"重新设计 252 张"。**

# 第三部 经济

## §3.1 时素

| 项 | 值 |
|---|---|
| 来源 | **只由时间产生**，无其他来源 |
| 速率 | 每 10 秒 +1（真实时间，不随加速变化） |
| 用途 | 唯一的用途是抽卡包 |

## §3.2 卡包

| 项 | 值 |
|---|---|
| 一包 | **6 张** |
| 筛选 | **按词条组合查询**，不是预设文件夹 |

### 3.2.1 按环级分档（这是唯一的"解锁"）

**没有"纪元"、没有"世界规模"这类阶段。**高环卡能不能拿到，只看你愿不愿意花时素。

| 包 | 价格 | 出什么环级 | 说明 |
|---|---|---|---|
| 基础包 | **12 时素** | 0–3 环 | 铺底，不会卡死 |
| 进阶包 | 24 时素 | 1–6 环 | 中期主力 |
| 高阶包 | 48 时素 | 3–9 环 | 大件 |
| 超环包 | 96 时素 | 超环 | 一局最多 3 张 |
| 禁物包 | **只能由成就解锁** | 禁物 | 买不到 |

**你不需要"发展"到某个阶段才能抽高级卡——攒够时素就行。**

想跳过铺底直接赌高阶包？可以。但抽到的 7 环卡，你可能连放它的地都没有。

### 3.2.1 创世包（开局必得）

| 位 | 内容 |
|---|---|
| 1 | 太阳（保证） |
| 2 | 土地（保证） |
| 3 | 水（保证） |
| 4 | 一张生物卡（草籽 / 苔 / 猴群里随机） |
| 5–6 | 从剩下 15 张池子里抽 |

> 保证位让**每一包都能开局**，随机位让**每局开局不一样**。

## §3.3 卡的三个去向

| 去向 | 结果 |
|---|---|
| **打出去** | 改变世界，卡消失 |
| **回收** | 换 **1 时素**（半价） |
| **合成** | 变成 1 个料 |

> 12 张废卡 = 1 包。净损耗 50%，不会无限循环，卡库永远不会堆到几百张。

# 第四部 生命

## §4.1 物种属性（四个）

| 属性 | 决定什么 |
|---|---|
| **握持** | 能否用工具 |
| **力量** | 能否推倒、搬运 |
| **认知** | 能否学复杂 Trait |
| **社会性** | 能否传授、协作 |

**Trait 不是写死的映射，靠属性阈值比较**：

```
猿猴：握持 0.6  力量 0.5  认知 0.4  社会性 0.7
石斧：需要握持 ≥ 0.5  →  0.6 ≥ 0.5，学会
```

**360 条映射 → 4 个属性 + 1 个阈值。**

## §4.2 动物行为

每 tick 只做三件事：

| 判什么 | 规则 |
|---|---|
| 我需要的东西在不在 | 自养：`W≥1 且 L≥1` → 龄 +1；否则停滞 |
| 我要吃的在不在 | 动物：本格或相邻有目标 → 存活；没有 → 生命 −1 |
| 我该死了吗 | 老死 / 旱死 / 暗死 / 饿死 |

### 4.2.1 捕食不是即死（延迟死亡）

**旧设计的问题**：`Predator` 吃到就杀，一张卡决定生死，玩家没有反应窗口。这是 Oceans 明确验证过的失败模式。

**改为"削减"**：

| 场景 | 旧 | 新 |
|---|---|---|
| 狼吃草 | 草死 1 株 | 草的种群数 **−1~3** |
| 狼吃鹿 | 鹿死 1 只 | 鹿的种群数 **−1**，且鹿群**逃跑 1 格**（若有 `Mobile`） |
| 熊吃树 | — | 不成立，熊不吃树 |

**只有在种群数归零时，这个物种才在该格消失。**所以：

- 一只狼吃不光一片草
- 鹿会跑，不会站着被吃
- **玩家有 3–5 个月反应窗口**

**死亡后**：留「腐尸」格，6 月后变回地形（养分 +3）。

## §4.3 人

**人不是特殊系统，是一个"高认知动物"。**

| 项 | 值 |
|---|---|
| 本体 | 动物 |
| 食性 | 杂食（草 + 肉） |
| 属性 | 握持 0.8 / 力量 0.7 / 认知 0.9 / 社会性 0.9 |
| 默认行为 | 有树就砍（木材 −1 自然度）、有地就种、人多就建屋 |

**"文明" = 一个挂满 Trait 的动物种群。**

> 人不需要单独的 AI，他们跑的是同一套 `Predator` + `Trait`。

# 第五部 目标与呈现

## §5.1 世界成就图鉴

**收的不是卡，是「世界状态」。**

### 5.1.1 六十条，分六组

| 组 | 主题 | 例 |
|---|---|---|
| **天文** | 太阳与光 | 三阳、长夜、极昼、双日交替、星尘成海… |
| **水文** | 水与干湿 | 长存（W>0 连续 100 月）、洪泛、死水、泉眼成湖… |
| **生态** | 物种与食物网 | 三级链、成林、独木、种群爆发、灭绝… |
| **文明** | 人与 Trait | 第一人、文字、城市、迁徙、失传… |
| **灾变** | 破坏 | 崩塌、烧穿、疫病、整岛焦土… |
| **反向** | 极端状态 | 空世界（0 格）、全暗、全冰、仅剩 1 格… |

**前 10 条示例**：

| # | 成就 | 判定 |
|---|---|---|
| 1 | 三阳 | 同月太阳源 ≥3 且最大温差 >20 |
| 2 | 长存 | 某格 W>0 连续 100 月 |
| 3 | 三级链 | 草 + 猴 + 狼 同月共存 |
| 4 | 孤岛 | 水域仅 1 格却物种 ≥3 |
| 5 | 炼狱 | 某格 T>45 连续 20 月 |
| 6 | 长夜 | 全格 L=0 连续 20 月 |
| 7 | 成林 | 植物格 ≥ **当前世界格数** 的 50% |
| 8 | 崩塌 | 10 月内 ≥5 物种灭绝 |
| 9 | 独木 | 仅剩 1 株植物存活 50 月 |
| 10 | 稳态 | 连续 50 月 T 在 15–25 且生命全满 |

**分母是动态的**：世界越大，"成林"越难。

### 5.1.2 成就是解锁卡池的途径（不是只记录）

**旧设计的问题**：12 时素 = 2 分钟 = 1 包，纯等待墙。玩家只能等，不能主动争取。

**改为双轨**：

| 来源 | 给什么 |
|---|---|
| **时素**（12 点） | **基础包**：0–3 环，保底能玩 |
| **成就** | **扩展包**：对应主题的卡池（天文组解锁天体卡、生态组解锁动物卡） |
| 禁物 | **只能由特定成就解锁**（如"崩塌"解锁禁物包） |

于是：

- 等不是唯一的路，**"再造一个世界试试能不能凑出长夜"** 也是路
- 图鉴页本身就是**可截图的收藏墙**
- 60 条 ÷ 每个世界能达 3–5 条 ≈ **15–20 个世界**的内容量

**表现**：时间降到 0.25× 停半秒 → 格子上浮一行成就名 → 图鉴点亮一格 + 卡池多一包。

## §5.2 界面

**常显只 5 个数**：

| # | 常显 | 为什么必须常显 |
|---|---|---|
| 1 | 年份 | 时间是唯一不变的东西 |
| 2 | **世界格数**（含分区） | **它是玩家每打一张土地卡都在改的核心决策变量** |
| 3 | 自然度 | 唯一的衰败指标 |
| 4 | 时素 | 唯一的货币 |
| 5 | 光标格 T·W·L·N（紧凑一行，越界变红） | 打牌前必须看得到 |

年龄、演替原值、种群数全进悬浮，越界时冒角标。

> 旧版常显的是"纪元 + 地形"，但世界大小才是这一作真正的**状态变量**。纪元降级为徽记，地形降级为格子底色。

**每格只三层**：剪影（尺寸=年龄）+ 地形色 + 最多一个警示角标。

### 5.2.1 视口随世界缩放（不分区）

世界大小是玩家造的，所以**镜头必须能跟着变**。但**不分区**——世界是一整块，只是屏幕装不下。

| 世界格数 | 视口 | 说明 |
|---|---|---|
| 0–12 | Z2 特写 | 一屏几格，看得到树冠 |
| 13–36 | Z1 标准 | 一屏读完 |
| 37–100 | Z0 俯视 | 格子变小，剪影变简 |
| 100+ | Z0 + **自由平移** | 缩到最小仍装不下时，靠拖拽移动 |

**没有"区域"这个概念。**世界就是一张连续的网格，你打到哪，它就长到哪。看不到的地方就真的看不到——**不是被切开了，是远了**。

### 5.2.1 让时间可见

| 手段 | 治什么 |
|---|---|
| **演替水位**：格子边缘半透明填充 | 草→灌 25 年，期间格子完全一样 |
| **同心年轮**：树一年一圈 | "这棵树多大了" |
| **十年前幽灵层**：长按叠加 10 年前地形 | 长周期变化看不见 |

## §5.3 开局流程

```
① 虚无（全黑，只有手牌）
② 撕创世包 → 6 张（太阳/土地/水/生物 保证）
③ 打土地 → 黑暗中浮现一块地
④ 打太阳 → 光落下来，世界第一次被照亮
⑤ 打水 → 溪从地里渗出
⑥ 打生物 → 第一个生命出现
⑦ 时间开始流动，时素开始累积
```

**前四步就是全部教学**：没有文字，只有屏幕发生的事。
