# 常量与数字（唯一索引）

> **为什么有这一页**：同一个数字被抄进 13 份文档，改一次要改 13 处——这是本项目最贵的维护成本。
> 本页是**所有跨文档共享数字的索引**：想改任何一个数，先在这里查到它会影响谁，再动手。
>
> **本页不写规格正文**，只写「值 / 真源在哪 / 还有谁在用」。真源改了，本页同次更新；**别处不得再抄一份完整表格**。

| 量 | 值 | 还有谁在用 |
|---|---|---|
| 取景距离 `Fit` | **5.63 R**（= `1.09R ÷ tan(半垂直FOV)`，FOV 38° 水平 + 16:9） | `game/Source/.../SolsticePlayerController.cpp` 的 `FitDistance()` |
| 最远 / 最近 | **1.6 × Fit** / **25 m（2500 uu）** | 同上，距离 clamp |
| 俯仰档 | **4**：14°（低角）/ **35°（默认）** / 62°（巡界）/ 88°（图纸） | `art.md` §2.6、`ops/PLAYTEST.md` §3；判据第 5 条「四机位成立」就指这四档 |
| 方位档 | **8**（45° 步进，−45° 为 0 档） | 同上 |

> **两条不能混的界**：远界跟 `R` 走（世界越大要退越远），近界跟格边长走（1 格恒 1 m，能看清苔的距离不变）。写成"都是 R 的倍数"会让 512² 的最近视角退到 200 m 外。

## 8 本页的更新触发

| 改动 | 同次必须更新 |
|---|---|
| 任何上表数字变化 | **先改真源**，再改本页那一行；带 `D-xx` 的同步改 `plan/work.md` |
| 新增跨文档共享的数字 | 本页加一行（值 + 真源 + 谁在用） |
| 发现某文档抄了完整表格 | 改成指针（`见 CONSTANTS §x`），不要两处各写一半 |
