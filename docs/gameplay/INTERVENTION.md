# 干涉流程与余响经济（INTERVENTION）

## 0 本文件管什么 / 不管什么

- **管**：**玩家怎么用卡、怎么拿到卡、怎么被约束**——手牌机制、释放与回收、实体池、余响经济与回收定价、扰动值、卡包与获取、卡与世界的双向联系、接管与释放、动画仪式、红线。
- **不管**：卡本身的设计（三轴 / 矩阵 / 生克 / 命名 → [`../setting/cards.md`](../setting/cards.md)；**卡种清单与功能位池** → [`../setting/cards.md`](../setting/cards.md)）；时间与现实耦合（→ [`TIME.md`](../later/TIME.md)）；界面布局与键位（→ [`UI-UX.md`](../later/UI-UX.md)）。
- **来源**：由 `CHARTER.md` §1 / §10.4 / §10.8 / §10.9 + §11 拆出；**v2.0 引入「手牌 / 实体池 / 回收」机制（2026-10-14 裁决）**。

## 1 手牌、释放与回收（★核心流程）

### 1.1 两个动作

| 动作 | 含义 | 结果 |
|---|---|---|
| **释放** | 使用这张卡，让它作用于世界 | 卡**被消耗**（实体池减一）；效果落到世界 |
| **回收** | 把这张卡退回纸包，换回**折扣余响** | 卡**被销毁**；返还一定余响（§2.3） |

**固化并入释放**：释放时若该卡有"可落地形态"，给**两个落点**——

| 落点 | 结果 | 例 |
|---|---|---|
| **生效即散** | 只改世界状态，不留实体 | 下一场雨、重力减半、永昼 |
| **落地成实体** | 在世界里留下**永久实体** | 留下一座永久火山、一株树、一块碑 |

> 因此 UI 上只有**两个动作**（上拖释放 / 下拖回收），但语义覆盖了原来的"施放 / 分解 / 固化"三种用法。
> **术语冻结**：原「施放」统一改叫**释放**，原「分解」统一改叫**回收**（见 [`../setting/LORE.md`](../setting/LORE.md) §4.1）。
>
> **撤销原则（★2026-10-15 定案）**：**释放后不可撤销**——"错着也是风景"，且低环卡永远有效、地形随时可再改。唯一反悔窗 = **纸片未干期**：落地成实体的卡，落点实体 **3 秒内可点回收回**（动画上"纸还没贴牢"）；生效即散无反悔。

### 1.2 释放流程

1. 从手牌**向上拖出**卡（或按对应快捷键）→ 世界内出现**作用域预览**（笔刷圈 / 区域框 / 单体高亮）；
2. 松手确认；有可落地形态时选择**生效即散 / 落地成实体**；
3. 效果展开 + 写入年表（§5.1）。

**可选仪式感**：在世界上手绘一个简单符（借鉴"神迹"的手势感），**默认关闭**，供玩家手动开启。

**作用域**（[`../setting/cards.md`](../setting/cards.md) §7）：全局（整界）/ 区域（笔刷或矩形）/ 单体（某个体 / 某格）/ 笔刷（连续涂抹）。

### 1.3 交互（★2026-10-14 裁决）

| 操作 | 手势 | 快捷键 |
|---|---|---|
| **释放** | 手牌**向上拖**（卡飞向世界） | 数字键选中 → `Enter`/左键点世界 |
| **回收** | 手牌**向下拖**（卡落回纸包） | 选中 → `Delete`/`Backspace` |
| **重抽** | 手牌区"重抽"按钮 | `R` |
| 切卡类 / 卡库 / 开包 | — | `Tab` / `B` / `G` |

> **拖拽方向即语义**：**向上 = 用出去，向下 = 收回来**——与"卡牌飞入世界 / 落回卡包"的动画同向，不需要教程。

### 1.4 消耗与代价（2026-10-14 定案）

**结论：卡是实物，用了就少一张；但释放本身不收资源、不进冷却。**

| 层 | 规则 |
|---|---|
| **释放开销** | **不花余响、不进冷却**——保持"随手就能玩"的手感 |
| **消耗** | 释放与回收**都消耗这一张卡的实体**（释放＝用掉，回收＝销毁换余响） |
| **0 环** | **免费无限补进实体池**（§1.6）→ 等价于"低环随便玩" |
| **1–9 级** | 靠**开包获得实体张数** → 放一次少一张，**神卡的软限制来自实体池**，不需要冷却 UI |
| **超环** | 定案见 [`../setting/cards.md`](../setting/cards.md) §2.5（21 张带标签，只在特殊包出） |
| **禁物** | 一种可持多张，但**同时只能启用一件**；启用即有代价；**不可回收** |
| **补充约束** | **扰动值**（§3）与**级生克**（高环覆盖低环）——世界层面的软约束，不是惩罚 |

### 1.5 手牌机制（★2026-10-14 新增）

| 项 | 规则 |
|---|---|
| **容量** | **最多 10 张**；不足时空位显示为**纸框空槽**（"我的弹药不多了"必须可读） |
| **来源** | **不是玩家构筑**——**从「实体池」随机抽取**（§1.6） |
| **抽取方式** | **纯随机**：每次独立抽取，**不洗牌袋** |
| **补抽** | **用掉一张（释放或回收）立即补一张**，直到实体池抽空；实际效果是**手牌恒满 10**（只要池里有货） |
| **重抽** | **整手重抽**：10 张全换（换下的卡**退回实体池**，**不返还余响**）；**免费、无冷却、不限次数**；快捷键 `R` |
| **存档** | 手牌**写进存档**；离线即暂停，重开时手牌原样 |
| **定位** | 手牌是"**我现在能做什么**"的选择集，**不是资源限制**——资源限制在实体池 |

**为什么允许免费无限重抽**：本作是"无失败、无压力"的沙盒，玩家不该被"手里没有想要的卡"卡住。代价是随机性只在"懒得挑"时体现——这是**有意的取舍**。

### 1.6 实体池（★2026-10-14 新增）

**定义**：玩家**实际持有**的卡（按"张"计），是手牌的唯一来源。

| 卡的档次 | 实体怎么来 |
|---|---|
| **0 环基础卡**（7 元素 × 3 类 = 21 个卡种） | **永久免费、无限补进池**——随便抽、随便用 |
| **开局实体池（★2026-10-15 定案）** | **新界的初始实体 = 21 个 0 环卡种各 1 张**（免费档全量，不赠 1 级卡——扩展卡的惊喜留给第一次开包）；**首手保底**：第一次抽取保证含**地形类 + 天气类各 ≥1**（避免开局全是记录卡）；**开局余响 = 0**（★第 47 轮）：手牌 10 张全是 0 环卡、0 环免费释放——**先玩后赚**，攒余响后开第一包 |
| **1–9 级扩展卡** | **开包开出实体张数**；用完要靠再开包补充（**这是开包的核心动力**） |
| **禁物** | **不随机出**，按"发现 / 事件"获得；同时只能启用一件 |
| **超环** | **只在「特殊包」（至日 / 节气 / 雨月）里出**，普通包不含（[`ECONOMY.md`](../later/ECONOMY.md) §5.2） |

**持有上限（★2026-10-14）**：**每种卡最多持 3 张**。开包时若某种卡已满，新出的这张**自动折算**成余响（**返还原价值的 20%**；**0 环不折算、直接不留**——它可以免费无限补）。

> **为什么必须有这条**：见 [`ECONOMY.md`](../later/ECONOMY.md) §8——没有它，100 小时后实体池会涨到上千张，手牌"随机 10 张"就失去意义（抽到想要的卡概率趋近 0）。

**卡库（Codex）语义更正**：**只读**——它是**图鉴 + 持有数 + 解锁进度**，**不再提供"直取"**。

> 一句话闭环：**余响 → 开包 → 实体 → 手牌 → 释放（改世界，产余响）/ 回收（折扣回血）**。

### 1.7 反馈

每次释放**写入年表**并给即时可见反馈；**跨过阈值的释放额外产出余响**（§2.1）。

## 2 余响：干涉世界的回响（★唯一积累物）

### 2.1 定义与产出

**定义**：你干涉世界 → 世界状态发生**可观测偏移** → 世界"回响"给你一份**余响**。它是全游戏**唯一的可积累物**，语义上是**世界的回声**，不是"钱"。

**产出（三源，只增不减）**：

| 源 | 触发 | 量级 |
|---|---|---|
| **事件回响（主）** | 干涉使世界**跨过阈值**并写入年表：重塑面积、水位升降、相变、种群剧变、灭绝、分化… | **按偏移幅度**给，越大越多 |
| **沉淀回响（次）** | 世界推进（真实或虚拟）时按**生态势能** = 生物量 × 多样性 × 稳定度 持续微量产出 | 小、持续 → 奖励"挂着的活世界" |
| **初见回响（一次性）** | **首次**出现某类现象：初雪 / 第一场雨 / 首次捕食 / 首次灭绝 / 首次分化… | 一次性，同时记入年表 |

> **防刷设计**：只有"让世界真的变了"才给事件回响——**反复刷同一张小卡几乎不产出**。

### 2.2 消耗与回收

| 用途 | 花费 | 性质 |
|---|---|---|
| 开一个**随机元素包**（3–5 张） | 低 | 有随机性与开包仪式 |
| **指定开**某个元素包 | 中 | 确定，规避随机 |
| 平息扰动（§3） | **1 余响 / 2 点**（[`ECONOMY.md`](../later/ECONOMY.md) §4） | 世界回到稳定 |
| **回收**一张卡 | **返还**（负数花费） | 按 §2.3 的环段折扣 |

### 2.3 回收定价（★2026-10-14 裁决）

**回收 = 销毁这张卡，换回折扣余响。**

| 档次 | 级 | 回收返还 | 说明 |
|---|---|---|---|
| **0 环** | 0 | **不可回收** | **只能使用**（释放）；**释放即销毁、无任何资源返回** |
| **低环** | 1–3 | **价值的 30%** | 便宜卡不保值 |
| **中环** | 4–6 | **价值的 50%** | 中间档 |
| **高环** | 7–9 | **价值的 70%** | **越高越保值** |
| **超环** | 超环 | **价值基数 ×2（回收率 70% → 返还 532，定稿见 [`ECONOMY.md`](../later/ECONOMY.md) §3.2）** | 档位定义见 [`../setting/cards.md`](../setting/cards.md) §2.5 |
| **禁物** | 无环 | **不可回收** | 启用即有代价，**不许靠回收逃避** |

- **卡的价值**由**级**推导（价值表见 [`../setting/cards.md`](../setting/cards.md) §4），写成卡种字段 `value`。
- **回收与重抽的区别**（都要记牢）：
  - **回收**：卡**销毁** + **返还余响**；
  - **重抽**：卡**退回实体池** + **不返还余响**。
  两者职责分明，不会凭空生出余响。

### 2.4 经济红线（不变量）

1. **任何单卡的回收返还 < 该卡的来源成本**——否则"抽到就换钱"，卡不再被使用。
2. **包层不变量**：`期望回收总额 < 开包价格`——即"开一个包再全部回收"**必须亏**。任何一次调价（包价或回收率）都必须回头验算这条。
3. **余响只增不减**（除消费），无失败扣除；
4. 余响只买**选择**（更多卡）与**审美**——**全卡功能平权**（"审美"一侧的商品已于第 47 轮随主题扩展一并否决，见 [`../art/art.md`](../art/art.md) §0.2 与本文 §4）。

### 2.5 数值模型

**已定稿（2026-10-14）**：产出速率、价值表、回收返还、包价、掉落权重与**六条红线验算** → 全部见 [`ECONOMY.md`](../later/ECONOMY.md)。

本文件只保留**规则**：三源产出的定义（§2.1）、只增不减与"只买选择与审美"（§2.4）、两条经济红线的表述（§2.4）。**任何数值调整只需改 `ECONOMY.md`，并重跑它的红线验算。**

## 3 扰动值：世界的状态

干涉会**累积扰动**（0–100）。**扰动不是惩罚，是世界的状态**：

| 区间 | 状态 | 世界表现 |
|---|---|---|
| 0–30 | **稳定** | 天气温和、地形稳、生态规律 |
| 30–60 | **波动** | 天气极端、地形震动、生物行为异常 |
| 60–100 | **剧烈** | 奇观频发：浮空岛、极光暴、物种爆发、地貌抖动 |

- **平息**：消耗余响降低扰动（世界回到稳定）。
- **放任**：不理会，让世界进入"剧烈"——**这是另一种玩法，不是失败**。
- 界面用**一条指示 + 世界画面上轻微的起伏**表达（[`UI-UX.md`](../later/UI-UX.md) §4）。

**规则（★2026-10-15 补完定案，与 §1.4 的"释放无开销"配套）**：

1. **全局一个值**（M0）：扰动整界共享一个读数，不分区；若实测"大界上局地感不足"，再议分区累积（M1+）。
2. **自然消退**：**每世界小时 −2**（初值，可调）——虚拟模式随加速一起加快；真实模式约 −48 / 真实日；下限 0。
3. **平息花费**：**1 余响 / 2 点**（定稿见 [`ECONOMY.md`](../later/ECONOMY.md) §4）——100 → 0 花 50。
4. **"剧烈"的机制后果**：**只提高奇观与极端事件概率 + 沉淀势能 ×0.5**（[`ECONOMY.md`](../later/ECONOMY.md) §6 闸四），**不产生失败或损失**（守"无失败"红线）。

## 4 卡包与获取

### 4.1 六种卡包

| 轨 | 包 | 内容 | 回答 |
|---|---|---|---|
| **玩法轨** | **元素包（Element Pack）** | **一个元素**的整套卡（**0–9 环共 10 档 × 3 类 = 30 个卡种**；**禁物不进包**——事件获得；超环不在其内） | "这次主玩哪个元素" |
| | **故事包（Story Pack）** | 一段世界故事串联的卡 + 专属记录卡 + 专属卡背 | "讲哪个故事" |
| | **精灵包（Spirit Pack）** | **生灵卡**（物种）成包，一包 = 一个生态位的物种组 | "放什么活物" |
| | **地脉包（Ley Pack）** | **触发卡**成包，一包 = 一套"世界自动规则" | "定什么规则" |
| **现实轨** | **特殊包（Special Pack）** | **与真实时节绑定**：至日包、节气包、雨月包；**唯一能开出超环的包**（150 余响 · 8% 概率） | "外面是什么季节" |

> **特殊包是"现实的桥"在卡包层的落地**：真实到了冬至，游戏里就浮出「至日包」→ 你开到的实体偏冰系 → **你这个冬天的手牌就是冰季手牌**。
> **包不排他**：同一张卡可同时属于"水元素包"与「逆流的故事」故事包——**包是视角，不是归属**。

### 4.2 获取规则

- **基础卡** = **0 环碎片卡**（21 个卡种）——**永久免费、无限补进实体池**。
- **扩展卡**（**级 1 – 9**）——**开包开出实体**；实体用完需再开包。
- **禁物档**——**不随机出**，按"发现 / 事件"获得；**同时只能启用一件**；**不可回收**。
- **无稀有度**：包内只按主题与协同分组，**不分强弱**——"保值率"只影响回收，不影响功能。

### 4.3 开包、卡库与手牌

- **开包**：消耗余响 → **撕纸包动画** → 得 3–5 张**实体** + 1 张**签名卡**（该包的核心动作）→ 实体直接进入**实体池**。
- **卡库（只读）**：浏览 / 检索**已解锁**的卡种（按**卡类 / 持续性 / 元素 / 级 / 包**筛选）；显示**持有张数**——**未解锁的卡种不显示**（★第 47 轮：不做剪影机制）。**不提供直取。**
- **手牌**：见 §1.5（10 格、随机抽取、免费重抽）。

## 5 卡与世界的联系（★重中之重）

"卡"与"世界"不是两样东西——**卡是世界的一部分**。

### 5.1 卡 → 世界：释放即留痕

| 环节 | 表现 |
|---|---|
| 预览 | 世界内浮现作用域（笔刷圈 / 区域框 / 单体高亮） |
| 落地 | **卡牌从手牌飞出、翻面、落入世界**（§6） |
| 生效 | 卡的"模拟效果"真的改写世界状态 |
| 留痕 | 写入年表；地形卡留下**永久地貌**，生灵卡留下**活着的个体** |

### 5.2 世界 → 卡：世界会"回话"

| 机制 | 说明 |
|---|---|
| **共鸣高亮** | 当前世界状态下"特别有用"的卡自动发光 / 排前（冰期里「冰封」「雪被」发亮）——**不是解锁，是世界在提示你** |
| **情境表现** | 同类卡在不同条件下表现不同（"雪"卡在极地更持久）——体现"分何时有用，不分强弱" |
| **卡随世界生长** | 生灵卡投放后会**自行演化**：你抽到的"走兽"几代后可能变成新种——**卡本身在变** |
| **世界改写卡** | 触发卡生效后，卡从"待触发"变为"已生效"，卡面盖上**世界印记** |

> **设计红线**：共鸣只改"**排序与视觉提示**"，**绝不改卡的强度数值**——也**不干预随机抽取**（抽取是纯随机，见 §1.5）。

### 5.3 接管与释放（现实项）

凡是覆盖现实输入的卡（日照 / 天气 / 温度 / 节气），UI 上标记"**已由你接管**"，可**一键释放回现实**（[`TIME.md`](../later/TIME.md) §4.2）。

### 5.4 时间倒带：回滚什么？（✅2026-10-15 定案：按建议执行）

时间类卡可"回滚 N 世界分钟""按年表重演"。**必须写明回滚范围**，否则存在"释放 → 抬高扰动 → 回滚 → 再释放"的刷法。

**定案（2026-10-15）**：

| 对象 | 是否回滚 | 理由 |
|---|---|---|
| **世界状态**（地形 / 生态 / 环境） | ✅ 回滚 | 这是"改错了可以退回去重看"的价值所在 |
| **余响** | ❌ **不回滚** | "余响 = 世界的回声 = 记忆"，**记忆不可逆** |
| **实体池 / 手牌 / 解锁** | ❌ 不回滚 | 否则会变成"回滚洗牌" |
| **年表** | ❌ 不回滚（追加一条"曾经回滚过"） | 年表是记忆本身；也天然成为防刷的可查证据 |

## 6 动画与仪式（动力来源）

要有"打开它"的动力 → **每一次操作都要有仪式感**。全部程序化 + 2D 生图，**零人工动画资产**。

| 场合 | 动画 |
|---|---|
| **开包** | 卡包从侧边滑入 → **撕开封套**（撕纸声 + 纸屑）→ 卡成扇形飞出 → **逐张翻面**（背面是赛璐璐纹样；特殊包内超环 / 禁物卡为对应特殊牌背，[`../art/art.md`](../art/art.md) §4.4）→ 签名卡最后亮起 → 实体落入实体池 |
| **释放（上拖）** | 卡从手牌飞起 → 空中**翻面朝向世界** → 落入落点、**纸片震荡** → 效果展开（地形隆起 / 光柱升起 / 生物落地） |
| **回收（下拖）** | 卡**向下落回纸包**、边缘卷起 → 化成一小叠余响（纸屑上浮）——**手感要"轻"，不是"毁掉"** |
| **重抽** | 整手牌**一起收进纸包再从左侧弹回**，像重新洗一副纸牌 |
| **补抽** | 用掉一张后，新卡从纸包边缘**滑入空槽**（不打断操作） |
| **世界反馈** | 硬阴影 + 移轴 + 草叶摆动；大事件配一次**镜头轻推 + 碎屑** |
| **触发卡生效** | 世界某处**亮起一枚印记**，UI 里同步"盖章" |
| **扰动起伏** | 扰动升高时世界画面**轻微起伏**：边缘微卷、光线下沉 |
| **相互作用** | 两条原质在同一区域相遇时，交界处**亮起光纹**，反应随之展开 |
| **年表回放** | 倒带 / 因果重演时世界**逐帧倒退** |

> **可及性**：全部动画可在设置里**降级 / 关闭**（防晕动、省电）。
