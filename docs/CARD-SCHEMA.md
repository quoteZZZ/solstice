# 卡片字段表（CARD SCHEMA）

> **一句话**：**数据 + 卡图 = 一张卡**。卡面、悬浮、图鉴全部由这份表里的字段渲染，任何显示内容都必须能在这张表里找到来源。
> 真源：本文。母规则见 [CARDS.md](CARDS.md)，物种规则见 [SPECIES.md](SPECIES.md)，版式见 [ART.md](ART.md) §8。
> 设计稿实例：[`CARD-NIGHTBIRD.html`](CARD-NIGHTBIRD.html)。

---

## 0 六条约束

1. **一个字段只有一个显示位置**（表里写明"显示在"），同一信息不许卡面和图鉴各写一遍。
2. **长度上限 = 版式能容纳的物理上限**（不是文风约束）：卡面 640 宽下 `line.fx` 两行可容 40 字、图鉴一栏可容 100 字。**上限之内鼓励写满**——信息量不足比超长更常见。
3. **数值必须被读取**：`stats[].bind` 指向世界里的变量或系统（雾、湿度、鱼群……）。写了不生效的数值一律删。
4. **关系必须是 id**：`rel[].to` 填卡 id 或物种 id，不填自由文本；渲染时查名。
5. **可选字段缺失即不显示**，不用占位符（不要出现"—"或"暂无"）。
6. **卡面只放能一眼读完的东西**：主效果一句、条件一行、数字三个。其余全部进图鉴。

## 1 身份 `id`

| 字段 | 类型 | 上限 | 必填 | 显示在 | 说明 | 例 |
|---|---|---|---|---|---|---|
| `id` | string | 48 | 是 | 图鉴路径 | `层.元素.环.类.slug`，全局唯一 | `fauna.water.1.matter.nightmarsh_bird` |
| `number` | string | 12 | 是 | 卡面底栏左 / 图鉴 | **图鉴号**：`№ ####`（4 位，按 元素→环→类→同格序号 排序，一格多卡加 `·k`）；底栏显示 `№ 0112 / 231`。**坐标码**（`W·1·M`）只进系统与检索，不上卡面 | `№ 0112 / 231` |
| `name.zh` | string | 6 | 是 | 卡面名条（大） | 卡名 | `夜沼鸟` |
| `name.en` | string | 24 | 是 | 卡面名条（小） | 英文名 | `Nightmarsh Bird` |
| `title` | string | 10 | 否 | 图鉴副标题 | 分类（图鉴用语，不是 ID） | `雾栖鸟` |
| `slug` | string | 24 | 是 | — | 文件名 / 音频名 | `nightmarsh_bird` |

## 2 元素与环 `element` / `tier`

| 字段 | 类型 | 上限 | 必填 | 显示在 | 说明 | 例 |
|---|---|---|---|---|---|---|
| `elements[]` | enum[1..3] | 3 | 是 | 卡面顶条元素章 / 图鉴属性行 | `金木水火土光暗` + 复合相 `风`；**首个为主元素** | `["水","暗","风"]` |
| `primary` | enum | 1 | 是 | 画芯主色 | 必须是 `elements[0]` | `水` |
| `tier` | int / `over` | 0–10 | 是 | 卡面环级条 / 悬浮 | **稀有度 + 强度**：越高越难抽、效果越强 | `1` |
| `rarity_word` | enum | — | 是 | 卡面环级右侧 | 常见 / 少见 / 稀有 / 罕见 / 至日 | `常见` |
| `class` | enum | 3 | 是 | 卡面角标 / 图鉴 | `matter` 物 / `rite` 术 / `law` 律 | `matter` |
| `duration` | enum | 3 | 是 | 图鉴效果 | `instant` / `sustain` / `permanent` | `sustain` |

> `tier` 决定抽卡权重（[CARDS.md](CARDS.md) §9），**不由格子里的卡数决定**；`elements` 越多通常 `tier` 越高。

## 3 卡面文字 `line`（三段，强约束）

| 字段 | 类型 | 上限 | 必填 | 显示在 | 说明 | 例 |
|---|---|---|---|---|---|---|
| `line.fx` | string | **40 字**（两行） | 是 | 卡面说明条第 1 行（19.5 px 白） | 主效果，语序固定：**做什么 → 范围/时长 → 附带后果**；允许一句半，不许写成两段 | `夜出成雾：贴水低飞时在身后留下 0.03 W 雾带，持续 20 秒，雾随鸟移动。` |
| `line.cond[]` | string[1..3] | 每条 **24 字** | 否 | 卡面说明条第 2 行（12.5 px 灰） | 触发条件：时段 / 地形 / 前置；三条以内，按"硬 → 软"排 | `夜 18–6`、`附近有木本横枝可落` |
| `line.num[]` | `{k,v}`[2..3] | 3 | 是 | 卡面说明条第 3 行（11.5 px mono） | 三个最关键数字，**必须与 `stats` 对齐** | `{k:"雾内",v:"能见度 −1"}` |
| `line.hl[]` | string[] | 2 | 否 | 卡面上色词 | 需要高亮的词（术语/来源），青色或紫色 | `["成雾","夜枭"]` |

**取舍规则**：`line.fx` 写"只有这张卡才有的动作"；通用机制（拖放、消耗）一律不写。写不下就说明效果太多，**该拆卡**，不是该缩字。

## 4 数值 `stat`（只进图鉴，不上卡面）

| 字段 | 类型 | 上限 | 必填 | 显示在 | 说明 | 例 |
|---|---|---|---|---|---|---|
| `radius_w` | float | 0–1 | 是 | 图鉴读数 / 作用圈（**不上卡面**） | 影响半径，**世界宽度的分数** | `0.012` |
| `disturb` | int | 0–100 | 是 | 图鉴读数 / 顶栏扰动（**不上卡面**） | 施加后增加的扰动 | `3` |
| `cooldown_s` | int | 0–3600 | 是 | 图鉴读数（**不上卡面**） | 同名卡冷却 | `30` |
| `value` | int | 1–760 | 是 | 图鉴 / 回收 | 卡的份量（[CARDS.md](CARDS.md) §7） | `5` |
| `reclaim` | int | 0–114 | 是 | 仅图鉴 | 回收返还（15 %，0 环为 0） | `1` |

### 4.1 ATK / DEF 怎么算（卡面底栏，图鉴也显示）

**两条独立公式，都用整数，取整到 5 的倍数。**

`ATK = tier × 15 + 类加成 + 半径 × 100 + 机动加成`

| 项 | 取值 |
|---|---|
| `tier` | 0–9，超环按 12 计 |
| 类加成 | 物 +5 / 术 +10 / 律 +15 |
| 半径 | `radius_w × 100`（0.012 → 1.2） |
| 机动 | 飞禽 / 水族 +5；其余 0 |

`DEF = tier × 10 + 持续加成 + 体型档`

| 项 | 取值 |
|---|---|
| 持续 | instant 0 / sustain +10 / permanent +25 |
| 体型 | 小 +5（≤0.03 W）/ 中 +10 / 大 +20（≥0.20 W） |

**示例（夜沼鸟）**

| 项 | ATK | DEF |
|---|---|---|
| 基础 | 1 × 15 = 15 | 1 × 10 = 10 |
| 类 / 持续 | 物 +5 | sustain +10 |
| 半径 / 体型 | 0.012 × 100 = 1.2 | 小 +5 |
| 机动 | 飞禽 +5 | — |
| **合计** | **25**（26.2 取 25） | **25** |

> **为什么攻防不参与世界规则**：ATK/DEF 只用于**比较与收藏**（谁的卡更强、卡册排序），不参与发芽、生长、捕食的真实结算——真实结算看 `radius_w` / `stats` / `effect`。所以公式可以简单，但必须可复算。

## 5 图鉴 `codex`（六块，全部由数据渲染）

### 5.1 读数 `stats[]`（6 条）

| 字段 | 类型 | 说明 | 例 |
|---|---|---|---|
| `stats[].k` | string ≤4 字 | 读点名 | `雾域` |
| `stats[].v` | string ≤12 | 显示值（带单位） | `0.03 W` |
| `stats[].w` | int 0–100 | 条长百分比（**绝对值，不是同类排名**） | `32` |
| `stats[].base` | int 0–100 | **同类中位线**，图上画一条竖刻度；缺省不画 | `50` |
| `stats[].t` | string ≤14 | 注（条件/换算） | `能见度 −1 档` |
| `stats[].bind` | string | **接线的世界变量**，没有就留 `null` | `fog.opacity` |

### 5.2 正文 `lore[]`（3 段）

| 字段 | 类型 | 上限 | 必填 | 说明 |
|---|---|---|---|---|
| `lore[].k` | enum | — | 是 | `habit` 习性 / `behavior` 行为 / `legend` 传说 |
| `lore[].t` | string | **100 字** | 是 | 一段只写一个主题（可含因果两句）；可用 `**` 强调一句。**卡面只显示其中 ≤40 字的前两行**（`intro`），其余进图鉴 |

> 三段分工不许混：习性 = 什么时候做什么；行为 = 为什么会这样（机制的诗意解释）；传说 = 别人的说法。

### 5.3 效果 `effect[]`（4–6 条）

| 字段 | 类型 | 上限 | 说明 |
|---|---|---|---|
| `effect[].k` | string | 4 字 | 条目名（来源 / 成雾 / 限制 / 进化……） |
| `effect[].v` | string | 90 字 | 完整裁定：数字 + 条件 + 边界（"除了……"） |
| `effect[].req` | string | 任意 | 可选：所需前置（有则渲染为标签） |

### 5.4 关系 `rel[]`（2–5 条）

| 字段 | 类型 | 说明 | 例 |
|---|---|---|---|
| `rel[].k` | enum | `food` 食物 / `foe` 天敌 / `sym` 共生 / `where` 出现地 / `req` 前提 | `food` |
| `rel[].to` | id | **卡 id / 物种 id / 地形 id**；查不到就不渲染 | `fauna.water.0.fish.stream` |
| `rel[].note` | string ≤16 | 补充（数量、条件、机制），**必须显示在图鉴 chip 上** | `每日 0.6 尾` |

### 5.5 风味 `flavor`

| 字段 | 类型 | 上限 | 说明 |
|---|---|---|---|
| `flavor.zh` | string | **30 字** | 一句画面，不解释规则；允许一个转折 |
| `flavor.en` | string | 90 字符 | 英文对应，不直译 |

### 5.6 用法 `usage` / `tips[]`（玩法，最高 2 条）

| 字段 | 类型 | 上限 | 必填 | 说明 | 例 |
|---|---|---|---|---|---|
| `usage` | string | **40 字** | 是 | 一句话：**什么时候该用它**（不是效果复述） | `夜里放在河湾，用雾把鱼赶到浅处，再让晨鸟来收。` |
| `tips[]` | string[1..2] | 每条 30 字 | 否 | 具体配合：先做什么、再做什么 | `先放夜枭，否则它不会出现。` |

### 5.7 进化 `evolve`

| 字段 | 类型 | 说明 | 例 |
|---|---|---|---|
| `evolve.from` | id | 从哪张卡进化来（有则卡面显示 `↑来源`） | `fauna.dark.0.bird.owl` |
| `evolve.to` | id / `null` | 进化成哪张卡；`null` = 链条末端 | `null` |
| `evolve.req` | string ≤36 | 条件（只写触发，不写概率） | `30 日内 3 次夜捕成雾` |
| `evolve.auto` | bool | `false` 默认：必须由玩家或事件触发 | `false` |

## 6 外观 `art`（数据侧只给参数，图由生成器产出）

| 字段 | 类型 | 说明 |
|---|---|---|
| `art.src` | path | 卡图文件（SVG / WebP）；缺省时退回 `sigil` |
| `art.sigil` | enum | 元素纹样 id（金菱/木叶/水波/火苗/土丘/光星/暗月/风带） |
| `art.palette` | string[3] | 画芯三色（天 / 中 / 地），用于暗角与渐变 |
| `art.focus` | `{x,y}` 0–1 | 主体在画芯中的位置，用于裁切与悬浮卡取景 |
| `art.frames` | enum | 边框花纹：物=回纹 / 术=云水 / 律=封印菱 |
| `art.sound` | path | 释放音（可选，≤1 s） |

| 字段 | 类型 | 说明 |
|---|---|---|
| `tags[]` | string[] | 检索标签（`nocturnal` `mist` `shore`），供卡与卡引用 |

## 8 校验（写入即检查）

| # | 规则 | 违反时的后果 |
|---|---|---|
| 1 | `line.fx` ≤40、`line.cond[]` ≤24、`lore[].t` ≤100、`usage` ≤40、`flavor.zh` ≤30 | 拒绝写入，不许"自动截断" |
| 2 | `line.num[]` 的 `k` 必须出现在 `stats[].k` 或 `effect[].k` 中 | 拒绝写入（防止卡面写了图鉴没解释） |
| 3 | `stats[].bind` 非空时，世界侧必须有对应变量 | 拒绝写入（防止死数值） |
| 4 | `rel[].to` 必须能在卡池或物种库里解析到 | 渲染时跳过并在构建日志报警 |
| 5 | `evolve.to` 为 `null` 时，卡面不显示进化角标 | — |
| 6 | `tier` 与 `elements.length` 冲突（3 元素且 ≤1 环） | 报警：复合卡应更稀有 |
| 7 | `reclaim` 必须等于 `round(value × 0.15)`（0 环为 0） | 拒绝写入 |

## 10 渲染映射（谁读哪个字段）

| 显示位置 | 读的字段 |
|---|---|
| 卡面顶条 | `elements[]` `tier` `rarity_word` `class` |
| 卡面画芯 | `art.src` / `art.sigil` `art.palette` `art.focus`；无图时用 `primary` 色 + 元素纹 |
| 卡面说明条 | `line.fx` `line.cond[]` `line.num[]` `line.hl[]` |
| 卡面名条 | `name.zh` `name.en` `title` `number` `class` |
| 图鉴读数（卡面**不放数值**） | `radius_w` `disturb` `cooldown_s` `reclaim` |
| 卡面角标 | `evolve.from`（有则显示 `↑来源`） |
| 悬浮卡 | `name` `elements` `tier` `line.fx` `radius_w` `disturb` `cooldown_s` `evolve` `flavor.zh` |
| 图鉴头 | `title` `elements` `tier` `class` `number` `evolve` |
| 图鉴读数 | `stats[]` |
| 图鉴正文 | `lore[]` |
| 图鉴关系 | `rel[]`（`to` 查名后渲染，可点跳转） |
| 图鉴效果 | `effect[]` |
| 图鉴风味 | `flavor.zh` `flavor.en` |
| 世界侧 | `stats[].bind` `runtime.tags` `runtime.gate` |
