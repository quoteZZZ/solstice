# 立项与口径（CHARTER）

> 本文件只回答四件事：**为什么做、做成什么、不做什么、还没定什么**。规格细节不在这里。

---

## 1 定位

**一句话**：一帧**会自己活起来的动画微缩世界**——它按自己的时间活着，你也可以把时间握在手里；你攒下的「余响」开出的**元素包**决定这次能怎样改写它；而它**永远不会输**。

| 项 | 裁决 |
|---|---|
| 品类 | 永续运行的上帝沙盒（生态界）——非战斗、非关卡、无失败 |
| 玩家角色 | 界外的观察者与创世者：**只看与施卡**，不操控个体 |
| 第一卖点 | **万物可干涉的活世界**：从地形到规则，手里的卡都能改写它 |
| 引擎 | UE5.8 + C++ 为主，Slate/UMG 表现层 |
| 平台 | Steam 单机买断（Windows），无服务端、无账号、无内购 |
| 规模 | 三档容量（128² / 256² / 512²），**基准 256²、代码当前 128²**——数字只在 [WORLD.md](WORLD.md) §3.1 写一次；多界 M2 |
| 内容量 | **231 卡种 + 21 禁物 = 252**（算式只在 [CARDS.md](CARDS.md) §1 写一次）；M0 先做 **21**（7 元素 × 3 类各一张） |
| 语言 | 默认中英双语 |

---

## 2 七条体验支柱

1. **它真的在活着**——有因果、会自己漂移的生态。
2. **万物可干涉**——卡池从地形到规则都能改。
3. **这次能怎么玩**——余响 → 开包 → 更多可用组合，只买选择不买强度。
4. **我的界我做主**——一键掷骰就是新世界，种子码可抄可复现。
5. **没有失败，也不会结束**——世界永续，离线即暂停。
6. **打开就好看**——动画赛璐璐的观感即产品。
7. **能一路推近看**——从"一整块界"推到"一个人在走路"（Z0→Z3），**每一次缩放都有东西可看**；这是"微型世界"成立的方式，不是彩蛋。

**唯一积累物是「余响」**，且只买选择与审美。扰动值升高是**另一种玩法**，不是惩罚。

---

## 3 非目标（明确不做）

- 多人 / 联机 / 排行榜 / 服务端 / 账号 / 云同步
- 移动端、主机、macOS / Linux
- 运行期 AI 调用或对话（AI 只用于离线量产素材）
- 战斗、失败、等级、属性成长、任务清单、成就、教程关卡
- 内购、付费抽卡、订阅、DLC 风格包
- 工坊 / MOD 平台（界只在本地导入导出）
- 写实 PBR 路线；**运行期依赖 Lumen / Nanite**（理由见 TECH §6）
- **现实时间 / 本地天气 / 定位同步**——"现实的桥"已删除（2026-10-20），世界只按自己的时钟走

## 4 已否决（不要再提，除非有新证据）

| 做法 | 否决理由 | 轮次 |
|---|---|---|
| 动态壁纸 / 场景引擎 / 卡牌收集 / 自走棋 / 2.5D / Tauri / WebGL | 形态试错，全部作废 | 1–26 |
| 纸雕微缩（Paper Diorama） | 用户："不要纸雕"；纸质感进不了动画赛璐璐 | 57 |
| T2–T5 风格主题（剪纸立牌 / 纸墨 / 木刻 / 粘土） | 资产成本随主题数线性上涨，只做 T1 | 47 |
| 风格包 / 剪影解锁 / 真实付费 | 商业化三连否决 | 47 |
| 相机自由环绕（含中键拖拽、匀速自动环绕） | 把验收口径从 32 格点放大成"任意角度"，实测缺陷全在没人设计过的角度 | 59 |
| 释放后撤销（`Z` / 撤回按钮） | "错着也是风景"；低环卡永远能用 | 49 |
| 混沌初态 / 生命种子 / 上色触发表 | 开局就该是完整世界，不需要玩家先点亮 | 54 |
| 首启问卷 / 9 步向导 | 降级为可选高级面板（M1） | 54 |
| 方位 360° 自由 + 俯仰 10–90° | 同上，被 32 格点取代 | 35 → 59 |
| 独立 `SolsticeSim` 模块 | 实测无收益；无头回归改走 Editor Commandlet | — |
| 现实的桥：真实时间 / 本地天气 / 联网同步 | 用户判定"设计太差"，先做好最基础的世界与玩法再谈扩展 | 60 |
| 单一形制（圆盘陆地 + 环形海 + 外缘必须是水） | 用户："只有考虑岛？不考虑无岛 / 群岛 / 大陆？"——改为六轴随机形制 + 六种界缘交代 | 61 |
| "文明 2 cm 级" | 与 `W` 比例锚冲突；微缩感由 Z 级缩放与移轴给出，不靠缩小人 | 61 |

## 5 已定但容易被忘掉的口径

| # | 口径 |
|---|---|
| 1 | **上帝不操控个体**：观察与干涉是仅有的两种关系，物种行为永远由模拟驱动 |
| 2 | **卡的效果范围是界宽 `W` 的分数**（曲线在 [CARDS.md](CARDS.md) §4.1），不是绝对米数/格数；因此**同一张卡在任何尺寸档都占同样的画面比例**，增大档只增加容量，不增加难度 |
| 3 | **0 环卡免费且无限补进实体池**；开局余响恒 0，手牌 10 张全是 0 环——先玩后赚 |
| 4 | **回收**销毁卡换余响；**重抽**退回实体池不返余响。两者不可混用 |
| 5 | **不可撤销**，唯一反悔窗是落地成实体后的 3 秒"未干期"（动画语义，不是撤销窗口） |
| 6 | **离线即暂停**，不做补偿推演 |
| 7 | 相机**角度离散、距离连续**：远界跟世界半径走，近界是 25 m 绝对值 |
| 8 | **形制不预设**：全海 / 全陆 / 单岛 / 群岛 / 大陆 / 半岛 / 环礁 / 峡湾 / 内陆湖国 / 裂谷都是正式品类；只有"界缘没有交代"或"占画面 >60% 的纯色死面"才重掷（[WORLD.md](WORLD.md) §2.3–2.4） |
| 9 | 禁物**只启不养**，件件带负面效果，不可回收，同时只能启用一件 |
| 10 | 表现层配方改一百遍，`bench` digest 不许动一个字节 |
| 11 | **屏幕就是地图，视角靠缩放**：Z0 全界 → Z3 看得见人；"远处看不见人"由 Z 级解决，**不靠把人做小**（[WORLD.md](WORLD.md) §1.2） |
| 12 | **比例恒定**：所有尺寸按界宽 `W` 的分数定义，不写绝对米数；换尺寸档只换容量，不改比例（[WORLD.md](WORLD.md) §1.3） |
| 13 | **前 10 分钟必须有一次开包**：引导只用一句话 + 一个动作；任何等待（余响 / 冷却 / 集齐）都要有可见进度条（[PLAN.md](PLAN.md) P-21） |
| 14 | **同类不同物必须有形状差异**：卡面靠图形区分（元素纹样 + 类别符号），不靠文字；文字只在悬浮详情里 |
| 15 | **每次释放必须留下可见痕迹**：落点处有该元素的痕迹（划痕 / 幼苗 / 水洼 / 焦痕 / 沙堆 / 褪色 / 暗斑），Z0 有色点、Z2 有形状；没有痕迹的释放等于没发生（[WORLD.md](WORLD.md) §6.1） |
| 16 | **开局是荒界**：世界生成完没有生命（植物 0 / 动物 0 / 智慧 0），生命只能由卡引入，且**不能跳级**（无植物不放兽、无兽不启智）。"世界会自己活起来"的前提是玩家先种下第一粒种子（[WORLD.md](WORLD.md) §9.0） |
| 13 | **默认是侧看**：俯仰 30° + 长焦压缩 + 地平线留在画内——读起来像 2.5D 沙盘，实际是 3D（可八向旋转 / 可推拉 / 可切 88° 看地图）。**88° 才是"地图"**（[ART.md](ART.md) §7） |
| 14 | **界面是两栏框**：左 56 功能（只放动作）+ 右 320 信息（只放读数），世界全程完整；**不用抽屉**（[TECH.md](TECH.md) §6.1） |
| 15 | **卡唯一**：每种卡只有一张，不存在第二张，也没有"重复卡折算"；开包只出未拥有的卡（[CARDS.md](CARDS.md) §8.1） |
| 16 | **创世是纯随机揭示**：形制 / 气候 / 特征 / 奇观全由骰子定，**玩家不能挑**（只能重掷或粘贴坐标复现）；先看剖面与特征，再进场（[WORLD.md](WORLD.md) §4.2） |

## 7 参考与借鉴（抄什么 / 不抄什么）

**只抄结构与交互，不抄美术与压力系统。**（美术真源是 [ART.md](ART.md)）

| 参考 | 抄什么 | 明确不抄 |
|---|---|---|
| **缺氧 ONI** | **创世三步**：选世界 → 剖面 + 特征(traits) → 分段种子；traits 是"声明式规则标签"，开局就告知名与效果；种子可输入复现 | 生存压力、资源链、复制人管理、失败重开 |
| **饥荒** | 斜俯视 30° + 长焦压缩 + 8 向旋转 + 地平线常驻；手绘赛璐璐的"整块感" | 战斗、饥饿、永久死亡、背包管理 |
| **RimWorld** | **右栏常驻事件流**（点一条就追到因果）；点世界里的东西看详情 | 殖民者/工作优先级/房间温度那套表格 |
| **Dorfromantik** | **极简 UI**：世界就是界面，目标不上屏；卡片拖放即落 | 拼图式卡牌循环、计分 |
| **Townscaper** | **操作即结果**：拖上去就有，不弹确认、不弹面板 | 网格编辑与程序化建筑细节 |
| **Terra Nil** | 阶段化的"先看后动"；世界状态用颜色说话，不用数字面板 | 关卡化、评分、通关 |
| **Islanders / Mountain / Everything** | "摆件感"：无目标、无失败、可以只看不动 | 计分、成就、解锁树 |
| **The Sims / Two Point** | **点读数 → 跳到来源**（右栏每一条都可点开因果） | 需求条满天飞、面板铺满屏幕 |
| **炉石传说 Hearthstone** | **卡是有实体的**：扇面排布、跟手拖动、抬升回正、松手有声（GDC 2015 Derek Sakamoto：UI 就是这个游戏本身） | 对局、费用曲线、随从交换 |
| **游戏王 Yu-Gi-Oh!** | **两层信息**：卡下框写摘要/特定信息，完整裁定归规则与图鉴；**进化能力写在卡上**（哪张能进、条件是什么，都是那张卡自己的事）；效果句固定语序（条件 → 动作 → 范围） | **种族与属性体系**（我们没有种族，只有元素构成）、数值对撞、连锁、卡差、原作怪兽与术语 |
| **万智牌 MTG** | **稀有度直接决定抽取难度**（同一张表里，稀有 = 弱概率，不做额外补偿）；效果文本用关键词压缩 | 颜色轮资源、法力曲线、退环境、生物类别 |
| **Against the Storm** | **把后果写在选择上**：卡面直接标"选它会发生什么 + 风险"；顶部一条威胁进度 | Roguelite 局内重开、失败惩罚、蓝图树 |
| **Manor Lords** | **默认没有 HUD**：点谁才出谁的信息条，走开就消失 | 领地/税收/农事排程 |
| **Timberborn** | **把水画出来**：水位、流向、干旱周期用图形预告，而不是数字 | 生存压力、人口与饥荒 |
| **Frostpunk** | 关键事件**一次全屏抉择**（世界会因此改变）；温度条常驻 | 道德困境、失败重开 |
| **The Planet Crafter** | **改造进度分阶段**，世界外观随进度明显变化（贫瘠→有草→有水） | 氧气/饥饿等生存条 |
| 反例：**Cities: Skylines** | — | 二十个面板、信息全藏在二级菜单 |
| 反例：**Stellaris** | — | 开局前丢一堆滑杆让玩家调参 |
| 反例：**Dwarf Fortress** | — | 信息过载：一切都真，但没人读得完 |

**判断标准**：一个设计只在这三条都成立时才抄——① 它服务"看世界"而不是"管理世界"；② 它不引入失败与数值成长；③ 它在 1080p 一屏内能读完。
