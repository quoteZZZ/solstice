## 3 当前批次（按序，不要并行）

### P-01 把画面验收换成"能看的东西"（P0）

**问题**：`measure-frame.py` 的三项（饱和 / 中位 / 高光）是全局统计量，可 PASS 而画面仍难看（用户原话"像十几年前的游戏"），且可被反向优化。
**做法**：
1. 建 **8 机位 × 3 时段 = 24 帧 golden set**（固定种子 / 分辨率 / 隐藏 UI），一条命令出拼图；
2. 指标换成分区结构指标：天/海/陆三区的明度分带数、16 px 块局部对比度中位数、边缘密度、色相分布熵、最大纯色连通块占比；
3. 三项统计量保留为**回归防线**（防爆掉），不作通过判据；
4. 人只看 24 帧拼图 + 10 秒录屏。
**验收**：一次表现层改动 → 5 分钟内得到拼图 + 数字 diff，能判断变好还是变坏。

### P-02 512² 实测，把预算从"目标"变成"数字"（P0）

**做法**：`bench.ps1 -Size=512` + 带渲染 `stat unit` + 首载计时；结果回填 TECH §5 与本节。
**验收**：帧率 / 内存 / 首载 / 分块重建尖峰四项都有数；据此决定默认档是 512 还是 256。
