## 3 当前批次（按序，不要并行）

### P-01 把画面验收换成"能看的东西"（P0）

**问题**：`measure-frame.py` 的三项（饱和 / 中位 / 高光）是全局统计量，可 PASS 而画面仍难看（用户原话"像十几年前的游戏"），且可被反向优化。
**做法**：
1. 建 **8 机位 × 3 时段 = 24 帧 golden set**（固定种子 / 分辨率 / 隐藏 UI），一条命令出拼图；
2. 指标换成分区结构指标：天/海/陆三区的明度分带数、16 px 块局部对比度中位数、边缘密度、色相分布熵、最大纯色连通块占比；
3. 三项统计量保留为**回归防线**（防爆掉），不作通过判据；
4. 人只看 24 帧拼图 + 10 秒录屏。
**验收**：一次表现层改动 → 5 分钟内得到拼图 + 数字 diff，能判断变好还是变坏。

### P-02 512² 实测，把预算从"目标"变成"数字"（P0）

**做法**：`bench.ps1 -Size=512` + 带渲染 `stat unit` + 首载计时；结果回填 TECH §5 与本节。
**验收**：帧率 / 内存 / 首载 / 分块重建尖峰四项都有数；据此决定默认档是 512 还是 256。

### P-08 形制从"7 个硬编码原型"改成六轴（P0，[WORLD.md](WORLD.md) §2 / §4）

**问题**：代码里 `Archetype` 是 0–6 的固定表（`SolsticeWorldGen.cpp:129-136`），与"形制是参数组合"的规格正面冲突；全海界与全陆界两条路根本走不到。
**做法**：参数化 `topology / shape / rim / water_cover` 四轴；`land_ratio` 恢复为一等参数；`Archetype` 降级为"内部剖面选择"，不对外。
**验收**：同一种子下能产出 全海 / 全陆 / 单岛 / 群岛 / 大陆 五类，`bench` 摘要打印 `topology` 与 `water_cover`。

### P-09 缩放阶梯 Z0–Z4（P0，[WORLD.md](WORLD.md) §1.2 · [ART.md](ART.md) §7）

**问题**：相机只有"距离连续"，没有"级"的概念；近界是 `25 m` 绝对值，与"看得见人"的 Z3 指标对不上（§1.3 要求人 `0.0065 W`）。
**做法**：把滚轮映射到 5 个 Z 级（视野宽 `1.00 / 0.55 / 0.30 / 0.12 / 0.04 W`）；**加 `Z` / `Shift+Z` 正向 / 反向循环**（2026-10-20 裁决）；移轴强度按 [ART.md](ART.md) §7.1 的联动表随 Z 级插值。
**验收**：Z3 下走兽 / 鱼 ≥20 px（M0）、人 ≥40 px（M1）；Z0 下整界进画且界缘有交代；Z4 下能看清苔；四级切换后画面"换调子"而不是放大远景。

### P-10 生态按气候带派生（P1，[WORLD.md](WORLD.md) §9）

**问题**：群系 4 个、物种 5 个是硬编码枚举，`species_pool` 字段没接；每界生态长得一样。
**做法**：生态域判定接七轴；物种池按 §9.3 从模板库抽样；演替顶极由气候带决定。
**验收**：同种子同结果；不同 `climate` 的两个世界在 Z2 能一眼区分（顶极与色板都不同）。

### P-11 卡的作用范围改成 `W` 的分数 + 回收率重算（P0，[CARDS.md](CARDS.md) §4.1 / §7）

**问题**：`radius_m / peak_m` 是绝对米数，违反"比例恒定"（同一张卡在 128² 与 512² 上观感完全不同）；旧回收率（30/50/70 %）配旧包价能套利。
**做法**：曲线改成 `radius_w / peak_w`，落进 `cards.*.json` 与 schema；回收率统一 15 %，0 环 / 超环 / 禁物不可回收；**卡唯一（无重复、无折算）**。
**验收**：`validate-contracts.py` 通过；同一张 5 环卡在 128² / 256² 上占画面比例一致（±2 %）；"买包→全拆"循环净亏。

### P-12 界面与交互重构（P0，六件一起做）

**问题**：① 侧板常驻吃掉 620 px，抽屉版又要开关两次；② 手牌卡 `150×142` 读作按钮；③ 默认 24° 是俯视构图，没有地平线；④ 释放只有"点一下"，无法指定落点；⑤ `R` 换手会给出未获得的卡；⑥ 开局直接进世界，玩家看不到这一界是什么样。

**做法**：
1. **三栏版式**：左 56 功能栏（8 个动作）+ 右 320 信息栏（界 / 响 / 年表 三页签），世界区全宽；抽屉作废（TECH §6.1）；
2. 卡比例 `140×204`（1:1.457），卡面 `2048×2986`（ART §8.1）；
3. 默认机位 `30° + 长焦`，俯仰 15/30/55/88，Z0 限 55°/88°（ART §7）；
4. **释放三种路径**：拖到地面＝指定落点 / 空格＝随机落点 / 上拖＝随机；**回收**：下拖或 `X`（CARDS §8.2）；
5. **手牌只从实体池抽**，`R` 只重抽已有卡，开包是获得新卡的唯一途径（CARDS §8.1）；
6. **创世界面**（缺氧式）：形制列表 + 缩略图 + 气候带 + 世界特征勾选 + 七条判据，进场 0.6–0.9 s 动画（WORLD §4.2）。

**验收**：`docs/PROTOTYPE.html` 全流程可点通；1080p 下 10 张卡在 1472 px 内不压字；拖卡到任意地面位置能落到该点；空格落在随机点；`R` 不会产出未拥有的卡；创世页能看到形制/气候/特征再进入。

### P-13 创世剖面 + 卡唯一 + 两栏定稿（P0，第三轮）

**问题**：① v2 创世是"小地图 + 参数表"，读起来像设置页，不像缺氧的"小行星 → 剖面 + 特征"；② 卡还能重复持有（3 张上限 + 折算），与"卡唯一"冲突；③ 左栏塞了 8 项（含"手牌""摆件"），右栏又要切三个页签。
**做法**：
1. 创世改**纯随机揭示**：**不能选**形制/气候/特征；界面 = 左列 15 行生成日志 + 中央**剖面图**（五层 + 双峰雪线 + 河谷 + 林带 + 地下水 + 洞穴群 + 矿脉簇）+ 右列**抽到的 3–5 条特征** + 顶栏分段坐标（可复制复现）+ 底栏只能重掷（WORLD §4.2）；
2. **卡唯一**：实体池每种 1 张；开包只出未拥有、按档降级；删除重复折算与"回声"（CARDS §8.1 / §9 / §10）；
3. **两栏定稿**：左 56 只放 6 个页面入口 + 1 个摆件开关；右 320 三段不分页签（这一界 / 生态 / 刚刚发生）（TECH §6.1）。
**验收**：创世页不滚动即可看完形制 + 剖面 + 特征；抽 10 包不出现同名卡；右栏在 320×774 内不出滚动条。

### P-14 剖面随形制 / 随特征变化 + 两段转场（P1，表现力）

**问题**：不管掷到哪种世界，剖面都长得一样 —— 群岛、全海、环礁共用一张"单岛图"，读起来像装饰而不是信息；特征只有文字，剖面里看不见。
**做法**：
1. **十种形制十种剖面**（WORLD §4.2 表）：群岛＝三块分开、全海＝无陆地只有礁、环礁＝两侧礁台 + 潟湖、峡湾＝深水槽、裂谷＝V 形断口、内陆湖国＝无海有湖……；
2. **十种特征十种可见变化**：火山锥 + 熔岩脉 / 矿脉加密 / 潮痕 / 悬空陆 / 雷云 + 闪电 / 小岛 / 双月 / 巨木 / 陡壁 / 薄表土；
3. **重掷动效**：0.5 s 尘扫 + 0.6 s 溶解重组；**进界转场**：剖面淡出 → 3D 自雾中升起（0.9 s）→ 顶栏/两栏/手牌依次进入（0.5 s，错峰 0.1 s）。
**验收**：连续重掷 10 次，剖面的形制与特征都不同且能对上文字；1080p 下 12 处标注不重叠。

### P-19 ~~抽取数学：卡唯一推翻了"保底"~~（**已作废**，见 P-25）

> 本节结论建立在"卡唯一"上。2026-10-20 用户修正为"卡是消耗品、可重复抽到"，于是"包数 = 池子 ÷ 张数"不再成立，保底重新变成必需品。数据留档，结论以 P-25 为准。

### P-19-old 抽取数学（历史）

**发现**：卡唯一（每种只有一张）直接决定两件事——

1. **包数 = 池子张数 ÷ 包张数**，概率只能改"开出的顺序"，改不了总数（主包 210 ÷ 5 = 42、至日包 84 ÷ 3 = 28、元素包 33 ÷ 5 = 7）。
2. **所有"N 包必出 X"的保底都是废机制**——每包必然全是你没有的卡。旧表 8 个包里有 4 个写着保底，等于写了四句没用的话。

**模拟**（300 次，主包 5 张 / 权重 70·25·5）：

| 里程碑 | 中位包数 |
|---|---|
| 首张 7+ | 3 |
| 首张 9 | 9 |
| 0–3 集齐 | 24 |
| 4–6 集齐 | 32 |
| 0–9 集齐 | 42 |

**改法**：

- 主包池 **210 张**（删掉 0.5 % 超环死权重——21 张超环配 0.5 %，等于永远抽不到）。
- 至日包 = 7–9 + 超（84 张），**保底改为"必含剩余最多的档"**。
- 两条顺序保护：**前 5 包不出 9 环**、**最后 8 包每包 ≤1 张 7+**（防高环倾泻）。

**验收**：任意时刻开包都是新卡；集齐 231 = 49 包 ≈ 9 小时。

**待核**：主题包（地脉 / 生灵）的子池张数还没数，105 的包价因此未校准；`guard` 与顺序保护尚未进代码。

### P-25 三条口径修正：格子、关系、消耗（P0，[CARDS.md](CARDS.md) §1 / §5 / §8.1 / §9.1）

**用户修正（2026-10-20）**：

1. **231 是"种类"不是"总数"**：每格是一个类别，会不断加新卡；卡总数不封顶。
2. **物种之间的关系也是卡效果**：授粉 / 捕食 / 竞争 / 共生不做隐式模拟，由具体卡表达。
3. **卡是消耗品**：手上同名最多一张，打出去就消失，可以再抽到同一张。

**连带改写**：

| 位置 | 旧 | 新 |
|---|---|---|
| `§1` | 231 = 卡种总数 | **231 = 格子**；每格可扩卡，卡数不封顶；**环级就是稀有度**（格子数不影响概率） |
| `§8.1` | 实体池 / 卡唯一 / 永不重复 | **手牌 + 卡池 + 图鉴**；同名手上 1 张、用掉消失、可重复抽到；图鉴只记"见过" |
| `§9` | 池抽空则降档、集齐不出售 | **永久可抽、允许重复**；保底改为"每 10 包必出 1 张未点亮" |
| `§9.1` | 包数 = 池 ÷ 张数（49 包） | **coupon collector**：50 % / 80 % / 95 % / 100 % = 27 / 50 / 75 / **112 包**（模拟 300 次） |
| `§5` | 生克自然涌现 | 元素生克保留（物理涌现）；**物种关系（授粉/捕食/竞争/共生）改成卡** |

**为什么必须改**：卡可重复之后，"包数 = 池 ÷ 张数"这类结论全部失效；沿用会让经济与图鉴设计建立在错误前提上。

**原型待改**：`S.owned` 仍按"唯一"去重，抽取尚未允许重复、手牌同名未限制（下一轮）。
