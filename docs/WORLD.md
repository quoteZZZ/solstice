# 世界（WORLD）

> 世界是**一座界**：一块自成一个世界的地形，和一片属于它的天。
> 玩家在界外，靠**缩放**从"一枚镇纸"一路推到"看得见一个人"。**屏幕就是这一界的地图。**
> 本文件管：视角与比例、形制、尺度与时间、世界骰、物理法则、地形、水、气候、生态、文明、灾害、生成、年表、术语。
> **卡怎么改世界**见 [CARDS.md](CARDS.md)；**画风与相机实现**见 [ART.md](ART.md)；**代码落点**见 [TECH.md](TECH.md)。

## 1 视角与比例（第一性，先定这一节）

### 1.1 屏幕即地图

界不预设"一座岛"。俯到图纸档（88°）时**整界铺满屏幕，屏幕就是这一界的地图**，四边靠雾 / 云 / 海 / 冰 / 暗渊收口（§2.3）。
**全海界**（只有水）、**全陆界**（没有海岸线）、**群岛界**、**大陆界**都是正式品类，不是边角情况。

**默认视角是"侧看"，不是俯视**：俯仰 `30°` + 长焦压缩（或正交）+ 地平线留在画内——读起来像 2.5D 沙盘，实际是 3D（可八向旋转、可推拉、可切 88° 看地图）。机位参数的真源在 [ART.md](ART.md) §7，本节只管"看到多少"。

### 1.2 缩放阶梯 Z0–Z4（本文件唯一的取景口径）

视野宽 = 屏幕上横向看到的世界宽度，以界宽 `W` 为单位。**只定视野宽，不写米数**；相机距离由 ART §7 的 FOV 换算。

| 级 | 名 | 视野宽 | 必须读得出来 | 不要求 |
|---|---|---|---|---|
| **Z0** | 全界 | `1.00 W` | 形制（有无岛 / 几块 / 边缘怎么收）、海岸线、主要地貌、气候带色调、疆域色块 | 个体、房屋 |
| **Z1** | 区域 | `0.55 W` | 山脉走向、河与湖、群系色块、雪线、聚落与田块位置、城墙 | 人、兽 |
| **Z2** | 生活圈 | `0.30 W` | 树个体、房屋、道路、田垄、鸟群、炊烟 | 面部细节 |
| **Z3** | 个体 | `0.12 W` | **人 ≥40 px 高（1080p，M1 起）**；**M0 的替代验收物：走兽 / 鱼 ≥20 px**；篝火、脚印 | 毛孔级细节 |
| **Z4** | 微观 | `0.04 W` | 苔、露水、昆虫、涟漪、火星、叶脉 | — |

**六条纪律**：

1. **验收只在 Z0 / Z2 / Z3 做**；Z1 / Z4 是连续推拉中的自然结果，不单独验收。
2. **"看得见人"是 Z3 的硬指标**，不是靠把人做小、也不是靠把岛做大。
3. 角度离散、距离连续（ART §7）；**缩放与俯仰解耦**——Z 只改视野宽，俯仰另算。
4. **Z0 只在 55° / 88° 成立**：低角度下 1 个视野宽的世界会露出大片天空与雾，看不到"整界"。
5. 默认 = 俯仰 `30°` + 方位 `0` + **Z2**；`Z` / `Shift+Z` 直跳（PLAN P-09）。
6. 任意 Z 级都不许出现穿地、出界、露空背景。

### 1.3 比例锚（唯一一张尺度表）

所有尺寸按**界宽 `W`** 的分数定义。**米数只是 256² 档的换算示例，不是规格。**

| 对象 | 相对 W | 256² 示例 | 读作 |
|---|---|---|---|
| 山高峰顶 | `0.12–0.25 W` | 31–64 m | 一座山，不是土包 |
| 树高 | `0.030–0.070 W` | 7.7–18 m | 山高的 1/4–1/3 |
| 兽体长 | `0.002–0.006 W` | 0.5–1.5 m | 树高的 1/12–1/20 |
| **人高** | `0.0065 W` | 1.66 m | 树高的 1/8 |
| 房屋 | `0.025–0.045 W` | 6.4–11.5 m | 人的 4–7 倍 |
| 聚落直径 | `0.10–0.20 W` | 26–51 m | Z2 看得见街道 |
| 城邦直径 | `0.30–0.50 W` | 77–128 m | Z1 看得见城墙 |
| 文明疆域 | `0.60–1.00 W` | — | Z0 看得见色块 |
| 地标（最高峰 / 最深湖 / 最长河） | `0.30–0.90 W` | — | 撑起 Z0 的尺度感 |

**三条推论**（写规格不许再违反）：

1. **比例恒定，换档只换 `W`**。512² 不是"同一座岛被放大"，而是"能装下更多块"（§3.2）。
2. **不存在"2 cm 文明"**。人的尺寸由本表定；"远处看不见"由 Z 级解决，不靠缩小人。
3. **新增物种 / 建筑 / 器物必须先在本表占一行**，否则不许进 `species.json` 与资产表。

### 1.4 微缩感从哪来（不是靠把人做小）

| 来源 | 做法 |
|---|---|
| 移轴 / 浅景深 | 上下各 12–18 % 模糊带，**只在 Z0–Z1 生效**，Z3 起减到 0（ART §3） |
| 全界在画内 | Z0 视野 = 1 W，边缘有交代，读作"一整块东西" |
| 尺度物同框 | 山 / 巨树 / 礁群 / 城墙 / 人同时可寻，人只是 40 px 的点 |
| 色彩 | 三色板 + 明度阶梯（ART §1），不做写实反射 |
| **禁止** | 靠缩小生物、靠纸质感、靠玩具化高光（ART 开头红线） |

## 2 形制（随机，不是一种）

### 2.1 六个形制轴

形制不是模板枚举，是六个轴的组合。每次掷骰在这六个轴上取一个值。

| 轴 | 取值 | 决定 |
|---|---|---|
| ① 陆块拓扑 `topology` | 0 块（全海）/ 1 块 / 2–4 块 / 5–12 块（群岛）/ 连续大陆（1 块 ≥85 % 面积） | 有没有岛、有几块 |
| ② 陆块形状 `shape` | 团块 / 长条 / 折枝（半岛 + 峡湾）/ 环（环礁、火山口）/ 破碎 | 海岸线怎么长 |
| ③ 界缘交代 `rim` | 外海 / 雾墙 / 云海 / 深渊 / 冰盖 / 硬切（图纸式） | 地图的边怎么收 |
| ④ 天空 `sky` | 穹顶 / 云顶（无天）/ 洞顶 / 双层天 | 抬头看见什么 |
| ⑤ 垂直结构 `vertical` | 单层 / 双层（地表 + 洞穴）/ 浮空多层 | M2 |
| ⑥ 水覆盖 `water_cover` | 0 %（全陆）/ 5–40 % / 40–80 % / >80 %（水世界） | 有多少水 |
| ⑦ 气候带 `climate` | §8 抽 1 | 这一界的世界基色 |

### 2.2 十种叫得出名字的形制（组合的结果，不是模板）

| 形制 | 判据 | 玩法差异 |
|---|---|---|
| 全海界 | 陆 0 块、`water_cover` = 100 % | 只有礁、浮岛、洋流；陆是施卡造出来的 |
| 全陆界 | `water_cover` = 0 %、无海岸线 | 只有内流湖与河；水卡造海 |
| 单岛界 | 1 块 + `rim` = 外海 | 基准形制 |
| 群岛界 | 5–12 块 | 隔离明显，特有种多（§9.3） |
| 大陆界 | 1 块 ≥85 % + `rim` = 雾墙 / 硬切 | 看不到全貌，靠 Z1 / Z2 走 |
| 半岛界 | 折枝 + 一侧接边 | 一侧是"界外的陆地"，卡不能越界 |
| 环礁界 | 环 + 浅海 | 中间潟湖、外圈礁冠 |
| 峡湾界 | 折枝 + 深水侵入 | 长条水道 + 陡壁 |
| 内陆湖国 | 无海 + 大湖群 | 水源全靠降水与地下 |
| 裂谷界 | 高原 + 深谷贯穿 | 垂直落差是全界最大特征 |

> 这张表是**交流用语**，代码里没有 `enum`。形制由 §4 的参数算出（§12）。

### 2.3 界缘交代（六种，取代"外缘必须是水"）

| 交代 | 表现 | 何时用 |
|---|---|---|
| 外海 | 陆地沉到水位以下，海铺到雾里 | 有水 + 有岛 |
| 雾墙 | 地形直接断在雾里，雾即边界 | 大陆 / 高湿 |
| 云海 | 地形悬空，云从下方涌上来 | `sky` = 云顶 / 浮空 |
| 深渊 | 地形断在暗处，看不到底 | 地下 / 极端高差 |
| 冰盖 | 水或陆收进冰层 | 寒带 / 冰封 |
| 硬切 | 地图式断边 + 暗角收口 | **只允许在图纸档** |

**红线**：界缘必须有交代，不许"凭空没了"；硬切只属于图纸档，其余机位一律要有海 / 雾 / 云 / 冰 / 暗的过渡。

### 2.4 形态判据（七条，任意形制都要过）

| # | 判据 | 口径 |
|---|---|---|
| 1 | 边缘有交代 | §2.3 六选一，不露空背景 |
| 2 | 有层次 | Z0 能读出 ≥2 个高度层或材质层 |
| 3 | 有对比 | 至少一处明暗或冷暖对比 |
| 4 | 有落点 | ≥30 % 可视表面可施卡 |
| 5 | 有尺度物 | 至少一处能读出尺度的对象（山脉 / 巨树 / 礁群 / 城墙） |
| 6 | 无死面 | 不存在占画面 >60 % 且无细节的单一色块（全海界靠波纹 / 礁 / 云影破面） |
| 7 | 三级成立 | Z0 / Z2 / Z3 不穿地、不出界、不露空背景 |

不过 → 换种子重掷（≤64 次）→ 回落安全配方（单岛 / 温带海洋 / 外海）并写进年表。

## 3 尺度与时间

### 3.1 尺寸档（容量档，不是放大镜）

| 档 | 边长 W | 格 | 分块 | 定位 |
|---|---|---|---|---|
| 小界 | 128² | 1 m | 2×2 | 沙盒与跑分基准（**当前代码只有这一档在跑**） |
| 中界 | 256² | 1 m | 4×4 | **基准档**：§1.3 的米数示例按这一档写 |
| 大界 | 512² | 1 m | 8×8 | 容量档：装得下群岛与多文明 |

- **1 格 = 1 m = 100 uu**：格是模拟单位，观感尺度由 §1.3 的比例决定。
- 高度上限 = `0.25 W`（128² → 32 m / 256² → 64 m / 512² → 128 m），量化 0.25 m。**代码当前写死 64 m，对应 256² 档**（[TECH.md](TECH.md) §5）。
- 换档时比例不变（§1.3），变的是**能装多少**（§3.2）。

### 3.2 形制容量（大界为什么不是"同一张图放大"）

| 档 | 陆块上限 | 山系上限 | 聚落上限 | 物种池上界 |
|---|---|---|---|---|
| 128² | 3 | 2 | 2 | 5 |
| 256² | 6 | 3 | 5 | 9 |
| 512² | 12 | 4 | 12 | 16 |

### 3.3 时间

| 项 | 值 | 说明 |
|---|---|---|
| 1 世界日 | 3 真实分钟（1x） | 默认速度 **4x**（45 s/日） |
| **可见变化预算** | **每 20–30 真实秒至少 1 处可感知变化** | 云、浪、风、生长、动物移动、炊烟；这条比年历重要 |
| 1 世界年 | 48 世界日 | 四季各 12 日 |
| 1 季 | 12 世界日 | |
| 快进 | 20x = 9 s/日 | 只加速模拟，不改事件顺序 |

## 4 世界骰（每界一次）

掷骰顺序固定：**形制 → 地貌 → 水 → 气候 → 生命**，每轴一条独立随机流，同种子同世界。

| # | 参数 | 范围 | 分布 | 决定 |
|---|---|---|---|---|
| 1 | `land_ratio` | 0.00–1.00 | 均匀（0 / 1 是正式品类） | 陆海预算：生成器用它二分海岸线 |
| 2 | `topology` | 0 / 1 / 2–4 / 5–12 / 大陆 | 权重 5 : 20 : 40 : 25 : 10 | 岛有几块 |
| 3 | `shape` | 5 类（§2.1） | 均匀 | 海岸线形态 |
| 4 | `rim` | 6 类（§2.3） | 由 `water_cover` / `climate` / `vertical` 派生 | 边缘怎么收 |
| 5 | `compactness` | 0–1 | Beta(2,2) | 团块 ↔ 长条 |
| 6 | `coast_rough` | 0–1 | Beta(2,3) | 平滑岸 ↔ 礁石小湾 |
| 7 | `relief` | 0.35–1.00 | 均匀 | 峰高 = §3.1 上限 × `relief` |
| 8 | `ranges` | 1–4 | 权重 5 : 3 : 2 : 1 | 单脊 / 双脊夹谷 / 三向交汇 / 多列 |
| 9 | `bearing` | 0–180° | 均匀 | 与风向夹角决定雨影 |
| 10 | `water_level` | `0.02–0.10 W` | 均匀 | 浅海多滩 ↔ 深海多崖 |
| 11 | `climate` | §8 的 9 带抽 1 | 均匀 | 世界基色与季节幅度 |
| 12 | `wind_dir` | 0–360° | 均匀 | 沙丘走向、雨影位置 |
| 13 | `veg_density` | 0.30–1.00 | 均匀 | 疏林 ↔ 密林 |
| 14 | `species_pool_size` | 3–16 | 受 §3.2 上界约束 | 这一界能长出几种 |
| 15 | `anomaly` | 0 / 1 / 2 处 | 80 : 15 : 5 | 无 / 一处奇观 / 两处（浮空岛、巨树、永久雷暴） |

**种子码**：`SOL-XXXX-XXXX`（base32，去 `0/O/1/I`）。复现三元组 = `seed + generator_version + size`。
**派生量**（不掷、算出来）：海岸线、峰高、雪线、物种名单、界名、界缘交代。

### 4.1 界名与奇观（让每界有名字、有一处记得住的地方）

**界名** = 2–4 字，`地标词 + 后缀`。后缀由形制 / 气候决定，同种子必同名。

| 形制 / 气候 | 后缀池 | 例 |
|---|---|---|
| 单岛 / 群岛 | 界 / 岛 / 屿 | 灰羽屿、长石岛 |
| 全海 | 海 / 洋 | 无边海 |
| 全陆 / 大陆 | 原 / 陆 | 干风原 |
| 环礁 | 环 / 礁 | 白环礁 |
| 峡湾 | 湾 / 峡 | 碎冰湾 |
| 裂谷 / 高原 | 谷 / 台 | 长裂谷 |
| 内陆湖国 | 湖 / 泊 | 三泊国 |
| 冰封 / 极地 | 雪 / 冰 | 静雪界 |

**奇观 8 种**（`anomaly` 抽中才出现；每处占 `0.05–0.15 W`，必须在 Z0 可见、Z2 有细节）：

| 奇观 | 表现 | 玩法钩子 |
|---|---|---|
| 浮空岛 | 悬在界上方的小块陆，投下移动阴影 | 重力 / 落物规则 |
| 通天巨树 | 一株高过所有山的树，冠层自成天气 | 木系卡、鸟类聚集 |
| 永久雷暴 | 一片不散的雷云，落雷点有焦痕 | 火 + 金属卡 |
| 温泉群 | 蒸汽柱、彩色矿物沉积 | 温度 / 雪线 |
| 天坑 | 深不见底的垂直洞，内部有独立微气候 | 地下生态（M2） |
| 盐柱林 | 干涸盐湖留下的柱状盐晶 | 盐碱域 |
| 双月 | 两颗月亮，潮汐加倍 | 潮汐 / 夜光 |
| 极光带 | 夜间天空的带状光 | 光系卡 |

> 奇观不是装饰：每一处都要能被至少一类卡改写，否则删掉。

### 4.2 创世界面（纯随机揭示：参考《缺氧》的展示方式，但**不能选**）

**核心口径：玩家不能挑世界，只能看 + 重掷。** 形制、气候、特征、奇观全部由骰子决定；玩家能做的只有"再来一颗"或"进入"。

| 区 | 界面 | 内容 |
|---|---|---|
| 顶栏 | 世界名 + 坐标 | 随机生成的界名（2–3 字，如"青石原"）+ **分段坐标** `SOL - CON - URI1 - RI0N`（前缀 / 形制码 / 细节 / 校验）；两个按钮：复制坐标、重掷 |
| 左列 | **这一界是怎么掷出来的** | 15 行生成日志，**按 6 组分段**（形制 / 水 / 地貌 / 气候 / 生命 / 命名·校验），逐条淡入：陆块拓扑 / 形状 / 界缘交代 / 水覆盖 / 陆海比 / relief / 山系数 / 走向 / 气候带 / 风向 / 植被密度 / 物种池 / 奇观 / 界名 / 判据。**每一步都不可选**；顶栏显示"已重掷 N 次" |
| 中央 | **剖面图**（不是俯视小地图） | 天空（日、云、两层远山）/ 双峰 + 雪线 / 河谷 / 林带 / 表层土 / 土壤 / 岩层 / 基岩 五层 + 地下水透镜 + 洞穴群 + 矿脉簇；八处标注 |
| 中央下 | 读数 chips | 水覆盖 / 陆块 / 山系 / 物种池 / 聚落上限 / 奇观 |
| 右列 | **本界特征 3–5 条**（抽到什么就是什么） | 卡片：图标 + 名 + 一句效果 + 类别（资源 / 地貌 / 气候 / 生态 / 天象 / 奇观）。**没有勾选、没有锁定**；下方是七条判据的 PASS 列表 |
| 底栏 | 只能重掷 | "重掷一颗骰子 ⟳" + "进入这一界 ▸"；重掷触发 0.55 s 的溶解重组动画 |

**为什么是剖面而不是地图**：玩家在这一步要判断的不是"地形好不好看"，而是"这界有什么可玩的"——层、水、矿、洞都在剖面上；地图留给进界后的 88° 图纸档（§1.1）。

**剖面必须随形制变**（同一种画法不能套十种世界）：

| 形制 | 剖面长什么样 |
|---|---|
| 单岛界 | 一块居中陆地，双峰 + 雪冠，四周是海 |
| 大陆界 | 陆地顶到左右两边，海岸线进雾，看不到端点 |
| 半岛界 | 左侧陆地、右侧陡崖入海；界外一侧无地形 |
| 群岛界 | **三块分开的小陆**，各自有地层与地下水，之间是海 |
| 环礁界 | 两侧低矮礁台 + 中间潟湖水面；没有山峰 |
| 峡湾界 | 一块陆，中间被一道**深水槽**切开 |
| 内陆湖国 | 无海，地表上有**一个湖**，湖底见地下水 |
| 裂谷界 | 中央一道**深 V 断口**，露出错开的岩层 |
| 全海界 | **没有陆地**，只有礁台露出水面 |
| 全陆界 | 陆地铺满整幅，只有一个内流湖 |

**特征必须在剖面上看得见**（否则特征只是文字）：金属富集 → 矿脉簇变密；地热活跃 → 长出火山锥与熔岩脉；强潮汐 → 水线旁两道潮痕；浮空岛 → 上方多一块悬空陆；永久雷暴 → 乌云 + 闪电；物种隔离 → 水里多两座小岛；双月 → 天空两个月亮；古树群 → 一株高于所有树的巨木；深海崖岸 → 海岸一道陡壁；贫瘠土壤 → 表层土变薄。

**进场动画**（0.6–0.9 s）：黑场 → 剖面淡出、3D 世界自雾中升起 → 天空推入 → HUD 淡入。**不做进度条**（世界本地生成，等不到进度）。

**复现口径**：坐标可复制、可粘贴——**输入别人的坐标是复现，不是挑选**；输入非法坐标时回落到随机并在年表记一行。

```text
  ↓                                       ↓
昼夜温差 ← 水体热容 ← 水体面积         径流 → 侵蚀 → 地形 → 微气候
```

## 7 水

| 水体 | 判据 | 行为 |
|---|---|---|
| 海 | 全域水位以下 | 潮汐、洋流、盐度 |
| 湖 | 洼地积水、无出口 | 静水、可结冰、会淤积 |
| 河 | 沿最陡下降、有流向 | 冲刷、搬运、三角洲 |
| 湿地 | 水位 − 地面 < 0.5 m 且高湿 | 沼泽植被、独立物种 |
| 地下水 | 土壤饱和度 | 影响井、泉、抗旱 |

**循环**：蒸发 → 云 → 降水 → 径流 / 下渗 → 地下水位 → 泉河 → 海。

**两种极端界的处理（都要过 §2.4 第 6 条）**：

- **无水界**：`rim` 不得是外海，边缘用雾墙 / 硬切 / 冰盖；水循环仍闭环，只是没有海这一池。
- **水世界**：陆地是礁、岛、浮岛；Z0 的破面靠波纹、礁冠、云影，否则一整屏纯色。

**潮间带**：海岸 0.5 m 内随潮汐露出 / 淹没，独立植被与物种。

## 8 气候（每界一个带）

**整界只抽一个气候带**：世界只有几百米宽，不可能同时有雨林和冰盖。带内差异来自海拔、坡向、水体、雨影。

| 带 | 温度基线 | 季节幅度 | 特征 |
|---|---|---|---|
| 热带雨林 | 26–28 °C | 小（±2） | 全年生长、多雨 |
| 热带季风 | 24–30 °C | 中 | 旱雨两季分明 |
| 沙漠 | 18–34 °C | 大（昼夜 15+） | 蒸发极强、少植被 |
| 地中海 | 15–26 °C | 中 | 夏干冬雨 |
| 温带海洋 | 8–18 °C | 小 | 湿润、多雾 |
| 温带大陆 | 4–22 °C | 大 | 四季分明、落叶 |
| 寒温带针叶 | 0–12 °C | 大 | 长冬、针叶林 |
| 极地苔原 | <6 °C | 中 | 无乔木、生长慢 |
| 高原 | 按海拔落 | 大 | 强日照、昼夜温差大 |

**海拔修正**：每 `0.02 W` 降 0.6 °C（256² 约每 5 m；最高峰可读出 7–8 °C 的温差，这样才能有雪线）。
**微气候**：坡向（南坡暖 / 北坡湿）、水体缓冲（沿海温差小）、雨影（山脉走向 × 风向）。

**天气状态机**（转移概率升级 / 降级，不随机跳变）：

| 状态 | 进入条件 | 表现 |
|---|---|---|
| 晴 | 默认 | 云量低、降水 0 |
| 多云 | 湿度 >0.4 | 云量升高、无降水 |
| 小雨 | 湿度 >0.6 且 >0 °C | 降水 |
| 雪 | 湿度 >0.6 且 <0 °C | 降水 + 覆白 |
| 暴雨 | 湿度 >0.8 且持续 | 强降水、冲刷 |
| 雷暴 | 暴雨 + 高温 | 闪电可引燃 |
| 雾 | 夜间 + 湿度 >0.7 + 无风 | 能见度下降 |
| 沙尘 | 干旱 + 大风 | 能见度下降、搬运沙 |

### 9.5 七个生态过程

1. **演替**：见 §9.4，顶极由气候决定。
2. **传播**：风（`0.08 W`）/ 鸟（`0.20 W`）/ 水（沿河）/ 兽（带刺种子）。
3. **传粉**：昆虫密度影响植物繁殖率 ±40 %。
4. **捕食**：成功率 × 遮蔽 × 猎物密度。
5. **分解**：尸体 → 地力，延迟 1–3 日。
6. **迁徙**：季节变化触发，向温暖 / 湿润处移动（`0.15–0.40 W` 半径）。
7. **灭绝 / 迁入**：种群 <5 且连续下降 → 灭绝风险；空位 2–5 日迁入。

## 12 生成流程

```text
⓪ 掷骰    种子 → 15 参数（§4）
① 形制    拓扑 / 形状 / 界缘 → 陆地掩膜与预算
② 高度场  大陆场 → 掩膜（按 rim 收边）→ 海陆预算二分 → 地貌省拼接 → 骨架 → 按面积分位定高
③ 水体    水位切湖 / 海 / 湿地；河沿最陡下降切谷；洼地填水；潮汐相位
④ 气候    气候带 → 温度基线；海拔 → 温度梯度；风 → 雨影与沙丘
⑤ 土壤    风化产土；坡度 → 厚度；降水 → 淋溶；蒸发 → 盐碱
⑥ 生态域  七轴阈值逐格判定，按优先级取唯一结果
⑦ 成种    物种池（§9.3）× 域可承载性直接投放 → 第一帧就是活的
⑧ 奇观    按 anomaly 落 0–2 处（§4.1），每处必须 Z0 可见、Z2 有细节
⑨ 命名    取全界最显著地标 → 界名（§4.1）
⑩ 校验    §2.4 七条判据 + 三级成立；不过重掷
⑪ 年表    写入「创世」：种子码 + 参数摘要 + 界名 + 生成器版本 + 双时间戳
```

## 14 术语

| 词 | 含义 |
|---|---|
| **界** | 这一座世界 |
| **界外** | 界壁之外，不可进入，只是观看位置 |
| **界宽 `W`** | 世界边长；一切尺寸按它的分数定义（§1.3） |
| **Z 级** | 缩放阶梯 Z0–Z4（§1.2），验收只在 Z0 / Z2 / Z3 |
| **形制** | 六个形制轴的组合结果（§2.1），十种名字只是交流用语 |
| **界缘交代** | 地图边缘怎么收：外海 / 雾墙 / 云海 / 深渊 / 冰盖 / 硬切 |
| **生态原型界** | 把气候 + 水 + 地形打包成"这界大概长什么样"的 12 种说法（§9.6） |
| **顶极群落** | 该气候带演替终点的群落（§9.4），由气候决定而不是写死天数 |
| **原质 / 元素** | 金木水火土光暗，固定七种 |
| **环级** | 卡的尺度档位 0–9，另有超环与禁物；**越大尺度越大，不是强度** |
| **禁物** | 从界外漏进来的碎片，不带元素标签，只启不养 |
| **余响** | 干涉世界产出的唯一积累物 |
| **释放 / 回收** | 用掉一张卡 / 销毁一张卡换回折扣余响 |
| **扰动** | 世界被改动的累积状态 0–100，不是惩罚 |
| **界名** | 每界一个名字，由地标生成 |
