# 世界（WORLD）

> 世界是**一座界**：一块被切下来的薄圆地，扣着半球形的天空。玩家不在界里，而在**界外最近的岸上**看它。
> 本文件管：形态与尺度、世界骰、生成流程、地块与生态、天气、年表、术语。**卡怎么改世界**见 [CARDS.md](CARDS.md)。

---

## 1 形态

### 1.1 尺寸（世界空间，与相机无关）

以穹顶半径 **R** 为单位。**所有数字是世界尺寸**；屏幕上看到的椭圆是相机投影的结果，不是设计。

| 部位 | 尺寸 | 说明 |
|---|---|---|
| 土地 | **圆盘**，半径 `1.0 R`，厚 `0.03 R` | 极薄，只够切出一条边 |
| 天空 | **半球**，半径 `1.0 R`，底面与土地顶面**同平面共边** | 那条共用圆就是地平线 |
| 切口 | 外缘一圈侧壁，高 `0.03 R` | 单色暗面 `#080B18`，无明暗过渡、无高光 |
| 山 | 峰顶 `0.30–0.55 R`，沿半径 `0.64–0.97 R` 的弧排布 | 山脚跟着地形走，不排成直线带 |
| 林 | 树高 `0.10–0.22 R`，密铺在 `0.55–1.0 R` 的环上 | 远半环先画 |
| 日月 | 画在天空层：月心 `0.66 R`，视直径 `0.21 R` | 是背景，不是可接近的实体 |

### 1.2 五条判据（做形态时逐条对）

1. **土地是圆盘**：俯视是正圆，不是椭圆片。
2. **半球与土地共面共边**：那条圆永远闭合，就是地平线。
3. **切口只有 1 像素级的暗边**：加厚成圆柱、亮起来成墙、卷起来成碗。
4. **地形向上生长**：有山有水才有"世界"，不要压平。
5. **厚度 : 山高 ≥ 1:10**（`0.03R` vs `0.30–0.55R`）。厚度超过山高 1/3，整块地就读成山体——**这是最容易被做错的数字**。

> **天空是体积，不是壳**：靠明度差读出来（界内天空比界外空场亮约 3:1），边缘 1–3 px 柔光即止。禁止玻璃反射、描边、分瓣硬边。
> **切口前提**：地表在 `0.84–1.0 R` 平滑降到水位以下，切口才是"一片地被切开"；不收低就是二十米高的山体断面。

### 1.3 投影规律（正交，俯角 θ）

| 看到什么 | 公式 | 30° | 45° | 65° |
|---|---|---|---|---|
| 地面椭圆（纵/横） | `sinθ` | 0.50 | 0.71 | 0.87 |
| 切口视厚 | `0.03 R · cosθ` | 0.026 R | 0.021 R | 0.013 R |
| 天空轮廓 | 恒为正圆 | — | — | — |

> 参照图：`studio/out/world/world_plate_p30/p45/p65.png`（同一模型换相机）。**不要照参考图的像素比写规格。**

## 2 尺度与分块

| 档 | 尺寸 | 边长 | 分块（64 格） | 定位 |
|---|---|---|---|---|
| 小界 | 128² | 128 m | 2 × 2 | 沙盒与算法跑分基准 |
| 中界 | 256² | 256 m | 4 × 4 | 轻量档（低配 / 快速开局） |
| 大界 | 512² | 512 m | 8 × 8 | **目标默认档**（未验收，见 PLAN P-02） |

- **1 格 = 1 m = 100 uu**；高度 `0–64 m`，量化 `0.25 m`。
- **尺寸是尺度，不是分辨率**：噪声频率按**世界米数**定义（每 100 m 一个周期），**禁止** `U = 格号 / 边长` 归一化。否则 512² 只是把同一张图放大四倍。
- **分块是加载单位**，不是结构单位：高度场是全局函数，块边界不得有台阶；改一格要标记该块**及其接缝**重建。
- 世界外缘**强制收边**：最外 3% 半径压到水位以下，圆盘不许出现断崖边。

## 3 世界骰（每局一个新世界）

开局不选预设，**掷一次骰**：种子派生六条独立随机流，一次抽定一套**世界配方**。

| 轴 | 参数 | 范围 | 决定 |
|---|---|---|---|
| ① 形制 | 海陆比 `land_ratio` | 0.00–1.00 | 多少是陆地（0 / 1 是正式品类） |
| | 起伏 `relief` | 0.35–1.00 | 山有多高（乘在峰高上） |
| | 山脉组数 `ranges` / 走向 `bearing` | 1–3 / 0–180° | 山带的数量与朝向 |
| ② 水体 | 基准水位 / 河流 / 湖泊 / 潮汐 | 3–12 m / 1–4 / 0–3 / 开关+0.5–1.5 m | 海湖河湿地 |
| ③ 气候 | 纬度 / 干湿 / 四季幅度 / 天气倾向 / 风向 | −55–55° / 0.1–0.9 / 0.3–1.5 / 晴旱·温润·多雾·雷暴 / 0–360° | 太阳路径与天气 |
| ④ 生态 | 群系组合 / 植被密度 / 物种池 | 3–6 类 / 0.3–1.0 / 5 取 2–5 | 这一局有哪些景与活物 |
| ⑤ 天象 | 太阳数 / 日月色相 / 月亮数 / 光环极光星密度 | 1–2 / 暖白金冷 / 0–3 / 各开关 | 这一局的天空 |
| ⑥ 时刻 | 季节 / 时刻 | 春夏秋冬 / 黎明·上午·正午·黄昏 | 开局色板与光（**禁止开局全黑**） |

**种子码**：`SOL-XXXX-XXXX`（base32，去 `0/O/1/I`）。复现三元组 = `seed + generator_version + size`；生成器升版必须升版本号。
**开局资源也掷**：手牌从 21 个 0 环卡种里抽 10（保底地形 + 天气各 ≥1）；**余响恒 0**。

### 3.1 七条成立性判据（生成后校验）

| # | 判据 | 口径 |
|---|---|---|
| 1 | 有层次 | 任一机位读出 ≥2 个高度 / 材质层 |
| 2 | 有对比 | 至少一处明暗或冷暖对比 |
| 3 | 有落点 | ≥30% 可视表面可施卡 |
| 4 | 有尺度物 | 至少一个能读出尺度的对象（山体 / 巨树 / 礁群） |
| 5 | 四机位成立 | F1–F4 不穿地、不出界、不露空背景 |
| 6 | 有变化 | 开局 3 真实分钟内至少一次可感知变化 |
| 7 | 无死面 | 不存在 >60% 画面且毫无细节的单一色块 |

不过 → 换种子重掷（≤64 次）→ 仍不过回落安全配方（`land_ratio 0.55 / relief 0.6 / ranges 2 / aridity 0.5`），并把回落写进年表。
**判据只做生成后校验，不做生成时偏置。**

## 4 生成流程

```text
⓪ 掷骰    种子 → 六轴参数
① 高度场  大陆场 → 掩膜（边缘压海）→ 海陆预算二分 → 地貌省拼接 → 骨架 → 按面积分位定高
② 水体    水位切湖/海/湿地；河沿最陡下降切谷；洼地填水；潮汐相位
③ 气候    纬度→太阳路径；干湿→降水；海拔→温度梯度；风→云与风蚀
④ 生态域  五轴阈值逐格判定，按优先级取唯一结果
⑤ 成种    按物种池 × 生态域可承载性直接投放 → 第一帧就是活的
⑥ 校验    七条判据；不过重掷
⑦ 年表    写入「创世」：种子码 + 六轴摘要 + 生成器版本 + 双时间戳
```

**算法真源**：`game/Source/Solstice/Sim/SolsticeWorldGen.{h,cpp}`（移植自 `studio/previews/world-model.html`）。

| 层 | 做什么 |
|---|---|
| L0 大陆场 | 极坐标谐波 + 定向半岛 + 两层海岸噪声 + 海峡 + 离岸岛链 → 距离场 |
| 掩膜 | `smoothstep` 收边 + 外圈强制压海带 → **边缘一定是水** |
| 海陆预算 | 对海岸半径二分，判据是真实高度 ≤ 0，目标面积来自 `land_ratio` |
| L1 地貌省 | 9–13 个省，各自一套剖面，按最近三省指数权重咬合 |
| L2 骨架 | 内陆抬升 + 整体倾斜 + 造山带（排水网的前提） |
| 定高 | 按面积分位重标：平原 / 低丘 / 高丘 / 中山 / 高山各占多少由 `relief` 决定 |

**未移植**（原型有、C++ 没有）：河流填洼汇流、冰川角峰、按省配色。

## 5 地块、水体、生态域

### 5.1 每格字段

| 字段 | 范围 | 说明 |
|---|---|---|
| 高度 | 0–64 m（0.25 量化） | 地表高度 |
| 地表类型 | 草 / 土 / 石 / 沙 / 水 / 雪 / 冰 | 表层材质 |
| 植被量 / 湿度 / 局部温度 | 0–1 / 0–1 / °C | 生态输入 |
| 地力 | 0–1 | 植被消耗、分解者回补；`<0.15` 退化为沙地 |
| 水体类型 | none / lake / river / sea / wetland | 该格属于哪种水体 |
| 流向 | 8 向（仅 river） | 下游方向 |

**光照不存字段**：每 tick 由太阳高度角 + 云量 + 坡向 + 遮蔽算出，供生态域与物种行为使用。

**地力闭环**：生长消耗 → 死亡经分解回补 → 低于 0.15 荒漠化。**山是三层**：外壳（地表+植被，可笔刷改写）/ 岩芯（石，山崩卡的作用主体）/ 矿脉（嵌在岩芯里，土→金相生的物理挂靠）。

### 5.2 水体

- **基准水位**全局一个值；`高度 < 水位` 自动成水体。
- **梯度切海**：把本界噪声值排序，最低的 14% 定为海床，其余重映射到「水位…峰高」。**不写绝对阈值**——写死了某种形制会一格水都没有。
- 湖静态可结冰；河沿流向有坡度（上游高于下游）；海受潮汐 `A·sin(2πt/T)` 驱动；湿地 = 水位−高度 < 0.5 m + 高湿度。
- 卡可以改水体类型、水位、潮汐、流向。

### 5.3 生态域（五轴：温度 × 湿度 × 高度 × 地力 × 光照）

| 生态域 | 温度 | 湿度 | 高度 | 地力 | 阶段 |
|---|---|---|---|---|---|
| 水塘 | — | >0.7 | < 水位+1 m | >0.3 | M0 |
| 草原 | 5–30 °C | 0.3–0.6 | <20 m | >0.4 | M0 |
| 林缘 | 5–28 °C | 0.5–0.8 | <30 m | >0.6 | M0 |
| 岩坡 | — | <0.4 | >25 m | <0.2 | M0 |
| 沼泽 | >5 °C | >0.8 | < 水位+2 m | >0.3 | M1 |
| 沙地 | >15 °C | <0.25 | <40 m | <0.15 | M1 |
| 雪原 | <0 °C | — | >15 m | — | M1 |
| 河谷 | 5–25 °C | 0.5–0.8 | 谷底 + 邻水 | >0.5 | M1 |

**优先级**（同时满足取最高）：水体 → 雪原 → 沙地 → 岩坡 → 河谷 → 林缘 → 草原。
**生态域会自己变**：阈值被穿越就变——这是荒漠化与沼泽化的机制，不是脚本事件。

## 6 环境与天气

**变量**：太阳高度角 / 光照 / 色温、气温、降水、风力风向、云量、湿度、大气含氧量。
**演化**：太阳由纬度 + 季节 + 时刻决定；气温 = 昼夜正弦 + 季节修正 + 海拔梯度（−0.6 °C/100 m）+ 水体邻接；湿度 = 降水升 / 蒸发降 / 邻水升；含氧量按世界日缓慢漂移。

**天气状态机（M0）**

| 状态 | 进入 | 表现 |
|---|---|---|
| 晴 | 默认 | 云量低、降水 0 |
| 多云 | 湿度 >0.4 | 云量升高，**无降水** |
| 小雨 / 雪 | 湿度 >0.6（气温 <0 °C 转雪） | 降水 |
| 暴雨 / 雷暴 | 湿度 >0.8 且持续 | 强降水，闪电可引燃 |
| 雾 | 夜间 + 湿度 >0.7 + 无风 | 能见度下降 |

状态按转移概率升级 / 降级（随湿度、温度、季节变化），**不随机跳变**——天气要有过程感。
**雾只由「雾状态 + 降水」驱动，不许把云量算进雾。**起雾距离按世界半径归一（`Start ≈ 0.35 R`）。

## 7 年表

- **记录**：初雪、第一场雨、首次繁殖 / 捕食、灭绝、迁入、种群新高、极端天气、**玩家每次重大干涉（含卡名）**、模式切换、余响里程碑。
- **结构**：世界钟（第 N 年 · M 日 · HH:MM）+ 现实日期 + 类型 + 涉及 + 一句话。
- **容量** 500 条环形缓冲。
- **定位**：年表是**记忆**，不是奖励清单；也是回滚与因果重演的索引。

## 8 术语

| 词 | 含义 |
|---|---|
| **界** | 这一座微缩世界（圆盘 + 天空） |
| **界外** | 界壁之外；「岸」是界外最近处，**不可进入**，只是观看位置 |
| **原质 / 元素** | 金木水火土光暗，世界的基本材料，固定七种 |
| **环级** | 卡的尺度档位 0–9，另有超环与禁物；**数值越大尺度越大，不是强度** |
| **禁物** | 从界外漏进来的碎片，不带元素标签，只启不养，件件有代价 |
| **余响** | 干涉世界产出的唯一积累物，世界的回声 |
| **释放 / 回收** | 用掉一张卡 / 销毁一张卡换回折扣余响 |
| **扰动** | 世界被改动的累积状态 0–100，不是惩罚 |
| **界名** | 每界一个名字，写在创世年表与世界卡上 |
