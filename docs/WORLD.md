# 世界（WORLD）

> 世界是**一座界**：一座岛、一片延伸到雾里的海、一顶跟着相机走的天空。
> 玩家不在界里，而在**界外最近的岸上**看它。
> 本文件管：形态与尺度、世界骰、物理法则、地形、水、气候、生态、文明、灾害、世界类型、年表、术语。
> **卡怎么改世界**见 [CARDS.md](CARDS.md)；**画风**见 [ART.md](ART.md)。

## 1 形态（以代码为准）

| 部位 | 实际形态 | 尺寸 |
|---|---|---|
| 陆地 | 圆盘状地形 sheet，外缘平滑沉到水位以下 | 半径 `1.0 R` |
| 海 | 环形水面，从岛边一直铺到雾里 | `0.02 R → 60 R` |
| 天空 | **相机附着的穹顶**，半径随相机距离伸缩 | `max(相机距离+1.35R, 63.6R)` |
| 地平线 | 海面远界与雾合成的一条线 | 由雾吞掉 60R 处的边缘形成 |

**没有的东西**（曾经的纸雕形态，已作废）：切口侧壁、底座、厚度断面、圆盘与半球的共用边。

**五条形态判据**：

1. 陆地是圆盘，不是椭圆片。
2. 地形向上生长：有山有水才有“世界”。
3. 厚度 : 山高 ≥ 1:10（`0.03R` vs `0.30–0.55R`）。
4. 外缘必须是水：最外 3% 半径压到水位以下，不出现断崖边。
5. 海天无缝：水面远界由雾接到天空地平线色，不出现硬线。

## 3 世界骰（每局一个新世界）

开局不选预设，**掷一次骰**：种子派生独立随机流，抽定 12 个连续参数。**没有“群岛/大陆”模板枚举**——形态是参数组合的结果。

| # | 参数 | 范围 | 分布 | 决定 |
|---|---|---|---|---|
| 1 | 陆块数 `continents` | 1–4 | 泊松(λ=1.6) | 1 = 大陆，4 = 群岛 |
| 2 | 紧凑度 `compactness` | 0–1 | Beta(2,2) | 低 = 峡湾长条，高 = 团块 |
| 3 | 海岸破碎度 `coast_rough` | 0–1 | Beta(2,3) | 低 = 平滑岸，高 = 礁石小湾 |
| 4 | 起伏 `relief` | 0.35–1.0 | 均匀 | 山高 = `0.30–0.55R × relief` |
| 5 | 山系数量 `ranges` | 1–3 | 权重 5:3:2 | 单脊 / 双脊夹谷 / 三向交汇 |
| 6 | 山系走向 `bearing` | 0–180° | 均匀 | 与风向夹角决定雨影 |
| 7 | 基准水位 `water_level` | 3–12 m | 均匀 | 浅海多滩 / 深海多崖 |
| 8 | 干湿 `aridity` | 0.1–0.9 | 均匀 | 0.1 苔原雨林 / 0.9 荒漠 |
| 9 | 纬度 `latitude` | −55–55° | 均匀 | 太阳高度角 + 季节幅度 |
| 10 | 风向 `wind_dir` | 0–360° | 均匀 | 沙丘走向、雨影位置 |
| 11 | 植被密度 `veg_density` | 0.3–1.0 | 均匀 | 疏林 / 密林 |
| 12 | 区域物种池 `region_pool` | 见 §8 | 按气候抽 | 这一界能长出哪些物种 |

**种子码**：`SOL-XXXX-XXXX`（base32，去 `0/O/1/I`）。复现三元组 = `seed + generator_version + size`。

### 3.1 七条成立性判据（生成后校验）

| # | 判据 | 口径 |
|---|---|---|
| 1 | 有层次 | 任一机位读出 ≥2 个高度 / 材质层 |
| 2 | 有对比 | 至少一处明暗或冷暖对比 |
| 3 | 有落点 | ≥30% 可视表面可施卡 |
| 4 | 有尺度物 | 至少一个能读出尺度的对象（山体 / 巨树 / 礁群） |
| 5 | 四机位成立 | F1–F4 不穿地、不出界、不露空背景 |
| 6 | 有变化 | 开局 3 真实分钟内至少一次可感知变化 |
| 7 | 无死面 | 不存在 >60% 画面且毫无细节的单一色块 |

不过 → 换种子重掷（≤64 次）→ 仍不过回落安全配方，并把回落写进年表。

## 4 物理法则（7 个变量）

所有模拟步长只读这张表，**代码里不写死系数**。规则卡改的就是它（见 [CARDS.md](CARDS.md)）。

| 变量 | 默认 | 范围 | 影响 |
|---|---|---|---|
| `gravity` | 1.0 | 0.3–2.0 | 落体、水波、树高上限、崖壁角度 |
| `heat_transfer` | 1.0 | 0.2–3.0 | 昼夜温差、水体缓冲、火蔓延 |
| `evaporation` | 1.0 | 0.1–3.0 | 湿度、云量、降水 |
| `erosion` | 1.0 | 0.0–4.0 | 山形、河谷、海岸线 |
| `sediment` | 1.0 | 0.0–3.0 | 三角洲、滩涂、湖淤 |
| `weathering` | 1.0 | 0.0–2.0 | 岩石→土、土壤厚度 |
| `insolation` | 1.0 | 0.3–1.5 | 光合、温度、蒸发 |

**主耦合链**：

```text
光照 → 温度 → 蒸发 → 湿度 → 云量 → 降水 → 土壤水 → 植被 → 地力
  ↓                                       ↓
昼夜温差 ← 水体热容 ← 水体面积         径流 → 侵蚀 → 地形 → 微气候
```

## 5 地形（12 种地貌）

每种地貌 = `坡度 × 粗糙度 × 波长 × 岩性` 四个连续参数的区域，不是模板。

| 地貌 | 坡度 | 特征 | 典型占比 |
|---|---|---|---|
| 平原 | <5° | 大片同色，缓 | 25% |
| 丘陵 | 10–20° | 起伏绿色 | 20% |
| 山地 | 25–45° | 岩+雪，明暗强 | 12% |
| 高原 | 顶平 + 边缘陡 | 台地、断崖 | 8% |
| 盆地 | 四周高中间低 | 内流湖 | 5% |
| 峡谷 | 深 V 形 | 深色裂缝 | 4% |
| 悬崖 | >60° | 岩壁、瀑布 | 4% |
| 海岸 | 0–3 m | 沙滩、礁石 | 8% |
| 沙丘 | 风成波长 15 m | 波纹、裸沙 | 3% |
| 喀斯特 | 溶蚀 | 石林、天坑 | 3% |
| 火山 | 锥形 + 口 | 黑岩、熔岩 | 2% |
| 冰川 | 高海拔 + 低温 | 白蓝、冰舌 | 2% |

**土壤四字段**（此前只有一个 `fertility`，撑不起荒漠化与盐碱化）：`thickness / fertility / salinity / erodibility`。

## 6 水（6 种 + 闭环）

| 水体 | 判据 | 行为 |
|---|---|---|
| 海 | 全域水位以下 | 潮汐 ±1.2 m、洋流、盐度 |
| 湖 | 洼地积水、无出口 | 静水、可结冰、会淤积 |
| 河 | 沿最陡下降、有流向 | 冲刷、搬运、三角洲 |
| 湿地 | 水位−地面 <0.5 m 且高湿 | 沼泽植被、独立物种 |
| 地下水 | 土壤饱和度 | 影响井、泉、抗旱 |
| 冰川 | 温度 <0 且高海拔 | 缓慢流动、融水补给河 |

**循环**：蒸发 → 云 → 降水 → 径流/下渗 → 地下水位 → 泉河 → 海。

**潮间带**：海岸 0.5 m 内随潮汐露出/淹没，独立植被与物种。

## 7 气候（5 带 × 4 季 × 8 天气）

| 带 | 纬度 | 年均温 | 特征 |
|---|---|---|---|
| 热带 | 0–23° | 24–28 °C | 雨林、全年生长 |
| 亚热带 | 23–35° | 16–22 °C | 常绿、旱雨季 |
| 温带 | 35–55° | 8–16 °C | 四季分明、落叶 |
| 寒温带 | 55–66° | 0–8 °C | 针叶林、长冬 |
| 极地 | >66° | <0 °C | 苔原、冰盖 |

**海拔修正**：每 100 m 降 0.6 °C。

**天气状态机**（按转移概率升级/降级，不随机跳变）：

| 状态 | 进入条件 | 表现 |
|---|---|---|
| 晴 | 默认 | 云量低、降水 0 |
| 多云 | 湿度 >0.4 | 云量升高，无降水 |
| 小雨 / 雪 | 湿度 >0.6（<0 °C 转雪） | 降水 |
| 暴雨 / 雷暴 | 湿度 >0.8 且持续 | 强降水，闪电可引燃 |
| 雾 | 夜间 + 湿度 >0.7 + 无风 | 能见度下降 |
| 沙尘 | 干旱 + 大风 | 能见度下降、搬运沙 |

**雨影**：山脉走向与风向夹角决定背风侧降水；**洋流**决定同纬度沿岸温度。

## 8 生态（8 群系 × 30 物种库）

### 8.1 群系

| 群系 | 温度 | 湿度 | 海拔 | 代表植物 | 代表动物 |
|---|---|---|---|---|---|
| 水塘 | 任意 | >0.7 | <水位+1 | 藻、芦苇 | 鱼、蛙 |
| 草原 | 5–30 | 0.3–0.6 | <20 | 苔草、野花 | 食草兽、昆虫 |
| 林缘 | 5–28 | 0.5–0.8 | <30 | 灌木、小乔木 | 鸟、狐 |
| 林地 | 5–25 | 0.6–0.9 | <35 | 阔叶/针叶树 | 鹿、掠禽 |
| 岩坡 | 任意 | <0.4 | >25 | 地衣、苔 | 山羊、猛禽 |
| 沼泽 | >5 | >0.8 | <水位+2 | 芦苇、苔藓 | 蛙、水鸟 |
| 沙地 | >15 | <0.25 | <40 | 沙草、仙人掌 | 蜥蜴、甲虫 |
| 雪原 | <0 | 任意 | >15 | 苔 | 极少数 |

**优先级**：水体 → 雪原 → 沙地 → 岩坡 → 沼泽 → 林缘 → 林地 → 草原。

### 8.2 物种库（按营养级，M0 实装 8 种）

| 营养级 | 物种 | 关键参数 |
|---|---|---|
| 生产者 | 苔草 / 灌木 / 阔叶树 / 针叶树 / 芦苇 / 藻 / 地衣 / 仙人掌 | 生长率、耐温、需水、固土 |
| 初级消费 | 昆虫 / 小型食草兽 / 大型食草兽 / 小鱼 / 大鱼 / 食种鸟 | 食量、繁殖阈值、迁徙 |
| 次级消费 | 掠禽 / 狐 / 蛇 | 捕食成功率、领地 |
| 顶级 | 大型捕食者 | 低密度、大范围 |
| 分解 | 真菌 / 细菌（数值场） | 分解速率、地力回补 |
| 共生 | 菌根 / 传粉昆虫 | 互利系数 |

**岛屿生物地理学**：`S ≈ c · A^0.25`。128² 约 8–10 种，512² 约 14–18 种。面积决定丰富度。

### 8.3 七个生态过程

1. **演替**：裸地 → 苔（3 日）→ 草（8 日）→ 灌木（20 日）→ 林（45 日）。
2. **种子传播**：风（20 m）/ 鸟（60 m）/ 水（沿河）。
3. **传粉**：昆虫密度影响植物繁殖率 ±40%。
4. **捕食**：成功率 × 遮蔽 × 猎物密度。
5. **分解**：尸体 → 地力，延迟 1–3 日。
6. **迁徙**：季节变化触发，向温暖或湿润处移动。
7. **灭绝/迁入**：种群 <5 且连续下降 → 灭绝风险；空位 2–5 日迁入。

## 9 文明（3 级 × 5 类型）

| 级 | 条件 | 表现 |
|---|---|---|
| 聚落 | 人口 ≥20 + 水源 + 可耕地 | 几间屋、田块、小路 |
| 城邦 | 3 聚落 + 粮仓 + 道路 | 城墙、市场、神庙 |
| 文明 | 3 城邦 + 文字 | 疆域、都城、纪念碑 |

| 类型 | 地形 | 特长 | 弱点 |
|---|---|---|---|
| 农耕 | 平原/河谷 | 人口快 | 怕旱涝 |
| 游牧 | 草原 | 机动、抗灾 | 怕寒冬 |
| 海洋 | 海岸 | 渔业、贸易 | 怕风暴 |
| 山地 | 山地/高原 | 防守、矿 | 粮少 |
| 森林 | 林地 | 木材、隐蔽 | 怕火 |

**三条轴**：技术 / 信仰 / 武力，由环境压力塑形（灾害多 → 信仰高；资源少 → 武力高）。

## 10 灾害与重生（8 种）

| 灾害 | 触发 | 影响 | 恢复 |
|---|---|---|---|
| 火山 | 地质活跃 + 随机 | 熔岩、火山灰、地力 +50% | 30–60 日 |
| 地震 | 断层带 | 地形位移、建筑倒塌 | 10–20 日 |
| 洪水 | 暴雨 + 低洼 | 淹没、冲刷、淤泥 | 5–15 日 |
| 干旱 | 长期无雨 | 植被枯死、荒漠化 | 20–40 日 |
| 山火 | 干燥 + 火源 | 烧毁植被、地力骤降 | 30–80 日 |
| 瘟疫 | 高密度 + 低卫生 | 种群锐减 | 10–30 日 |
| 陨石 | 极低概率 | 陨石坑、灭绝级 | 100+ 日 |
| 冰川期 | 长期低温 | 雪线下移、海平面降 | 数百日 |

**重生**：灾害 → 演替重启 → 新物种迁入 → 文明重建（可能换类型）。不是失败，是世界重来。

## 11 世界类型（5 种，参数组合而非模板）

| 类型 | 特征 | 玩法差异 |
|---|---|---|
| 标准界 | 岛 + 海 + 穹顶 | 基准 |
| 浮空界 | 无海，云海，岛屿悬空 | 重力可改、坠落风险 |
| 水世界 | 海覆盖 80% | 岛小、文明少、鱼多 |
| 地下界 | 无天空，洞顶 | 光照恒暗、洞穴生态 |
| 冰封界 | 雪线低、海结冰 | 热量稀缺、生长慢 |

类型不是预设：是“海平面 / 重力 / 光照 / 温度”四个参数的极端组合。

## 12 生成流程

```text
⓪ 掷骰    种子 → 12 参数
① 高度场  大陆场 → 掩膜（边缘压海）→ 海陆预算二分 → 地貌省拼接 → 骨架 → 按面积分位定高
② 水体    水位切湖/海/湿地；河沿最陡下降切谷；洼地填水；潮汐相位
③ 气候    纬度→太阳路径；干湿→降水；海拔→温度梯度；风→雨影与沙丘
④ 土壤    风化产土；坡度→厚度；降水→淋溶；蒸发→盐碱
⑤ 生态域  五轴阈值逐格判定，按优先级取唯一结果
⑥ 成种    按物种池 × 生态域可承载性直接投放 → 第一帧就是活的
⑦ 校验    七条判据；不过重掷
⑧ 年表    写入「创世」：种子码 + 参数摘要 + 生成器版本 + 双时间戳
```

**算法真源**：`game/Source/Solstice/Sim/Gen/SolsticeWorldGen.{h,cpp}`。
