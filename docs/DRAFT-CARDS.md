## 合成树

### 主树（7 标签 → 工具 → 能力）

```
石 ──┬── 石斧 ──── 能力「切割」── 猿猴/人 学会「砍树」
     ├── 石锤 ──── 能力「敲击」── 碎石、砸开
     ├── 燧石 ──┬─ 火 ──┬── 炭 ──── 冬季不冷
     │          │       ├── 窑 ──── 陶罐、砖
     │          │       └── 熔炉 ── 铸金
     │          └─ 火 + 土 ── 砖 ── 建房 ×2
     └── 石 + 土 ── 砖

木 ──┬── 木棍 ──── 材料：矛
     ├── 木 + 纤维 ── 弓 ── 能力「远射」── 狩猎
     ├── 木 + 绳 ──── 梯 ── 能力「攀爬」
     ├── 木 + 水 ──── 筏 ── 能力「渡水」
     └── 木 + 骨 ──── 鱼叉 ── 能力「捕鱼 ×2」

纤维 ─┬── 绳 ──┬── 梯
      │        └── 网
      ├── 针（+骨）── 能力「缝制」
      └── 投石索（+石）── 能力「远射（弱）」

骨 ──┬── 骨刀（+石）── 能力「切割（弱）」
     ├── 鱼叉（+木）
     ├── 针（+纤维）
     └── 骨笛 ── 能力「社交」（吸引兽）

土 ──┬── 泥（+水）── 砖
     ├── 陶罐（+水+火）
     └── 窑（+火）── 烧砖

水 ──┬── 泥（+土）
     ├── 筏（+木）
     └── 蒸汽（+火）── 变体

相克 ── 水+火 → 蒸汽（变体）
        光+暗 → 深渊（禁物）
```

### 环级树（同标签三张升一环）

```
苔(0) ×3 → 草(1) ×3 → 灌木(2) ×3 → 树(3) ×3 → 古树(4) ...
```

**这条是"生态演替"的合成版本**：三株同类长成一株更大。
