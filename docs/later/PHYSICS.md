# 物理属性系统（PHYSICS）

> **⏸ 冻结（2026-10-17 文档重构）**：本文件是 **M1 及以后** 的规格，**不参与当前施工、不参与评审、不参与契约校验**。M0 开工时不读它；M1 立项时再解冻并对齐现状。引用它时请注明「M1 设想」。


## 0 本文件管什么 / 不管什么

- **管**：**世界万物的物理表达**——静态属性与动态状态的清单、七原质到物理属性的映射（含**暗 = 吸光**）、分级结算规则、相变与状态转换、**物理系统为卡提供的基础能力清单**、扰动值的世界观解释、涌现示例。
- **不管**：每张卡的**具体功能逻辑**（逐卡定义，见 [`cards.md`](../setting/cards.md) §3 的"逐卡制作"定案）；地块/水体/环境曲线的定义（→ [`WORLD.md`](../setting/WORLD.md) §3）；生态判定（→ [`WORLD.md`](../setting/WORLD.md) §2.2）；渲染表现（→ [`../art/art.md`](../art/art.md)）。
- **来源**：2026-10-15 第 36 轮裁决新建——"世界的所有物品有物理属性，以便模拟真实世界"。

> **★第一原则（2026-10-15 第 37 轮纠正）：元素是卡的设定语言，与世界模拟无关。**
> 世界本体没有"元素实体"——模拟只认**物理量**（温度、含水量、光照、密度…）。卡上的元素标签是世界观包装；§4 的映射表是**翻译表**（把卡层语义翻译成物理量写入），**不是世界的组成方式**。

## 1 总则：全量定义 + 分级结算

> **所有实体与地块都有物理属性**；**结算按代价分级**，不是所有属性所有时刻都在算。

| 层 | 内容 | 结算方式 |
|---|---|---|
| **常驻粗结算** | 温度 · 含水量 · 燃烧 · 相变 · 浮力（**格子级**） | 每 tick，随 SimLOD 降频 |
| **事件精结算** | 崩塌 · 碎裂 · 溅射 · 倒伏（**涉事实体**） | 仅事件发生时 |
| **注视精结算** | 个体级细节（特写机位附近，可选） | 跟随相机（[`../gameplay/UI-UX.md`](UI-UX.md) §2.3） |

**生物实体同样带物理属性**（体温、含水量、燃烧态…），与格子系统共用同一套属性字典（[`SPECIES.md`](SPECIES.md) §1 的存活约束即由这些属性驱动）。

## 2 静态属性（生成期由"元素配比 + 材质"定）

| 属性 | 单位 / 范围 | 驱动什么 |
|---|---|---|
| 质量 / 密度 | kg、kg/m³ | 崩塌、沉浮、堆积、散体行为 |
| 硬度 / 强度 | 阈值 | 破坏、碎裂、风化 |
| 刚性 ↔ 流体性 | 序 | 造物板刚体 · 水流体 · 沙散体 |
| 可燃性 / 燃点 | 0–1、°C | 火的蔓延与自持 |
| 比热容 / 导热 | — | 升降温快慢（金属烫得快凉得快） |
| 反照率 | 0–1 | 吸热与雪线反馈 |
| 透水性 | 0–1 | 湿度渗透、泥化 |
| **元素配比** | 七原质比例 | **上面一切的来源**：配比变，属性跟着变 |

## 4 七原质 ↔ 物理量翻译表（卡层语义 ↔ 世界模拟）

> 本表把**卡层语义**翻译为**物理量写入**；世界本体由物理量构成，不存在元素实体（§0 第一原则）。

| 原质（卡层语义） | 翻译结果（物理量） |
|---|---|
| **金** | 高密度 · 高导热导电 · 高硬度 · 不可燃——**能量的快速通道** |
| **木** | 中密度 · **可燃** · 低导热 · 透水——**储存了阳光的燃料** |
| **水** | 流体 · 高比热容 · 相变 0°C / 100°C——**温度的缓冲垫** |
| **火** | **不是物质，是"高温 + 燃烧过程"本身**——火的本质 = 向实体注入能量 / 点燃可燃物 |
| **土** | 可塑 · 散体 · 密度中——**形状的承载者** |
| **光** | **辐射能**——加热 · 供光合 · 显形 |
| **暗** | **吸光**（★定案）：**纯效果，无实体**——阴影 / 遮蔽处反照率记 0、吸收辐射、局地降温；光照恢复暗即散（**不做暗浓度场**，第 37 轮）。暗在**光照轴**（[`WORLD.md`](../setting/WORLD.md) §2.2 五轴）上有作用点，**喜暗物种的栖息条件 = 光照轴低值**；**光暗生克因此是物理必然**（暗克光 = 吸收辐射；光克暗 = 辐射填平低照区） |

> **生克 = 属性结算的自然涌现，不逐卡特判**：火克金 = 金属高导热 → 升温到熔点 → 真的熔成液态；金生水 = 高导热的冷金属面使水汽凝露；水克火 = 比热容吸热 + 隔氧。生克表（[`cards.md`](../setting/cards.md) §8）是世界观表述，**结算走本文件的属性方程**。

## 5 相变与状态转换（初值表）

| 转换 | 条件（初值） | 结果 |
|---|---|---|
| 水 → 冰 | 格温度 < 0 °C | `地表类型` 覆冰 · 河湖封冻 · 体积微胀（可裂石） |
| 冰 → 水 | ≥ 0 °C | 融雪 · 春洪 |
| 水 → 汽 | 格温度 > 100 °C 或强日照 | 蒸发 → 湿度↑ → 云量↑ |
| 岩 → 熔 | > 700 °C（岩浆注入 / 高热） | 液态岩浆流入低处，冷却成岩 |
| 可燃物燃烧 | 局部温度 > 燃点 且 有可燃性 | 明燃 → 蔓延（受风、湿度、含水量调制） |
| 烧尽 | 可燃物耗尽 | 灰烬 → **回补地力**（与 [`WORLD.md`](../setting/WORLD.md) §3.1 地力闭环衔接） |

> 数值全部是初值，调参不改结构。

## 6 物理系统为卡提供的基础能力（与"逐卡逻辑"的关系）

**每张卡的模拟效果 = 该卡特定的功能逻辑，逐卡定义**（如"山崩"卡让某座山崩塌；法则类卡改写世界常量）——**卡不收敛为"属性写操作"**。物理系统是这些逻辑**调用的基础能力层**：

| 基础能力 | 说明 | 典型调用者 |
|---|---|---|
| 属性写 | 改密度 / 反照率 / 硬度 / 可燃性… | 世界规则卡、演化卡 |
| 状态转 | 点燃 / 熔化 / 冻结 / 泥化 | 温度与能量卡、天气卡 |
| 常量改 | 重力 / 生长率 / 时间流速 / 大气成分 | **律类卡（`law`，改写世界常量的那一支）** |
| 地形操作 | 抬升 / 挖掘 / 平滑 / 崩塌 | 地形地貌卡 |
| 生态操作 | 投放 / 迁移 / 灭绝 / 演化压力 | 生命类卡 |
| 时间操作 | 快进 / 倒带 / 局部时间泡 | 时间与因果卡 |
| 记录操作 | 年表写入 / 命名 / 立碑 | 记录类卡 |

> **逐卡设计的职责**：把"这张卡做什么"翻译成上面 7 类能力的**调用序列 + 作用域 + 参数**——这正是逐卡制作时登记的"效果 / 数值 / 动画"（[`cards.md`](../setting/cards.md) §3）。

## 7 涌现示例（设定自检用，也是宣传素材的来源）

| 现象 | 物理链条 |
|---|---|
| **火克金真的熔金** | 高导热 → 升温过熔点 → 液态流动 → 冷却成矿锭 |
| **雪线正反馈** | 雪反照率高 → 吸热少 → 更冷 → 保持积雪——可被"气温基线"卡打破 |
| **浮空岛** | 密度被改到低于空气 → 上浮（浮力属常驻粗结算） |
| **重力卡牵全身** | 改 g → 河流变慢 · 鸟飞更高 · 沙丘塌得更缓 |
| **暗区生态位** | 暗浓度高 → 反照率 0 · 辐射被吸 → 光照轴低值 → 喜暗物种栖息 · 一般植被死亡 |

## 8 扰动值的世界观解释

**扰动 = 当前界物理状态偏离自然基线的总量**（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §3）：注入的热、抽走的水、改掉的密度都是对基线的偏移。偏离越大 → 天气越极端、奇观越多。世界观表述为"元素配比失衡"（卡层语言），**模拟层就是物理量偏离度**。
