## 1 物种模板（JSON 契约草案，P1 定稿）

| 字段 | 说明 |
|---|---|
| `id` | `sp.<名>`（如 `sp.moss-grass`） |
| `角色` | 生产者 / 消费者 / 分解者 |
| `体积` | **占地格数 + 体高 / 体长（m）**（见 §2） |
| `寿命` / `成熟期` | 以**世界日**计 |
| `繁殖能量阈值` / `繁殖环境条件` | 能量与温度 / 湿度 / 水位条件 |
| `食性` | 目标（物种 / 植被量 / 地力）+ 效率 |
| `移动速度` | m / 世界秒 |
| `栖息偏好` | 生态域白名单（[`WORLD.md`](../setting/WORLD.md) §2.2） |
| `温度耐受` / `光照需求` / `水位需求` | 存活约束 |
| `死亡掉落` | 回补对象（**分解者回补 `地力`**，见 §3） |
| `感知范围` | 格数（不做全局寻路） |
| `遗传字段` | 体型 / 色彩 / 特化（演化用，M2） |
| `视觉` | 几何生成器 id + 部件集 + 着色组（[`../art/art.md`](../art/art.md) §1） |

> **契约落位**：`shared/schema/species.schema.json`（🟡 计划中）→ 运行时 `game/Config/Solstice/Data/species.json`。
> **几何与外观**：物种 3D 主体由**程序化几何生成器**产出，**不做建模**；动画同样程序化（铰链运动 / 低频摆动 / 顶点位移）。

## 2 M0 五个物种（★含尺寸）

| # | 角色 | 定位 | **占地 / 尺寸** | 关键机制 |
|---|---|---|---|---|
| 1 | 生产者 | **苔草**：基础植被 | **不占个体格**——它是 `植被量` 的表现（覆盖层） | 提高 `植被量`；**消耗 `地力`**；需光照与水；低温停长 |
| 2 | 生产者 | **灌木**：慢生、提供遮蔽 | **1 格**，高 0.6–1.2 m，冠幅 1 格 | 提升同格 `湿度`、提供庇护；**消耗 `地力` 更快** |
| 3 | 消费者 | **走兽**：食草 | **1 格**，体高 0.5 m / 体长 0.8 m | 吃 `植被量`、饮水、夜休；繁殖需植被阈值 |
| 4 | 消费者 | **掠禽**：食肉 | **1 格（栖息）**；飞行时跨格，体长 0.4 m / 翼展 0.8 m | 捕食走兽；**雨雪天活动下降** |
| 5 | 消费者 | **溪鱼**：水生 | **1 格**，只在水体格（`水体类型 ≠ none`），体长 0.2 m | 水温敏感；随水位迁移；**退水时搁浅** |

**为什么尺寸要写死**：物理尺度是 **1 格 = 1 m**（[`WORLD.md`](../setting/WORLD.md) §2.1）。走兽半米高、苔草是"一片覆盖"——**视觉上正好是"一只微缩箱里的低模小动物"**。尺寸同时决定：单体几何的预算、碰撞与遮挡、`个体预算 500–1200` 的空间含义。

**M0 没有分解者**（角色缺一席）：M0 的"分解"由** abiotic 规则**承担——**每个世界日按固定速率把 `地表类型` 的有机部分回补为 `地力`**；真正的分解者物种在 M1 加入（[`../plan/ROADMAP.md`](../plan/ROADMAP.md) §1）。

### 2.1 物种模板初值（★v2.2 新增，初值可调）

> **开局即成种（★2026-10-17 第 54 轮，取代原「混沌初态」）**：世界**第一帧就是活的**——生成流程第⑤步直接按**物种池 × 生态域可承载性**投放初始种群（[`WORLD.md`](../setting/WORLD.md) §3.3）。哪些物种出现、各有多少、落在哪片生态域，由该局的**世界骰**决定（§2.4 生态轴），不是玩家播种。本表数值是**模板初值**；同一物种在不同生态域下按存活约束自行兴衰分布。「生命与生态」类卡的作用因此改为**影响已有种群**（引入新物种 / 压制 / 催生），不再承担"从零引入生命"。

| 物种 | 模板初值 |
|---|---|
| **苔草**（覆盖层） | 生长 +0.02 植被量 / 世界时（需光照 >0.3 + 湿度 >0.3）；适温 10–28 °C；<0 或 >38 °C 停长；地力消耗 0.01 / 世界时 |
| **灌木**（1 格） | 成熟 15 世界日 · 寿命 120 日；繁殖 = 邻格植被 >0.6 且湿度 >0.45，每 8 日撒 1 苗；地力消耗 = 苔草 ×2；同格湿度 +0.05 / 日 |
| **走兽**（食草） | 能量 100 满 · 消耗 1 / 世界时；进食 +0.03 植被量 / 世界时；能量 <30 强制觅食、=0 饿死；繁殖 = 能量 >70 且植被 >0.5 → 孕 5 日产 1 崽（−40 能量）；寿命 90 日；昼行夜休，移速 2 格 / 世界时；距水 >8 格 3 日脱水 |
| **掠禽**（食肉） | 捕食走兽成功率 30%；饥饿耐受 4 日；觅食半径 30 格；繁殖 = 累计捕食成功 3 次 → 产 1 卵（10 日孵）；雨雪天活动 −50%；寿命 70 日；巢限岩坡 |
| **溪鱼**（水生） | 只活在水体格；水温 4–26 °C 外死亡；离水 1 日搁浅死亡；繁殖 = 春季 + 水温 >15 °C → 产 3 尾；寿命 40 日；移速 3 格 / 世界时 |

> **节奏自检**：健康小界约 10–15 个世界日（≈ 半小时真实时间）出现完整"生—捕—死—分解"循环。
> **种子雨**（防永久死局，§3）：物种灭绝后每 **30 世界日 10%** 概率外来迁入 1–2 个体。

## 3 交互与种群动力

**固定 tick 顺序**：

```text
环境更新 → 生产者生长 → 消费者决策（有限状态机 + 局部感知）
        → 进食 / 被捕食 → 繁殖 → 死亡 → 分解回地力
```

- 消费者**不做全局寻路**（性能与可复现）。
- **承载力由 `植被量` 与 `地力` 共同决定**：植被长得多、地力耗得快 → 地力跌破 0.15 → 该格退化为**沙地**生态域（[`WORLD.md`](../setting/WORLD.md) §2.2 / §3.1）。
- **分解回地力**是闭环的最后一环（M0 用 abiotic 规则，M1 起由分解者物种承担）。
- **"无失败"落到机制**：物种灭绝后仍可由"**种子雨**"（每 N 世界日小概率外来迁入）自然恢复；开启演化时还会分化出新形态。

> 可复现性约束（固定逻辑 tick、随机数分流域、按显式 ID 升序遍历）见 [`../tech/tech.md`](../tech/tech.md) §2.2。

## 5 因果可读性（硬要求）

1. 每次死亡带**原因枚举**（饿死 / 被捕食 / 冻死 / 淹死 / 老死）并短暂显示图标。
2. 种群崩溃必须给出**主导原因**并写入年表（[`WORLD.md`](../setting/WORLD.md) §4）。
3. **验收**：随机抽查 10 次死亡，玩家都能从画面读出死因（[`../plan/ROADMAP.md`](../plan/ROADMAP.md) §2 第 10 条）。
