# 用户自定义 · 界创建向导与创世面板（CUSTOMIZE）

> **⏸ 冻结（2026-10-17 文档重构）**：本文件是 **M1 及以后** 的规格，**不参与当前施工、不参与评审、不参与契约校验**。M0 开工时不读它；M1 立项时再解冻并对齐现状。引用它时请注明「M1 设想」。


## 0 本文件管什么 / 不管什么

## 1 界创建（★第 54 轮改写：一键掷骰 + 高级面板）

**两层，默认只露第一层**：

| 层 | 玩家做什么 | 发生什么 |
|---|---|---|
| **一键（默认）** | 点「新世界」 | **掷一次世界骰**（[`../setting/WORLD.md`](../setting/WORLD.md) §2.4）→ 生成 → 直入；尺寸 **512²**，六轴（形制 / 水体 / 气候 / 生态 / 天象 / 开局时刻）**全随机** |
| **高级（可选）** | 展开后逐组改 | 9 组参数，**每组可"锁定"**——锁住的轴不掷，其余照掷（见下"锁定掷骰"） |

> **设计意图**：默认路径必须**零决策**。玩家点两下就站在一个没见过的地方；想较真时才展开参数。**9 步向导从"必经流程"降级为"可选面板"**——这是第 54 轮的核心改动。

**锁定掷骰（Lock & Roll）**：每一组参数旁边有一个锁。锁上 = 这组按你写的值固定，其余组继续掷。这是"我要一片有雪山的雨林，但别的随便"的唯一表达方式，避免玩家为了一个偏好去填 9 页表单。

| 组 | 内容 | 选项 / 取值 |
|---|---|---|
| 1 | **尺寸与形制** | 128² / 256² / **512²（默认）**；海陆比、起伏度、山脉组数、主走向、台地·盆地·裂谷 |
| 2 | **风格主题** | T1 动画赛璐璐（**唯一**；运行中可换，见 [`../art/art.md`](../art/art.md) §0.1） |
| 3 | **种子码** | `SOL-XXXX-XXXX`：留空 = 随机；填入 = **完全复现那个世界** |
| 4 | **水体** | 海 / 湖 / 河 / 湿地 / 群岛的倾向；基准水位；潮汐开关与振幅 |
| 5 | **气候** | 纬度、干湿基调、四季幅度、天气倾向（晴旱 / 温润 / 多雾 / 雷暴）、主导风向 |
| 6 | **生态与物种** | 生物群系组合、植被密度、**物种池（默认 5 种全开）** |
| 7 | **天象** | 太阳数、日月色相与亮度、月亮数、光环 / 极光 / 星密度 |
| 8 | **开局时刻与资源** | 季节、时刻（黎明 / 上午 / 正午 / 黄昏）；开局手牌与首包命题（见 §1.3） |
| 9 | **法则与时间耦合** | 预设（标准 / 低重力 / 高重力 / 慢时光 / 快生长）或逐项；真实 / 虚拟模式、比例、联网与否 |

> **原来的第 8 步「生命种子」已删除**（第 54 轮）：世界开局即有完整生态，生命不是"玩家撒下去的"，而是**骰子掷出来的**——它属于世界，不属于操作。物种池改成"这一局会有哪些活物"，仍是参数，但**没有"是否播种"这个开关**。

### 1.1 首次启动流程（★第 54 轮：开场 + 世界卡 + 直入）

1. **穹顶开场**（约 10 秒）：从罩外高空推进——穹顶渐显 → 越过天顶渐隐处 → 落到 F1 全景机位（[`UI-UX.md`](UI-UX.md) §2.3）；
2. **同时掷骰**：开场动画期间世界已在生成，**不留加载条**；
3. **世界卡浮层**（约 4 秒后淡出，可点击展开）：一张小卡，三行字 +
   - 地貌标签（例：`双列山脊 · 河谷切割`）
   - 气候标签（例：`温带湿润 · 多雾`）
   - 天象标签（例：`单日 · 双月 · 有光环`）
   - **种子码** `SOL-7F3A-91C2`（可点击复制）
   - **「重掷」**（一次点击换一个世界，不消耗余响）
4. **直入世界**：世界已在跑，手牌已备好（开局实体池见 [`INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.6）；第一次释放有**纸片箭头**轻引导（一次性，无弹窗）。

- **首启问卷取消**（第 54 轮）：原 4 问里的"预设 8 选 1"随"随机世界"作废；语言按系统检测；**时间模式沿用既有默认**（[`TIME.md`](TIME.md) §2），首启不问，面板可改。
- **之后每次启动**：直接回到上次的界；主菜单为极简覆盖层（继续 / 新世界（掷骰）/ 设置）——首帧永远是世界。
- **设置页最小集**：音量四总线（占位）· 动画降级 · 语言 · 纬度城市 · 画质。

### 1.2 重掷与复现

| 动作 | 规则 |
|---|---|
| **重掷** | 丢弃当前世界、按其锁定轴重新掷一次；**只在"新世界"或"开局 60 秒内"可用**（之后世界已经跑出记忆，重掷等于删档）；不消耗余响 |
| **换种子码** | 输入别人的 `SOL-XXXX-XXXX` → 生成**完全相同的世界**（同 `generator_version`） |
| **回到上一局** | 从主菜单"继续"读存档，不重掷 |

### 1.3 开局资源（★第 54 轮：也掷）

| 项 | 规则 |
|---|---|
| **开局手牌** | 从 21 个 0 环卡种里随机抽 10 张，**保底含地形类 + 天气类各 ≥1**（[`INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.6） |
| **首包命题** | 第一个元素包从土 / 火 / 金里随机（M0 卡池范围），决定你第一次开包先见到哪一支 |
| **开局余响** | **恒为 0**，不随机（[`ECONOMY.md`](ECONOMY.md)） |

> 卡侧的随机只到"先见到什么"，**不到"能不能玩"**——0 环免费无限补池，保底手牌保证第一分钟就有地形与天气可动。

## 2 世界配方库（原「出厂预设 8 个」）

**配方 = 一撮锁定轴，不是一整个固定世界**。点一个配方 = 用它锁住几组参数，其余照掷：

| 配方 | 锁住什么（其余随机） |
|---|---|
| **四季常态**（默认） | 无锁定——纯随机 |
| **永夏雨林** | 气候：高热高湿；生态：林缘 / 湿地 |
| **永冬苔原** | 气候：低温；生态：雪原；天象：冷白日光 |
| **沙漠绿洲** | 气候：极干；水体：仅湖泊 |
| **群岛潮汐** | 形制：海陆比 0.35；水体：潮汐开 |
| **浮空岛** | 形制：多岛 + 高起伏（M2 配方，需重力参数支持） |
| **倒置世界** | 法则：重力反向（M2 配方） |
| **无昼夜深渊** | 天象：无日；光：恒定低照度（M2 配方） |

> 预设是**参数集**，与风格主题**正交**——预设决定"世界怎么长"，主题决定"用什么皮渲染"（当前只有 T1，见 [`../art/art.md`](../art/art.md) §0.2）。
> **种子码不写进配方**：配方是"想要什么类型"，种子码是"那一次的具体结果"。

## 3 运行中的「创世面板」

- **风格主题随时换**（当前只有 T1；换皮是纯表现层，**不重置世界**，见 [`../art/art.md`](../art/art.md) §0.1）。
- 所有法则参数**实时可改**：重力、时间比例、生长率、衰变率、繁殖率、熵、因果延迟…
- 所有现实输入**可接管 / 可释放**（[`TIME.md`](TIME.md) §4.2）。
- **重掷与种子码**：面板里常驻"当前种子码（可复制）+ 输入种子码 + 重掷本界"三项——重掷按锁定轴重来，**不消耗余响**（§1.2）。
- **锁定轴清单**：面板里能看见"这一局哪些轴是锁的、哪些是掷的"，避免玩家忘了自己锁过什么。
- **"把当前界存为预设"** → 复用为下次创建的模板。
- **生效规则清单**（★待补）：玩家用「律」类卡写下的触发规则当前有哪些在跑、哪些被现实接管，应在此面板统一查看与停用。

## 4 存档分层与导入导出

```
一界 = 元数据(JSON) + 地形分块快照 + 生态快照 + 法则集合 + 卡池与历史 + 年表
```

支持：**复制界、导入 / 导出文件、模板保存**。**不做线上分享与工坊**（[`../charter/CHARTER.md`](../charter/CHARTER.md) §2）。

- 存档版本化键：`solstice.save.v<n>`，**每界一份**（[`../tech/tech.md`](../tech/tech.md) §6）。
- 导出位置：`%USERPROFILE%\Documents\Solstice\Exports\<realmId>.solstice`。
- **多界并存**与"只推演激活界"见 [`../setting/WORLD.md`](../setting/WORLD.md) §2.3。
- **导出携带"世界故事"摘要（✅2026-10-15 定案）**：界名 + 出生日期（双时间戳）+ 年表精华（条数与挑选规则 P1 定稿，[`../setting/WORLD.md`](../setting/WORLD.md) §11）。
