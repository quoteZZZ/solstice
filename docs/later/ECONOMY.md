## 1 设计目标与节奏锚点

| # | 目标 | 数值含义 |
|---|---|---|
| 1 | **活跃玩时：每 5–10 真实分钟能开一个包** | 产出 ≈ **7–14 余响 / 真实分钟** |
| 2 | **挂着看：2–3 小时能攒一个包** | 沉淀 ≈ **18–30 余响 / 真实小时** |
| 3 | **离线不产出**（世界暂停、无补偿推演） | 经济只挂在**在线真实时长**上 |
| 4 | **数字不膨胀**（§6 的五道闸） | 无复利、无无限源、产出速率有天花板 |

**"真实时间"是经济的时间单位**——不是世界日。这条同时解决"加速刷钱"与"挂机刷钱"。

## 2 余响的产出（三源）

### 2.1 事件回响（主源）

**触发**：干涉使世界**跨过阈值**并写入年表。

| 幅度 | 典型干涉 | 余响 |
|---|---|---|
| **微小** | 一片苔、一粒沙、一滴水 | **1–3** |
| **小** | 一小片草地、一丛树、一口塘 | **4–10** |
| **中** | 一座丘、一段溪、一次天气过程 | **12–25** |
| **大** | 一道山脉、一条大河、一片林、种群剧变 | **30–60** |
| **剧变** | 一个气候带、物种灭绝、整界规则 | **100–400** |

**三条限流规则（防刷，逐层收紧）**：

| 层 | 规则 | 作用 |
|---|---|---|
| **① 阈值本身** | 只有"让世界真的变了"才给——**同一区域被改过之后，再改同样的东西不跨阈值** | 天然衰减（§6 闸一） |
| **② 同卡种冷却** | 同一卡种在 **1 世界日内**第 2 次 50%、第 3 次 25%、第 4 次起 **0%** | 防"0 环无限补池刷同一张" |
| **③ 速率上限（★新增）** | **事件回响每分钟最多 20 余响**；超出部分只给 **25%** | 一劳永逸：**换着卡刷、加速刷都撞这道墙** |

> ③ 同时也是"**倍率不产钱**"的第二重保证：限流按**真实分钟**计，20x 加速不会放宽它。

### 2.1.1 偏移幅度（offset）的测量公式（★初值提案，2026-10-15）

上表"幅度"档位由**归一化偏移量 offset** 决定（公式将进契约，逐卡无需再发明"幅度"）：

```text
offset = 0.5 × √(改动面积 / 界面积) + 0.3 × (最大高度变化 / 64 m) + 0.2 × 生物量变化比
```

| offset | 档位 | 余响 |
|---|---|---|
| < 0.05 | 微小 | 1–3 |
| 0.05 – 0.15 | 小 | 4–10 |
| 0.15 – 0.30 | 中 | 12–25 |
| 0.30 – 0.60 | 大 | 30–60 |
| ≥ 0.60 | 剧变 | 100–400 |

> 权重（0.5 / 0.3 / 0.2）与分界为**初值提案**，调参不改结构；三项量纲归一，保证不同效果类型（地形 / 生态 / 天气）可比。

### 2.2 沉淀回响（次源）

```
沉淀（余响） = 生态势能 × 0.5 × 真实分钟
生态势能 = 生物量 × 多样性 × 稳定度      （各 0–1 归一化，乘积 0–1）
```

| 世界状态 | 势能 | 产出 |
|---|---|---|
| 荒芜（刚创建） | ~0.05 | 1.5 / 小时 |
| 健康的小界 | ~0.6 | **18 / 小时** |
| 繁盛的大界 | ~1.0 | **30 / 小时（上限）** |
| **动荡（扰动 > 60）** | **×0.5 惩罚** | 最多 15 / 小时 |

**三因子的计算定义（★初值提案，2026-10-15）**：

| 因子 | 定义 |
|---|---|
| **生物量** | Σ(个体生物量) / 个体预算（预算见 [`../setting/WORLD.md`](../setting/WORLD.md) §2.1） |
| **多样性** | 有效物种数（辛普森倒数 1/Σpᵢ²）/ 现有物种种数 |
| **稳定度** | clamp(1 − 扰动/150, 0, 1)；闸四"扰动 > 60 再 ×0.5"在此之上独立叠加 |

> **稳定性即产能**：干涉越猛 → 扰动越高 → 稳定度越低 → 沉淀越少。**这是"放任世界进入剧烈"的真实代价**（不是失败，但有经济后果）。

### 2.3 初见回响（一次性）

| 现象 | 余响 |
|---|---|
| 首次下雨 / 初雪 / 第一场雾 | **20** |
| 首次繁殖 / 首次捕食 / 首次死亡 | **25** |
| 首次灭绝 / 首次物种迁入 | **40** |
| 首次分化（演化） / 首次触发卡生效 | **50** |

一次性，**不可重复**（§6 闸五）。M0 约 15–25 个 → 总量 **300–900**：新手期开包快是有意为之。

### 2.4 一个标准会话的产出预算

**假设**：30 真实分钟、虚拟模式、每分钟释放 1 张卡。

| 源 | 估算 |
|---|---|
| 事件回响 | **≈ 248**（30 × 8.26 / 张） |
| 初见回响 | 90–150（仅前期） |
| 沉淀回响 | **≈ 5** |
| **合计** | **≈ 250–400** → **3.5–5.5 个随机包**（70 一个） |

✅ 达成目标 1。

### 3.2 回收返还表

|---|---|---|---|
| 0 环 | 0 | **不可回收** | **0** |
| 低环 | 1 / 2 / 3 | 30% | **3 / 6 / 9** |
| 中环 | 4 / 5 / 6 | 50% | **25 / 40 / 60** |
| 高环 | 7 / 8 / 9 | 70% | **126 / 182 / 266** |
| 超环 | 超环 | 70%（价值基数 ×2） | **532** |
| 禁物 | 无环 | **不可回收** | **0** |

### 3.3 三种"卡的消失方式"（必须分清）

| 方式 | 触发 | 卡的去向 | 返还 |
|---|---|---|---|
| **释放** | 玩家上拖 | 销毁（效果落到世界） | **0**（产出走事件回响） |
| **回收** | 玩家下拖 | 销毁 | **价值的 30–70%** |
| **折算** | **自动**（实体池超出持有上限时） | 销毁 | **价值的 20%**（0 环 **0%**） |

> **折算的返还率刻意最低**：它不该成为一条"变相回收"的赚钱路径，只是"纸包挤满了"的礼貌处理。

| 项 | 规则 |
|---|---|

| **价格** | **150** |

## 6 数值不膨胀：五道闸（★核心）

**问题**：余响"只增不减"，产出持续不断 → 若无闸门，必然通胀；而"余响 → 卡 → 干涉 → 余响"还是一条潜在的正反馈回路。

| 闸 | 名称 | 规则 | 堵住什么 |
|---|---|---|---|
| **一** | **阈值衰减** | 同一区域改写过的机制再改，**不跨阈值**（无事件回响） | 重复改同一处刷钱 |
| **二** | **同卡种冷却** | 1 世界日内 100% → 50% → 25% → **0** | 用同一张卡反复刷 |
| **三** | **每分钟产出上限** | 事件回响 **≤ 20 / 真实分钟**，超出只给 25% | **换卡刷、加速刷、脚本刷**——全部撞墙 |
| **四** | **势能与红利** | 沉淀 ≤ 30/小时；**扰动 > 60 时势能 ×0.5**；平息扰动可提高势能 | 挂机 + 同时把世界玩坏还拿满产出 |
| **五** | **一次性源封顶** | 初见回响每项只给一次 | 靠重开世界刷初见 |

### 6.1 第六道（最关键的数学闸）：**放大回路不成立**

经济里唯一危险的结构是"**花余响买卡 → 用卡产余响**"的正反馈。逐项验算：

```
每张卡的获取成本 = 包价 / 平均张数 = 70 / 4 = 17.5
每张卡释放一次的期望产出 = Σ(档位权重 × 该档幅度中值)
                         = 8.26
─────────────────────────────────────────────
每张卡："买" 花 17.5，"用一次" 收 8.26  →  净亏 9.24
✅ 不放大（且缺口达 47%，留足调参余量）
```

**注意**：这个不等式**必须**在每次调整（包价 / 张数 / 掉落权重 / 事件回响档位）后重算。它是整套经济里最容易被一张新表打破的地方。

## 7 数据流转账本（每一环的进出）

### 7.1 全域流转图

```text
【产出端】                          【唯一账户】        【消耗端】
世界偏移（跨阈值）× 幅度 ──┐
初见现象（一次性）      ──┼──→    余 响     ──→ 开包（70 / 105 / 90 / 150）
势能 × 真实分钟        ──┘         ↑  ↓            平息扰动（1 : 2）
                                   │  │
                    ┌──────────────┘  └──────────────┐
                    │ 回收（30–70%）                 │ 折算（20%）
                    │  ↑                             ↓
                    └── 手牌 ──→ 实体池 ←──────── 开出的实体
                          │  ↑
                    释放（销毁）  重抽（退回池，钱包不动）
                          ↓
                       世界（可落地为永久实体）
```

### 7.2 每一环的"进 / 出"审计表

| 环节 | 进 | 出 | 是否守恒 / 风险 |
|---|---|---|---|
| **余响账户** | 事件 + 沉淀 + 初见 + 回收 + 折算 | 开包 + 平息 | ✅ 唯一账户，无隐藏产出 |
| **实体池** | 开包 + 0 环免费补池 + 重抽退回 | 释放 + 回收 + 折算 + 手牌占用 | ⚠ **唯一无限源是 0 环补池**（受闸二 / 三约束） |
| **手牌（≤10）** | 抽取 + 补抽 | 释放 + 回收 + 重抽退回 | ✅ 用掉补抽，恒满（只要池有货） |
| **世界状态** | 释放的效果 | 被后续干涉覆盖 / 衰减 | ✅ 与余响无关（不产出余响的因果不闭环） |
| **年表** | 所有跨阈值事件 | 只读（倒带索引） | ✅ 不回滚（防刷，见 [`INTERVENTION.md`](../gameplay/INTERVENTION.md) §5.4） |

### 7.3 审计清单（每次改数值后逐条打勾）

- [ ] **唯一账户**：余响只有 §7.2 那一进一出，没有第二个产出通道。
- [ ] **唯一无限源**：除"0 环免费补池"外，没有任何"零成本可得"的东西；且它受闸二 + 闸三约束。
- [ ] **唯一时间源**：沉淀按**真实分钟**、有上限、受扰动惩罚。
- [ ] **一次性源**：初见回响每项一次。
- [ ] **回退率 < 100%**：所有返还（回收 30–70%、折算 20%）都 < 成本（§6.1）。
- [ ] **无复利**：没有任何"持有余响 → 产生更多余响"的机制。
- [ ] **加速中立**：倍率不影响任何产出（§2.1 ③、§2.2）。
- [ ] **离线中立**：离线不产出、不消耗。

## 8 长期平衡验算（100 小时模型）

**假设**：活跃 50 小时（每分钟释放 1 张）+ 挂机 50 小时；虚拟模式。

| 项 | 算式 | 数量 |
|---|---|---|
| 释放次数 | 50 × 60 | 3,000 次 |
| **事件回响** | 3,000 × 8.26 | **≈ 24,780** |
| **沉淀回响** | 100 h × 均 9 / h（干涉压低了势能） | **≈ 900** |
| **初见回响** | 一次性 | **≈ 600** |
| **产出小计** | | **≈ 26,280** |
| 回收 + 折算回流 | ≈ 22% 的回退 | **+ ≈ 5,900** |
| **可用总量** | | **≈ 32,180** |

| 消耗 | 算式 | 数量 |
|---|---|---|
| **开包** | 26,280 / 70 ≈ 375 包 | **≈ 26,250** |
| **平息扰动** | ≈ 100 次 × 50 | **≈ 5,000** |
| **消耗小计** | | **≈ 31,250** |
| **净** | 32,180 − 31,250 | **≈ +930（基本平衡）** |

**结论**：100 小时后玩家的余响**没有滚雪球**——余额仍在 **0–2,000** 的区间波动，符合"数字不膨胀"。同时 375 个包 ≈ 1,500 张实体 → **必须配合 §6 的持有上限**（否则实体池会膨胀到手牌失去意义）。

**实体池规模的自我约束**（配合 [`INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.6）：

| 项 | 数值 |
|---|---|
| 每种卡持有上限 | **3 张** |
| 理论池上限 | 252 卡种 × 3 = **756**（实际远低于此，因为玩家不会集齐所有卡种） |
| 手牌抽取 | 10 张从池中**按持有张数加权**随机 |
| 抽到某卡的概率 | 例：池 40 张、某卡持 3 张 → 手牌中出现至少 1 张 ≈ **58%**（体验良好） |

## 9 调参联动（改一个数要一起看什么）

| 改什么 | 必须联动复核 |
|---|---|
| **包价** | §6.1 放大闸门 + §8 长期平衡 |
| **回收率 / 折算率** | §3.2 + §6.1（回退率总和必须 < 成本） |
| **价值表** | §3.2 + §6.1 |
| **掉落权重** | §5 期望值 → §6.1（**提高高环权重会显著抬高期望回收**） |
| **包内张数** | 期望回收 = 单张 × 张数；张数上调要同步上调包价 |
| **事件回响档位** | §2.4 节奏 + §6.1 + §2.1 ③ 速率上限（档位上调试探上限） |
| **沉淀系数 / 势能公式** | 闸四 + §8 |
| **持有上限 3 张** | §8 实体池规模 + §7.2（它同时是"折算"的触发条件） |
| **特殊包价格 / 超环概率** | §5.2 + §6.1（超环 532 的返还很大，概率上调会冲击期望） |

**总原则**：

```
包价  >  期望回收（39.7）
包价  ≈  产出速率 × 目标包间隔（8.26 / 分钟 × 8.5 分钟 ≈ 70）
卡成本（17.5）  >  单次释放产出（8.26）
产出速率上限（20 / 分钟）  >  正常产出（8.26 / 分钟）
```
