# 触发规则语法（TRIGGERS）

> **⏸ 冻结（2026-10-17 文档重构）**：本文件是 **M1 及以后** 的规格，**不参与当前施工、不参与评审、不参与契约校验**。M0 开工时不读它；M1 立项时再解冻并对齐现状。引用它时请注明「M1 设想」。


## 0 本文件管什么 / 不管什么

- **管**：**律类规则写进世界的语法**（持续性 = 触发）——`WHEN-THEN` 结构、条件词表、动作词表、频率、容量上限、冲突规则、"生效规则清单"的数据形态。
- **不管**：律卡的设定与清单（→ [`../setting/cards.md`](../setting/cards.md) §6 / [`../setting/cards.md`](../setting/cards.md)）；创世面板的界面落点（→ [`UI-UX.md`](UI-UX.md) §1 / [`CUSTOMIZE.md`](CUSTOMIZE.md) §3）。
- **来源**：2026-10-15 第 38 轮定案——**有限词表 DSL**（不用自由文本），地脉包（M1）与"给世界定规则"的核心语法；第 43 轮起"触发"不再是一个卡型，而是**持续性枚举的一个取值**（律类 + 触发），本语法不变。

## 1 语法

```text
规则 = WHEN <条件> THEN <动作> [AT 作用域] [EVERY / ONCE]
```

| 段 | 取值 |
|---|---|
| `WHEN <条件>` | **条件词表**（§2）中的单项或"且"组合（≤2 个条件，防复杂度爆炸） |
| `THEN <动作>` | **动作词表**（§3）：引用一张**已解锁卡**的效果（带其参数） |
| `AT 作用域` | 全局 / 区域（笔刷圈）/ 单体 / 单格——与卡的作用域枚举一致（[`../setting/cards.md`](../setting/cards.md) §9.3） |
| `EVERY / ONCE` | 每次满足都触发 / 仅首次触发（触发后卡盖"已生效"世界印记） |

## 2 条件词表（有限，防失控）

| 类 | 条件项 |
|---|---|
| 时间 | 时刻（日出 / 正午 / 日落 / 夜）· 季节 · 节气阶段 |
| 环境 | 温度（阈）· 水位（阈）· 湿度（阈）· 光照（阈）· 天气状态 = X |
| 生态 | 某物种种群数（阈）· 某个体死亡 · 某物种灭绝 / 首次分化 |
| 世界 | 扰动值（阈）· 某卡生效（事件）· 某禁物启用（事件） |

**算子**：`>` `<` `=` `进入区间` `每次` `首次`。
**组合**：最多 **2 个条件 AND**；不支持 OR / NOT（M1 保持最小语法，够玩且可校验）。

## 3 动作词表

**动作 = 引用一张已解锁卡的效果（带该卡参数与作用域）。**

- 不另造"动作效果池"——**动作复用卡**，规则是"世界的自动按钮"；
- 这保证：① 规则的能力随卡池增长；② 经济红线不被绕开（没解锁的卡进不了动作）；
- 物理 7 类基础能力（[`../setting/PHYSICS.md`](PHYSICS.md) §6）由被引用的卡间接携带，**不直接暴露给规则**。

## 4 约束与冲突

| 项 | 规则 |
|---|---|
| **容量上限** | 每界同时生效 **12 条**（与地脉包一套 8–12 张一致，[`../charter/CHARTER.md`](../charter/CHARTER.md) #8）；满员时必须停用一条才能写新的 |
| **冲突** | 两条规则改同一目标 → **后写覆盖先写**，双方都写年表（留痕可查） |
| **回滚** | 世界状态回滚时**规则不回滚**（规则属"玩家写在世界上"的记录层，同手牌 / 实体池，[`INTERVENTION.md`](../gameplay/INTERVENTION.md) §5.4） |
| **接管边界** | 条件只读**世界当前值**（不管值来自现实锚还是卡覆盖）——现实项被接管 / 离线降级时条件真假自然变化 |
| **查看 / 停用** | 全部规则在**创世面板「生效规则清单」**列出：条件 / 动作 / 来源卡 / 状态，可停用（[`CUSTOMIZE.md`](CUSTOMIZE.md) §3） |
| **数据形态** | 将来 `shared/schema/trigger.schema.json`；规则存档随界走 |

## 5 示例

```text
WHEN 水位 > 40 THEN 引用「冰封」AT 区域（写规则时的笔刷圈） EVERY
WHEN 时刻 = 日落 AND 天气 = 晴 THEN 引用「霞光」AT 全局 ONCE
WHEN 走兽种群数 < 5 THEN 引用「催生」AT 区域 EVERY
```
