# 物种档案（SPECIES）

> **一句话**：一张卡 = 一个物种。不是"种一棵树"，是"种一棵**铁杉**"。
> 真源：本文；卡与矩阵见 [CARDS.md](CARDS.md) §4.2，开局无生命见 [WORLD.md](WORLD.md) §9.0。

---

## 0 三条铁律

1. **开局无生命**：世界生成完是荒界（植物 0 / 动物 0 / 智慧 0），所有生物都来自卡。
2. **一张卡 = 一个物种**：`种子` 这种泛称卡只作为 M0 占位；M1 起每张物种卡指向一个具体档案（铁杉 / 花楸 / 晨鸟 / 夜枭……）。
3. **物种是数据，不是代码**：加一个物种 = 加一行 JSON + 一张卡面，不改 C++。

## 1 档案字段

| 字段 | 取值 | 说明 |
|---|---|---|
| `id` | `flora.hemlock` | 命名空间 + slug |
| `label` | 铁杉 | 中文名（英文另存） |
| `layer` | `flora` / `fauna` / `sapient` | 三层，见 WORLD §9.0 |
| `habitat` | `alpine` / `forest-edge` / `wetland` / `grass` / `water` / `cave` | 可多选；不匹配则卡失败 |
| `size_w` | `0.02` | 成体尺寸（界宽分数，§1.3） |
| `lifespan_d` | `1200` | 寿命（世界日）；`-1` = 多年生 |
| `season` | `evergreen` / `deciduous` / `annual` | 季节策略 |
| `bloom` | `spring` / `-` | 开花季 |
| `color_by_season` | `["#8fae74","#3f7549","#b0723a",""]` | 四季色；空串 = 落叶后只剩枝干 |
| `diurnal` | `day` / `night` / `crepuscular` | 昼夜节律；**同类不同种可以完全相反** |
| `diet` | `sun` / `herb` / `carn` / `omni` | 营养级 |
| `social` | `1` / `3–8` / `20+` | 独居 / 小群 / 大群 |
| `spread` | `wind` / `water` / `bird` / `beast` | 繁殖传播方式 |
| `effects` | `soil-hold` / `pollinate` / `prey` / `nest` / `burrow` | 对世界的作用（可多选） |
| `elements` | `["木"]` / `["水","木"]` | **元素构成**，1–3 个，首位是主元素（§1.1） |
| `tier` | `0–9` / `over` | **环级 = 稀有度 = 强度档**：越高越难抽、效果越强 |
| `line` | `≤ 24 字` | **卡面说明条**：特定信息 + 效果要点（§4.1） |
| `codex` | `100–300 字` | **图鉴完整效果**：条件 / 动作 / 数值 / 限制 / 进化 |
| `dex` | 九个槽位 + ≤60 字正文 | **图鉴条目**（宝可梦式七问：分类/属性/体型/进化/习性/食物/亲近/害怕/出现地），见 §1.2 |
| `evolve` | `{to:"flora.mossmat", when:"3 株 + 湿 ≥0.40 + 30 日"}` / `null` | **只有部分卡有**（§2.1） |
| `flavor` | `≤ 16 字` | 风味句，只在图鉴里 |

### 1.1 元素构成（一张卡是几个元素做的）

**没有"种族""类别""职业"。** 每张卡只由元素构成：**1 个是纯卡，2–3 个是复合卡**。

| 构成 | 例 | 读法 |
|---|---|---|
| 单元素 | 苔 `["木"]`、溪鱼 `["水"]`、岩羊 `["土"]` | 一件事，做到底 |
| 双元素 | 芦苇 `["水","木"]`、夜枭 `["暗","木"]`、花楸 `["木","光"]` | 两件事同时成立（水生 + 木质 / 夜行 + 栖枝） |
| 三元素 | 守火人 `["火","光","土"]` | 少、贵、环高 |

三条硬规则：

1. **元素构成不产生隐藏规则**。一张双元素卡的全部行为，都写在它自己的 `line` 与 `codex` 里；后台不会因为"水 + 木"就自动给它加成。
2. **元素越多，环越高**（也就越难抽）。这是复合效果要付的代价。
3. **落点亲和只是口径，不是公式**：卡想在哪类地块更有效，就在 `codex` 里写"在水边效果加倍"；没写就是不加倍。

### 1.2 图鉴：读数 + 自由文本 + 关系

**不搞九格填空。** 结构分三层，能算的进读数，能讲的进正文，能连的进关系：

| 层 | 内容 | 上限 |
|---|---|---|
| **头部** | 分类 · 属性 · 编号 · 环级 · 进化（来源 → 去处） | 一行 + 一行 |
| **读数** | 6 条：体型 / 活跃 / 领地 / 捕食 / 耐温 / 湿度；每条 = 名称 + 数值 + 一条相对长度的条 + 可选注 | 6 条 |
| **正文** | 三段自由文本：**习性 / 行为 / 传说**，各写一件事，不排比、不列表 | 每段 ≤50 字 |
| **关系** | 4 项：食物 / 天敌 / 共生 / 出现地；**值必须是卡名或地形名**（可点跳转） | 4 项 |

**夜沼鸟的例子**（`PROTOTYPE.html` 图鉴页实装）：

```
雾栖鸟 · 水 / 暗 / 风
体型  ▓▓░░░░░░░░  0.03 W      翼展
活跃  ▓▓▓▓▓░░░░░  12 时/日    18–6
雾域  ▓▓▓░░░░░░░  0.03 W      能见度 −1
捕食  ▓▓░░░░░░░░  0.6 尾/日   +0.02 W 范围
耐温  ▓▓▓▓▓▓░░░░  8–26 °C     正午停飞
湿度  ▓▓▓▓░░░░░░  ≥ 0.35      雾内 +0.08

习性  昼伏夜出。日落后离枝，贴水面低飞，天亮前归枝；白天在木本横枝上不动。
行为  翼下绒膜收水面凉气，飞一圈拖出一条雾。雾里靠听觉找鱼，所以它怕的不是黑，是安静。
传说  渔人把它的落羽缝在网边，说这样雾会认得人。没有人证实过。

食物 溪鱼   天敌 —   共生 苔   出现地 河湾
```

**三条约束（不然读数就是装饰）**：

1. **读数必须被世界读走**：`雾域` → 夜里真的加一层雾、`湿度` → 顶栏读数 +8、`捕食` → 鱼群数量下降。写了不生效的数值，一律删掉。
2. **读数必须是可比的数**，不是形容词：写 `0.03 W` 不写"很小"，写 `8–26 °C` 不写"怕热"。
3. **关系必须是卡名**：能点、能跳、没见过的给"还未记录"。这样 231 张卡才连成网，而不是 231 页说明书。

### 1.3 「风」是复合相，不是第 8 元素

七元素不动（231 矩阵也不动）。**风 = 光与暗交替处生出的复合相**（气流），允许出现在卡面上：

| 规则 | 说明 |
|---|---|
| 画章 | 卡面可以画"风"章（青灰），和水/暗并列 |
| 落格 | 按**主元素**落格：夜沼鸟 = `水 · 1 环 · 物`，不新增第 8 组格子 |
| 图鉴 | 属性写全：`水 / 暗 / 风` |
| 规则 | 与风有关的效果只写在卡里（翼下收水汽），**不建全局风系统** |

> 这样"风"是**描述性的第三相**，不是第 8 个抽卡维度；以后真要做风元素，把这条映射删掉即可，矩阵仍可扩。

## 2 十个示例（M1 起步集）

| 物种 | 层 · 元素 | 栖息 | 季节 | 昼夜 | 作用 |
|---|---|---|---|---|---|
| **铁杉** | flora · 木 | 山地 / 林 | **常绿**（四季不变） | — | 固土、遮荫、冬季唯一绿 |
| **花楸** | flora · 木+光 | 林缘 | **春开白花 → 夏绿 → 秋黄 → 冬秃** | — | 果实喂鸟、招来候鸟 |
| **苔** | flora · 水+木 | 岩面 / 湿地 | 常绿贴地 | — | 保水、为分解者提供基底 |
| **芦苇** | flora · 水+木 | 湿地 | 夏绿冬枯 | — | 滤水、水鸟筑巢 |
| **晨鸟** | fauna · 光+木 | 林缘 | 候鸟（冬迁出） | **昼行 6–18** | 传播种子、吃虫 |
| **夜枭** | fauna · 暗+木 | 林缘 / 洞 | 留鸟 | **夜行 18–6** | 控鼠、夜里的声音 |
| **岩羊** | fauna · 土 | 高山 | 换毛（冬白） | **晨昏 5–8 / 17–20** | 踩兽径、把种子带上山 |
| **穴兔** | fauna · 土 | 草原 | 常年 | **夜行** | 打洞翻土、被猎 |
| **溪鱼** | fauna · 水 | 水域 | 洄游 | 昼行 | 清藻、把养分带上游 |
| **守火人** | sapient · 火+光+土 | 水边 | — | 昼行 | 用火、筑屋、记事 |

> **为什么列鸟和树，而不是"植物/动物"两类**：玩家能记住的是"那棵冬天不落叶的铁杉"和"半夜叫的枭"，不是"植物 3 棵"。

### 2.1 进化：写在卡上，不是规则

**没有演替链。** 会不会进化、进化成什么、要什么条件，全部由**那张卡自己**写；没写这一条的卡，就是长到底了。

| 卡 | 写在自己身上的进化 |
|---|---|
| 苔 | `→ 苔毯`：同处 3 株 + 湿度 ≥0.40 + 30 日 |
| 花楸 | `→ 古树`：生物量 ≥300 + 5 年 |
| 幼虫 | `→ 晨鸟`：化蛹 7 日（**只有这一张有，别的虫没有**） |
| 铁杉 | 无。它就是终点 |

四条规则：

1. **部分卡有，部分卡没有**：进化的存在与否是卡的设计选择，不是物种的固有属性。
2. **条件由卡写**：可以是数量、湿度、天数、附近有什么，也可以是"被雷劈过"。
3. **同一物种在不同卡里可以进到不同结果**——因为没有全局链，"苔"这张卡进成苔毯，"苔"的另一张变体完全可以进成泥炭。
4. **进化要留痕**：换掉的那一刻进年表（"第 312 天，这处苔结成了毯"），旧实体消失，图鉴两个格子分别点亮。
5. **进化产物不入卡池**：抽卡只抽"种子"。从夜枭长出来的夜沼鸟不消耗手牌、不进包，只进图鉴与物种池——**它带你这个界的日期和地点**，所以比抽到的那只更值得留。1 环卡容易抽到，不等于它容易长出来。

## 3 表现规则（Z 级）

| 级 | 树 | 鸟 / 兽 | 智慧 |
|---|---|---|---|
| Z0 | 只是色块与密度（常绿深绿 / 落叶随季变色） | 几个点 | 房屋色块 |
| Z2 | 能分出针叶 / 阔叶 / 落叶枝干 | 能看出飞行方向与群散 | 屋、田、烟 |
| Z3 | 花、果、叶形 | 羽毛色、走姿 | 人、工具、火 |

**季节**：`evergreen` 不变；`deciduous` 用 `color_by_season`，第四格为空时只画枝干；`annual` 一岁一枯荣。
**昼夜**：`day` 6–18、`night` 18–6、`crepuscular` 5–8 / 17–20；**夜幕只压地形，生物与痕迹保持亮度**，否则夜里什么都看不见。

## 4 与卡的关系

- 物种卡在矩阵里占**物**位：`元素 × 环级 × 物`；**多元素卡按主元素落格**，副元素记在卡里，不占额外格。
- **环级 = 稀有度 + 强度**：环越高越难抽、效果越好；半径随之变大只是它的表现，不是它的定义。
- 卡面画该物种的**剪影 + 元素纹 + 说明条**；完整效果只在图鉴（§4.1）。
- 打出后物种进入**本界物种池**，不可撤回；**环境不匹配会失败**（"这里太干，铁杉活不了"），卡不消耗。
- `seed-life` / `spawn-entity` 的 `species` 字段指向档案 id（[CARDS.md](CARDS.md) §4.2）。

### 4.1 两层信息：卡上说要点，图鉴说全部

参照游戏王：**卡面下框写一段**（效果摘要或特定信息），**完整裁定在图鉴**。我们照这个分层，不照它的术语。

| 层 | 放什么 | 上限 |
|---|---|---|
| **卡面** | 名字 / 元素构成 · 环级 · 类 / **说明条**（特定信息 + 效果要点）/ 环点 | 名 4 字 · 说明条 **24 字** |
| **图鉴** | 完整效果：条件 → 动作 → 范围 → 数值 → 限制 → **进化（若有）** + 风味句 | 100–300 字 |

**示例（花楸）**

```
卡面说明条：种下花楸；果熟时招来候鸟
```

```
图鉴 · 花楸
元素 木 + 光 · 2 环 · 物
种下 1 株花楸，需湿土（湿度 ≥0.40）。
若 30 日内有晨鸟栖枝，则秋季结红果，果期 20 日。
果期内每只候鸟每一日把种子带走 0.02 W。
进化：生物量 ≥300 且满 5 年 → 古树（此卡无进化则写"无"）。
风味：春开一树白，秋落一地红。
```

**说明条写什么、不写什么**：

- 写**只有这张卡才有的信息**：条件、特殊触发、例外。
- 不写通用规则（"拖到地面"、"消耗 1 张"）——那些在键位与帮助里。
- 不写数值表——数值进图鉴。
- 效果句一律按 **条件 → 动作 → 范围** 的语序，只写一句。

### 4.2 没有套系

**不做 archetype，不做阵营，不做生态套，不做隐藏加成。**

卡与卡之间唯一的关系，是**某张卡自己写了"对谁生效"**：

| 写法 | 出处 |
|---|---|
| "若附近有木本，则……" | 这张卡的条件句 |
| "对虫豸与走兽有效" | 这张卡的作用对象 |
| "被雷劈过后进化为……" | 这张卡的进化条件 |

除此之外，后台不认任何组合。**玩家看到的每一条互惠，都能在那张卡的说明条或图鉴里读到原文**；读不到，就是不存在。

## 6 术语

| 词 | 意思 |
|---|---|
| **物种卡** | 打出去会引入一个具体物种的卡 |
| **档案** | 一个物种的全部参数（本文 §1） |
| **季节色** | 该物种在春夏秋冬的四个颜色，落叶类第四格为空 |
| **昼夜相** | 该物种活动的时间段（昼 / 夜 / 晨昏） |
| **元素构成** | 一张卡由哪 1–3 个元素组成，首位为主元素 |
| **说明条** | 卡面下方那一段 ≤24 字的话：特定信息 + 效果要点 |
| **图鉴效果** | 卡的全部裁定（条件 / 数值 / 限制 / 进化），只在图鉴里 |
| **进化** | 部分卡自带的能力：满足卡上写的条件后变成另一张卡；没有全局链 |
