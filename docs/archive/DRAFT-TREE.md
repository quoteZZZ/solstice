# 提案 v11：卡片树

> **状态：draft**。配套 [DRAFT-ISLAND.md](DRAFT-ISLAND.md) v10、[DRAFT-CARDS300.md](DRAFT-CARDS300.md)。
> 用户思路（2026-10-22）：**低环合成高环，形成卡片树（像科技树）；用过的卡成为资源；生物学会使用工具**。
> 三家分析（科技树 / 卡牌经济 / 文明演化）的结论：思路成立，但**不能做配方表**。

---

## 1 为什么不能做配方表

| 算法 | 数量 |
|---|---|
| 300 张卡两两组合 | **44,850** |
| 加上三张组合 | 4,455,100 |

**业界三条压缩路径，各有代价**：

| 做法 | 代价 |
|---|---|
| 模式配方（任意金系工具 + 任意木系材料 → 工具系） | 独特记忆点消失，"合什么都一样" |
| 属性运算（元素/环级相加） | 变成算术题 |
| 白名单 + 分层（只手工设计关键节点） | 大量卡对撞空，需要 UI 明示"不能合" |

**我们的选择：以规则为主，彩蛋为辅。**

## 2 合成：三条法则 + 20 条彩蛋

### 2.1 配方的单位不是"卡"，是"材料标签"

每张卡有 1–2 个**材料标签**（不是元素）：

| 标签 | 来源卡 | 例 |
|---|---|---|
| **石** | 石、燧石、黏土、矿脉 | 拾石、砂 |
| **木** | 树、灌木、竹 | 白桦、铁杉、藤 |
| **纤维** | 草、藤、芦苇 | 野草、柳 |
| **骨** | 兽、鱼 | 鹿、熊、鲸 |
| **火** | 火类卡 | 炭、篝火、燧石 |
| **土** | 土类卡 | 松土、堆肥 |
| **水** | 水类卡 | 滴水、引水 |

> **7 个标签，覆盖 300 张卡**。配方从 4 万降到"7×7 = 49 种组合"。

### 2.2 三条通用法则（不查表也知道）

| 法则 | 规则 | 例 |
|---|---|---|
| **同标签 ×3** | 3 个同标签 → 1 个高级材料 | 木×3 → 木材；石×3 → 石料 |
| **异标签 ×2** | 2 个不同标签 → 1 个工具 | 石+木 → 石斧；纤维+木 → 弓 |
| **相克标签** | 水+火 / 光+暗 → **变体或禁物** | 水+火 → 蒸汽（变体）；光+暗 → 深渊（禁物） |

**卡面自带公式**：每张卡的说明条最后一行写「材料：木」，可合性是一眼能看到的属性，不是隐藏表。

### 2.3 20 条彩蛋配方（手工）

通用法则之外，只手工设计 **20 条"有记忆点"的配方**：

| 配方 | 产物 | 效果 |
|---|---|---|
| 石 + 木 | **石斧** | 能力：切割（砍树 ×2） |
| 石 + 石 | 石锤 | 能力：敲击（碎石） |
| 木 + 纤维 | 弓 | 能力：远射（狩猎） |
| 骨 + 石 | 骨刀 | 能力：切割（弱），不腐 |
| 木 + 木 | 木棍 | 材料：可做矛 |
| 木 + 火 | 炭 | 燃料，冬季不冷 |
| 土 + 水 | 泥 | 材料：砌墙 |
| 石 + 火 | 燧石 | 取火 |
| 纤维 + 纤维 | 绳 | 材料：绑扎 |
| 木 + 绳 | 梯 | 能力：攀爬 |
| 土 + 石 | 砖 | 材料：建房 ×2 |
| 水 + 土 + 火 | 陶罐 | 储水 +2 |
| 骨 + 纤维 | 针 | 能力：缝制 |
| 木 + 骨 | 鱼叉 | 能力：捕鱼 ×2 |
| 石 + 纤维 | 投石索 | 能力：远射（弱） |
| 火 + 土 | 窑 | 设施：烧砖 |
| 木 + 水 | 筏 | 能力：渡水 |
| 石 + 木 + 纤维 | 犁 | 设施：农田 +1 |
| 骨 + 木 | 骨笛 | 能力：社交（吸引兽） |
| 火 + 石 + 木 | 熔炉 | 设施：炼金 |

**只有这 20 条需要记。**其余全部走三条法则。

### 2.4 UI：卡片树

```
环 9  ┃ ● ● ● ● ● ● ●
环 8  ┃ ● ● ● ● ● ● ●
 ...  ┃
环 2  ┃ ● ● ● ● ● ● ●
环 1  ┃ ● ● ● ● ● ● ●
环 0  ┃ ● ● ● ● ● ● ●
      ┗━━━━━━━━━━━━━━━━━
        金 木 水 火 土 光 暗
```

- **纵轴 = 环级**（低在下，高在上），**横轴 = 7 元素**
- 已拥有的卡亮，未解锁的暗
- **连线 = 合成关系**（同标签竖线向上，异标签斜线交叉）
- 悬停显示"怎么合出来 / 能合成什么"

> 这就是"科技树"的视觉：一屏看完 252 格，玩家能看见自己的位置与下一步。

## 3 素材池：一个池，两个出口

### 3.1 不做两个池

用掉的卡 → **回收池**（它同时就是素材池）。**卡进池后有两个出口**：

| 出口 | 做什么 | 代价 |
|---|---|---|
| **A 攒包** | 3 张同系 → 1 个卡包（3 张） | 要等，且包是随机的 |
| **B 拆料** | 立即拆成 1 个材料标签 | 失去"凑三合一"的机会 |

> **这是全作最便宜的策略深度**：同一张卡被两条路争抢。
> 玩家每轮只需回答一句话：**"这张卡，我是留着凑三张，还是现在就拆了用？"**

### 3.2 标签管量，具体卡管质

| 类型 | 处理 | 例子 |
|---|---|---|
| 普通卡 | 拆成标签计数（石×3、木×5） | 拾石、野草、滴水 |
| **关键卡** | **保留具体身份，不可替代** | 古树、鲸、守火人 |

**配方可以点名某张具体卡**：「巨鲸」只能由"鲸 + 骨 + 水"合成，不能用 3 个骨标签代替。

> 这样既保留"稀有卡当素材的心疼"，又不用管 300 张的库存列表。

### 3.3 三条防线（防闭合正循环）

风险：用卡 → 得素材 → 合更强卡 → 更强卡产更多素材 → 卡包失去意义。

| 防线 | 规则 |
|---|---|
| **转换有损** | 1 张卡 → **1 个标签**；配方需 **2–3 个标签**。永远净损 |
| **时间即预算** | 每次用卡推 1 年。年份与岛况是硬约束，卡包不可替代 |
| **只变形不净增** | **卡包是唯一的新增来源**；高环卡拆料有衰减（9 环卡拆出 1 个标签，不是 3 个） |

## 4 文明：能力标签 + 属性阈值

### 4.1 不做"物种 × 工具"的映射表

12 物种 × 30 工具 = 360 条，做不完也不可控。

**改成两侧声明，中间靠阈值比较**：

| 侧 | 声明什么 |
|---|---|
| **物种** | 4 个属性：**握持 / 力量 / 认知 / 社会性**（各 0–1） |
| **工具** | 1 个能力 + 1 个需求阈值 |

例：

```
猿猴：握持 0.6  力量 0.5  认知 0.4  社会性 0.7
石斧：能力「切割」  需要握持 ≥ 0.5
→ 0.6 ≥ 0.5，学会
```

**映射从 360 条降到"4 个属性 + 1 个阈值"的比较**，0 条枚举。

### 4.2 只保留 20 条招牌例外

有些组合必须有名字，否则玩家记不住：

| 物种 + 工具 | 学会什么 |
|---|---|
| 猿猴 + 石斧 | **砍树**（新动词） |
| 猿猴 + 火 | **用火**（取暖、烤食、驱兽） |
| 人 + 弓 | **狩猎**（远程） |
| 人 + 犁 | **耕作**（农田 +1） |
| 人 + 窑 | **烧砖**（建材 ×2） |
| 鲸 + 无 | （鲸不需要工具） |

### 4.3 "学会"给什么：主新动词，辅小数值

| 给什么 | 优先级 | 理由 |
|---|---|---|
| **新动词**（砍树、建房、烧窑） | **主** | 文明跃迁的体感来自"能做新事了"，不是 +10% |
| 小数值（砍树 ×2） | 辅 | 可见、可验证 |
| 改世界规则 | 慎 | 可读性成本最高，留给高环卡 |

> 石斧 = **新动词「砍树」+ 1 张派生卡「木板」**，到此为止。不要一次给三个加成。

## 5 自动化：授权一次，持续执行

用户矛盾：**要动手，但不想点按钮**。解法是分三层：

| 层 | 玩家做什么 | 例子 |
|---|---|---|
| **L1 手动** | 每张卡自己点 | 前期 |
| **L2 指令**（默认） | **下一次意图**，生物自主执行并汇报 | "这片林子砍到 50 木" |
| **L3 规则**（后期解锁） | 常驻条件 | "木 < 50 就砍" |

**边界判据：摩擦放在"决策"，不放在"重复"。**

**自动化的代价必须来自世界，不能来自 UI**：

| 代价 | 表现 |
|---|---|
| 耗食物 | 猿猴干活要吃更多 |
| 会受伤 | 砍树有概率受伤，受伤减产出 |
| 招野兽 | 砍树的声音引来兽 |

> 于是"自动化"不是变简单，而是**你把风险外包给了世界**。

## 6 完整链路（用户的例子，跑通一遍）

```
第 1 年  用「猿猴」卡        → 场上出现猿猴（握持 0.6 / 认知 0.4）
第 2 年  用「白桦」卡        → 场上出现一棵树（材料标签：木）
         （石头是初始自带）    → 素材池：石 ×2
第 3 年  用「拾石」拆成料     → 素材池：石 ×3
第 4 年  石 ×1 + 木 ×1       → 合成「石斧」（能力：切割，需握持 ≥0.5）
第 5 年  把石斧放到猿猴所在格 → 0.6 ≥ 0.5，**猿猴学会「砍树」**
第 6 年  下指令"这片林子砍到 50 木"
         → 猿猴自主砍树，每年 +3 木，自然度 −0.5/年
第 8 年  木材够了 → 用「建屋」卡 → 人口上限 +5
第 10 年 猿猴 + 火 → 学会「用火」→ 夜间不用怕，可烤食
```

**这条链就是"文明"**：物种 → 素材 → 工具 → 能力 → 新建设 → 更多人口 → 更复杂的工具。

## 7 风险

| # | 风险 | 缓解 |
|---|---|---|
| R1 | **死路卡**（入度 0，永远合不出来） | 三条法则保证每张卡至少有 1 条入度；0 环卡永远可得 |
| R2 | **必由之路**（某张卡是唯一解） | 每条关键路径必须有 ≥2 个来源且可再生 |
| R3 | **唯一最优**（石斧通吃，其余 29 把工具全废） | 工具按场景分工：切割／敲击／远射／容器／绳索／复合，各有不可替代的动词 |
| R4 | **触发不透明**（有石有木却不学） | 悬停显示"缺什么"：`握持 0.4 < 0.5` |
| R5 | **合成变算术**（玩家在算标签） | 只保留 7 个标签；UI 直接显示"可合成"高亮 |
