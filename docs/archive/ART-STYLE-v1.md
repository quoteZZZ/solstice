## 1. C1「纸墨卡通」定义

一句话锁死：**硬边 Cel-shading + 墨线描边 + 大色块强剪影 + 纸张颗粒叠加**。

### 1.1 Cel-shading 分层色阶

| 项 | 参数 |
|---|---|
| 色阶数 | **3 阶**（基色 / 一次影 / 二次影）+ **1 点高光** |
| 阶间过渡 | **硬过渡**（硬边），抗锯齿 ≤ 2px；**禁止软渐变、禁止渐变贴图** |
| 每阶降幅 | 暗部：明度 **−18%~−22%**、饱和 **−8%~−12%**、色相向冷偏 **+5°** |
| 二次影占比 | ≤ 画面 **15%**（仅出现在背光转折处） |
| 高光 | **单点小硬块**；禁用广域反光/湿润高光 |

### 1.2 描边（Outline）

| 项 | 参数 |
|---|---|
| 外描边粗细 | **主体高度的 0.8%~1.2%**（1.8m 角色 ≈ 1.5~2.2cm 世界单位） |
| 描边色 | 墨色 **#1E1A24**（深墨紫黑）；随环境光整体偏色 ±10%；**绝不发光** |
| 内线 | 仅结构分割（眼/口/缝线/鳞羽分层），粗细 = 外线 **40%~50%**，取环境暗部色 |
| 稳定性 | 拒绝屏幕空间描边抖动；远景可切**贴图描边**省性能 |

### 1.3 大色块与强剪影

- 主体色块 **≤ 5 块**；配饰点缀 **≤ 2 块**。
- **剪影测试**：纯黑填充下须一眼辨识主体身份与朝向；不通过则重做轮廓。
- 靠**识别特征**（冠/角/纹/尾/器）取胜，不靠细节密度。

### 1.4 纸张 / 版画颗粒叠加

| 层 | 位置 | 不透明度 | 粒度 |
|---|---|---|---|
| 屏幕层 | 全屏叠加，暗部与留白处最显 | **8%~15%** | 1~2px |
| 纹理层 | 单位自身（贴图空间） | **5%~10%** | 1px 噪点 |
| 边缘 | 轮廓毛边 | 极轻 | 1px |

### 1.5 受光与阴影

- **硬边二分明**：受光面 / 阴影面硬切；**拒绝写实软阴影与 AO 软糊**。
- 阴影不靠压暗，而用**提升饱和度的冷色块**（暗部混入环境冷色）。
- 环境阴影用**贴地椭圆硬阴影**或烘焙 AO 面片。
- **场景主光锁定：左上 45° 斜射**（与 2.5D 相机语言一致，见 §6）。

## 4. 单位设计规范

### 4.1 体型分级（对齐 `DESIGN.md` §5.4）

| 级 | 世界高度 | 用途 |
|---|---|---|
| 小 | 0.4~0.8m | 低费铺场单位（Cost 1–2） |
| 中 | 1.0~1.6m | 主力单位（Cost 3–5） |
| 大 | 1.8~3.5m | 高费/精英（Cost 6–8） |

### 4.2 剪影与表情

- **200×200px 缩略下**识别特征（冠/角/纹/器）必须可辨。
- 眼睛：**大而简化**（椭圆/半圆），描边眼，眼神光 **1~2 点**；禁止写实瞳孔与湿润反光。
- 姿态优先于面部：**靠站姿与器物的朝向表达性格**。

### 4.3 卡面版式合同（Card Layout Contract）★

| 项 | 规格 |
|---|---|
| 尺寸 | **1024 × 1365 px（3:4 竖版）** |
| 画芯 | **无文字、无边框、无徽记** —— 边框/角饰/系徽/数值由 **UMG 统一绘制** |
| 安全区 | 上 **96px**、左右各 **88px**、下 **176px** 内不得放关键主体 |
| 画芯有效区 | **848 × 1093 px** |
| 主体占幅 | 占安全画幅 **60%~75%**，居中偏上，底部留信息条空间 |

**卡面信息层级（UMG 绘制，自上而下）**

| 层 | 内容 | 位置 |
|---|---|---|
| 1 | 名称（zh 主 / en 副） | 顶部信息条 |
| 2 | **系徽** | 左上角 |
| 3 | **源徽**（四域） | 左上角系徽旁 |
| 4 | 稀有度 | 右上角 |
| 5 | **墨费**（Cost） | 左上角外侧大号数字 |
| 6 | 数值（HP / ATK / SPD） | 底部信息条 |
| 7 | 词条图标 | 数值上方一行 |
| 8 | 卡语 flavor | 数值下方小字 |

### 4.4 星阶视觉（合契）

| 阶 | 表现 |
|---|---|
| ★1 | 标准边框，素角饰 |
| ★2 | 边框加**鎏金内线**，角饰升级为双线 |
| ★3 | 边框**鎏金+微光脉冲**，角饰为完整纹章，卡面叠一层**极轻金尘粒子**（不透明度 ≤8%） |

> 星阶只改**边框与粒子**，**不改卡面画芯**——这是控制美术量的硬规则。

## 5. 场景与 2.5D 视角规范

| 项 | 参数 |
|---|---|
| 相机语言 | **固定斜俯视**：俯角 **~45°**、方位角 **~45°**；近正交感（长焦压缩） |
| 相机行为 | **不跟手旋转**、不自由俯仰；战斗与地图**共用同一相机语言** |
| 岁盘呈现 | 2 排 × 6 列布阵区在盘面上以**刻线 + 微凹槽**表现；两军分区以**色温差**区分 |
| 场景分层 | ① 前景遮挡（雾/器/枝叶，可半透明）② 岁盘面（清晰、低噪点）③ 背景（岁轮剪影，降饱和压对比） |
| 尺度参照 | **1 世界单位 = 1 cm**；格边长 **= 100 uu**；单位高度见 §4.1 |

## 6. 生图线 Prompt 规范

### 6.1 正向风格串（固定前缀，勿改）

```
cel shaded, flat color blocks, bold ink outline, 3-tone step shading, hard-edge shadow,
high silhouette readability, screen-print paper grain overlay, limited seasonal palette,
2.5D game asset, single centered subject, clean lineart, solid chroma background, crisp edges, no soft gradient
```

### 6.2 负向串

```
photorealistic, hyperrealistic, soft gradient shading, airbrush, subsurface scattering,
3d render, glossy realistic skin, blurry, depth of field bokeh, lens flare,
front-facing portrait, extreme close-up face, text, watermark, signature, letters, numerals,
frame, border, corner ornament, extra limbs, extra fingers, cluttered background, multiple subjects
```

### 6.3 生成参数（与 `studio/` 实际管线一致）

| 用途 | 尺寸 | 步数 | CFG | 说明 |
|---|---|---|---|---|
| 卡面 | **1024×1365** | 4 | 1.0 | FLUX.2 Klein 4B FP8 专用采样（euler + Flux2Scheduler） |
| 立绘 | **1024×1024** | 4 | 1.0 | 同上；**纯色 chroma 底**（模型无 alpha 通道） |

> **注意**：CFG=1 时负向串**不参与采样**（走 zero-out），仅作为 manifest 留档用途。真正的负向控制靠**正向串的精确用词**与后期挑图。这一点与 `studio/prompts/hard-rules.md` 保持一致。

### 6.4 批量一致性

1. 每批以**风格锚图**为参照（同批固定风格前缀与色板用词）。
2. 同系同季**固定基底 seed**，只变主体描述。
3. 色板 hex 与 prompt 用词**必须与本文档 §2/§3 同源**（见 §7）。
4. 逐张写 `credits{model, promptRef, date}` 进 manifest。

### 6.5 QC 验收清单（逐条打勾，供批量挑图）

- [ ] 1. 硬边 Cel-shading，**无软渐变/写实反光**
- [ ] 2. **墨线描边完整**，未被光效吃掉，粗细符合 §1.2
- [ ] 3. **缩略图下剪影可辨**（识别特征清楚）
- [ ] 4. 色彩落在对应**季板 hex** 范围内，未跑偏色
- [ ] 5. **无正面人脸特写**（见 §4.5）
- [ ] 6. 卡面**画芯无文字 / 无边框 / 无徽记**
- [ ] 7. 主体落在**安全区**内（上 96 / 左右 88 / 下 176）
- [ ] 8. **无多余肢体/手指**、无明显结构崩坏
- [ ] 9. 纸张颗粒可见但**不过度**（不糊掉描边）
- [ ] 10. 系属性母题与 §3 **一致**

### 4.5 「避免人脸特写」现实约束 ★

卡面与立绘由**扩散模型量产**，而**正面人脸特写在批量生成中不稳定**（五官崩坏、瞳距漂移、跨张不一致）。硬规则：

| 约束 | 规则 | 替代方案 |
|---|---|---|
| 卡面主体 | **不得要求正面人脸特写**；面部占画幅 ≤ 1/5 | ① 3/4 侧脸 ② 背身/回首 ③ 面部被纹样/器物/雾遮挡 ④ 仅给眼部剪影 |
| 人物立绘 | **禁止 >1/3 画幅的正面大脸** | 半身/侧身/低头侧视；情绪靠身姿与器物 |
| Prompt | 负向串含 `front-facing portrait, extreme close-up face` | 生成后按 §6.5 逐条筛 |

## 8. 待用户裁决
