## 0. 叙事设计原则

| 原则 | 说明 |
|---|---|
| **不写小说** | 所有叙事可拆成 ≤3 句一屏的短对话或一幕卡面级插画 |
| **不解释机制** | 世界观不承担教学功能；教学由 UI 与提示承担 |
| **肉鸽即叙事** | "败了从岁首重演"是世界内的真实机制，不装作读档 |
| **真相靠拼接** | 单局只能看到片段；多周目、不同事件随机池才能拼出全貌 |
| **反派有人格** | 逆岁者的动机必须**可被理解**，甚至令人认同；不做脸谱化邪恶 |
| **原创零借名** | 不得出现任何现有作品的专有名词、角色、术语 |

## 1. 世界观词典

### 1.1 岁轮（The Year Wheel）

四时界的四季并非自然现象，而是**岁轮**运转的结果。岁轮是一具无形的巨构，上有 **24 齿**——每一齿对应一个**节气**。

- 岁轮转动 = 四季更替；岁轮**停住** = 时间在世上凝固。
- 岁轮不可被人扛动，只能被**重演**——这是本作世界观的核心设定。

### 1.2 岁盘（The Year Board）

**四时界的中心**，一座比山更高的圆形石盘，盘面刻 12×2 格。冬至之夜，四时界在岁盘上**重演一次岁局**，以定来年四季之序。

- 岁盘上的每一格，对应世上的一片土地、一群生灵。
- 在盘上输掉的，会在世上真实地发生。**岁局的胜负不是游戏，是定序。**

### 1.3 岁局（The Yearbound Game）

岁局由**四位岁守**共同执盘，与**一位司岁者**对弈。

- 一局岁局须走满 **24 步**（24 节气），自岁首（立春）至岁末（大寒）。
- 若司岁者在第 24 步前寿数耗尽，岁盘会**自动回卷到立春**，重演一次——不是惩罚，是岁盘的本能。
- **每一次重演，岁盘上的痕迹都会淡一点。** 这是逆岁者存在的根源。

### 1.4 司岁者（Warden）

主持岁局的人。岁盘不为活人留名，只留**印记**——历任司岁者的「使」会以残影形态留在盘上，可被后来的司岁者**借用**。

> 机制映射：玩家可选的**值守者**即历任司岁的「使」；「借用残影」解释了一次跑团中能换英雄。

**八节使**（八位印记）：

| 使 | id | 源（四域） | 主系 | 定位 |
|---|---|---|---|---|
| 立春使 | `wd.lichun` | 庭 | 木 | 铺场成长（起始首发） |
| 立夏使 | `wd.lixia` | 海 | 火 | 爆发速攻 |
| 立秋使 | `wd.liqiu` | 岭 | 金 | 精准消耗 |
| 立冬使 | `wd.lidong` | 宫 | 水 | 防守反击 |
| 春分使 | `wd.chunfen` | 庭 | 木/日 | M5 解锁：铺场+回复 |
| 夏至使 | `wd.xiazhi` | 海 | 火/日 | M5 解锁：高燃爆发 |
| 秋分使 | `wd.qiufen` | 岭 | 金/月 | M5 解锁：控制消耗 |
| 冬至使 | `wd.dongzhi` | 宫 | 水/月 | M5 解锁：终局向 |

### 1.5 寿数（Vitality）

司岁者的**寿数**（30 点）写在他的印记上。交兵期落败按对手存活单位的数量与代价扣寿数；寿数归零，岁局回卷。

> 机制映射：就是 HP。

### 1.6 岁印（Year Seal）

岁盘上抹不掉的**刻痕**——是司岁者在重演中留下的记忆与经验。

> 机制映射：局外货币。**它的存在本身就是"你不是第一次来"的证据。**

### 1.7 四域与四位岁守

| 域 | 岁守 | 主张（被逆岁者说动之处） | 6 层节点区间 |
|---|---|---|---|
| 春庭 | **青阳** | "生长即痛苦——你们每年都要重来一次，何必？" | 节气 1–6 |
| 夏海 | **朱明** | "最盛的时刻该被留住——为什么让它落下去？" | 节气 7–12 |
| 秋岭 | **白藏** | "收成之后即是荒芜——不如从不开始。" | 节气 13–18 |
| 冬宫 | **玄英** | "静止不是死亡，是安静。" | 节气 19–24 |

> **四时别称**（青阳 / 朱明 / 白藏 / 玄英）为传统四时雅称，用于本作原创命名。

## 2. 逆岁者（The Unyearning）★核心真相

### 2.1 他是谁

**逆岁者没有名字。** 因为名字是岁盘留不住的东西之一。

他是**上一次岁局中，那位司岁者的余数**。

岁盘回卷时，司岁者的记忆会被抹去——但抹不干净。**每重演一次，就有极少量的"记得"渗进盘里。** 岁盘转过太多轮了，渗出来的"记得"多到攒成了一个东西。它记得每一局的结局。

### 2.2 他的观点（为什么他是对的——至少有一半是对的）

逆岁者不是因为恨而反抗。他见过**每一次岁局的所有分支**：

- 他见过立春使赢过 30 次，每次赢的方式都不同，但**来年的立春都长得一模一样**。
- 他见过司岁者拼尽全力守住秋分，然后大雪照旧把一切盖住。
- 他得出一个判断，而这个判断**无法被证伪**：

> **「岁轮不记得任何人。它只是转。你们以为在改变什么？」**

他的目标不是毁灭世界，而是**把岁盘钉在至点**——让岁局不再重演、岁轮不再转动。代价是四季凝固，世上不再有春天，但也**不再有人被抹去**。

### 2.3 他能做到的事（机制层面的表现）

| 能力 | 在游戏中的表现 |
|---|---|
| 记得所有分支 | 他会**预判**玩家的构筑倾向（AI 对手阵容按你的历史卡池生成） |
| 渗入岁盘 | 随周目数上升，天时开始**出现异常值**（岁劫难度） |
| 借用抹掉的名字 | 他的随从是**没有名字的卡影**（无法被记入图鉴/岁印） |

### 2.4 结局的三个方向（供 M4 后裁决）

| 结局 | 内容 | 倾向 |
|---|---|---|
| **同为逆岁** | 你认同他，但选择"让岁轮继续转，你我一起记得"——你成为下一位"记得的人" | 治愈 / 承继 |
| **归位止争** | 你击败他，把渗出的记忆全部刻进岁印——他终于被记住，也因此停止存在 | 悲壮 / 收束 |
| **钉在至点** | 隐藏结局：你选择停下岁轮。四季凝固，游戏进入"无春模式"（永久可玩的高难模式） | 反转 / 后日谈 |

> 默认走「同为逆岁」。是否做三结局需用户裁决。

## 3. 事件驱动叙事骨架

叙事不按幕推进，而是**挂在节点上**。下表是**事件池**，每局从池中抽取子集，因此每局见到的故事不同。

### 3.1 节点与叙事的绑定

| 节点类型 | 叙事密度 | 说明 |
|---|---|---|
| `encounter` | 无叙事 | 纯战斗，仅开场一句台词 |
| `shop`（坊市） | 低 | 摊主的一两句调侃，埋设定碎片 |
| `event`（奇遇） | **高** | 主要叙事载体：短对话 + 选项 + 后果 |
| `elite` | 中 | 精英战前后的岁守传话 |
| `boss`（岁守） | **最高** | 岁守本人的长篇对峙（拆成 3–5 短段） |

### 3.2 事件池（按节气区间，每区间 ≥10 条，此处给骨架示例）

**春庭（节气 1–6）· 青阳的领域**

| 事件 id | 标题 | 内容骨架 | 选项与后果 |
|---|---|---|---|
| `ev.first-thaw` | 初 thaw | 你第一次踏上岁盘，盘面还是上一任留下的残局。一个模糊的影子坐在对面。 | ① 走向它 → 得 `wd.lichun` 印记 ② 先观察盘面 → 得 2 墨料 |
| `ev.blank-name` | 无名卡 | 一张卡上没有名字。它打出去后，卡面浮出一行自己写下的字。 | ① 收下 → 得 1 张无名灵契卡 ② 烧掉 → 得岁印 +5 |
| `ev.sprout-toll` | 抽芽的代价 | 青阳的声音从盘下传来："你让它长了。你知道它明年还得从头长。" | ① 反驳 → 士气 +（下战 +1 墨） ② 沉默 → 得 1 张木系卡 |

**夏海（7–12）· 朱明的领域**：`ev.high-noon`（正午的顶点）、`ev.tide-ledger`（潮汐的账本）、`ev.burn-bright`（燃尽）…

**秋岭（13–18）· 白藏的领域**：`ev.harvest-debt`（收成的债）、`ev.frost-sign`（霜的记号）、`ev.empty-granary`（空仓）…

**冬宫（19–24）· 玄英的领域**：`ev.quiet-is-not-death`（静止不等于死亡）、`ev.last-name`（最后一个名字）、`ev.solstice-pin`（至点之钉）…

### 3.3 数据库结构映射

```
StoryEvent {
  id            "ev.first-thaw"
  term          0..23 或区间 [1,6]        // 可出现的节气
  weight        抽取权重
  once          是否每局只能出现一次
  minCycle      最早在第几周目可出现（用于"真相逐步解锁"）
  lines         [{speaker, text{zh,en}, portrait}]
  choices       [{label{zh,en}, effects[], nextEventId?}]
  storyFlag     触发后置位（跨局保留，用于解锁后续事件）
}
```

**跨局叙事推进（关键）**：`storyFlag` 存在存档里**跨周目累积**。某些事件只有在特定 flag 已置位时才会进入事件池——因此**真相随周目逐步解锁**，而每一局本身仍然独立完整。

**剧情示例（JSON）**

```json
{
  "id": "ev.blank-name",
  "term": [1, 6],
  "weight": 30,
  "once": true,
  "minCycle": 1,
  "lines": [
    { "speaker": "你", "text": { "zh": "这张卡是空的。连名字都没有。", "en": "This card is blank. Not even a name." }, "portrait": "" },
    { "speaker": "？", "text": { "zh": "……不是空的。是还没想起来。", "en": "...Not blank. Just not yet remembered." }, "portrait": "por.unnamed.fog" }
  ],
  "choices": [
    { "label": { "zh": "收下它", "en": "Take it" }, "effects": ["grant.card.unnamed-familiar"] },
    { "label": { "zh": "把它烧了", "en": "Burn it" }, "effects": ["grant.seal.5", "flag.unnamed.burned"] }
  ],
  "storyFlag": "flag.met-unnamed"
}
```

### 4.2 对话写作规范

| 项 | 规则 |
|---|---|
| 单条长度 | **≤ 40 中文字符**（英文 ≤ 90 chars），**最多两行**，超出必须拆条 |
| 一段事件 | 总行数 ≤ 6 行；对话与选项交替出现 |
| 语气 | 岁守：克制、陈述、不咆哮；逆岁者：**从不使用"邪恶"词汇**，始终像在陈述事实；八节使：各有一句口头禅 |
| 禁止 | 长块旁白、说明性倾倒（一次交代两个以上新设定）、元词（"玩家""点击""镜头"）、直接说出机制数值 |
| 双语 | 先 `zh` 后 `en`；**英文为口语本地化，非直译** |
| 立绘 | `por.<subject>.<mood>`；**不要求正面人脸特写**（生图不稳定，见 `ART-STYLE.md` §4.5） |

## 5. 多周目叙事解锁表（示例）

| 解锁条件（跨局 flag） | 新开放内容 |
|---|---|
| 首次通关任意一域 | 逆岁者的第一次现身（`ev.unnamed-appears`） |
| 累计通关 2 域 | 岁守的开场对话扩展（他们开始解释立场） |

| 通关 5 次 | 第三结局分支「钉在至点」开放 |

## 6. 待用户裁决

1. **结局数量**：默认「同为逆岁」单结局；是否做三结局（含「钉在至点」高难模式）？
2. **反派是否有名字**：目前设定「无名」（主题更统一）；若你希望有名字以获得更强记忆点，给出 2–3 个候选由你选。
3. **四时雅称**（青阳/朱明/白藏/玄英）作为岁守名——是否符合你的审美方向？
4. **叙事密度**：当前为"轻叙事、重机制"（奇遇节点承载）；若你要更重的剧情，需要重新评估工期。
