# 玩法真源

> 只回答"怎么玩、怎么赢"。借鉴清单与出处见 [GAME-SCAN.md](GAME-SCAN.md)。世界生成归 [WORLD.md](WORLD.md)，卡数据归 [CARDS.md](CARDS.md)。
> **与 CHARTER 冲突时，本文优先**（2026-10-22 重设计）。

## 1 三版废案

| 版本 | 机制 | 死因 |
|---|---|---|
| 永续沙盒 | 施卡改世界，无对手无失败 | 是玩具，不是游戏 |
| 双神抢格 | 12 格 + 3 分制 + 神威 10 点 | 就是炉石：HP + 场面 + 抢点，只换皮 |
| 能量之网 | 产能 → 存量 → 掠食 → 收割 | 方向对（无 HP），但**画面弱**：玩家看不见"网"，只看见数字 |

**共同病根**：始终没有解决 **multiplayer solitaire**——玩家之间没有必须共享的东西（[GAME-SCAN](GAME-SCAN.md) §1.1）。

## 2 这一版：三行 · 挂卡 · 换季

**一句话**：棋盘是三行生境；**卡挂在卡上**，关系是物理位置；每回合只能打**一个季**的牌。

三个被验证过的机制，组合成一个没人做过的形状：

| 零件 | 出处 | 在这里干什么 |
|---|---|---|
| **行 = 能力类型** | Wingspan / Gwent | 三行不是装饰，每行产出不同、规则不同 |
| **挂卡** | Forest Shuffle | 图鉴的"食物/共生"从文字变成**卡压在卡上** |
| **每回合换季** | KeyForge | 手牌有一半打不出去，取舍是硬的 |

## 3 棋盘：三行 × 四位

```
林冠   [1] [2] [3] [4]     ← 鸟 / 兽 / 攀援虫        产出「果」
林下   [5] [6] [7] [8]     ← 草 / 木 / 菌 / 虫       产出「材」· 公共行
水岸   [9] [10][11][12]    ← 鱼 / 两栖 / 芦苇 / 涉禽  产出「鱼」
```

每行一条规则：

| 行 | 谁能放 | 产出 | 归属 |
|---|---|---|---|
| **林冠** | 飞禽 / 走兽 / 虫豸 | **果**（1/位） | 私有：谁放的归谁 |
| **林下** | 草本 / 木本 / 菌 / 虫 | **材**（1/位） | **公共**：双方各得一半 |
| **水岸** | 水族 / 两栖 / 草本 | **鱼**（1/位） | 私有 |

> **林下是公共行**，这是本作对抗的根：你种的草会喂对手。你在公共行放得越多，对手拿得越多——但你不放，这一行就空着，谁都拿不到。**这是"共同演化"而不是"互相打"。**

## 4 位：一张基座，最多两张依附

每个位只有三层，摆法是物理的：

```
┌──────────────┐
│  依附   依附  │  ← 鸟 / 虫 / 菌（最多 2 张）
│  ┌────────┐  │
│  │  基座   │  │  ← 树 / 芦苇 / 岩（1 张）
│  └────────┘  │
│   地形：林    │
└──────────────┘
```

| 规则 | 说明 |
|---|---|
| 基座 | 每位**只能有一张**。树、芦苇、岩、水洼，决定这一位能挂什么 |
| 依附 | 最多两张，**必须挂在基座上**。没有基座，鸟无处落 |
| 地形 | 林 / 湿 / 岩 / 水。基座必须与地形匹配（`出现地`） |
| 先占先得 | 12 个位，谁先放谁占。占位不消耗额外资源（位本身是稀缺的） |

> **为什么挂卡是关键**：TCG 的卡都在一个平面上（战场），关系只能用文字写。挂卡让"这只鸟属于这棵树"变成**位置事实**——你烧掉树，鸟就掉下来。**破坏的路径变短了，也变好读了。**

## 5 每回合：宣布季，只能打一季

```
回合开始 → 宣布季（春/夏/秋/冬）→ 愿力 +3
├─ 出牌：只能出该季的卡，最多 3 张
├─ 可选：换季一次（换完本回合结束）
└─ 结算：各行产出 → 进下一回合
```

| 规则 | 为什么 |
|---|---|
| **每张卡有季** | 一副牌必须覆盖多季，构筑从一开始就有取舍 |
| **只能打一个季** | 每回合有一半手牌是"能看不能出"的——这是 KeyForge 验证过的硬限制 |
| **愿力固定 3 点/回合，不靠抽** | 炉石式资源，杜绝卡手/爆牌（[GAME-SCAN](GAME-SCAN.md) §1.2） |
| **换季不消耗行动，但本回合立即结束** | 给自己留一条"我这回合没牌可打"的退路，代价是少打一张 |

**费用**：0 环免费 / 1–3 环 1 点 / 4–6 环 2 点 / 7–9 环 3 点。环级 = 强 + 贵 + 稀有。

---

## 6 资源：只有一种，但有上限

产出有三种名字（果 / 材 / 鱼），**用途完全一样**，统称 **生机**：

| 用途 | 代价 |
|---|---|
| 支付高环卡的额外费用 | 1 卡 = 1 生机 |
| 季末转成分数 | 1 生机 = 1 分（**上限 5**，多的浪费） |
| 冬季越冬 | 每张自己的卡 1 生机，付不起就**凋落** |

> **上限 5** 是刻意的：囤积没有意义，必须每季兑现一次。这就把"什么时候卖"变成每 6 回合一次的硬决定。

---

## 7 清算：四季各做一件事

每 6 回合一次（第 6 / 12 / 18 / 24 回合末）：

| 季末 | 清算内容 |
|---|---|
| **春末** | 抽 3 张，弃 1 张 |
| **夏末** | 生机翻倍（上限仍 5），这一季产出最多 |
| **秋末** | **可收割**：拆掉自己任意一个位，该位卡的分值 ×2 落袋，位空出 |
| **冬末** | **越冬**：每张自己的卡付 1 生机；付不起 → 凋落（移出，不计分） |

> **秋收冬藏**：秋天是唯一能"变现离场"的窗口，冬天是唯一会"自然死亡"的窗口。年的节奏就是游戏的节奏——不需要"攻击"来制造压力。

---

## 8 胜负

终局（第 24 回合冬末清算后）：

```
分数 = 落袋分 + 场上每张卡的分值 + 共生加成
```

| 计分项 | 分值 |
|---|---|
| 基座卡 | 2 |
| 依附卡 | 1 |
| **共生对**（同位的两张卡在对方 `共生` 字段里） | 各 +2 |
| 落袋分（秋末收割 / 季末转分） | 实得 |

平局：比场上卡数；仍平则比"未被动过的位"（**界越完整，越算赢**）。

> 最后这条是世界观：**赢不是把对手清空，是让自己的那一角长得完整。**

## 9 对抗：不杀人，只降级

**没有攻击卡，没有伤害。**破坏只有三种"灾"，且全部**延迟生效、可恢复**（Oceans 的做法，[GAME-SCAN](GAME-SCAN.md) §1.3）：

| 灾 | 效果 | 恢复 |
|---|---|---|
| **火** | 一个位的**依附卡全部掉落**（基座留 1 回合空窗） | 下回合可以重挂 |
| **旱** | 一个位 **3 回合不产出** | 3 回合后自动恢复 |
| **寒** | 一个位**冬季越冬成本 ×2** | 只影响冬末 |

三种灾都**不直接消灭卡**。你可以烧掉对手的鸟，但那棵树还在——**下回合他还能挂回来**。

真正的对抗来自**位置**：

| 手段 | 说明 |
|---|---|
| **抢位** | 12 位先到先得，好位（地形匹配多）只有几个 |
| **抢卡** | 公共市场 5 张明牌，拿走即补；你拿走的正是他要的 |
| **公共行** | 林下双方共享；你铺满，他白拿；你空着，两人都少 |
| **灾** | 打断他的链，而不是杀他的卡 |

## 10 为什么这一次不是 solitaire

| 共享的东西 | 效果 |
|---|---|
| **12 个位** | 必须有争夺，位置总量固定 |
| **林下公共行** | 你放的每一张草都在喂对手 |
| **公共市场 5 张** | 抢卡是零和的 |
| **同一棵树的依附位**（每棵树 2 个） | 他挂满了，你就挂不上 |
| **季节同步** | 双方在同一季节里抢同一批"当季强卡" |

## 11 与遗留资产

**留**：六轴形制（决定 12 位的地形分布）、7 元素 × 11 环 × 3 类、环级=稀有度+强度+费用、卡面三轴质感、双层信息、**图鉴四关系（升为挂卡规则）**、痕迹层（灾的留痕）、Z0–Z4、余响（局外解锁）。

**扔**：无失败 / 永续 / 卡唯一 / 离线后台 / 观察者身份 / HP 与攻击力 / 抢格 3 分制 / 能量存量。

## 13 术语

| 词 | 意思 |
|---|---|
| **行** | 林冠 / 林下 / 水岸，各有产出与规则 |
| **位** | 12 个格子，先占先得 |
| **基座** | 每位一张，树/芦苇/岩 |
| **依附** | 挂在基座上的卡，最多 2 张 |
| **季** | 卡的四种类别；每回合只能打一季 |
| **生机** | 唯一资源（果/材/鱼同义），上限 5 |
| **落袋** | 已转成分数的生机或卡分，不会被夺走 |
| **灾** | 火 / 旱 / 寒，降级而不杀 |
| **越冬** | 冬末每张卡付 1 生机，付不起就凋落 |
