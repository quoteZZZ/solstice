# 美术设定 · 风格主题（STYLE）

## 0 本文件管什么 / 不管什么

- **管**：**风格主题的设定层**——为什么风格可自由切换、有哪些主题（**只 T1**）、主题的定义与取舍、参数落在哪、排期。
- **不管**：**执行层参数**（渲染配方、色板 hex、素材规格、QC、验收流程）→ 见 [`../art/ART-STYLE.md`](../art/art.md)；资产生产与登记 → [`../art/ASSETS.md`](../art/art.md)。
- **边界**：本文件回答"**主题是什么、为什么是它**"，ART-STYLE 回答"**怎么画出来、怎么验收**"。

---

## 1 机制：风格是纯表现层，因此可随时切换

**架构前提**：`Sim`（世界模拟）**零渲染依赖**（[`../tech/ARCHITECTURE.md`](../tech/tech.md) §2.2）→ 风格完全属于 `Render` 层。于是：

- 风格主题**可逐界独立**、**可随时切换**、**可存为预设**；
- **同一份存档能长出完全不同的长相**；
- **一套几何资产 → 多套皮**（差异只在材质、后期与几何处理策略上），**不会产生多套建模工作量**。

---

## 2 风格主题（★第 47 轮收口：只做 T1）

| 主题 | 名 | 一句话 | 关键技术 | 成本 |
|---|---|---|---|---|
| **T1** | **纸雕微缩** Paper Diorama | 一盒手工纸雕景观：纸厚度、硬折角、锐利投影、层叠景深 | 双面挤出 + Cel LUT + Inverted Hull + 硬阴影 + 移轴 | 中 |

> **T2–T5 已否决（第 47 轮，CHARTER §5 第 47 轮）**：剪纸立牌 / 手绘纸墨 / 木刻版画 / 粘土定格**不再排期**——只做默认 T1 一套。§1 的"换皮机制"作为**架构能力保留**（`Sim` 零渲染依赖的事实不变），但产品上不出第二主题。

### 2.1 每个主题由六组参数定义

**着色模型 / 描边方式 / 调色板 / 光照与阴影 / 后期（景深 · 暗角 · 颗粒 · 抖动）/ 几何处理（是否用立牌、是否减面）**。

参数落位（目录状态见 [`../tech/STRUCTURE.md`](../tech/tech.md) §0，🟡 = 计划中）：

| 内容 | 位置 | 状态 |
|---|---|---|
| 参数契约 | `shared/schema/style.schema.json` | 🟡 计划中 |
| 主题实例 | `studio/presets/style.*.json` | 🟡 计划中 |
| 主题资产 | `game/Content/Styles/<主题>/` | 🟡 计划中 |
| 执行细则 | [`../art/ART-STYLE.md`](../art/art.md) | ✅ 已定（T1） |

### 2.2 排期

| 阶段 | 主题 | 说明 |
|---|---|---|
| **M0** | **T1（默认 · 唯一）** | 打通"换皮"机制（架构能力验证）；**不排 T2–T5**（第 47 轮否决） |

### 2.3 风格与成本（★第 47 轮收口）

卡面 / UI / 贴图是 2D 图、成本随主题数线性涨——因此**风格主题只做默认一套（T1）**，**不做风格包 / 主题扩展**；资产规模按**单主题**预算（[`../art/ASSETS.md`](../art/art.md) §1.3）。

## 3 风格验收（设计层约定）

每个主题上线前必须出**三张对照图（正午 / 黄昏 / 雨）**，由**用户裁决锁定**；出图与风格锚对不上 = 退回重新生成。**风格不定标不进内容量产。**

> 流程细节与 M0 验收挂钩见 [`../art/ART-STYLE.md`](../art/art.md) §6、[`../plan/ROADMAP.md`](../plan/ROADMAP.md) §2 第 9 条。
