# 规格 v1：卡牌创世沙盒

> **状态：draft。** 这份是当前口径，与 V12–V19 那批（时间演变/纪元/四轴）**不是同一个游戏**，那批作废。
> 用户口径：**虚无开局；撕包得卡；用卡改变世界；时素（时间）换卡；纯自由 + 图鉴收集，无四轴。**

---

## 1 一句话

> **从一片虚无开始，用抽到的卡创造世界，然后看它自己运转。**

---

## 2 核心循环

```
虚无 → 撕创世包（10 张）→ 打元素卡造出地水火风
   → 世界开始运转（温度/水/光 三个数在动）
   → 时间流逝 → 产出时素 → 时素换新卡包 → 用卡改变世界
   → 循环，无终局
```

| 状态 | 说明 |
|---|---|
| 时间 | 1 秒 = 1 个月，可暂停 / 1× / 2× / 4× |
| 时素 | **每 10 秒 +1**（真实时间），不随加速变化 |
| 卡包 | **12 时素 = 1 包 = 10 张** |
| 卡 | **用掉即从卡库消失** |

---

## 3 世界物理（每 tick = 1 月）

每格维护三个数：

```
温度 T = 20 + 太阳×0.5 − 遮阳×0.5 − 蒸发降温×0.5
水量 W = 水源×1.0 − 蒸发(T) − Σ植物吸水        （W 钳位 0 ~ 3.0）
光照 L = 太阳 − 遮阳

蒸发(T) = 0.5 × (T − 10)/10      （T<10 时为 0）
```

**量纲统一**：太阳 1 = 一格日照；水 1 = 一格水量；温度 1 = 1°C。
**取消旧版的 1.2 / 0.8 / 0.05**——那是三处互相矛盾的数，现在统一成 0.5。

### 3.0 遮阳的正确物理（这条改过）

**旧版 bug**：太阳树遮阳 0.5 作用在本格，太阳=1 时 `L=0.5 < 1`，**树把自己饿死**，稳态根本不存在。

**修正**：遮阳只作用于 **相邻格 + 本格的其他实体**，**不减自己的光照**。

| 谁被减 | 减多少 |
|---|---|
| 本格的其他实体 | −0.5 |
| 相邻格的实体 | −0.5 |
| 自己 | **0** |

> 树冠遮的是树下的草，不是树自己。这条一改，稳态才成立。

### 3.1 实体每 tick 做三件事

| 判什么 | 规则 |
|---|---|
| **我需要的东西在不在** | 自养：`W≥1 且 L≥1` → 龄 +1；否则**停滞**（不生长，也不死） |
| **我要吃的东西在不在** | 动物：本格或相邻有目标 → 存活；没有 → 生命 −1 |
| **我该死了吗** | 见下表 |

**死亡规则（旧版缺失，导致正反馈断开）**：

| 死因 | 条件 |
|---|---|
| 老死 | `龄 > 寿命`（草 20 月 / 灌木 60 / 树 400 / 太阳树 300） |
| 旱死 | `W=0` 连续 **3 月** |
| 暗死 | `L<0.5` 连续 **6 月** |
| 饿死 | 动物生命归零 |

**死亡后**：留下「腐尸」格（本体=腐尸，可被腐食），**6 月后变回普通地形**。

> 有了死亡，`温度↑→蒸发↑→水↓→植物死→遮阳↓→温度↑` 这条正反馈才真正闭合。

## 4 词条系统（28 条，一套，不分类）

**原则一：只有一套词条。**没有"逻辑词条"和"检索词条"之分——**同一条词条既参与世界判定，也参与卡包筛选。**

**原则二：卡包不是预设分类，是「按词条组合查询」的结果。**

```
创世包  = 含「创世」的卡
食草包  = 含「动物」+「食草」的卡
神奇包  = 含「神奇」的卡
地形包  = 含「地形」的卡
```

> 所以你加一个新词条，可能自动长出一个新卡包；你改一条组合，卡包内容自己变。**卡包是查询，不是文件夹。**

| 类 | 词条 | 数量 | 谁在读 |
|---|---|---|---|
| **源** | 创世 / 自然 / 神奇 / 禁物 | 4 | 卡包查询 |
| **本体** | 天体 / 地形 / 水体 / 植物 / 动物 / 腐尸 | 6 | 规则 1（吃） |
| **形态** | 微 / 小 / 中 / 大 / 巨 | 5 | 规则 1（体型比较） |
| **食性** | 自养 / 食草 / 食肉 / 腐食 | 4 | 规则 1、3 |
| **功能** | 遮阳 / 保水 / 发光 / 发热 / 传粉 / 净水 | 6 | 规则 2、4 |
| **性质** | 可食 / 有毒 / 速生 | 3 | 规则 1、3 |
| | | **28** | |

### 4.1 四条判定规则（逻辑链的全部）

```
规则 1 · 吃
  食肉 且 目标.本体=动物 且 目标.形态 ≤ 自身.形态  → 吃
  食草 且 目标.本体=植物 且 目标.可食              → 吃
  腐食 且 目标.本体=腐尸                            → 吃
  ★ 吃到「有毒」的目标 → 自身生命 −2（可能一起吃死）

规则 2 · 影响环境
  遮阳 → 相邻格与本格其他实体 T −0.5 / L −0.3（不减自己）
  保水 → 该格蒸发 ×0.5
  发光 → 夜间 L +1
  发热 → T +0.5
  传粉 → 相邻同本体实体生长 +1
  净水 → 该格 W +0.3

规则 3 · 自养
  消耗 W 1 + L 1 → 龄 +1
  ★ 带「速生」→ 龄 +2

规则 4 · 传播
  植物 且 （相邻格有 传粉 源 或 本格 L≥2）
    → 每 N 月向相邻空格生成 1 个同类幼体
```

> **没有一条规则是专为某张卡写的。**卡的差异全部来自词条组合。
> **★ 是这次补的两条**：`有毒` 和 `速生` 原本没有规则读，会变成死词条。

## 5 创世包（6 张，含保证位）

**旧版问题**：18 张池子里生物卡只有 3 张（权重 3/22），开局 6 张里**约 45% 概率一张生物卡都没有**——玩家造出地水火风，却发现什么都不长，直接判定"游戏坏了"。

**修法：保证位。**

| 位 | 内容 | 说明 |
|---|---|---|
| 1 | **太阳** | 保证 |
| 2 | **土地** | 保证 |
| 3 | **水** | 保证 |
| 4 | **一张生物卡** | 草籽 / 苔 / 猴群里随机 |
| 5–6 | 随机 | 从剩下 15 张池子里抽 |

池子（18 张）：

| 组 | 卡 | 权重 |
|---|---|---|
| 天体 | 太阳 / 空气 / 星辰 | 3 / 3 / 1 |
| 地形 | 土地 / 岩石 / 沙洲 | 2 / 2 / 1 |
| 水体 | 水 / 地下水 | 3 / 2 |
| 生物 | 草籽 / 苔 / 猴群 | 1 / 1 / 1 |
| 神奇 | 太阳树 / 月桂 | 1 / 1 |

> 保证位让**每一包都能开局**，随机位让**每局的开局不一样**。

## 9 三份分析查出的四个硬伤

### 9.1 时素通胀 —— **判断错误，已撤销**

分析说"一棵太阳树让产率翻倍"，前提是「太阳树带产时素词条」。

但**时素只由时间产生，没有别的来源**。所以：

- 「产时素」这个词条删掉
- 这条问题不存在
- 上一轮给的修法（+0.2 / 上限 +3）一并作废

### 9.2 废卡堆积 —— **改为"回收换时素"**

| 卡的去向 | 结果 |
|---|---|
| 打出去 | 改变世界，卡消失 |
| 不打 | **回收 → 1 时素** |

汇率：抽包是 **12 时素 = 6 张**（2 时素一张），回收只拿回 **1 时素**（半价）。

于是每张卡都有一个真实选择：**打出去，还是换回 1 时素。**

- 12 张废卡 = 1 包
- 净损耗 50%，不会无限循环
- 卡库永远不会堆到 560 张

顺带把卡包从 10 张改成 **6 张**：30 分钟 15 包 × 6 = 90 张，与实际消耗（60–90）持平。

### 9.3 死词条 —— **直接删，不做补救**

六个（滤食 / 稀有 4 档 / 固土 / 净水 / 天体·地形·水体 / 器物）**全部删除**，不补规则。

理由：**词条如果不能改变任何判定，它就不该存在。**

同时：

- **「创世」等改为"检索词条"**，只用于卡包筛选，不参与世界逻辑
- **加规则 4 · 传播**——唯一新增的规则，让世界自己长
- **尸体转地形**——让「腐食」有落点
- **空气改为有功能**：`传粉`

### 9.4 归因断裂（玩家会在这里关游戏）

**第 30–40 分钟，世界第一次崩掉那一分钟**：玩家按 4× 回来，看见整片红、植物全枯，手里剩 3 张卡、时素 6/12。

> 玩家心里那句话：**"我就放了个太阳，怎么全死了？"**

**修法**：崩溃时必须给一句话归因，且可点开看链条：

```
温度 38°C ─ 遮阳为 0
  → 蒸发 1.4/月，水 2.1 → 0.3
  → 草停止生长（L<1）
  → 猴群断粮 3 个月
```

### 9.5 图鉴只撑 5 小时

| 算法 | 结果 |
|---|---|
| 252 张 / 每局 90 张 | 约 **3 局**抽完 |
| 算重复（等概率） | 约 **10 局 ≈ 5 小时** |

**修法：图鉴收的不是卡，是「世界状态」。**

| # | 成就 | 自动判定条件 |
|---|---|---|
| 1 | **三阳** | 同月太阳源 ≥3，且最大格温差 >20 |
| 2 | **长存** | 某格 W>0 连续 100 月 |
| 3 | **三级链** | 草 + 猴 + 狼 同月共存 |
| 4 | **孤岛** | 水域仅 1 格，且物种 ≥3 |
| 5 | **炼狱** | 某格 T>45 连续 20 月 |
| 6 | **长夜** | 全格 L=0 连续 20 月 |
| 7 | **成林** | 植物格 ≥ 总格 50% |
| 8 | **崩塌** | 10 月内 ≥5 个物种灭绝 |
| 9 | **独木** | 仅剩 1 株植物存活 50 月 |
| 10 | **稳态** | 连续 50 月 T 全在 15–25，且所有生命满 |

**表现方式（不做弹窗）**：

```
时间降到 0.25×，停 0.5 秒
格子上浮一行「第 37 年 · 孤岛」
右侧年鉴落一条刻痕
```

**关键：不给奖励，只记录。**给奖励就变成任务清单了。

> 图鉴做成**地质层 / 年鉴**：未达成的显示为空白拓印，达成后刻上。世界自己长目标。

## 10 卡的可编辑参数

| 卡 | 可编辑什么 | 交互 | 成本 |
|---|---|---|---|
| **太阳** | 大小 / 高度 / 相位速度 | 3 个滑块 + 轨迹预览线 | 低（约半天） |
| **土地** | 形状 + 高度 | **涂抹**，预算制：20 格额度 | 高 |
| **水** | 位置 + 水量 | 涂抹 + 分配（岛内 1 / 岛外 2） | 高 |

> 「土量固定」= **预算制**：给你 20 格额度，涂多少消耗多少。这本身就是设计——你不能造一个无限大的岛。

### 10.1 上限（必须有，否则一改就崩）

太阳是**线性**进温度公式的，调到最大会立刻触发自毁链：

```
太阳↑ → T↑ → 蒸发↑ → 水枯 → 植物死 → 遮阳↓ → T↑（正反馈）
```

| 上限 | 值 |
|---|---|
| 温度钳位 | **60°C** |
| 太阳源数量 | **≤3** |
| 第 2 / 3 个太阳 | 贡献 **×0.6 / ×0.4** |

> **上限本身就是玩法**：「三个太阳」应该是**可作死的选择**，不是无限增益。

### 10.2 天文系统的工作量（这条要提前知道）

真做"三个不同轨迹的太阳"，需要：物理层从标量改向量（3–5 天）+ 阴影渲染（3–5 天）+ 轨迹编辑器（2 天）+ **可读性调优（约 1 周）**。

**v1 只做**：大小差 + 高度差 + 相位速度差，**不做真轨道**。视觉上能看出"三个太阳不一样"，但不动几何。

### 12.1 审出来的三处空壳

| # | 问题 | 具体 |
|---|---|---|
| 1 | **毒沼是空壳** | `有毒` 只在规则 1（吃）里被读，而规则 1 不吃「水体」→ 这张卡什么都没发生 |
| 2 | **寒霜与永夜重复** | 两张都是 `遮阳`，只是形态不同（巨 / 小），行为完全一样 |
| 3 | **土地与岩石重复** | 两张都是 `地形·巨`、无功能、只是容器，玩家没有任何理由选岩石 |

**根因**：词条表缺三样东西——

| 缺什么 | 应该加什么 |
|---|---|
| 负面效果的表达 | `污染`（水体）/ `干旱`（地形）/ `遮光`（区别于遮阳） |
| 地形的差异 | 土地=可耕、岩石=不可耕（需要 `可耕` 性质） |
| 天体的差异 | 太阳=昼夜、星尘=仅夜间（需要 `昼夜` 对 `恒亮`） |

**待定**：这三处是补词条（28 → 31），还是接受"禁物靠组合表达"、把毒沼和寒霜换掉？
