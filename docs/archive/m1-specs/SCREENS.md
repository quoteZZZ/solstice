## 1 设计原则（界面三原则）

1. **S1 是唯一的根屏**：其余全部是**浮层 / 抽屉 / 模态**，没有独立场景切换——"首屏即世界"（[`UI-UX.md`](UI-UX.md) §1）落到导航结构上；
2. **纸材语言**：所有面板 / 卡片 / 按钮都是**纸**（折角、撕裂边、蜡封印章）；浮层不是"玻璃板"而是"翻开的纸页"；
3. **默认收起**：顶栏与抽屉默认淡出，鼠标靠近 / 快捷键才浮现；手牌区常驻底部。

## 3 导航流

```text
首次启动：穹顶开场动画 → S0 世界卡（三标签 + 种子码 + 重掷，不阻塞） → S1
之后启动：直接进 S1（上次的界）
S1 为根 ─┬─ 顶栏 ⚙ → S6 设置
         ├─ 顶栏 界名 → S7 主菜单覆盖层
         ├─ 卡包区 [卡库 B] → S3 ──（Esc/B 返回 S1）
         ├─ 卡包区 [开包 G] → S3b 开包模态 ──（完成回 S1）
         ├─ 左缘 → S4 年表抽屉（滑出）
         ├─ 右缘 / `C` → S2 创世面板（滑出）
         └─ 点选个体 → S5 状态卡（跟随浮层，再点空地关闭）
```

**S1 补注（★第 39 轮）**：

- **穹顶可见性**：俯瞰时画面**上缘隐约露出穹顶内壁的弧线**（分瓣纸壳 + 瓣缝微光，随 F3 低角机位愈发明显）——世界不是悬空的，它在罩子里；
- **开局无空态**（第 54 轮）：世界第一帧就有生态——种群计数、S5 状态卡、年表从开局就可用。原来的「混沌空态」随混沌初态一起作废；
- **余响计数**：蝴蝶形纸屑图标 + 数字（概念图已验证此气质）。
- **0 起步引导**（#59，第 48 轮）：首次进入 S1 时**高亮手牌中的 0 环卡 + 拖动箭头**示意"上拖释放"——一次性、可点击跳过、不打断（开局余响 = 0 的配套，[`INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.6）。

**S3b 分镜（五关键帧，全部程序化 + 2D 素材）**：

| 帧 | 画面 | 时长 |
|---|---|---|
| 1 | 纸包居中，蜡封「界印」朝上，微微呼吸浮动 | 0.5s |
| 2 | **撕封前摇**（#48）：按压蜡封 → 封套裂纹蔓延 → 纤维沿裂纹撕裂（位移贴图）→ 纸屑物理散落并**留在桌面**直到下次开包 | 0.8s |
| 3 | 3–5 张卡**扇形飞出**悬停（背面 = §4.4 牌背；特殊包内超环 / 禁物卡即对应特殊牌背，翻面前已可见） | 0.5s |
| 4 | **逐张翻面**（间隔 0.15s），按下方**拆卡动画分级**区分（#47） | 0.8s~4s |
| 5 | 特殊包时签名卡**最后亮起**（金光一瞬）；全部实体飞入卡包区计数 | 0.6s |

**拆卡动画分级（#47，第 48 轮）**——只按**环级与卡种身份**分级（= 华丽度，守 #6 红线：不引入强度稀有度）：

| 档 | 触发 | 表现 | 增量 |
|---|---|---|---|
| 普通 | 0–7 环 | 现行翻面节奏 | — |
| 金尘 | 8–9 环 | 翻面后金尘沿卡面花纹流过 | +0.6s |
| 超环 | 超环 | 全屏定格 → 视差层逐层立起 → 金光扫屏 → 轻震屏 | +2~3s |
| 禁物 | 禁物 | 翻面顿挫 + 黑雾蚀边（与金光相对的"不祥"感） | — |

> 全档可跳过（点击快进）；超环金光扫屏受 §6「减弱闪光」约束（#49）。

> 可跳过：点击任意处快进；设置里可关（动画三档，§6）。

## 5 释放交互的三态（核心交互过程线框）

```text
态1 拖出：手牌卡上拖 → 卡牌抬起（阴影扩大 + 微倾斜跟随 + 纸声，#52）
          → 卡片放大跟手，世界出现十字光标
态2 瞄准：悬停世界 → 相机自动降到 ~45°（F2 位）+ 作用域预览
          （笔刷圈/区域框/单体高亮，按卡的作用域）
态3 确认：松手 → 卡飞向落点、翻面、卡牌震荡 → 落点压痕涟漪（#52）
          → 效果展开 + 年表一笔
          └ 落地成实体：POP-UP 逐层展开生长入场（≤1.2s、可跳过，#53）
                        + 3 秒"墨未干"涟漪提示，可点收回
态0 取消：拖回手牌区 = 取消，不消耗
```

## 6 建模与实现注记

| 项 | 注记 |
|---|---|
| 控件树 | 每屏一个 `UUserWidget` 根；S1 常驻 + 浮层用 `ZOrder` 叠加，**不切关卡** |
| 九宫格 | 纸面板素材走九宫格拉伸（art.md §7.1 的 UI 产物） |
| 双语 | 所有文案走 `{"zh","en"}` 表（`setting/LORE.md` §5），版式预留英文 90 字符宽 |
| 空槽 | 纸框空槽是独立控件态（不是"不渲染"）——弹药可读性硬要求 |
| 收起 | 顶栏 / 抽屉的"默认淡出"用透明度 + 输入穿透，不做隐藏开关 |
| 概念图 | `tmp/ui-concepts/`（gitignore，过程参考，不定稿不入库） |
