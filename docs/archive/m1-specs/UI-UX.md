## 1 界面区域

| 区域 | 内容 |
|---|---|
| **顶栏** | 世界钟 · 模式标记（真实 / 虚拟）· 环境读数（节气 / 天气 / 温度 / 光照）· 种群计数 · 界切换 |
| **时间条** | **仅虚拟模式**：暂停 / 1x / 4x / 20x + 比例滑块（[`TIME.md`](TIME.md) §2.2） |
| **卡包区** | **余响余额** · "开一个元素包"（撕包动画）· **卡库入口**（只读图鉴，按卡类 / 持续性 / 元素 / 级筛选）· **重抽按钮** · 风格切换 |
| **手牌区（底部）** | ★ **最多 10 格**：每格一张卡牌；不足时显示**卡框空槽**；每张可**向上拖＝释放**、**向下拖＝回收**（[`INTERVENTION.md`](../gameplay/INTERVENTION.md) §1.3） |
| **创世面板** | 法则滑块、现实项接管开关、预设另存（[`CUSTOMIZE.md`](CUSTOMIZE.md) §3） |
| **选中个体** | 状态卡：物种、年龄、能量、状态、**死因**（[`../setting/SPECIES.md`](SPECIES.md) §4） |
| **年表抽屉** | 按世界年分组；可"**回到此刻**"（倒带） |

**首屏即世界**：以上界面**默认收起或淡出**，不遮挡世界；**手牌区常驻底部**（它是主操作面）。

### 1.1 手牌区的三条视觉规则

1. **容量可读**：10 格固定显示，**空槽用卡框表示**——"我的弹药不多了"必须一眼看出。
2. **共鸣高亮**：当前世界状态下特别有用的卡**发光 / 前移**（只改排序与视觉，**不改数值**，见 [`INTERVENTION.md`](../gameplay/INTERVENTION.md) §5.2）。
3. **实体张数**：卡角标出**该卡种的持有张数**（同种多张时，玩家要知道"还能放几次"）。

## 2 交互与键位

### 2.1 手牌的两个方向（★核心手势）

| 操作 | 手势 | 快捷键 |
|---|---|---|
| **释放** | 手牌**向上拖**（卡飞向世界；有可落地形态时再选"生效即散 / 落地成实体"） | `1`–`0` 选卡 → `空格` / 左键点世界 |
| **回收** | 手牌**向下拖**（卡落回卡包，化成一小叠余响） | `X` |
| **重抽** | 手牌区"重抽"按钮（整手 10 张全换） | `R` |

> **方向即语义**：**上＝用出去、下＝收回来**——与卡牌动画同向，不需要教程。
> **切槽**：`Q` / `E` 在十格手牌里前后移动选择（`1`–`0` 是直达某一格）。

### 2.2 其他键位（★2026-10-17 第 49 轮 A-01 重排：**本节为唯一真源**，帮助面板与代码绑定都以此为准）

| 键 | 作用 |
|---|---|
| `1`–`0` / `Q`·`E` | 选卡 / 前后切槽 |
| `空格` / 左键 | 释放当前手牌到光标处 |
| 右键 | 切换「生效即散 / 落地成实体」 |
| `X` / `R` | 回收当前卡 / 换一手 |
| `H` `C` `B` `L` `G` `O` | 帮助 · 年表 · 开包 · **卡库** · 创世面板 · 中英切换 |
| `P` | **摆件 / 截图模式**（#55，第 48 轮）：隐藏全部 UI；`Tab` 复原——「桌面玩具」的分享出口（**时间冻结与 2× 截图待做**，见 `plan/ROADMAP.md` #55） |
| `Tab` | 显示 / 隐藏界面 |
| `T` `K` `J` | 虚拟·现实时间模式 / 暂停 / 倍速（**仅虚拟模式生效**；现实 1:1 下时间控件隐藏，见 §1） |
| `Y` | 自动环绕（像卫星那样绕界慢转） |
| `F1`–`F4` | 固定机位预设（见 §2.3） |
| `F5`–`F8` / `N` | 调试与创世：真实节奏 / 开包（随机·特殊）/ 生态预设 / 播种生命 |
| `Esc` | 退出 |

> **`Z` 撤回已废**（第 49 轮 A-02）：`INTERVENTION` §1.3 的无撤销红线是硬约束，三秒未干期是"墨还没干"的状态，不是撤回窗口。

### 2.3 相机与视角（★2026-10-15 第 35 轮定案：上半球全角度 + 固定预设机位）

**前提**：世界是**全 3D 程序化几何**（[`../charter/CHARTER.md`](../charter/CHARTER.md) §0）——模型没有"立牌单面"问题，相机可环绕到**上半球任意角度**（第 34 轮的"固定俯视角"**作废**）。

| 项 | 规则 |
|---|---|
| **环绕** | 方位角 **360° 自由**（**中键拖拽**）+ 俯仰角 **4°–88°**；**不越过水平面**——界底是"世界断面、不见底"，这是世界观的一部分（[`../setting/WORLD.md`](../setting/WORLD.md) §1.1） |
| **缩放** | 滚轮连续缩放；最近 ≈ 每格占屏 1/8（能看清一片苔），最远 = 全界入画 |
| **平移** | `WASD` |
| **自动环绕** | `Y` 开关：相机像卫星那样绕界慢转（3.5°/秒），接手拖动即让位 |
| **预设机位** | **4 个固定观察位**，一键切回（`F1–F4`；`1`–`0` 已给选卡，故机位落在功能键） |

| 预设 | 俯仰 | 用途（相机为玩法服务） |
|---|---|---|
| **F1 全景**（默认） | ~50° | 开局一眼、大尺度改写——"岸上看一只微缩箱" |
| **F2 卫星** | ~76° | 近俯视巡界：看地势分布与年表痕迹（像卫星过顶） |
| **F3 低角** | ~14° | 贴着地表看**剪影 / 层叠断崖 / 天际线**——"微缩模型箱"感最强，适合挂着看 |
| **F4 顶视** | ~88°（近正交） | **笔刷 / 编辑位**：涂地形、看年表痕迹，当"图纸"用 |

> **四个机位的共同前提**：距离都是「界半径 × 1.45–1.55」，**落在世界外缘之外**（壳在半径 × 1.34）。相机在壳外时穹顶自动让位（`ASolsticeRealm::Tick` 的 `SetSkyVisible`），进去则壳重新成为界壁——所以四个预设看到的都是界本身，不会撞进一只不透明的碗里。

> **微缩感的来源不变**：移轴 / 浅景深 / 暗角是后处理（[`../art/art.md`](../art/art.md)），跟随任意机位；低角 + 长焦压缩依然成立。
> **低角机位注意**：立牌 LOD 是双面面片（[`../art/art.md`](../art/art.md) §0.2），低角机位下要处理**侧视线**（加薄边或抬高 F3 俯仰下限）。
> **与"岸"的关系**：上半球约定就是"站在岸上"的相机化表达——你始终从上方某个位置看进这只"微缩箱"，从不沉到箱底。

## 3 极简原则与实现分工

- **原则**：无教程、无任务列表、无成就弹窗；**首屏即世界**；机制学习靠世界反馈而非弹窗。
- **实现**：默认由 AI 用 **C++ 构建控件树**；后期审美打磨在编辑器里用 **UMG** 可视化调整。
- **卡面与 UI 素材**：生图线产出（画芯无文字、无边框；名称 / 徽记 / 数值由 UMG 绘制，见 [`../art/art.md`](../art/art.md) §4）。
- **中英双语**：所有用户可见字符串必须双语（[`../setting/LORE.md`](../setting/LORE.md) §5）。
