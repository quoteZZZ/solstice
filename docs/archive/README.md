## 这里为什么会有这些

这些文档是**上一款游戏**的提案——「卡牌驱动的荒岛经营」。

它和现在这款的区别：

| | 这里的旧提案 | 现在的设计 |
|---|---|---|
| 世界大小 | 固定 24 格 | **0 格起，打土地卡才长，无上限** |
| 时间 | 一张卡换一年 | **自己流动，1 秒 ≈ 1 月** |
| 进度 | 四轴 + 六纪元 | **无终局，无纪元** |
| 卡数 | 252 张固定 | **不固定，随合成图增长** |
| 卡的行为 | 词条 + 4 条规则引擎 | **25 个组件，声明读写** |
| 合成 | 三条法则 + 7 标签 | **蕴含关系（A+B=C 则 C⊃A,B）** |
| 演变 | 五层（生命史/演替/林冠/气候/纪元） | **无层，全由组件跑出来** |
