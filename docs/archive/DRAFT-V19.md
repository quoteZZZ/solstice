# 提案 v19：三个判决

> **状态：draft。** 这一版不加新机制。三个方向（文档一致性 / UE 实现 / 核心动词）查出的问题，已经不在设计层了。

---

## 1 判决一：文档层有 10 处硬冲突，不能再加第 19 份

六份 draft（V12/V13/V14/V17/V18/CARDS）互相矛盾，**同一件事各说各的**：

| # | 项 | 各处说法 | 应取 |
|---|---|---|---|
| 1 | 一局卡数 | 24 / 34 / 42 | **34**（V17 算出来的） |
| 2 | 纪元门槛 | 消费者 3 个 / 2 个 | **2**（V17） |
| 3 | 自然度 | 每 10 年 −3 / −4；砍树 −0.5 / −0.8；间伐 −0.2 | **−4 / −0.8 / −0.2** |
| 4 | 卡池总量 | 252 / 273 / 300 | **252**（V12 + CARDS） |
| 5 | 局时长 | 30–40 分钟 / 30 分钟 | **30–40** |
| 6 | 食物链免疫 | 100% / 50% | **50% + 每 10 年复检**（V18） |
| 7 | 机会窗口 | 3–5 分钟 / 30–40 秒 | **30–40 秒**（V17） |
| 8 | 概念层 | 已删（V15/V16）但 V12/V13/V18 仍在引用 | **彻底删** |
| 9 | 每格位置 | 只有 V12 写了 3 位，后续没继承 | **3 位**（保留） |
| 10 | 四轴级数 | 各 3 级 / 纪元五要各 2 级 / 8 个里程碑 | **各 3 级，共 12 里程碑** |

**三份以上各说各的**：静观卡、自然度速率、一局卡数、时间模型、枯竭纪元、灾害频率。

> **判决**：**停止新增 draft。**先把这 10 条裁决写进一份 `GAME.md`，V12–V18 全部标 `superseded`。
> 不合并的后果很具体：**没有人能照着实现**，因为同一个数字有 2–3 个值。

## 2 判决二：技术上第一件事不是设计，是"时间刻度"

技术负责人读了现有工程，结论是可量化的：

| 现状 | 问题 |
|---|---|
| `FSimKernel::Advance` 每帧最多跑 **600 步** | 超出即**丢弃 accumulator** |
| `StepWorldMinute()` 粒度是 **1 世界分钟** | 1 年 = **525,600 tick** |
| 需求是「1 秒 = 1 个月」 | 一帧需要 **≈730 步** → **超限** |

**后果**：世界时间会**静默落后于真实时间**，且**没有任何报错**。
验收 A1（60 秒前进 5 年）会直接失败，并把熵增、灾害、机会窗口的时间轴一起拖歪。

**修法（必须先做）**：

| 动作 | 内容 |
|---|---|
| 1 | tick 从「分」改到「日」或「半月」 |
| 2 | 同步重标定 `StepEcology` 的 per-hour 速率常数 |
| 3 | 重跑 bench，更新 digest 基准 |
| 4 | 把 `bPaused` 的 Real 模式漏洞补上（现在只在 Virtual 模式生效） |

**其余五项的工作量**（人日）：

| 项 | 人日 | 风险 |
|---|---|---|
| 时间自流 + 变速 + 暂停 | **6–8** | 如上，阻塞全部 |
| 五层演变 | 5–7 | 林冠遮荫要改渲染 |
| 连通块判定 | 1.5–2 | 无风险（24 格太小） |
| 个体 id + 年轮 | 2–3 | 年表要能引用个体（现在只有字符串） |
| 三个时间可见 | 4–6 | 年轮必须走材质参数，不能建几何 |
| 年表跨局存档 | 5–7 | **工程里没有存档系统**，从零建 |
| **合计** | **24–33** | |

> **判决**：先做时间刻度（6–8 人日），**它是所有数值的分母**。在此之前写任何卡数值都是白写。

## 3 判决三：核心动词是"种"

玩家每 30 秒做的动作有六种：施卡 / 划线引水 / 间伐 / 标记 / 追因果 / 调速。

**六种动作 = 没有核心动词。**而好游戏都有一个：

| 游戏 | 核心动词 |
|---|---|
| 炉石 | **换**（随从交换） |
| 游戏王 | **连**（连锁） |
| Factorio | **扩**（扩产线） |
| RimWorld | **排**（排班） |
| Islanders | **摆**（摆一块） |
| **本作** | **种** |

**"种"能统摄全部六种动作**：

| 动作 | 用"种"怎么解释 |
|---|---|
| 施卡 | 种下一张卡 |
| 划线引水 | 种一条河 |
| 间伐 | 拔掉一株 |
| 标记 | 预定要种的地方 |
| 追因果 | 看它长成了什么 |
| 调速 | 让它长得快一点 |

**一句话（第三版，终于稳了）**：

> **你在这座岛上种东西，然后看它们互相吃掉。**

前三版是"用卡推年""用 24 张卡决定它老成什么样子"，都偏管理。这一版偏**因果**——种下去的东西会自己长、自己吃、自己死。
