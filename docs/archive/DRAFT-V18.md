# 提案 v18：补三处结构性空洞

> **状态：draft。** 三份分析（最优解 / 长线留存 / 情感）查出的都不是数值问题，是**结构性空洞**。

---

## 1 三个结构性问题

| # | 问题 | 证据 |
|---|---|---|
| **1** | **最优解唯一，20 张卡 40 年通关** | 0 环刷卡铺底 → 鹿×2 + 狼 → 一张狼把熵增永久关掉 → 之后 60 年零决策 |
| **2** | **第 10 局 = 第 50 局** | 概念在 12 局放完，之后每局同一剧本；87% 的卡没有跨局累积 |
| **3** | **没有失败，也没有"值得在乎"的东西** | 四份文档里没有失败条件；树没有名字，删掉的是"树"不是"那棵树" |

**附带问题**：摆烂能半赢（演替自己走 30 年成林，纪元自动满足）；「静观」在 30 秒冷却下 = 每 30 秒白拿一包。

---

## 2 补丁一：拆掉"一招通吃"

### 2.1 狼不再是开关

| 现状 | 改为 |
|---|---|
| 有狼 = 熵增永久停止 | **免疫 −50%**，不是 −100% |
| 狼永远在 | **狼会饿死**（鹿 <2 只时，每年 30% 概率离开） |
| 食物链成立一次就够 | **每 10 年复检**，任一环断了免疫立刻失效 |

> 于是"摆一条食物链然后收工"变成"维持一条食物链"。**维持才是玩法。**

### 2.2 0 环卡不许跨演替阶段

| 卡 | 现状 | 改为 |
|---|---|---|
| 播种 | 荒 → 草（跳过演替） | **只能加速**：演替值 +10，不直接改地形 |
| 垒土 | 荒 → 草 | 同上 |
| 滴水 | 水 +1（无限） | **上限 3**（超过无效） |
| **静观** | 0 环，白过一年得 1 包 | **移到 2 环**，且每 10 年 1 次 |

> **0 环卡的定位是"最低保底的行动"，不是"免资源发展"。**

### 2.3 摆烂不再能赢

| 现状 | 改为 |
|---|---|
| 演替自己走（荒 +2/年），30 年成林 | 演替**只在有"因果"的条件下自动**（玩家至少施过 1 张物种卡） |
| "动物可以进入"（没写必须玩家引入） | 改为"**动物必须由卡引入**"（回到 WORLD §9.0 的荒界口径） |
| 世界目标要 8 张里程碑（唯一闸门） | 加第二道闸门：**第 40 年时自然度 ≥ 50** |

## 3 补丁二：长线三层（不加卡）

### 3.1 卡池按纪元分包（跨局累积）

**252 张拆成 6 包 × 42 张**，每包对应一个纪元：

| 包 | 内容 | 解锁条件 |
|---|---|---|
| 包一 | 0–1 环 | 开局 |
| 包二 | 2–3 环 | 第一次进入纪元二 |
| 包三 | 4–5 环 | 第一次进入纪元三 |
| 包四 | 6–7 环 | 第一次进入纪元四 |
| 包五 | 8–9 环 | 第一次进入纪元五 |
| 包六 | 超环 + 禁物 | 第一次进入纪元五 **且** 通关一次 |

> **走完纪元才把该包并入未来局的抽池。**这是跨局累积，且不需要新机制——复用的是现成的纪元结构。

### 3.2 星标图鉴（12 × 4 = 48 格）

世界目标从"通关条件"升级为**评级 + 约束变体**：

| 变体 | 约束 |
|---|---|
| 标准 | 无 |
| **禁伐流** | 不能砍树 |
| **无动物流** | 不能引入动物 |
| **干旱岛** | 开局水格 = 0 |
| **不施超环** | 全程不用超环卡 |

每组（目标 × 岛型）记**最好成绩**，48 格全部点亮才算全通。

### 3.3 年表跨局存续

**上一局的年表，变成下一局的遗迹。**

| 上局结束时的状态 | 下局开局 |
|---|---|
| 有石碑 | 开局地上有石碑残骸（可读上局最后一句话） |
| 森林覆盖率 >60% | 开局有枯木（可直接引木本） |
| 自然度 <30（枯竭） | 开局是**焦土**（养分 −1，但有稀有矿物） |
| 人口 >30 | 开局有废墟（可挖出工具） |

> 这同时解释了"为什么有些卡一开始就有"——**它们是你上一局留下的**。

## 4 补丁三：让世界"值得在乎"

### 4.1 个体连续性（最关键的一条）

**每棵树、每只鹿都有唯一 id 和年龄。**

| 现状 | 改为 |
|---|---|
| "森林 7 格" | "**第 8 年种下的那棵白桦，今年 47 岁，是岛上最老的树**" |
| 年表只记面积 | 年表记**个体出生与死亡**："第 12 年，第一只鹿出生""第 58 年，那棵白桦倒了" |
| 移除无提示 | 移除前显示"**这棵 40 年**" |

> 能在乎的不是"森林面积"，是"你第 8 年种下、第 55 年还站着的那棵"。

### 4.2 后果写在按钮上

点每个动作前，先显示会发生什么（沿用 CHARTER §7 已验证的手法）：

```
┌─ 开田 ──────────────────┐
│ 食物 +3/年               │
│ 光照 −1                  │
│ 成林羁绊断开             │
│ → 这只鸟明年不回来       │
└─────────────────────────┘
```

**不弹确认框**（Townscaper 的"操作即结果"），只是**按钮旁边写着代价**。

### 4.3 枯竭不给折扣，改为"抹掉历史"

| 现状 | 改为 |
|---|---|
| 进入枯竭后禁物代价减半（打折促销） | **枯竭之后，年表每年自动删掉最早的一条** |
| 还能继续玩 | 年表删空时，游戏结束（"这座岛不再记得自己"） |

> 玩家会看着自己的历史一条一条消失。**这比任何失败画面都重。**

## 5 补丁汇总

| # | 补丁 | 治什么 |
|---|---|---|
| 1 | 狼会饿死 + 免疫 −50% + 每 10 年复检 | 一招通吃 |
| 2 | 0 环不许跨演替、滴水上限 3、静观移出 0 环 | 0 环白嫖 |
| 3 | 演替需玩家先施物种卡；动物必须由卡引入 | 摆烂半赢 |
| 4 | 卡池 6 包跨局累积 | 87% 的卡没去处 |
| 5 | 星标图鉴 48 格 | 12 目标变 KPI |
| 6 | 年表跨局存续（上局变下局遗迹） | 局与局之间没有联系 |
| 7 | **个体 id + 年龄 + 年轮** | 没有"值得在乎"的东西 |
| 8 | **后果写在按钮上** | 玩家不知道自己造成了什么 |
| 9 | **枯竭 = 每年删一条年表** | 枯竭没有重量 |

## 6 验收

| # | 验收 | 判定 |
|---|---|---|
| A1 | 狼不是开关 | 鹿减到 <2 后 3 年内，免疫失效（自然度重新下降） |
| A2 | 0 环不越级 | 只用 0 环卡，30 年内无法从荒到林 |
| A3 | 摆烂不能赢 | 全程只施 0 环卡，80 年内达不到世界目标 |
| A4 | 卡池分包有效 | 第 1 局可抽卡池 ≤42 张；通关一次后 ≤84 张 |
| A5 | 个体可指认 | 能说出"最老的那棵树是第几年种的" |
| A6 | 后果可读 | 任意动作，按钮旁有 ≥2 条代价说明 |
| A7 | 枯竭有重量 | 进入枯竭后，每 10 年可见年表少 1 条 |
