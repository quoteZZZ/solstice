## 3 七条红线

1. **`Sim/` 零渲染依赖**——不 include UObject / Tick / 渲染 / 输入；改完表现层跑 `bench`，digest 必须不变。
2. **不新建模块**——能力落主模块子目录（`SolsticeSim` 独立模块已被实测否决）。
3. **数字只在一处**——规格数字写在对应域文档里，代码里的常量标注出处；**禁止在第二份文档里抄一遍**。
4. **相机只许停在 32 个格点**（方位 8 × 俯仰 4）+ **Z0–Z4 五级缩放**——验收态禁止任何连续环绕入口。
5. **画面里不出现纸质感**（纸纹 / 纸厚 / 纸纤维 / 撕裂边）——纸雕形态已作废。
6. **界缘必须有交代**——海 / 雾 / 云 / 深渊 / 冰盖 / 图纸硬切六选一，不许"凭空没了"（[WORLD.md](WORLD.md) §2.3）。
7. **提交前两条自检 0 错 + `CHANGELOG.md` 一行**；未提交 = 未落地。

## 4 开工顺序

```text
读本文 → 读对应域文档（一份）→ 读 PLAN 的「当前批次」→ 动手 → 跑 OPS 的自检 → 提交
```

- **不读**：`docs/archive/**`（无约束力）、`LATER.md` 及其指向的 M1 细则。
- **遇到文档与代码不一致**：以「代码在跑什么 + 用户裁决」为准，把差异写进 `PLAN.md` 的「已知缺陷」，不要私自改规格。

## 5 文档纪律

| 动作 | 做什么 |
|---|---|
| 改内容 | 只改正文 + `CHANGELOG.md` 加**一行**（日期 / 结果 / 影响文件） |
| 加新数字 | 写进对应域文档的表格，**不建索引页、不抄副本** |
| 新增 / 作废文档 | 才改本节 §2 的表 |
| 旧稿 | 移入 `docs/archive/`，不再引用、不再维护 |
