# 卡合成树

> 这张表同时是**图鉴**（我知道什么）和**工作台**（我能造什么）。
> 环级 = 合成深度 = 效果水平 = 稀有度，四者绑定。

---

## §1 三条构造规则

| 规则 | 内容 |
|---|---|
| **环级递推** | `卡.环 = max(所有输入的环) + 1` |
| **向下蕴含** | 拥有一张卡 → 自动拥有它的全部输入 |
| **向上蕴含** | 拥有全部输入 → 自动获得这张卡的知识（不用抽到它） |

**所以「石斧(1环) = 石(0环) + 木(0环)」天然满足"石斧的环 > 石和木"。**

## §8 超环与禁物（不在树里）

| 类 | 卡 | 为什么不在树里 |
|---|---|---|
| **超环** | 造陆 / 拔山 / 改季 / 长昼 / 潮汐 / 星河 / 深渊 | **没有输入**——它是"从无到有"，所以只能靠抽 |
| **禁物** | 永夜 / 火种 / 毒沼 / 寒霜 / 死土 / 噬光 / 锁 | **没有输入，还要付债务** |

**这两层是树的例外**：树的规则是"必须有输入"，而它们故意违反。

## §10 工作台视图

选中两样东西，工作台自动判断能不能合成：

```
┌─────────────────────────┐
│   石        木           │
│    ↓        ↓            │
│   ┌──────────┐           │
│   │  石斧    │  1 环     │
│   │ 切割      │  需要握持≥0.5 │
│   └──────────┘           │
│   [ 合成 ]  [ 取消 ]      │
└─────────────────────────┘
```

**工作台不显示"配方表"，只显示"这两个能变成什么"。**因为规则是通用的，玩家试两次就懂。

## §12 这棵树证伪了什么

| 之前的说法 | 现在的实际情况 |
|---|---|
| "252 张卡" | **实际 7 + 19 + 17 + 14 + 10 + 8 = 75 张**（不含超环禁物） |
| "卡数固定" | 75 是**当前设计需要**，不是规则限制。加一个分支就多 10 张 |
| "环级要设计 12 档" | **环级是算出来的**，你只需要保证每个节点有两个输入 |
| "合成要写配方表" | **只有 75 行数据**，没有"4 万种组合"的问题 |

### 12.1 还缺什么

| 缺 | 说明 |
|---|---|
| **生物卡** | 这棵树里只有工具和建筑，**没有任何动物/植物**。它们不在合成树里，在"物种卡"里 |
| **术·境** | 暴雨、焚烧、引水这些干预卡，也不在树里 |
| **律** | 长夏、禁伐这些全局规则，不在树里 |

**所以完整卡池 = 合成树（75）+ 物种卡（约 40）+ 术·境（约 30）+ 律（约 15）≈ 160 张。**

**160 就是"当前设计需要"的数量，不是 252。**
