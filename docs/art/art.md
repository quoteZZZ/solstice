## 0.1 机制：风格是纯表现层，因此可随时切换

**架构前提**：`Sim`（世界模拟）**零渲染依赖**（[`../tech/tech.md`](../tech/tech.md) §2.2）⇒ 风格完全属于 `Render` 层。于是：

- 风格主题**可逐界独立**、**可随时切换**、**可存为预设**；
- **同一份存档能长出完全不同的长相**；
- **一套几何资产 → 多套皮**（差异只在材质、后期与几何处理策略上），**不产生多套建模工作量**。

> 这条能力是**架构事实**，与产品上出几套主题无关——即使只做 T1，换皮机制也依然成立。

## 0.5 外部参照（第 52 轮用户点名；第 57 轮补「动画组」）

用户原话：「参考林中世界或类型其他游戏」。**《林间小世界 / Tiny Glade》**（Pounce Light, 2024）是本作地景密度与光感的**第一参照**，其余为同类型补充。参照的是**做法与读感**，不是素材。

| 游戏 | 该拿什么 | 不该拿什么 |
|---|---|---|
| **《林间小世界》Tiny Glade** | ① **程序化植被**：墙脚自动长苔藓、路边自动生野花——场景细节不靠手摆，靠规则长；② **光时分段**：晨 / 午 / 夕 / 雨 / 雪 各有一套色温与影子长度，切档不改几何；③ **微缩尺度感**：镜头永远在"能一把捧起来"的距离；④ **路径即引导**：小径自动找门、绕开水体 | 建筑玩法（无网格堆叠）——本作不盖房，只摆卡 |
| **Townscaper** | 单次操作的**即时可读反馈**（点一下立刻看到结果） | 网格化的几何规则 |
| **Dorfromantik** | **远山分层**的节奏：三层就够，越远越淡、越少细节 | 六边形拼图机制 |
| **Islanders** | **小体量 + 强轮廓**：一眼能认出这一坨是什么 | 计分与关卡 |
| **A Short Hike** | **低饱和渐变天空** + 低多边形地形，颜色少而准 | 开放世界规模 |

**动画组参照（★第 57 轮补：T1 换成动画赛璐璐后的第一参照组）**：

| 参照 | 该拿什么 | 不该拿什么 |
|---|---|---|
| **吉卜力**（《天空之城》《龙猫》） | ① **天空的渐层读法**：天顶深、地平线近白，云是**手绘白块**而不是光照计算结果；② **多段绿**：一片林子有 3–5 个绿，不是单色加明暗；③ 云带**有形状**（顶部平、底部圆），不是噪声 | 具体角色、飞行器、场景造型 |
| **新海诚** | ① **过曝边缘**：亮部往白里收一档；② **云隙光 / 逆光轮廓**；③ 黄昏的**橙紫双层**过渡 | 摄影后期式的镜头光斑与颗粒——会把微缩模型感打散 |
| **《旷野之息》卡通渲染** | ① 卡通材质的**分带硬切 + 描边按深度调宽**；② 草地摆动的**整体韵律**（成片波动，不是逐株乱摆） | 具体地形、神庙、UI |

**四条红线**：
1. **不复制素材**——不描摹任何游戏的贴图、模型、UI 元素；只借"读法"。
2. **不借品牌**——不出现任何游戏的标志性造型（如独特的塔楼剪影、特定配色组合）。
3. **尺度优先于细节**——先保证"一看就知道是捧在手里的小世界"，再谈草有几根。
4. **不出现纸质感**（★第 57 轮）——纸纹、纸厚、纸纤维、撕裂边、纸浆颗粒**一律不进画面**；这些是已作废 T0 的语言，见到即视为风格事故。

> 落点：§2 的 T1 配方；地景密度的验收见 §6，形态尺寸见 [`../setting/WORLD.md`](../setting/WORLD.md) §1.1。

## 2 T1「动画赛璐璐」渲染配方（默认主题 · ★第 57 轮整体重写）

一句话口径：**画面应该像一帧手绘动画的定格，而不是一盒纸做的模型。** 分带靠色阶硬切，立体靠描边与明暗面，微缩靠移轴——**不靠材质厚度和纸纹**。

### 2.1 着色与描边

| 项 | 做法 | 参数（初值，定标时可调） |
|---|---|---|
| 主体着色 | **Cel LUT**：3 段（亮 / 中 / 暗），**段间硬切**，段内允许 ±2% 微渐变（防塑料死板） | 分段点 `0.30 / 0.62`；段内渐变 `0.02` |
| 暗部 | **抬亮**：暗段不低于亮段的 45% 明度，阴影色**偏冷**（蓝紫），不用纯黑也不用 AO 压黑 | 暗段色相偏移 −12°，明度 ×0.55 |
| 高光 | **高光断点**：第 4 段色阶（比亮段更白更冷），只给**水 / 金属 / 湿石**三处 | 阈值 0.86，色 `#F2F7FF` |
| 描边 | **Inverted Hull**（反法线外扩）；宽度**随深度反比**：近景 2 px、中景 1.5 px、远景 1 px；**不描地平线、不描云、不描天空** | 基准宽 `0.9 cm` 世界尺度 |
| 轮廓光 | 山脊、树冠迎光侧加 1 px 亮边（比本体亮 15%）——动画里"边上有光"的读法 | — |
| 描边色 | 不是纯黑：按环境色取**深同族色**（白天深褐绿、黄昏深紫红、夜深蓝） | 明度 ≈ 本体的 22% |

### 2.2 天空（占画面一半，必须先做对）

| 层 | 做法 |
|---|---|
| **天顶** | 最深的一档（白天 `#4E8FD0` 量级，不是天蓝原色） |
| **中层** | 渐变过渡带（占天空高度 55–70%） |
| **地平线** | **近白**（`#EAF3FA` 量级）——这是"看起来像动画"的第一要素，比任何材质都重要 |
| **云** | **2 层云带**：卷云（细长、横向拉伸、半透明 60%）+ 积云（顶部平、底部圆、**不透明纯白 + 底面色**）；云用**平面分层**，不用体积云 |
| **云的动态** | 整层低频平移 0.5–2°/s；阴天靠**云覆盖率**而不是压暗天空 |
| **天体** | 太阳 = 圆盘 + 2 圈光晕（同心、不透明度递减）；月 = 圆盘 + 相位遮罩；星 = 点精灵 + 闪烁周期 |

> **为什么单列天空**：实测画面里天空占 ~50%，纸雕时期这一半是空的（[`../plan/work.md`](../plan/work.md) `R-20`）。动画风格的辨识度**七成来自天空**——渐层与云带做对，剩下的都好办。

### 2.3 地形、水、植被

| 项 | 做法 |
|---|---|
| 地形 | **平涂色块 + 色带分界 + 坡面明暗**：山体靠**明暗面切分**读体积，**不做纸层叠、不做厚度断面** |
| 色带 | 每个生态域给 **2–3 档同族色**（如草地：`#7FBF5F` / `#5F9E4A` / `#3F7A3C`），按高度或坡度切换，**硬边切换** |
| 水面 | 平涂水色 + **白描波纹线**（3–5 条，缓慢平移）+ 岸线**一圈亮边**；不用真实反射 |
| 植被 | 树 = 低模几何 + Cel 着色（**不做立牌卡片**）；草 = 成片**整体波动**，周期 2–4 s |
| 微缩感 | **移轴 / 浅景深**（上下各 12–18% 模糊带）+ 轻度暗角 + 机位 26–60° |
| 世界外缘 | **不做纸厚断面**：外缘一条**硬描边 + 下方世界色切断**（口径见 [`../setting/WORLD.md`](../setting/WORLD.md) §1.1） |

### 2.4 昼夜与天气（只改四组参数）

| 项 | 白天 | 黄昏 | 夜 |
|---|---|---|---|
| 天空三段 | 天顶蓝 / 地平线近白 | 天顶紫 / 中橙 / 地平线金 | 天顶深蓝 / 地平线暗青 |
| 主光色温 | 5600 K | 2400 K | 9000 K（月光） |
| 描边色 | 深褐绿 | 深紫红 | 深蓝 |
| 云 | 纯白 + 底面色 | 顶金 + 底紫 | 半透 + 月光镶边 |

| 天气 | 表现（全部是"画上去的"，不是模拟的） |
|---|---|
| 雨 | 斜向细线段（3–4 px）+ 水面涟漪环 + 地面降饱和 10% |
| 雪 | 白色扁片飘落 + 地表覆白（LUT 亮段上移） |
| 雾 | **3 层半透明平面**（近浓远淡），不用体积雾 |
| 雷 | 全屏 1 帧白闪 + 延迟 0.4–1.2 s 的音效 |

**M0 硬约束**：**无 Lumen / Nanite / 全 PBR**；**无体积云 / 体积雾**（一律平面分层）；**无纸纹 / 纸厚 / 纸纤维**（§0.5 红线 4）；材质实例集中管理（[`../tech/tech.md`](../tech/tech.md) §1.4）。

### 2.6 取景与机位（★角度离散，距离连续）

> **一句话**：玩家可以在**有限个角度**里选看哪一面，但**远近是连续的**。自由度砍在方向上，不砍在推拉上。
> **口径来源**：[`../charter/CHARTER.md`](../charter/CHARTER.md) 第 59 轮裁决。本节是唯一真源，别处只写指针。

**为什么禁连续环绕**（这条推翻了 `later/UI-UX.md` §2.3 的「方位 360° 自由」；理由是**验收口径**，不是"操作复杂"）：

1. **它把美术成本乘了 360**。连续环绕意味着穹顶背面、世界断面、低角侧视线、逆光轮廓面都要成立。实测暴露的缺陷——外缘托盘与梳齿（`R-19`）、水面黑椭圆（`R-34`）、穹顶被当成实体画——**全部是在自由旋转时转到"没人设计过的角度"才露出来的**。角度离散后，验收从"任意角度都要对"降到"32 个格子必须成立"，这是唯一做得完的口径。
2. **diorama 的可读性来自正对**。歪 15° 时地面椭圆比、山脊走向、岸线弧度都是错的读数，玩家会把镜头误差读成世界本身是歪的。
3. **每格的构图可复用**：固定机位能预烘后期（移轴焦平面、暗角中心），连续旋转只能给一套折中参数。

**方向档（两个轴各自离散，不做到 32 个机位的独立预设）**

| 轴 | 档数 | 值 | 键 |
|---|---|---|---|
| **俯仰** | 4 | 低角 **14°** / 标准 **35°** / 巡界 **62°** / 图纸 **88°** | `V` 循环；`F1`–`F4` 直跳 |
| **方位** | 8 | 45° 步进（以 **−45°** 为 0 档基准） | `[` `]` 转 45° |

| 俯仰档 | 用途 | 该档必须成立的东西 |
|---|---|---|
| 低角 14° | 剪影、世界断面、穹顶内壁的弧 | 地平线切过画面下 1/3；**不露出壳的背面**；世界外缘只有一条硬描边 |
| **标准 35°** | **默认观赏档**，入场与日常；落在 §2.3「机位 26–60°」内 | 三个面都看得见；微缩感靠移轴压出来 |
| 巡界 62° | 找地形层次、看山脊走向 | 地面椭圆比 ≈ `sin62°` = 0.88 |
| 图纸 88° | **地形可读性验收**（判据「无死面」靠它） | 圆盘的轮廓接近正圆，岸线连续，无缺口 |

> **为什么是 8 个方位不是 4 个**：世界骰给每个世界随机的地形与天象，最好看的那一面是随机的——4 个方位可能整局都没碰上。8 个方位是「覆盖得住」与「不用记」的折中；实际操作里 90% 的时间只会用 35° × 8 方位这一圈。
> **14° 与 88° 是验证档，不是主玩视角**——它们用来把世界逼到极限看有没有穿帮，不指望玩家长时间停在那里。

**距离：两个界，量法不一样**

| 界 | 值 | 为什么这样量 |
|---|---|---|
| 取景距离 `Fit` | `1.09 R ÷ tan(半垂直 FOV)`；FOV 38° 水平 + 16:9 → **5.63 R** | 让直径 `2R` 的圆盘正好填满垂直视场。**永远不要用 "半径 × 常数" 写机位距离**——它不知道镜头，换 FOV 立刻裁边 |
| 最远 | **1.6 × Fit**（128² ≈ 9.0 R） | 再远穹顶轮廓也糊成点，世界失去"可以捧起来"的尺度感 |
| 最近 | **25 m（2500 uu）**，≈ 一格占屏 1/5 | **近界必须用绝对距离，不能用 Fit 的倍数**：世界从 128² 长到 512²，一格还是 1 m，能看清苔藓的距离不变。用倍数会让大世界的最近视角退到 200 m 外 |

- **远界跟世界半径走，近界跟格边长走**——这是 §1.1「尺寸是尺度不是分辨率」在相机上的同一句话。
- 缩放**不做档位吸附**：推拉是手感，档位会毁掉"贴近看一片苔"和"退开看全界"之间的中间态。角度才需要吸附。
- 缩放**锚在世界中心**（M0 口径）；"锚在光标下那一点"列为 M1 改进，需要射线求解，不值得在 M0 做。

**顺带禁掉的三条路**

1. 中键拖拽**不再是环绕**（改为推拉）。任何能连续改 yaw / pitch 的入口都要堵死，否则离散化白做。
2. 俯仰**不得越过 88°**、不得低于 14°——不进入水平面下方，界底是"世界到此为止"，不是可以翻过来看的东西。
3. 自动环绕（`Y`）**不得匀速连续转**：改成档间巡游（每档停 3 s，0.8 s 过渡）。它是最后一个能转出"没人设计过的角度"的通道。

### 4.3 花纹系统（★第 39 轮定案骨架）

**原则**：花纹只出现在**边框内衬与牌背**，绝不进画芯；线宽 = 描边的 40%（§3.1），随环境光偏色。

| 卡类 | 边框花纹 | 语言 |
|---|---|---|
| **物** | **回纹**（方折连续） | 大地、砌筑、器物 |
| **术** | **云水纹**（圆曲流动） | 无形、流动、一闪即逝 |
| **律** | **封印菱纹**（连续菱格 + 符点） | 契约、刻写、不可撤回 |
| **超环**（叠加） | 花纹升级为**缠枝纹** + 金线 | 越界档的华丽度；**金 = 特殊信号**：全卡面（正 + 背）只允许超环正面与超环牌背用金（§4.4，第 45 轮收口） |
| **禁物** | **无花纹 + 撕裂边** | 不属于任何体系的花纹语言 |

**四角角花**：全部卡类统一为「**界印**」（穹顶 + 圆盘的俯瞰微形，与牌背中央同源）。

**常规档内的华丽度梯度（★第 46 轮）**：0–9 环共用本节卡类花纹，**华丽度只随环级（尺度）递进，与卡类正交**；金仍为超环专属（§4.3 金语言收口、§4.4）。

| 环段 | 边框内衬 | 角花 | 一句话 |
|---|---|---|---|
| **0–1** | 卡类花纹的**简化单笔**（单线内衬） | 界印**线稿** | 最素：碎片卡本就轻 |
| **2–4** | 卡类花纹**标准一圈** | 界印 + 微角花 | 基线 |
| **5–7** | 花纹一圈 + **内缘细纹** | 界印 + 完整角花 | 渐繁 |
| **8–9** | **双圈花纹** + 角部繁花 | 界印描边加粗 | 常规顶点（仍无金） |

> 禁物**不参与梯度**（无花纹 + 撕裂边）；超环走缠枝金线，不受本表约束。

### 4.4 牌背（★第 39 轮定案；★第 45 轮修订：三档牌背）

**常规牌背（0–9 环 · 全卡类统一）**（正面色带已区分卡类，背面不重复承担信息）：

- 构成：中央**界印**（穹顶罩 + 圆盘的俯瞰图形，直径 ~30% 卡宽）+ 四角角花 + 赛璐璐纹底（平涂色带 + 细描边，§2）+ 细双框；

- 开包翻面动画的"背面是赛璐璐纹样"（INTERVENTION §6）即此背；
- 牌背随风格主题参数集走（换主题 = 换纹样与底色，构图不变）。

**特殊牌背（★第 45 轮新增：超环 / 禁物各一张，背面即认出档位）**：

| 档位 | 牌背 | 与正面同语言 |

| **超环** | 界印外包**缠枝纹 + 金线**环带 + 日轮微章 | 正面日轮金框的金线同源 |
| **禁物** | **撕裂边 + 无花纹 + 暗纸色**，界印换**裂章** | 正面黑框 / 裂章同源 |

- 特殊包（INTERVENTION §6）中，超环 / 禁物卡**翻面前背面已可见**——特殊牌背本身就是稀有揭晓信号，无需额外特效；

> **核心不变量**：`game/Content/` 的二进制**不入 git**，因此必须能由 **"种子 + 生成器 + 契约 + manifest"** 完整重建（[`../tech/tech.md`](../tech/tech.md) §0）。

### 7.1.1 两条生产线（+ 一条可选）

| 线 | 内容 | 谁做 |
|---|---|---|
| ① **程序化几何** | 生成器产出低模块面：地形、岩石、植物、动物部件、云 | AI（C++） |
| ② **生图线** | 立牌 LOD 贴图 / 卡面 / UI / 地表色带 / 粒子 / 天空渐层与云带 | AI 调度，用户挑图 |
| ③ **可选 3D 生成** | 日后接入本地 3D 生成补多样性；**M0 不依赖** | 后续 |

> **全 3D 没有废掉生图线**：卡面、UI、贴图、云带与天空渐层恰好是动画赛璐璐最需要的东西——2D 产出反而有了更明确的用武之地。

### 7.1.2 动画：零人工资产

- **铰链运动**：动物视为低模关节件，正弦 / 缓动驱动部件旋转（走路、扇翅、低头）。
- **整体摆动**：低频噪声驱动的轻微摇摆（立牌感）。
- **形态变化**：缩放、倾斜、翻转 + 顶点位移（生长、枯萎、翻滚）。
- 结论：**不需要任何人工动画资产**，且"立牌玩具般的动作"正是风格的一部分。

### 7.1.3 资产规模预算（T1 基准）

| 类别 | 数量（M0 → 最终） | 来源 |
|---|---|---|
| 地形色带 | 5 种高度模板 | 程序化 |
| 岩石 / 建筑 / 装饰 | 12 → 40 | 程序化 |
| 植物（3D 主体 + 立牌） | 6 → 30 | 程序化 + 生图 |
| 动物 | 5 → 30 物种（共用几套部件集） | 程序化 |
| **立牌贴图** | 20 → 120 | **生图线** |
| **卡面** | 36 → **≥252**（卡种数；每种可多张，但只出一张卡面） | **生图线** |
| **UI / 图标 / 边框** | 30 → 90 | **生图线** |
| 地表色带 / 粒子贴图 | 20 → 60 套 | 生图线 + 程序化混合 |

> **单主题预算（★第 47 轮）**：风格包 / 主题扩展已否决（CHARTER §5 第 47 轮）——上表即**全量预算**，不再有"×N 主题"乘数。
> **卡面复用（★建议，待定）**：同一功能位在不同级之间**共用画芯**（1 级"降雨"与 5 级"降雨"只换版式标识），可把卡面产出量降到约 **1/3**。

### 7.2 资产登记（manifest）

**位置**：`studio/out/manifest.jsonl`（**该文件必须入库**；同目录的其他产物不入库）。

**逐张一行**，字段：

| 字段 | 含义 | 必填 |
|---|---|---|
| `id` | 资产 id（如 `card.water.3.rite.rain`、`tex.paper.grain`） | ✅ |
| `file` | 产物相对路径（`out/cards/...`） | ✅ |
| `kind` | `card` / `cutout` / `texture` / `fx` / `bg` / `ui` | ✅ |
| `style` | 所属风格主题（当前**恒为** `T1`；主题扩展已否决） | ✅ |
| `model` | 模型文件名与版本（如 `flux-2-klein-4b-fp8`） | ✅ |
| `prompt_ref` | prompt 的引用键（不放全文，放 `jobs/` 里的条目 id） | ✅ |
| `seed` | 随机种子 | ✅ |
| `size` | 像素尺寸 | ✅ |
| `date` | 生成日期（YYYY-MM-DD） | ✅ |
| `source` | `generated` / `procedural` / `cc0` | ✅ |
| `pick` | 是否被用户选中（`yes`/`no`/空） | 建议 |
| `note` | 备注（返工原因等） | 可选 |

**为什么强制**：① **Steam AI 内容披露**需要逐张可追溯；② 两台机器靠它确认"产物身份"；③ 缺 manifest 的素材视为**不可复现**，**不得进游戏**（[`../tech/tech.md`](../tech/tech.md) §9）。

### 7.3 生图批次规范

**环境**：本机 ComfyUI 便携版 `D:\ComfyUI`，服务 `http://127.0.0.1:8188`（探针 `/system_stats`）；模型与实测参数见 [`../ops/ENVIRONMENT.md`](../../tools/docs/ENVIRONMENT.md) §2。

**采样基线**：`steps=4` · `cfg=1.0` · `sampler=euler` · `Flux2Scheduler`。
> ⚠ **CFG=1 时负向串不参与采样**（走 zero-out），**仅作 manifest 留档**——真正的负向控制靠正向串的精确用词 + 后期挑图。

**批次一致性四条**：

1. 每批以**风格锚图**为参照；同批固定正向风格前缀与色板用词。
2. 同元素 / 同季节**固定基底 seed**，只变主体描述。
3. **色板 hex 与用词必须与 [`art.md`](art.md) 同源**——要加新色 / 新词，先回写 art.md 再落 prompt。
4. 逐张写入 manifest（§7.2）。

**候选风格串**（迁移自旧稿，**尚未随新形态定标**，定标前不作为硬约束）：

```text
high silhouette readability, screen-print paper grain overlay, limited seasonal palette,
clean lineart, single centered subject, solid chroma background, crisp edges, no soft gradient
```
