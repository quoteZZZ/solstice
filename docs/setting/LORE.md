# 世界叙事与文案（LORE）

## 0 本文件管什么 / 不管什么

- **管**：**世界怎么说、叫什么、怎么记事**——七原质的术语表与用词约定、**已留档但不运行的设定**（相合 / 异质）、叙事设计原则、**术语与命名规范（中英对照 + 代码 id 前缀）**、文案与本地化规范、叙事承载方式、与归档稿的迁移说明、已关闭的待裁决。
- **不管**：世界的形态、尺度、地块模型、环境曲线、生成流程 → [`WORLD.md`](WORLD.md)（**施工只读那一份**）；卡片设计 → [`cards.md`](cards.md)；美术配方 → [`../art/art.md`](../art/art.md)。
- **为什么单独一份**：本文 **M0 施工不需要读**。它只在两件事上被用到——**写 / 改任何玩家可见的文案**（卡名、卡面描述、本地化、创世文案），以及**给新概念定名**。把它从 `WORLD.md` 里拆出来，是为了让"世界怎么跑"那份只有 400 行、且不会因为改一句文案而变动。
- **来源**：原 `WORLD.md` 的 §1.3–1.6 / §5–§9 / §11，2026-10-17 拆档迁入。

## 1 术语与用词

### 1.1 术语表（核心只有一个：原质）

| 名 | 是什么 | 数量 | 状态 |
|---|---|---|---|
| **原质** | 世界的**基本材料** | **7** | **核心**，固定不可增删 |
| ~~原性~~ | ~~原质的作用倾向~~ | —— | **已删除，不再存在** |
| ~~异质 / 异性~~ | ~~原质合成出的质与其性~~ | —— | **撤出核心，留档待扩展**（§2.2） |

> **元素 vs 级（两个正交维度）**：**元素**是世界的材料（7 种）；**级（环级）**是改动的**尺度**（0 – 9 · 超环 · 禁物，[`WORLD.md`](WORLD.md) §1.3）。**任何元素都覆盖全部级**；**元素间**走生克，**级之间**只讲尺度覆盖。
>
> **★层次澄清（2026-10-15 第 37 轮）**：原质是**世界观叙事语言**（"世界由七原质构成"是设定层的表述）；**模拟层不存在元素实体**——世界按物理量运行（第一原则见 [`PHYSICS.md`](../later/PHYSICS.md) §0）。卡上的元素标签是把玩家意图翻译成物理量的**语义层**。

## 2 留档：相合与异质（**不运行**）

> 这一节是**已撤出核心**的设定，保留只作素材池（禁物与生图的命名来源）。**不要按它写代码。**

### 2.1 相合（留档，暂不运行）

**两条原质**相合会生成"第三种质"——**这套产物归类（曾叫"新质"，后叫"异质"）已整体撤出核心**，**世界目前按"七原质"运行**。

### 2.2 异质 · 异性（留档）

**当前决定**：**不做进本作**——理由是这套设定没立住。

| 曾试过的方案 | 结果 |
|---|---|
| **方案 A**：七异质 **引 / 斥 / 熵 / 谐 / 相 / 虚 / 时**（挂引力 / 斥力 / 热力学第二定律 / 共振 / 相变 / 真空 / 时间），各配三条原质配方 | **作废** |
| **方案 B**：异质 = **两条或多条原质合成**、自带**异性**；两条这一层沿用 §1.5 的 21 项 | **作废** |
| **保留的结论**：若日后重启，**"两条原质相合"是异质的入口层** | 待扩展时再议 |

> **重启时机**：**开发完成之后**再作为**扩展内容**考虑（与"多界 / 演化 / 导入导出"同级，见 [`../plan/ROADMAP.md`](../plan/ROADMAP.md) §1）。
> **风 / 雷 / 霜 不是元素**：它们降为**「现象」**——原质在世界里的表现，归入卡的「大气与气候」与「天气」两类；**光** 已升为原质；**虚 / 时** 一并留档。
> **禁物（[`WORLD.md`](WORLD.md) §1.4）不受影响**：那是**从界外漏进界里的碎片**，与"合成出来的异质"是两回事。

## 3 叙事设计原则

| 原则 | 说明 |
|---|---|
| **不写小说** | 所有叙事可拆成 ≤3 句一屏的短句，或一幅插画级画面 |
| **不解释机制** | 世界观不承担教学功能；教学由 UI、卡面图示与世界反馈承担 |
| **世界自己讲** | 主叙事载体是**世界本身的状态变化**与**年表**（§4） |
| **真相靠拼接** | 不提供设定百科；玩家从年表、禁物代价、物种行为里自行拼出"界 / 界外 / 岸" |
| **原创零借名** | 不得出现任何现有作品的专有名词、角色、术语；命名一律取平实 |
| **可留白** | 允许"没有解释"——界不是谁造的，它本来就浮在那里 |

### 4.2 命名禁忌

1. 不用现有作品的专有名词（含音译变体）。
2. 不造生僻字与自造字；优先用能一眼读懂的汉语词。
3. 同一事物不出现两个名字（旧名一律作废，见 [`../charter/CHARTER.md`](../charter/CHARTER.md)）。
4. 代码 id 用英文小写 + 连字符；**不要拼音**。

## 5 文案与本地化规范

| 项 | 规则 |
|---|---|
| 语言 | **默认中英双语**；缺语言时先 `en` 兜底再 `zh` |
| 存储形态 | 文案以 `{"zh":"…","en":"…"}` 成对出现 |
| 单条长度 | 中文 **≤ 40 字**、英文 **≤ 90 字符**，**最多两行**，超出必须拆条 |
| 语气 | **克制、陈述**；禁咆哮式文案、禁"邪恶"词汇；禁元词（"玩家""点击""镜头"） |
| 禁止 | 长块旁白、一次交代两个以上新设定、直接报出机制数值 |
| 英文 | **口语本地化，非直译**；术语按 §6.1 的英文列统一 |
| 卡面 | 画芯**不含文字**（名称 / 数值 / 徽记由 UMG 绘制，见 [`../art/art.md`](../art/art.md) §4） |
