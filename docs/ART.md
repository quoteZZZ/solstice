# 画面与资产（ART）

> **口径一句话**：画面应该像**一帧手绘动画的定格**，不是一盒纸做的模型。
> 分带靠色阶硬切，立体靠描边与明暗面，微缩靠移轴。**纸质感（纸纹 / 纸厚 / 纸纤维 / 撕裂边）一律禁止**。
> 本文件是画面与资产的唯一真源；管线的开关与性能见 [TECH.md](TECH.md) §6。

---

## 1 三条色彩法则

### 1.1 明度阶梯：要档，不要连续

| 档 | L\* | 用途 |
|---|---|---|
| 高光 | 85–95 | 只给水 / 金属 / 湿石 |
| 亮部 | 65–80 | 受光面 |
| 中间调 | 40–55 | 过渡 |
| 暗部 | 20–35 | 背光面 |

相邻档 `ΔL* < 12` → 读不出受光/背光，只觉得脏；`> 35` → 断层，像贴纸。同族色之间保证 `ΔL* ≥ 15`。

### 1.2 冷暖对位：由时段决定

| 时段 | 光 | 影 |
|---|---|---|
| 日间 / 黄金时刻 | 暖（奶油黄、金） | **冷（蓝紫偏移）**——不能用黑色代替 |
| 阴天 / 黎明 / 月光 | 冷（青灰、银蓝） | 暖（暗褐、紫） |

阴影色相应落在主光色相的**补色侧 30–60°**，不是把亮度乘 0.7。

### 1.3 饱和度预算 60-30-10

| 面积 | 角色 | S |
|---|---|---|
| 60% | 天、海、草 | 20–45% |
| 30% | 沙、岩、植被 | 40–60% |
| 10% | 太阳、泡沫、花 | 70–90% |

**高饱和超过 15% 面积 = 糖水。**

## 3 着色配方

| 项 | 做法 | 参数 |
|---|---|---|
| 主体 | **三段硬切**（亮 / 中 / 暗），段内允许 ±2% 微渐变防塑料感 | 分段点 `0.24 / 0.52`，见 `SolsticeCelMaterial.cpp` 顶部 |
| **分带位置** | **三档切在 `Emissive` 里，不在 `BaseColor` 里** | `Emissive = albedo × lerp(暗段×0.80, 亮段×1.05, hi) × CelFill` |
| 暗部 | 抬亮 + 偏冷，不用 AO 压黑 | 明度 ×0.55、色相 −12°；暗段 ≥ 亮段 45% |
| 高光 | 第 4 段，只给水 / 金属 / 湿石 | 阈值 0.86，`#F2F7FF` |
| 描边 | **Inverted Hull**（反法线外扩），宽度随距离反比 | 近 2 px / 中 1.5 / 远 1 px；不描天空与云 |
| 描边色 | 本体明度的 22% 同族色（白天深褐绿 / 黄昏紫红 / 夜深蓝） | — |
| 微缩感 | 移轴 / 浅景深（上下各 12–18% 模糊带）+ 轻度暗角；**只在 Z0–Z1 生效**，Z2 减半、Z3 起为 0 | — |

> **为什么分带必须在自发光**（2026-10-19 实测）：这个世界只有一盏方向光和一盏天光，在手动曝光下它们对地表的贡献接近零——实测太阳 ×1/×3/×20、关阴影、天光 ×2.6，岛的**中位线性亮度恒为 0.045**。`BaseColor = albedo × 三档` 被乘了零，三档在画面上完全不存在。灯从此只负责阴影贴图与天光捕获。
> **贴图必须写 sRGB 编码后的字节**（`tools/art/gen-textures.py::save()` 已处理），运行时 `LoadPng` 一律 `SRGB = true`。写线性值等于多解一次 gamma（草地 0.58 → 0.30）。

## 4 天空

- **形态**：相机子挂的**单位球**，缩放 = `SkyDistance`；几何由 `Gen::BuildSkyDome()` 生成。**不是平面卡片**（卡片有边，任何调参消不掉它的下沿）。
- **逐像素**：`M_Sky` 的 Custom 节点算渐变 / 日 / 月 / 云。不用引擎默认 Sky Atmosphere（它出不来"地平线近白 + 手绘云带"）。
- **三层渐层**：天顶（最深）→ 中层（占 55–70%）→ 地平线（**近白**）。近白地平线是"看起来像动画"的第一要素。
- **两层云**：卷云（细长、横向、半透明 ~60%）+ 积云（顶平底圆、不透明纯白 + 底面色）。**平面分层，不用体积云。**
- **动态**：整层低频平移 0.5–2°/s；阴天靠云覆盖率，不靠压暗天空。云用软分母投影 `d.xy/(h+0.30)`，采样前加低频域扭曲（否则格点边界变成折线，"折纸感"）。
- **天体**：太阳 = 圆盘 + 两圈淡晕；月 = 圆盘 + 相位遮罩；星 = 点精灵。位置由纬度 + 季节 + 时刻算，不要写死。
- **雾**：三层半透明平面（近浓远淡），不用体积雾；起雾距离按世界半径归一。

## 5 地形、水、植被

| 项 | 做法 |
|---|---|
| 地形 | 平涂色块 + 色带分界 + 坡面明暗。**不做纸层叠、不做厚度断面** |
| 色带 | 每个生态域 2–3 档同族色，按高度/坡度**硬边**切换；坡度只在**同族内**取暗档，不直跳岩石灰（否则整界变石堆） |
| 水面 | 单层水面（`M_Sea`）：平涂水色三档（浅滩/中层/深水）+ 四层方向波法线 + 浪尖白沫 + 岸线亮边。**全世界只有一个水面**——tile 水面不发射，否则两套色彩模型在岸线打架 |
| 植被 | 树 = 低模几何 + Cel 着色（不用立牌）；草 = 成片整体波动，周期 2–4 s |
| **无水界** | `water_cover = 0` 时**不发射水面**，边界走雾墙 / 冰盖 / 图纸硬切；不许为了"好看"硬加一片海（WORLD §2.3） |
| **水世界** | 一整屏水靠三层破面：波纹高光、礁冠白边、云影移动；纯色水在 WORLD §2.4 第 6 条直接判死 |
| 世界外缘 | 按 WORLD §2.3 六种交代：**海沉 / 雾吞 / 云涌 / 暗收 / 冰封 / 图纸硬切 + 暗角**；不许凭空没了，也不做纸厚断面 |

**必须避开的三个坑**（都实测踩过）：
1. **绕序**：外海网格绕序反了会被背面剔除，只剩天空透出来；单面材质才正确。
2. **双面材质会翻转背面法线** → Fresnel 恒为 1 → 整片海永远 75% 天空色。
3. **雾把天空洗白**：指数雾在 400 km 穹顶上完全饱和，`ClearFogDepth` 要压到 0.06 量级。

## 6 昼夜与天气

| 项 | 白天 | 黄昏 | 夜 |
|---|---|---|---|
| 天空三段 | 天顶蓝 / 地平线近白 | 天顶紫 / 中橙 / 地平线金 | 天顶深蓝 / 地平线暗青 |
| 主光色温 | 5600 K | 2400 K | 9000 K（月光） |
| 描边色 | 深褐绿 | 深紫红 | 深蓝 |
| 云 | 纯白 + 底面色 | 顶金 + 底紫 | 半透 + 月光镶边 |

| 天气 | 表现（全部是"画上去的"） |
|---|---|
| 雨 | 斜向细线段 + 水面涟漪环 + 地面降饱和 10% |
| 雪 | 白色扁片 + 地表覆白（LUT 亮段上移） |
| 雾 | 三层半透明平面 |

| 时段 | saturation | midpoint | headroom |
|---|---|---|---|

## 7 取景与机位

**默认三件套：俯仰 `30°` · 方位 `0` · 视野宽 `0.30 W`（Z2）。开局第一帧就是它。**

**角度离散（32 格点），距离连续**；缩放级定义见 [WORLD.md](WORLD.md) §1.2。

| 轴 | 档数 | 值 | 键 |
|---|---|---|---|
| 俯仰 | 4 | 侧视 **15°** / **默认 30°** / 俯瞰 **55°** / 图纸 **88°** | `V` 循环，`F1`–`F4` 直跳 |
| 方位 | 8 | 45° 步进（−45° 为 0 档） | `[` `]` |
| 缩放 | 连续 | Z0 `1.00 W` → Z1 `0.55` → Z2 `0.30` → Z3 `0.12` → Z4 `0.04` | 滚轮推拉；`Z` / `Shift+Z` 直跳 |

### 7.1 为什么默认是 30°（2.5D 的读法，3D 的实现）

要让"3D 读起来像 2.5D 沙盘"，靠三条，缺一条就散：

1. **固定斜俯视 30°**——不是顶视（看不到侧面），也不是平视（地形互相遮挡、看不出高差）。
2. **长焦压缩**：等效焦距 ≥ 85 mm（或正交投影），远近物体大小接近，像等距插画。
3. **地平线永远留在画内**：天空占画面 1/4–1/3；没有地平的画面"像一张盘子"。

同时它仍然是 3D：8 方位离散旋转、连续推拉、88° 图纸档看地图、山体有真实遮挡与光影方向。

> **8° 旧档的教训**：垂直视场 29.4° 时，俯仰大于 14.7° 地平线就出画。所以 15° 是"能看见地平线"的下限，再低就只剩天空与海。

| 界 | 值 | 理由 |
|---|---|---|
| 最远 | 视野宽 `1.00 W`（Z0，**仅 55° / 88° 成立**） | 整界进画、边缘有交代；低角度下 Z0 会露空、被雾吞 |
| 最近 | 视野宽 `0.04 W`（Z4） | 走近看苔与露水；人高 `0.0065 W` 在 Z3 已是 40 px |
| 相机距离 | `视野宽 ÷ (2 · tan(半垂直 FOV / 2))` | **只由视野宽与 FOV 决定，不写绝对米数**——换尺寸档不换观感 |

**视角 × 缩放可用矩阵**（✅ 成立 / ⚠️ 只在高层俯角成立）：

| 俯仰 | Z0 | Z1 | Z2 | Z3 | Z4 |
|---|---|---|---|---|---|
| 15° 侧视 | ⚠️ | ✅ | ✅ | ✅ | ✅ |
| 30° 默认 | ⚠️ | ✅ | ✅ | ✅ | ✅ |
| 55° 俯瞰 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 88° 图纸 | ✅ | ✅ | ✅ | ✅ | ✅ |

> **待核（G-22）**：旧稿写"FOV 38° → `Fit = 5.63 R`"，但同一公式算得 `1.09R / tan(19°) = 3.17R`，两者对不上。以 `ASolsticeObserver` 的实际 FOV 为准实测一次，改完回填本表。

**三条禁路**：① 中键只推拉，不环绕；② 俯仰不越 88°、不低于 **15°**；③ 自动环绕**不匀速连续**（档间巡游，每档停 3 s）。

> 为什么禁：自由旋转把验收口径从"32 格点必须成立"放大成"任意角度必须成立"，而实测缺陷几乎全部是在没人设计过的角度露出来的。**验收态必须离散**；观赏态是否放开见 CHARTER D-3。

### 7.2 投影（正交 vs 长焦）

**已裁决（2026-10-20）：参考饥荒，用透视长焦，不做正交。**

| 方案 | 读感 | 代价 | 状态 |
|---|---|---|---|
| **长焦压缩**（FOV 24–30°，等效 60–85 mm） | 接近 2.5D：远近同大、遮挡可控，但仍有一点透视 | 需重新标定雾与远景 | ✅ **采用** |
| 正交投影 | 最像等距插画 | **雾、SSGI、反射都要重算**；UI 拾取与描边宽度要重映射 | ❌ 移 [LATER.md](LATER.md) |

**从饥荒抄的四件事**（只抄这四件，不抄美术）：

1. **固定斜俯视**：俯角 ~30°，不鼓励玩家长期停在 15°（遮挡多）。
2. **平透视**：长焦压缩让远近物体大小接近，读起来像等距插画。
3. **8 向旋转**（45° 步进），而不是 4 向 90°——45° 步进能避开"正面糊成一片"。
4. **地平线常驻**：天空占 1/4–1/3，地形的轮廓线永远在画内。

> 正交不是"换个相机参数"：`M_Sea` 的逐像素天空反射与指数雾都按透视距离写的，正交下会整片错。
> 所以 M0 用长焦，正交只在真的需要"完全等距"时才做（解冻条件写在 LATER）。

### 7.3 Z 级 → 表现联动（一张表，避免"推近了还是远景的调子"）

| 表现项 | Z0 全界 | Z1 区域 | Z2 生活圈 | Z3 个体 | Z4 微观 |
|---|---|---|---|---|---|
| 移轴 / 景深强度 | 100 % | 100 % | 50 % | 0 | 0 |
| 暗角 | 100 % | 80 % | 40 % | 0 | 0 |
| 描边宽度 | 1 px | 1.5 px | 2 px | 2 px | 2 px |
| 雾密度 | 基准 | ×0.8 | ×0.4 | ×0.1 | 0 |
| 云层细节 | 卷云 + 积云 | 同 | 积云为主 | 无（云在头顶之外） | 无 |
| 水面 | 三档水色 + 波纹 | 同 | 泡沫 + 涟漪 | 涟漪 + 湿边 | 露水 / 水面张力 |
| 阴影 | 生成期烘焙 | 烘焙 | 烘焙 + 接触暗部 | 接触暗部 | 无 |
| 允许的 LOD | 低模 | 低模 | 中模 | 高模（树冠 / 兽） | 最高（苔 / 昆虫） |

> **判据**：任何一级推近后，画面必须**换一套调子**而不是把远景放大。这一条属于 §2.4 的"三级成立"的补充，写死在走查清单里。

> **卡面说明条**（2026-10-20 定，取代"UI 不排任何效果文本"）：效果文本框在**实体卡 / 图鉴大图**里放**完整效果**；游戏内手牌卡只放**一行说明条（≤24 字）**——写这张卡才有的特定信息与效果要点，参照游戏王卡下框。完整裁定归图鉴（[TECH.md](TECH.md) §6.1.1）。卡面仍然不许出现操作提示（"拖到地面"之类），那些只出现在设置 → 键位。
>
> **画芯是占位**：M0 阶段 UI 卡面用"七元素几何纹样"占位（金菱 / 木叶 / 水波 / 火苗 / 土丘 / 光星 / 暗月），等 §8 的 231 张插画产出后同一画框直接替换，不改布局。

**卡面版式**（按 2048 × 2986 写，UI 按比例缩）：顶区 元素章 Ø120 + 卡名横额（≤640 宽）+ 环级 Ø120，高 **300**；画芯 **1696 × 1900**；效果文本框 高 **560**（中 ≤40 字 / 英 ≤90 字符）+ 回收价值；底缘 12 px 卡类色带（物灰石 / 术靛蓝 / 律赭红）；边框花纹按卡类（物回纹 / 术云水纹 / 律封印菱纹），**花纹不进画芯**。

### 8.4 卡面风格矩阵（231 套 = 7 × 11 × 3）

风格**不画 231 张**，而是三维叠加：**21 个插画母版（元素 × 类）× 11 层环级装饰 × 21 种卡背**。

**元素维度**（决定色相与底纹）

| 元素 | 主色 | 底纹 | 质感 | 象征 |
|---|---|---|---|---|
| 金 | `#C8A94B` | 直线、棱面、铸痕 | 拉丝铜 | 六边棱、钥匙 |
| 木 | `#4F7A3A` | 年轮、藤蔓、分叉 | 哑光木 | 枝、芽、环 |
| 水 | `#1F5C7A` | 波纹、流线、滴落 | 湿玻璃 | 滴、涡、月相 |
| 火 | `#B4432E` | 焰舌、放射、裂隙 | 炽铁 | 三角焰、日轮 |
| 土 | `#8A6A45` | 等高线、层理、碎块 | 粗陶 | 方、山、层 |
| 光 | `#E8DCC0` | 光芒、星芒、羽状 | 镜金 | 圆盘、眼、十字 |
| 暗 | `#2A2340` | 烟、蚀刻、虚空 | 黑曜石 | 空环、缺口、瞳 |

**环级维度**（决定装饰层级，环级即稀有度）

| 环级 | 名称 | 边框 | 光效 | 卡背印章 |
|---|---|---|---|---|
| 0 | 碎卡 | 缺角、石片裂口、边缘毛刺 | 无 | 破碎环 |
| 1–3 | 凡 | 单线细框 | 哑光 | 小环 |
| 4–6 | 稀有 | 双线 + 元素纹章 | 局部高光 | 双环 |
| 7–8 | 史诗 | 浮雕外框 + 宝石位 | 边缘流光 | 三环 + 刻字 |
| 9 | 闪卡 | 全息框 + 烫金签名 | 整卡扫光（UV 流动） | 星芒环 |
| 超环 | 星轨 | 外框溢出画幅、轨道弧线 | 粒子环绕 + 呼吸 | 星轨盘 |
| 禁物 | 裂界 | 无框、不规则撕裂（**非纸质**） | 吸光、背景变暗 | 无印章，只有裂痕 |

**类别维度**（决定构图语言）

| 类 | 构图 | 画芯倾向 | 底缘色带 |
|---|---|---|---|
| 物 | 静态实体、正面陈列 | 居中，投影压底 | 灰石 |
| 术 | 动势、能量线、方向明确 | 偏一侧，留运动轨迹 | 靛蓝 |

**卡背**（21 种）：元素主色压暗 40% + 中央象征 + 类差异（物实心 / 术残影 / 律封印环）+ 右下环级印章。

**红线**：不得出现纸质感。碎卡毛边是**石片与金属缺口**，开包的“撕”是**封印崩解**。

### 8.5 背景质感 = 元素（色）× 类别（线）× 环（密度）

**问题**：之前背景只有一条固定的 45° 斜纹——231 张卡同一层皮，元素、类别、环级都不参与质感。

**公式**：`质感 = f(元素 RGB, 类别线条, 环密度)`，三个参数**各管一件事，互不越界**。

| 参数 | 只控制 | 不控制 |
|---|---|---|
| 元素 | **RGB**：纹样颜色 + 顶部与底部两道元素光（20 % / 10 %） | 线条形状、密度 |
| 类别 | **线条语言**：物 = 48° 直线 / 术 = 同心弧 / 律 = 45° × 2 菱格 | 颜色、密度 |
| 环 | **密度与亮度**：纹样单元、不透明度、外光强度 | 颜色、线条形状 |

**环的 12 档**（0–9 + 超环 + 禁物）：

| 环 | 纹样单元 | 不透明度 | 外光 | 读感 |
|---|---|---|---|---|
| 0 | 22 px | .045 | 0 | 素面 |
| 1 | 19 px | .055 | 0 | 几乎无纹 |
| 2 | 18 px | .060 | .08 | 微纹 |
| 3 | 16 px | .070 | .16 | 可见 |
| 4 | 15 px | .080 | .24 | 可见 |
| 5 | 13 px | .090 | .32 | 明显 |
| 6 | 12 px | .100 | .42 | 明显 |
| 7 | 10 px | .115 | .55 | 细密 |
| 8 | 9 px | .130 | .70 | 细密 |
| 9 | 8 px | .145 | .85 | 满纹 |
| 超环 | 7 px | .160 | 1.0 | 满纹 + 描金 |
| 禁物 | 9 px | .140 | 1.0 | 满纹 + 红 |

**元素 RGB**（纹样与光晕共用一组，避免两处色偏）：

| 金 | 木 | 水 | 火 | 土 | 光 | 暗 |
|---|---|---|---|---|---|---|
| `200,169,75` | `94,143,71` | `63,143,171` | `180,67,46` | `138,106,69` | `224,214,184` | `106,90,138` |

**实现**：三层背景叠加——上层元素径向光（`rgba(var(--el),.20)`）、中层纹样（`background-image: var(--pat)` + `background-size: var(--d)`，`mix-blend-mode: screen`）、底层金属渐变。切卡只换三个类：`elwater` + `matter` + `t5`。

> **为什么不让元素也改线条**：元素是"什么世界"，类别是"怎么作用"，环是"多强"。三条轴一旦互相串（比如火卡用焰纹、水卡用波纹），231 张就会变成 231 套手绘，无法批量产出，也无法一眼比对。

## 10 创世剖面（全游戏唯一的"示意图"）

创世界面里那张剖面是**唯一的非 3D 画面**，所以它有单独的规矩：

| 项 | 规矩 |
|---|---|
| 视角 | 正面剖面（正交），不做透视，不做等距 |
| 分层 | 天空 / 表层土 / 土壤 / 岩层 / 基岩 **五层**，用硬边分界（不做渐变糊） |
| 岩层 | 45° 斜纹 hatch（`#000` 16% 透明），一眼区别于土层 |
| 地貌 | 双峰 + **雪冠**、河谷、林带（小三角树）；雪线位置由气候带决定 |
| 地下 | 地下水虚线水位 + 一块透镜状含水层 + 2–3 处洞穴 + 1–2 簇矿脉 |
| 标注 | 8–12 条引线标注，字号 10，颜色 `#7e8a9a`；水源类用 `#5f9fc0`，矿用 `#c79a54` |
| 随形制变 | 见 [WORLD.md](WORLD.md) §4.2 的十种剖面（群岛＝三块分开、全海＝无陆地、环礁＝两侧礁台 + 潟湖…） |
| 随特征变 | 见同表：火山 → 锥 + 熔岩脉；双月 → 两个月；古树 → 巨木；浮空 → 悬空陆 |
| 动效 | 重掷：0.5 s 尘扫 + 0.6 s 溶解重组（`blur 9→0`）；进界：剖面淡出、3D 自雾中升起、HUD 依次进入（0.9 s） |
| 禁止 | 写实光影、体积云、渐变色带、"示意图里出现 UI 卡片" |

> 卡图暂缓期：UI 用 `glyph`（`元素-动词`）+ 元素色 + 环级框渲染，靠规则而非贴图区分 231 格。
