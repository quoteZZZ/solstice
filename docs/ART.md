# 画面与资产（ART）

> **口径一句话**：画面应该像**一帧手绘动画的定格**，不是一盒纸做的模型。
> 分带靠色阶硬切，立体靠描边与明暗面，微缩靠移轴。**纸质感（纸纹 / 纸厚 / 纸纤维 / 撕裂边）一律禁止**。
> 本文件是画面与资产的唯一真源；管线的开关与性能见 [TECH.md](TECH.md) §6。

---

## 1 三条色彩法则

### 1.1 明度阶梯：要档，不要连续

| 档 | L\* | 用途 |
|---|---|---|
| 高光 | 85–95 | 只给水 / 金属 / 湿石 |
| 亮部 | 65–80 | 受光面 |
| 中间调 | 40–55 | 过渡 |
| 暗部 | 20–35 | 背光面 |

相邻档 `ΔL* < 12` → 读不出受光/背光，只觉得脏；`> 35` → 断层，像贴纸。同族色之间保证 `ΔL* ≥ 15`。

### 1.2 冷暖对位：由时段决定

| 时段 | 光 | 影 |
|---|---|---|
| 日间 / 黄金时刻 | 暖（奶油黄、金） | **冷（蓝紫偏移）**——不能用黑色代替 |
| 阴天 / 黎明 / 月光 | 冷（青灰、银蓝） | 暖（暗褐、紫） |

阴影色相应落在主光色相的**补色侧 30–60°**，不是把亮度乘 0.7。

### 1.3 饱和度预算 60-30-10

| 面积 | 角色 | S |
|---|---|---|
| 60% | 天、海、草 | 20–45% |
| 30% | 沙、岩、植被 | 40–60% |
| 10% | 太阳、泡沫、花 | 70–90% |

**高饱和超过 15% 面积 = 糖水。**

## 3 着色配方

| 项 | 做法 | 参数 |
|---|---|---|
| 主体 | **三段硬切**（亮 / 中 / 暗），段内允许 ±2% 微渐变防塑料感 | 分段点 `0.24 / 0.52`，见 `SolsticeCelMaterial.cpp` 顶部 |
| **分带位置** | **三档切在 `Emissive` 里，不在 `BaseColor` 里** | `Emissive = albedo × lerp(暗段×0.80, 亮段×1.05, hi) × CelFill` |
| 暗部 | 抬亮 + 偏冷，不用 AO 压黑 | 明度 ×0.55、色相 −12°；暗段 ≥ 亮段 45% |
| 高光 | 第 4 段，只给水 / 金属 / 湿石 | 阈值 0.86，`#F2F7FF` |
| 描边 | **Inverted Hull**（反法线外扩），宽度随距离反比 | 近 2 px / 中 1.5 / 远 1 px；不描天空与云 |
| 描边色 | 本体明度的 22% 同族色（白天深褐绿 / 黄昏紫红 / 夜深蓝） | — |
| 微缩感 | 移轴 / 浅景深（上下各 12–18% 模糊带）+ 轻度暗角 | — |

> **为什么分带必须在自发光**（2026-10-19 实测）：这个世界只有一盏方向光和一盏天光，在手动曝光下它们对地表的贡献接近零——实测太阳 ×1/×3/×20、关阴影、天光 ×2.6，岛的**中位线性亮度恒为 0.045**。`BaseColor = albedo × 三档` 被乘了零，三档在画面上完全不存在。灯从此只负责阴影贴图与天光捕获。
> **贴图必须写 sRGB 编码后的字节**（`tools/art/gen-textures.py::save()` 已处理），运行时 `LoadPng` 一律 `SRGB = true`。写线性值等于多解一次 gamma（草地 0.58 → 0.30）。

## 4 天空

- **形态**：相机子挂的**单位球**，缩放 = `SkyDistance`；几何由 `Gen::BuildSkyDome()` 生成。**不是平面卡片**（卡片有边，任何调参消不掉它的下沿）。
- **逐像素**：`M_Sky` 的 Custom 节点算渐变 / 日 / 月 / 云。不用引擎默认 Sky Atmosphere（它出不来"地平线近白 + 手绘云带"）。
- **三层渐层**：天顶（最深）→ 中层（占 55–70%）→ 地平线（**近白**）。近白地平线是"看起来像动画"的第一要素。
- **两层云**：卷云（细长、横向、半透明 ~60%）+ 积云（顶平底圆、不透明纯白 + 底面色）。**平面分层，不用体积云。**
- **动态**：整层低频平移 0.5–2°/s；阴天靠云覆盖率，不靠压暗天空。云用软分母投影 `d.xy/(h+0.30)`，采样前加低频域扭曲（否则格点边界变成折线，"折纸感"）。
- **天体**：太阳 = 圆盘 + 两圈淡晕；月 = 圆盘 + 相位遮罩；星 = 点精灵。位置由纬度 + 季节 + 时刻算，不要写死。
- **雾**：三层半透明平面（近浓远淡），不用体积雾；起雾距离按世界半径归一。

## 5 地形、水、植被

| 项 | 做法 |
|---|---|
| 地形 | 平涂色块 + 色带分界 + 坡面明暗。**不做纸层叠、不做厚度断面** |
| 色带 | 每个生态域 2–3 档同族色，按高度/坡度**硬边**切换；坡度只在**同族内**取暗档，不直跳岩石灰（否则整界变石堆） |
| 水面 | 单层水面（`M_Sea`）：平涂水色三档（浅滩/中层/深水）+ 四层方向波法线 + 浪尖白沫 + 岸线亮边。**全世界只有一个水面**——tile 水面不发射，否则两套色彩模型在岸线打架 |
| 植被 | 树 = 低模几何 + Cel 着色（不用立牌）；草 = 成片整体波动，周期 2–4 s |
| 世界外缘 | 硬描边 + 下方世界色切断，不做纸厚断面 |

**必须避开的三个坑**（都实测踩过）：
1. **绕序**：外海圆盘绕序反了会被背面剔除，只剩天空透出来；单面材质才正确。
2. **双面材质会翻转背面法线** → Fresnel 恒为 1 → 整片海永远 75% 天空色。
3. **雾把天空洗白**：指数雾在 400 km 穹顶上完全饱和，`ClearFogDepth` 要压到 0.06 量级。

## 6 昼夜与天气

| 项 | 白天 | 黄昏 | 夜 |
|---|---|---|---|
| 天空三段 | 天顶蓝 / 地平线近白 | 天顶紫 / 中橙 / 地平线金 | 天顶深蓝 / 地平线暗青 |
| 主光色温 | 5600 K | 2400 K | 9000 K（月光） |
| 描边色 | 深褐绿 | 深紫红 | 深蓝 |
| 云 | 纯白 + 底面色 | 顶金 + 底紫 | 半透 + 月光镶边 |

| 天气 | 表现（全部是"画上去的"） |
|---|---|
| 雨 | 斜向细线段 + 水面涟漪环 + 地面降饱和 10% |
| 雪 | 白色扁片 + 地表覆白（LUT 亮段上移） |
| 雾 | 三层半透明平面 |
| 雷 | 全屏 1 帧白闪 + 延迟 0.4–1.2 s 的音效 |

**量具分档**（`measure-frame.py --hour day|dusk|night`）——用同一把尺子量黄昏会把诚实的黄昏判成失败：

| 时段 | saturation | midpoint | headroom |
|---|---|---|---|
| day | >0.25 | 0.45–0.60 | <0.10 |
| dusk | >0.25 | 0.33–0.55 | <0.10 |
| night | >0.15 | 0.20–0.42 | <0.10 |

> 这三项是**回归防线**，不是通过判据——它们能防爆掉，不能证明"好看"。真正的验收见 PLAN §2。

## 7 取景与机位

**角度离散（32 格点），距离连续。**

| 轴 | 档数 | 值 | 键 |
|---|---|---|---|
| 俯仰 | 4 | 海岸 **8°** / 标准 **24°** / 高处 **48°** / 图纸 **88°** | `V` 循环，`F1`–`F4` 直跳 |
| 方位 | 8 | 45° 步进（−45° 为 0 档） | `[` `]` |

> **8° 档不是"更低的 14°"，它决定了画面里有没有天空。** 垂直视场 29.4°，俯仰只要小于 ±14.7°，
> 地平线才落在画内；35° 档的顶边在水平线**下方 20°**，整帧都是海——没有地平的画面读起来像
> 一张盘子，没有远近也没有尺度。这是"缺少氛围"的结构性原因，不是调色问题。

| 界 | 值 | 理由 |
|---|---|---|
| 取景距离 `Fit` | `1.09R ÷ tan(半垂直 FOV)`；FOV 38° + 16:9 → **5.63 R** | 让 `2R` 刚好填满垂直视场 |
| 最远 | `1.6 × Fit` | 再远穹顶糊成点，失去"捧得起来"的尺度感 |
| 最近 | **25 m（2500 uu）绝对值** | 一格恒 1 m，能看清苔的距离不随世界变大 |

**三条禁路**：① 中键只推拉，不环绕；② 俯仰不越 88°、不低于 14°；③ 自动环绕**不匀速连续**（档间巡游，每档停 3 s）。

> 为什么禁：自由旋转把验收口径从"32 格点必须成立"放大成"任意角度必须成立"，而实测缺陷几乎全部是在没人设计过的角度露出来的。**验收态必须离散**；观赏态是否放开见 CHARTER D-3。

## 8 资产

### 8.1 规格

| 类 | 规格 |
|---|---|
| 卡面 | **2048 × 2732 px（3:4）**；画芯有效区 1696 × 2186；主体占安全画幅 60–75% |
| 安全区 | 上 192 / 左右 176 / 下 352 px（2048 基准）内不放关键主体 |
| 画芯 | **无文字、无边框、无徽记**——名称/徽记/数值由 UI 统一绘制 |
| 站牌 / 立绘 | 1024 × 1024，纯色 chroma 底（模型无 alpha），生成后抠图 |
| 字体 | 正文 / UI：思源黑体；卡名 / 年表：思源宋体（均可商用） |

**卡面版式**（UI 层，1024 基准）：顶区元素章 Ø88 + 卡名横额（≤420 宽）+ 级环 Ø88；画芯 848 × 890；信息条 = 效果一句话（中 ≤40 字 / 英 ≤90 字符）+ 回收价值；底缘 12 px 卡类色带（物灰石 / 术靛蓝 / 律赭红）；边框花纹按卡类（物回纹 / 术云水纹 / 律封印菱纹），**花纹不进画芯**。

### 8.2 生成登记（manifest）

`studio/out/manifest.jsonl`（**必须入库**，产物不入库），逐张一行：
`id · file · kind · style · model · prompt_ref · seed · size · date · source · pick · note`

**为什么强制**：Steam AI 内容披露要逐张可追溯；缺 manifest 的素材视为不可复现，不得进游戏。

### 8.3 QC（批量挑图逐条打勾）

- Cel 硬边，无软渐变 / 写实反光
- 描边完整、粗细符合 §3
- 缩略图下剪影可辨
- 色彩落在色板范围内
- 无正面人脸特写（面部占画幅 ≤1/5）
- 画芯无文字 / 边框 / 徽记
- 主体落在安全区
- 无多余肢体 / 手指
- **无纸质感**
- 已写入 manifest

## 9 改观感只动这五处

| 要改什么 | 动这里 |
|---|---|
| 色板（地表 / 水 / 植被 / 描边 / 暗部） | `Gen/SolsticeGenerators.h` 的 `FCelPalette`（一律 `CelSrgb()`） |
| 地形与植被几何 | `Gen/SolsticeGenerators.cpp` 的 `BuildChunk` / `BuildLife` |
| 着色分带 / 描边 / 天色 | `Render/SolsticeCelMaterial.cpp` + 编辑器侧 `SolsticeCelMaterialBuilder.cpp`（改完必须升 `RecipeVersion`） |
| 灯光 / 雾 / 天空 | `World/SolsticeRealm.cpp` 顶部调参区 + `BuildSkyMesh` / `UpdateSun` |
| 后期（移轴 / 暗角 / 饱和） | `UPostProcessComponent` 参数（`SolsticeRealm.cpp`） |

**验收**：`tools/run/shot.ps1` 无人值守抓帧（固定机位 + 固定种子），自动跑 `measure-frame.py`；改完表现层再跑 `bench`，digest 必须不变。
