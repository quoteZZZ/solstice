# 立项与口径（CHARTER）

> **本文件是全项目唯一真源（`truth: owner`）**：它只回答**为什么做、做成什么、不做什么、定过什么、还没定什么**。
> 其它文档与本文冲突时以本文为准。**规格细节不在这里**——去 [`../INDEX.md`](../INDEX.md) 找对应域文档。

## 0 定位与第一卖点

**一句话**：一帧**会自己活起来的动画微缩世界**——你可以让它与真实时间同频（天气、昼夜、季节皆真），也可以把时间握在手里；你攒下的「余响」开出的**元素包**决定这次能怎样改写它；而它永远不会输。

**第一卖点「现实的桥」**：现实的时间 / 天气 / 纬度不是"联动"，而是**你站在界外的岸上，看着同一片界外压着这座界**——你那下雨，界里也下雨；**某些存在只在真实的雨天 / 初雪 / 大雾里出现**。

> 完整机制见 [`../gameplay/TIME.md`](../later/TIME.md) §1；世界观见 [`../setting/WORLD.md`](../setting/WORLD.md) §1。

## 3 体验支柱（七条）

1. **它真的在活着**——有因果、会自己漂移的生态。
2. **外面发生什么，里面就发生什么**——现实的桥。
3. **万物可干涉**——卡池从地形到物理法则都能改。
4. **这次能怎么玩**——干涉世界攒下「余响」，开包换回"下一次的命题"：更多卡、更多可用组合。
5. **我的界我做主**——**一键掷骰就是一个新世界**（种子码可抄可复现），想较真再开高级面板锁轴；法则参数随时可改。
6. **没有失败，也不会结束**——世界永续。
7. **打开就好看**——动画赛璐璐的观感即产品。

> **本节是七条支柱的唯一真源。** 每条支柱由哪些机制承担见 §3.1；在五个尺度上重复什么见 §3.2；"无失败"如何落到节奏上见 §3.3。

### 3.2 核心循环（五个尺度）

| 尺度 | 循环 |
|---|---|
| **秒** | 看一眼：光、影、风、草叶摆动、生物在爬 |
| **世界日**（虚拟默认 3 真实分钟） | 一轮昼夜；植被长一截；有进食 / 繁殖 / 死亡 |
| **分钟** | 挑一张卡 → 笔刷施放 → **看后果（世界偏移即产「余响」）** → 攒够开一个元素包 |
| **会话** | 打开 → 观察 → 干涉 / 改法则 → 离开（时间暂停） |
| **真实周** | 真实模式下季节推移 → 世界法则换挡 |

**这条链的设计意图**：

- **秒级**给"它在活着"（无需操作就有回报，适合挂着看）；
- **分钟级**给"我的手在起作用"（干涉 → 世界偏移 → 余响 → 开包 → 更多干涉手段）；
- **会话级**不要求留存（**离线即暂停**，没有补偿推演，也就没有"回来要补作业"的压力）；
- **真实周级**给"外面在变"（现实的桥在长时间尺度上显形）。

### 3.3 "无失败"如何落到节奏上（红线）

- **不设**：战斗、失败、等级 / 属性成长、稀有度、每日任务、签到、广告、成就弹窗（见 §2）。
- **唯一积累物**是「余响」，且**只买选择与审美，不买强度**（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §2）。
- **扰动值升高不是惩罚**：世界进入"剧烈"是**另一种玩法**，不是失败态（[`../gameplay/INTERVENTION.md`](../gameplay/INTERVENTION.md) §3）。
- **个体不可直接控制**（★2026-10-15 定案）：上帝不操控个体——**观察与干涉是仅有的两种关系**；物种行为永远由模拟驱动（防范围爆炸，守"它自己活着"）。
- **打开就好看**是留存手段，不是数值钩子——所以风格主题与观感优先级高于任何进度系统。
