| **竹** | 极快 | 20 | 0.1 | 中空 | **3 年成材，蔓延极快** |
| **橡胶** | 慢 | 200 | 0.6 | 软 | 产胶 |

**这张表本身就是玩法**：

| 场景 | 该种什么 |
|---|---|
| 荒岛第一棵树 | **桦**（快、要求低） |
| 要长期遮荫 | **楠 / 红木**（慢但遮得多） |
| 河边 | **柳**（必须临水） |
| 要木材 | **竹**（3 年就够） |
| 要食物 | **栎 / 无花果**（产果） |

**同样的 22 张"树"卡，玩法完全不同。**这就叫"树有不同的树"。

## 19 神奇（80）

**"神奇"不是现实世界的东西。**它和"自然"是并列的两套素材——一套来自博物学，一套来自奇幻、神话、传说。

# §25 万物谱系（不止物质）

**之前我只做了"能摸到的东西"。但那不是"万物"。**

从最具体到最抽象，一共有六层：

| 层 | 是什么 | 归三类中的 | 张数 |
|---|---|---|---|
| **L1 物质** | 能触摸的东西 | 物 | 540 |
| **L2 现象** | 发生的事 | 术·境 | **60** |
| **L3 状态** | 持续的条件 | 术·境 | **30** |
| **L4 关系** | 两者之间的东西 | 律·局部 | **20** |
| **L5 抽象** | 世界的规则 | 律·全域 | **30** |
| **L6 概念** | 心智的产物 | 术·体 + 律 | **30** |
| | | | **≈ 710** |

**关键：六层不需要新的类。**三类（物/术/律）从 L1 一直覆盖到 L6，只是每层的"作用方式"不同。

## 25.6 六层怎么互相作用

**举一个完整的例子：一场雨**

```
L2 现象：雨          → 全图 W +2
  ↓
L3 状态：潮湿        → 该格蒸发 ×0.5（持续 3 月）
  ↓
L1 物质：草          → 水够了，开始长
  ↓
L1 物质：鹿          → 草多了，鹿繁殖
  ↓
L4 关系：敌对        → 狼把鹿群标为目标
  ↓
L5 抽象：因果        → 雨水引发的一切被记录为"因果链"
  ↓
L6 概念：故事        → 鹿群把这场雨写进歌里
```

**六层不是并列的清单，是一条从"下雨"到"传说"的链。**

## §31 四个设计改进

### 31.1 L2–L6 也有合成输入（否则只能抽，不能造）

**旧问题**：如果上层 170 张都没有输入，它们就是"只能碰运气"的卡。

**改进**：**每一层都有输入，只是料的种类不同**。

| 层 | 输入举例 |
|---|---|
| L2 雨 | 水 + 风 |
| L3 永夜 | 光 + 暗 |
| L4 契约 | 语言 + 信任 |
| L5 加速 | 时间砂 + 星图 |
| L6 文字 | 语言 + 陶罐 |

**于是六层全部进合成树，环级照样按"输入最高 + 1"算。**

### 31.2 关系卡需要「双目标」（三类契约要加一条）

`物` / `术` / `律` 的目标都只有一个。关系卡需要**两个**：

```
Target  两方（各需满足条件）
```

**这是第四种目标形态**，但不需要第四类——它是 `律` 的一个子型（局部律的一种）。

### 31.3 概念卡有前置（唯一有门槛的）

```
前置  认知 ≥ 低 / 中 / 高
```

**石头不会做梦，猴子不会立法。**没有前置，概念卡就等于白送。

### 31.4 抽象卡有同时上限（`律` 必须限流）

| 类型 | 上限 |
|---|---|
| 全域律 | **同时最多 1 张**（时间、因果这类） |
| 局部律 | 每格 1 张 |
| 关系 | 每个实体最多 2 条 |

**为什么**：全域律一张下去世界规则就变了。两张同类的全域律会互相打架（加速 + 减速 = 无解）。
