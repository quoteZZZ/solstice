种子码怎么读

8 位 = 7 位种子 + 1 位校验（Crockford Base32， 去掉了 I / L / O / U，手抄不会混）。校验位由前 7 位算出，抄错任何一位都会被判无效， 而不是悄悄变成另一个世界。

游戏端只要两个函数：rollWorld(seed) 出世界，worldData() 出这份 JSON。渲染代码一行都不用带。

JSON

这是游戏端唯一需要读的东西。顶层键： seed 种子与校验 · world 地形/面积/水系 · ecology 气候与植被带 · resources 树与矿的采样 · dynamics 火的系数与栅格规格 · params 当前滑块值。
